if и else

20 минутЕрофеев А. И.

Научиться выполнять код только при истинном условии, выбирать одну из двух ветвей и задавать границы ветви отступом.

1. Инструкция if

Теория

До сих пор программа выполняла все свои строки по порядку, сверху вниз, при любых данных. На прошлых страницах она уже умела ответить True или False, но только печатала ответ. Теперь ответ начнет управлять тем, какие строки выполнятся.

Инструкция if выполняет блок кода только тогда, когда условие истинно. После слова if пишется условие, в конце строки ставится двоеточие, а строки блока сдвигаются вправо отступом. Если условие ложно, блок пропускается целиком. Строки после блока, записанные без отступа, выполняются в любом случае.

схема
if {{условие}}:
    {{блок: выполняется, если условие истинно}}
{{следующая инструкция: выполняется всегда}}

Условная инструкция — инструкция, которая выполняет блок кода в зависимости от значения условия.

Логическое выражение после if называют условием, а блок, который выполняется при одном из ответов, ветвью. Отсюда и слово «ветвление».

Условием может быть все, что вы писали на страницах 01–03: сравнение, составное условие с and и or, проверка in, переменная с логическим значением, а также вызов метода вроде startswith() из второй практики.

Пример

Предупреждение о короткой последовательности

short_seq.py
seq = "ATGCGTACGTTAG"
if len(seq) < 20:
    print("короткая последовательность")  # → короткая последовательность
print("длина:", len(seq))                 # → длина: 13
Вывод
короткая последовательность
длина: 13
  1. Строка 2: условие 13 < 20 истинно.
  2. Строка 3: строка с отступом входит в блок и выполняется.
  3. Строка 4: строка без отступа стоит после блока и выполняется при любой длине.

Блок пропущен

Та же программа с последовательностью подлиннее. Предскажите вывод.

long_seq.py
seq = "ATGCGTACGTTAGCCATGCAGGTA"
if len(seq) < 20:
    print("короткая последовательность")
print("длина:", len(seq))  # → длина: 24
Вывод
длина: 24

Условие 24 < 20 ложно, строка 3 не выполняется, и программа сразу переходит к строке 4. Сообщения об ошибке нет: пропущенный блок для Python обычное дело.

Типичная ошибка: нет двоеточия

Неверно: SyntaxError
gc = 65
if gc > 60
    print("GC-богатая")
Сообщение об ошибке
  File "colon.py", line 2
    if gc > 60
              ^
SyntaxError: expected ':'
Верно
gc = 65
if gc > 60:
    print("GC-богатая")  # → GC-богатая
Вывод
GC-богатая

Двоеточие сообщает Python, что дальше начинается блок. Сообщение прямо называет пропущенный знак и показывает место, где его ждали.

Типичная ошибка: = вместо == в условии

Неверно: SyntaxError
count = 5
if count = 5:
    print("пять")
Сообщение об ошибке
  File "assign.py", line 2
    if count = 5:
       ^^^^^^^^^
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
Верно
count = 5
if count == 5:
    print("пять")  # → пять
Вывод
пять

После if нужен вопрос «равно ли?», то есть == (страница 01). Знак = присваивает значение, и Python сам подсказывает замену. Запись := из подсказки относится к другой конструкции, в курсе она не встречается.

Практика

Измените последовательность так, чтобы предупреждение не появилось. Затем поменяйте порог 20 на 10.

try_if.py
seq = "GGCATT"
if len(seq) < 20:
    print("короткая последовательность")  # → короткая последовательность
print("длина:", len(seq))                 # → длина: 6
Вывод
короткая последовательность
длина: 6

2. Две ветви: else

Теория

Часто при ложном условии тоже нужно что-то сделать. Строка файла FASTA либо заголовок, либо часть последовательности; раствор либо годен, либо нет. Для такого выбора одного из двух действий к if добавляют вторую ветвь.

Ветвь else выполняется, когда условие ложно. Слово else пишется на одном уровне с if, без условия, с двоеточием, а под ним свой блок с отступом. Из двух ветвей выполняется ровно одна: условие не может быть одновременно истинным и ложным.

схема
if {{условие}}:
    {{ветвь 1: условие истинно}}
else:
    {{ветвь 2: условие ложно}}
Пример

Заголовок или последовательность

Строка-определение FASTA начинается со знака >, за ним идет идентификатор записи. Остальные строки записи содержат нуклеотиды.

fasta_line.py
line = ">Seq1"
if line.startswith(">"):
    print("заголовок")      # → заголовок
    print("ID:", line[1:])  # → ID: Seq1
else:
    print("нуклеотиды")
print("строка обработана")  # → строка обработана
Вывод
заголовок
ID: Seq1
строка обработана
  1. Строка 2: вызов line.startswith(">") дает True, и этот результат служит условием.
  2. Строки 3–4: в ветви if две инструкции, обе выполняются.
  3. Строки 5–6: ветвь else пропущена целиком.
  4. Строка 7: стоит после обеих ветвей и выполняется всегда.

Регистр буквы из ввода

Программа ждет ввода. Пользователь набирает g и нажимает Enter.

case_check.py
base = input()
if base.isupper():
    print("прописная")
else:
    print("строчная, приводим:", base.upper())  # → строчная, приводим: G
Вывод
g
строчная, приводим: G

Метод isupper() (страница 05 второй практики) для строчной буквы дает False, и выполняется ветвь else. Программа печатает ответ в любом случае, но в каждой ветви свой.

Типичная ошибка: условие после else

Неверно: SyntaxError
ph = 8.1
if ph < 7:
    print("кислая")
else ph >= 7:
    print("не кислая")
Сообщение об ошибке
  File "else.py", line 4
    else ph >= 7:
         ^^
SyntaxError: expected ':'
Верно
ph = 8.1
if ph < 7:
    print("кислая")
else:
    print("не кислая")  # → не кислая
Вывод
не кислая

Ветвь else означает «во всех остальных случаях», ее условие уже известно: противоположное условию if. Если вариантов больше двух, нужна цепочка elif со страницы 05.

Практика

Поставьте в line строку нуклеотидов, например "ATGCGT", и предскажите вывод до запуска. Затем добавьте в ветвь else печать длины строки.

try_else.py
line = ">NM_000546"
if line.startswith(">"):
    print("заголовок")  # → заголовок
else:
    print("нуклеотиды")
Вывод
заголовок

3. Блок и отступ

Теория

Во многих языках ветвь заключают в фигурные скобки, а в Python ее границы видны по отступу. Отступ здесь входит в смысл программы: сдвиньте строку влево, и она окажется вне ветви.

Границы блока задает отступ. Все строки блока сдвинуты на одинаковое число пробелов, обычно на четыре; блок кончается на первой строке с прежним отступом. В блоке должна быть хотя бы одна инструкция. Если ветвь нужна, а писать в ней пока нечего, ставят pass: эта инструкция ничего не делает.

Нет отступа после двоеточия или лишний пробел в начале строки дают ошибку IndentationError. Редакторы VS Code и PyCharm сами делают отступ в четыре пробела, когда вы нажимаете Enter после двоеточия; клавиша Tab тоже вставляет четыре пробела. Не смешивайте пробелы с символом табуляции.

Пример

Где кончается блок

Предскажите, какие строки будут напечатаны.

block.py
gc = 35
if gc > 60:
    print("GC-богатая")
    print("проверьте праймеры")
print("анализ завершен")  # → анализ завершен
Вывод
анализ завершен
  1. Строки 3–4 сдвинуты и входят в блок. Условие 35 > 60 ложно, поэтому обе пропущены.
  2. Строка 5: отступа нет, блок закончился, строка выполняется всегда.

Типичная ошибка: нет отступа после двоеточия

Неверно: IndentationError
gc = 65
if gc > 60:
print("GC-богатая")
Сообщение об ошибке
  File "indent.py", line 3
    print("GC-богатая")
    ^
IndentationError: expected an indented block after 'if' statement on line 2
Верно
gc = 65
if gc > 60:
    print("GC-богатая")  # → GC-богатая
Вывод
GC-богатая

Сообщение называет и причину, и строку с if, после которой ждали блок. Обратная ошибка, лишний отступ у строки, которая не начинает блок, дает IndentationError: unexpected indent.

Пустая ветвь

pass_branch.py
reads = 0
if reads > 0:
    pass
else:
    print("прочтений нет")  # → прочтений нет
Вывод
прочтений нет

Обработку прочтений еще не написали, а ветвь уже нужна: pass занимает место блока, и программа запускается. В готовой программе такую ветвь обычно убирают, переворачивая условие: if reads == 0:.

Сдвиньте последнюю строку вправо на четыре пробела, чтобы она вошла в блок, и запустите. Что изменилось в выводе?

Упражнение 3.4.1. Отрицательный контроль

Что нужно сделать

В отрицательном контроле нет образца, и оптическая плотность должна быть не больше 0,05. Если это так, результат серии принимают, иначе серию повторяют. Дана оптическая плотность контроля. Выведите решение. Воспользуйтесь инструкциями if и else.

Входные данные

Одна строка: вещественное число от 0 до 4.

Выходные данные

Слово принять, если плотность не больше 0,05, иначе слово повторить.

Примеры
Входные данныеВыходные данные
 
0.12
повторить
0.05
принять

Упражнение 3.4.1. Число кодонов

Что нужно сделать

Последовательность кодирующей области должна состоять из целого числа кодонов, то есть ее длина делится на 3. Дана последовательность. Если ее длина делится на 3, выведите число кодонов. Иначе выведите, сколько нуклеотидов лишних.

Входные данные

Одна строка: последовательность из прописных букв A, C, G, T длиной от 1 до 300.

Выходные данные

Если длина делится на 3, одно целое число: число кодонов. Иначе строка лишних: k, где k число нуклеотидов сверх целого числа кодонов.

Упражнение 3.4.1. Позиция мутации в гене

Что нужно сделать

Ген занимает на хромосоме участок с позиции start по позицию end включительно. Ген на цепи + читается в сторону возрастания позиций, ген на цепи - в сторону убывания. Мутация найдена в позиции p хромосомы. Определите номер мутантного нуклеотида в гене: первый прочитанный нуклеотид гена имеет номер 1.

Подсказка

Возьмите маленький ген, например с позиции 10 по 14, и пронумеруйте его нуклеотиды для каждой цепи. С какой позиции начинается ген на цепи -?

Входные данные

В первой строке целое число start, во второй целое число end (1 ≤ start < end ≤ 109), в третьей знак цепи + или -, в четвертой целое число p (start ≤ p ≤ end).

Выходные данные

Одно целое число: номер мутантного нуклеотида в гене.
