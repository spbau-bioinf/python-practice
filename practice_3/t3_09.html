Проверка записи FASTA

20 минутЕрофеев А. И.

Научиться относить букву последовательности к группе по коду IUPAC и проверять запись FASTA цепочкой правил, сообщая о первом нарушенном правиле.

1. Коды IUPAC

Теория

Прежде чем проверять буквы последовательности, нужно договориться, какие буквы допустимы. Секвенатор не всегда уверен в нуклеотиде, а в сборке генома бывают участки, где возможны два варианта. Для таких позиций есть стандартные буквы, и NCBI требует, чтобы в последовательности были только они.

Буквы нуклеотидов задает код IUPAC. Четыре буквы A, C, G, T однозначные: каждая означает одно основание. Одиннадцать букв неоднозначные: они обозначают позицию, где возможны несколько оснований. Буква N означает любое основание. Код не зависит от регистра, поэтому перед проверкой букву приводят к прописной.

КодОснованияПодсказка к запоминанию
A, C, G, Tодно основаниеоднозначные коды
Nлюбое основаниеaNy
RA или GpuRine, пурин
YC или TpYrimidine, пиримидин
SG или CStrong, три водородные связи
WA или TWeak, две связи
KG или TKeto

Код описал А. Корниш-Боуден в 1985 году. Его утвердил Номенклатурный комитет Международного союза биохимии (NC-IUB, ныне IUBMB), но в литературе он известен как код IUPAC. Для РНК вместо T используют U. Строчные буквы в файлах геномов часто означают замаскированные повторы (страница 04 второй практики), а при жесткой маскировке повторы заменяют буквой N.

Пример

Алфавиты строками

Удобно хранить алфавит строкой и проверять букву оператором in. Предскажите вывод.

alphabets.py
exact = "ACGT"
ambiguous = "RYSWKMBDHVN"
print("N" in ambiguous)          # → True
print("y".upper() in ambiguous)  # → True
print("U" in exact)              # → False
Вывод
True
True
False
  1. Строка 3: N входит в неоднозначные коды.
  2. Строка 4: строчная y после upper() находится в алфавите.
  3. Строка 5: U бывает только в РНК, в алфавите ДНК ее нет.
Практика

Проверьте, входит ли в алфавит неоднозначных кодов буква K, затем буква X, затем строка "RY". Почему последний ответ True?

try_codes.py

print("W" in ambiguous)  # → True
Вывод
True

2. Классификация буквы

Теория

На странице 03 у оператора in нашлась ловушка: "" in "ACGT" и "AC" in "ACGT" тоже истинны. Здесь она становится настоящей ошибкой проверки: пустая строка или две буквы прошли бы как «однозначный нуклеотид».

Букву относят к группе цепочкой elif с проверками вхождения в строки-алфавиты. Проверка b in "ACGT" надежна только для одной буквы, поэтому первой ветвью стоит защитная проверка длины: она отсекает пустую строку и сочетания из нескольких букв. Все, что не попало ни в один алфавит, недопустимо, и этот случай достается ветви else.

Пример

Однозначная, неоднозначная или недопустимая

classify.py
base = "r"
b = base.upper()
if len(b) != 1:
    print("не одна буква")
elif b in "ACGT":
    print("однозначная")
elif b in "RYSWKMBDHVN":
    print("неоднозначная")  # → неоднозначная
else:
    print("недопустимая")
Вывод
неоднозначная
  1. Строка 2: код IUPAC не зависит от регистра, строчная r приведена к прописной.
  2. Строка 3: защитная проверка длины стоит первой.
  3. Строки 5–8: R нет среди однозначных, но есть среди неоднозначных.

Типичная ошибка: нет проверки длины

Неверно: две буквы считаются одной
b = "AC"
if b in "ACGT":
    print("однозначная")  # → однозначная
else:
    print("недопустимая")
Вывод
однозначная
Верно
b = "AC"
if len(b) != 1:
    print("не одна буква")  # → не одна буква
elif b in "ACGT":
    print("однозначная")
else:
    print("недопустимая")
Вывод
не одна буква

Строка "AC" входит в "ACGT" как подстрока, и проверка вхождения ее пропускает. Проверка длины ставится раньше, потому что цепочка останавливается на первой истинной ветви.

Практика

Запустите программу для "g", "", "X" и "-". Затем добавьте ветвь «РНК» для буквы U перед ветвью else.

try_classify.py
base = "N"
b = base.upper()
if len(b) != 1:
    print("не одна буква")
elif b in "ACGT":
    print("однозначная")
elif b in "RYSWKMBDHVN":
    print("неоднозначная")  # → неоднозначная
else:
    print("недопустимая")
Вывод
неоднозначная

3. Запись целиком

Теория

Запись FASTA состоит из строки-определения и последовательности. Проверка записи собирает все, что было на страницах этой практики: защитные условия, проверку вхождения, цепочку сравнений, плоскую цепочку elif с ошибками первыми ветвями.

Правила записи проверяют плоской цепочкой в том порядке, в каком их удобно сообщать: сначала строка-определение, затем последовательность. Каждое следующее правило может опираться на предыдущие: если до правила дошла очередь, все правила выше уже выполнены.

Проверить каждую букву последовательности по очереди можно циклом, а циклы разбираются в теме 4 «Циклы и итеративная обработка». Но уже сейчас можно узнать, есть ли в последовательности посторонние буквы: метод count() считает каждую допустимую букву, и если в сумме их меньше длины, остальные буквы посторонние (страница 09 второй практики).

Пример

Заголовок и последовательность

record_check.py
header = ">seq1"
seq = "ACGTUAC"
s = seq.upper()
known = s.count("A") + s.count("C") + s.count("G") + s.count("T")
if not header.startswith(">"):
    print("нет >")
elif not s:
    print("пустая последовательность")
elif known != len(s):
    print("есть буквы кроме ACGT")  # → есть буквы кроме ACGT
else:
    print("OK")
Вывод
есть буквы кроме ACGT
  1. Строка 4: букв A, C, G, T вместе шесть, а длина последовательности семь.
  2. Строка 7: проверка на пустую последовательность стоит раньше подсчета. Пустая последовательность иначе прошла бы как верная: у нее и букв, и длины по нулю.
  3. Строка 9: одна буква посторонняя, это U.
Практика

Добавьте в программу правило «нет ID»: строка-определение не должна состоять из одного знака >. Проверьте программу на заголовке ">".

try_record.py
header = ">contig_12"
seq = "acgtac"
if not header.startswith(">"):
    print("нет >")
elif not seq:
    print("пустая последовательность")
else:
    print("OK")  # → OK
Вывод
OK

Упражнение 3.9.1. Качество последовательности

Что нужно сделать

Перед сборкой генома последовательности проверяют по правилам, в таком порядке. Пустая последовательность: пустая. Есть символы, кроме A, C, G, T, N в любом регистре: недопустимые символы. Буквы N составляют больше половины длины (без учета регистра): низкое качество. Все буквы строчные, то есть последовательность целиком замаскирована: замаскирована. Иначе OK. Дана последовательность. Выведите результат первого сработавшего правила.

Подсказка

Посторонние буквы найдет сумма count() по допустимым буквам. Регистр для правил 2 и 3 не важен, а для правила 4 важен: сохраните исходную строку и ее копию прописными буквами. Метод islower() (страница 05 второй практики) смотрит только на буквы.

Входные данные

Одна строка длиной от 0 до 100 символов.

Выходные данные

Одна строка: пустая, недопустимые символы, низкое качество, замаскирована или OK.
