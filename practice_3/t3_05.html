Цепочка elif

30 минутЕрофеев А. И.

Научиться выбирать один из нескольких вариантов цепочкой if, elif, else, расставлять условия в правильном порядке и отличать цепочку от нескольких отдельных if.

1. Больше двух вариантов

Теория

Результат анализа редко делится ровно на «да» и «нет». GC-состав бывает низким, средним и высоким, качество прочтения хорошим, приемлемым и плохим, давление оптимальным, нормальным и повышенным. Для выбора из трех и более вариантов вкладывать один if в другой неудобно: в Python есть цепочка условий.

Слово elif (сокращение от «else if») добавляет к if следующую проверку. Условия проверяются сверху вниз. Выполняется ветвь первого истинного условия, и на этом вся инструкция заканчивается: остальные условия даже не вычисляются. Ветвь else в конце выполняется, если ни одно условие не оказалось истинным; ее можно не писать. Ветвей elif может быть сколько угодно.

схема
if {{условие 1}}:
    {{ветвь 1}}
elif {{условие 2}}:
    {{ветвь 2: условие 1 ложно, условие 2 истинно}}
else:
    {{ветвь 3: все условия ложны}}

До elif очередь доходит, только если все условия выше уже ложны. Поэтому в условии elif не нужно повторять то, что уже исключено. После if gc < 0.4 условие elif gc < 0.6 означает 0.4 <= gc < 0.6, то есть граница 0.4 входит, а 0.6 нет.

Цепочка условий — инструкция if с ветвями elif и, возможно, else, из которых выполняется не больше одной.

Пример

Классификация по GC-составу

gc_class.py
seq = "GCGCATGCTA"
n_g = seq.count("G")
n_c = seq.count("C")
gc = (n_g + n_c) / len(seq)
print(gc)                # → 0.6
if gc < 0.4:
    print("низкий GC")
elif gc < 0.6:
    print("средний GC")
else:
    print("высокий GC")  # → высокий GC
Вывод
0.6
высокий GC
  1. Строка 4: шесть букв G и C из десяти, доля 0.6.
  2. Строка 6: 0.6 < 0.4 ложно, переходим к elif.
  3. Строка 8: 0.6 < 0.6 тоже ложно: значение на границе не меньше границы.
  4. Строка 10: все условия ложны, выполняется else.

Граничное значение попадает в ту группу, которую задает знак сравнения. Если 0.6 должно считаться средним, во втором условии нужен знак <=.

Та же цепочка для трех значений доли. Таблица показывает, какие условия вычислялись.

Типичная ошибка: else if вместо elif

Неверно: SyntaxError
ph = 7.0
if ph < 7:
    print("кислая")
else if ph == 7:
    print("нейтральная")
Сообщение об ошибке
  File "ph_chain.py", line 4
    else if ph == 7:
         ^^
SyntaxError: expected ':'
Верно
ph = 7.0
if ph < 7:
    print("кислая")
elif ph == 7:
    print("нейтральная")  # → нейтральная
Вывод
нейтральная

Так ошибаются те, кто писал на C, Java или JavaScript: там «иначе если» записывают двумя словами. После else в Python сразу ставится двоеточие, поэтому сообщение и ждет двоеточие на месте if.

Практика

Сделайте так, чтобы доля 0.6 считалась средним GC. Затем добавьте четвертую группу «очень высокий GC» для доли от 0.7.

try_elif.py
gc = 0.6
if gc < 0.4:
    print("низкий GC")
elif gc < 0.6:
    print("средний GC")
else:
    print("высокий GC")  # → высокий GC
Вывод
высокий GC

2. Порядок условий

Теория

Каждое условие в цепочке может быть правильным по отдельности, а программа все равно будет ошибаться. Python не предупредит: код синтаксически верный, просто до одной из ветвей никогда не доходит очередь.

Раз цепочка останавливается на первом истинном условии, порядок условий важен. Если широкое условие стоит раньше узкого, узкая ветвь не выполнится никогда: в цепочке if gc > 0.3, elif gc > 0.6 любое значение больше 0.6 уже больше 0.3. Узкое условие ставят первым или записывают условия так, чтобы они не пересекались.

Несколько отдельных if подряд ведут себя иначе: каждый проверяется независимо, и могут выполниться все их ветви. Цепочка elif нужна, когда должен сработать ровно один вариант из нескольких. Отдельные if нужны, когда проверки независимы и могут сработать одновременно, например несколько правил проверки пробы.

Пример

Отдельные if и цепочка

Предскажите вывод: сколько строк напечатает каждая половина программы?

if_vs_elif.py
gc = 0.7
if gc > 0.6:
    print("высокий")  # → высокий
if gc > 0.3:
    print("средний")  # → средний
print("---")          # → ---
if gc > 0.6:
    print("высокий")  # → высокий
elif gc > 0.3:
    print("средний")
Вывод
высокий
средний
---
высокий
  1. Строки 2–5: два отдельных if. Оба условия истинны, и выполняются обе ветви.
  2. Строки 7–10: одна цепочка. Первое истинное условие завершает ее, и второе не проверяется.

Проверьте цепочку на значении из каждой группы. Если какая-то ветвь не выполняется ни на одном значении, перед ней стоит более широкое условие.

Независимые правила

У пробы проверяют объем и концентрацию. Нарушения не исключают друг друга, поэтому проверки записаны отдельными if.

sample_rules.py
volume = 8
conc = 3.5
if volume < 10:
    print("мало объема")          # → мало объема
if conc < 5:
    print("низкая концентрация")  # → низкая концентрация
Вывод
мало объема
низкая концентрация

Замените второй if на elif, и о низкой концентрации программа промолчит: цепочка остановится на первом нарушении. Для сообщения об ошибке ввода это бывает нужно (страница 08), а для полного отчета о пробе нет.

Практика

При глюкозе от 11,1 должно печататься «высокая», но цепочка печатает «повышенная». Поменяйте ветви местами и проверьте значения 5.2, 8 и 12.5.

    print("повышенная")  # → повышенная

    print("высокая")
else:
    print("нормальная")

Задача со звездочкой 3.5. Вид мутации

Что нужно сделать

Сравнивают последовательность гена до мутации и после нее. Будем считать, что мутация одна и она одного из трех видов: замена (буквы меняются, длина та же), вставка (в ген добавлены нуклеотиды) или делеция (часть нуклеотидов удалена). Ген читают подряд тройками нуклеотидов, кодонами. Если число вставленных или удаленных нуклеотидов не делится на 3, все тройки после места мутации сдвигаются: это сдвиг рамки считывания. Если последовательности совпадают, мутации нет. Даны последовательности до и после мутации. Выведите вид мутации, а для вставки и делеции еще и то, сдвинута ли рамка.

Подсказка

Вид мутации и рамку удобно определить двумя отдельными инструкциями: сначала цепочкой выбрать вид, затем дописать к нему слова о рамке.

Входные данные

Две строки: последовательность до мутации и после нее, из прописных букв A, C, G, T, длиной от 1 до 100 каждая.

Выходные данные

Одна строка: без изменений, замена, вставка в рамке, вставка со сдвигом рамки, делеция в рамке или делеция со сдвигом рамки.
