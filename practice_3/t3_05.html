Цепочка elif

30 минутЕрофеев А. И.

Научиться выбирать один из нескольких вариантов цепочкой if, elif, else, расставлять условия в правильном порядке и отличать цепочку от нескольких отдельных if.

1. Больше двух вариантов

Теория

Результат анализа редко делится ровно на «да» и «нет». GC-состав бывает низким, средним и высоким, качество прочтения хорошим, приемлемым и плохим, давление оптимальным, нормальным и повышенным. Для выбора из трех и более вариантов вкладывать один if в другой неудобно: в Python есть цепочка условий.

Слово elif (сокращение от «else if») добавляет к if следующую проверку. Условия проверяются сверху вниз. Выполняется ветвь первого истинного условия, и на этом вся инструкция заканчивается: остальные условия даже не вычисляются. Ветвь else в конце выполняется, если ни одно условие не оказалось истинным; ее можно не писать. Ветвей elif может быть сколько угодно.

схема
if {{условие 1}}:
    {{ветвь 1}}
elif {{условие 2}}:
    {{ветвь 2: условие 1 ложно, условие 2 истинно}}
else:
    {{ветвь 3: все условия ложны}}

До elif очередь доходит, только если все условия выше уже ложны. Поэтому в условии elif не нужно повторять то, что уже исключено. После if gc < 0.4 условие elif gc < 0.6 означает 0.4 <= gc < 0.6, то есть граница 0.4 входит, а 0.6 нет.

Цепочка условий — инструкция if с ветвями elif и, возможно, else, из которых выполняется не больше одной.

Пример

Классификация по GC-составу

gc_class.py
seq = "GCGCATGCTA"
n_g = seq.count("G")
n_c = seq.count("C")
gc = (n_g + n_c) / len(seq)
print(gc)                # → 0.6
if gc < 0.4:
    print("низкий GC")
elif gc < 0.6:
    print("средний GC")
else:
    print("высокий GC")  # → высокий GC
Вывод
0.6
высокий GC
  1. Строка 4: шесть букв G и C из десяти, доля 0.6.
  2. Строка 6: 0.6 < 0.4 ложно, переходим к elif.
  3. Строка 8: 0.6 < 0.6 тоже ложно: значение на границе не меньше границы.
  4. Строка 10: все условия ложны, выполняется else.

Граничное значение попадает в ту группу, которую задает знак сравнения. Если 0.6 должно считаться средним, во втором условии нужен знак <=.

Типичная ошибка: else if вместо elif

Неверно: SyntaxError
ph = 7.0
if ph < 7:
    print("кислая")
else if ph == 7:
    print("нейтральная")
Сообщение об ошибке

    else if ph == 7:
         ^^
SyntaxError: expected ':'
Верно
ph = 7.0
if ph < 7:
    print("кислая")
elif ph == 7:
    print("нейтральная")  # → нейтральная
Вывод
нейтральная

Так ошибаются те, кто писал на C, Java или JavaScript: там «иначе если» записывают двумя словами. После else в Python сразу ставится двоеточие, поэтому сообщение и ждет двоеточие на месте if.

Практика

Сделайте так, чтобы доля 0.6 считалась средним GC. Затем добавьте четвертую группу «очень высокий GC» для доли от 0.7.

try_elif.py
gc = 0.6
if gc < 0.4:
    print("низкий GC")
elif gc < 0.6:
    print("средний GC")
else:
    print("высокий GC")  # → высокий GC
Вывод
высокий GC

2. Порядок условий

Теория

Каждое условие в цепочке может быть правильным по отдельности, а программа все равно будет ошибаться. Python не предупредит: код синтаксически верный, просто до одной из ветвей никогда не доходит очередь.

Раз цепочка останавливается на первом истинном условии, порядок условий важен. Если широкое условие стоит раньше узкого, узкая ветвь не выполнится никогда: в цепочке if gc > 0.3, elif gc > 0.6 любое значение больше 0.6 уже больше 0.3. Узкое условие ставят первым или записывают условия так, чтобы они не пересекались.

Несколько отдельных if подряд ведут себя иначе: каждый проверяется независимо, и могут выполниться все их ветви. Цепочка elif нужна, когда должен сработать ровно один вариант из нескольких. Отдельные if нужны, когда проверки независимы и могут сработать одновременно, например несколько правил проверки пробы.

Пример

Отдельные if и цепочка

Предскажите вывод: сколько строк напечатает каждая половина программы?

if_vs_elif.py
gc = 0.7
if gc > 0.6:
    print("высокий")  # → высокий
if gc > 0.3:
    print("средний")  # → средний
print("---")          # → ---
if gc > 0.6:
    print("высокий")  # → высокий
elif gc > 0.3:
    print("средний")
Вывод
высокий
средний
---
высокий
  1. Строки 2–5: два отдельных if. Оба условия истинны, и выполняются обе ветви.
  2. Строки 7–10: одна цепочка. Первое истинное условие завершает ее, и второе не проверяется.

Проверьте цепочку на значении из каждой группы. Если какая-то ветвь не выполняется ни на одном значении, перед ней стоит более широкое условие.

Независимые правила

У пробы проверяют объем и концентрацию. Нарушения не исключают друг друга, поэтому проверки записаны отдельными if.

sample_rules.py
volume = 8
conc = 3.5
if volume < 10:
    print("мало объема")          # → мало объема
if conc < 5:
    print("низкая концентрация")  # → низкая концентрация

мало объема
низкая концентрация

Замените второй if на elif, и о низкой концентрации программа промолчит: цепочка остановится на первом нарушении. Для сообщения об ошибке ввода это бывает нужно (страница 08), а для полного отчета о пробе нет.

При глюкозе от 11,1 должно печататься «высокая», но цепочка печатает «повышенная». Поменяйте ветви местами и проверьте значения 5.2, 8 и 12.5.

    print("повышенная")  # → повышенная
elif glucose >= 11.1:
    print("высокая")
else:
    print("нормальная")
Вывод

  • Объем — количество жидкости в пробе, здесь в мкл.
  • Концентрация — количество ДНК в единице объема, здесь в нг/мкл.
  • Отношение A260/A280 — отношение поглощения пробы на двух длинах волн; по нему судят о чистоте ДНК.
  • Счетчик — переменная, к которой прибавляют единицу за каждое нарушение.
Подсказка
  1. Прочитайте объем, концентрацию и отношение: volume, concentration, ratio через float(input()).
  2. Заведите счетчик: errors = 0.
  3. Три независимых условия: volume < 10, concentration < 5, ratio < 1.8 or ratio > 2.0; в каждом теле счетчик увеличивают на 1.
  4. Выведите счетчик; сверьтесь с примером: 12, 8.4 и 1.9 нарушают ноль правил, а 6, 2.5 и 2.3 — все три.

Упражнение 3.5.2. Категория давления

Условие задачи

Артериальное давление записывают двумя числами: систолическим и диастолическим. Оптимальное: систолическое меньше 120 и диастолическое меньше 80. Нормальное: систолическое меньше 130 и диастолическое меньше 85. Высокое нормальное: систолическое меньше 140 и диастолическое меньше 90. В остальных случаях гипертензия. Даны два значения. Выведите категорию.

Входные данные

Две строки: систолическое давление, затем диастолическое, целые числа от 40 до 250.

Выходные данные

Категория: оптимальное, нормальное, высокое нормальное или гипертензия.

Пример

Разберем пример

Ввод 125
78
→
Вывод нормальное

125 не меньше 120, поэтому «оптимальное» не подходит, но 125 меньше 130, а 78 меньше 85 — это «нормальное». Категорию определяет худшее из двух чисел.

Примеры
ВводВывод

88

Контекст

Категории давления вложены: оптимальное — частный случай нормального, а нормальное — высокого нормального. Поэтому цепочку if/elif строят от узкой категории к широкой, и категорию задает первое подходящее условие.

Основные определения

  • Систолическое давление — верхнее число в записи давления.
  • Диастолическое давление — нижнее число в записи давления.
  • Вложенные условия — каждая следующая категория включает предыдущую.
  • if/elif/else — цепочка ветвлений: работает первый истинный блок.
Подсказка
  1. Прочитайте давления: sys_p = int(input()), dia_p = int(input()).
  2. Оптимальное — sys_p < 120 and dia_p < 80.
  3. Дальше условия шире: sys_p < 130 and dia_p < 85 и sys_p < 140 and dia_p < 90.
  4. Добавьте else для гипертензии и выведите категорию; сверьтесь с примером: 125 и 78 дают нормальное, а 118 и 88 — высокое нормальное.

Задача со звездочкой 3.5. Транзиция или трансверсия

Условие задачи

Точечная замена меняет одну букву нуклеотида на другую. Пурины: A и G, пиримидины: C и T. Замену пурина пурином или пиримидина пиримидином называют транзицией, а замену пурина пиримидином или пиримидина пурином трансверсией. Даны исходная и новая буква. Выведите тип замены. Если буквы одинаковы, замены нет.

Входные данные

Две строки, в каждой одна прописная буква A, C, G или T.

Выходные данные

Одна строка: нет замены, транзиция или трансверсия.

Пример

Разберем пример

Ввод C
T
→
Вывод транзиция

C и T оба пиримидины, а буквы разные: пиримидин заменен пиримидином, это транзиция. Замена G на G дала бы «нет замены».

Примеры
ВводВывод
 
C
T
транзиция
G
G
нет замены
Контекст

Пурины A и G имеют двухкольцевую структуру, пиримидины C и T — однокольцевую. Признак пурина — сравнение буквы с A и G, а тип замены определяет совпадение этих признаков у старой и новой буквы.

Основные определения

  • Точечная замена — замена одного нуклеотида другим.
  • Транзиция — замена пурина пурином или пиримидина пиримидином.
  • Трансверсия — замена пурина пиримидином или пиримидина пурином.
  • Пурин — A и G.
  • Пиримидин — C и T.
Подсказка
  1. Прочитайте обе буквы: old = input(), new = input().
  2. Признак пурина: old_purine = old == "A" or old == "G"; так же для новой буквы.
  3. Если буквы одинаковы, замены нет; иначе при old_purine == new_purine — транзиция.
  4. Оставшийся случай — трансверсия; выведите тип; сверьтесь с примером: C и T дают транзиция, а G и G — нет замены.

Задача со звездочкой 3.5. Консенсус трех прочтений

Условие задачи

Одну позицию генома покрывают три прочтения, и каждое дает в ней свою букву. Консенсусом позиции называют букву, которую дали не меньше двух прочтений из трех. Если все три буквы разные, консенсуса нет, и в позицию ставят N. Даны три буквы. Выведите консенсус.

Входные данные

Три строки, в каждой одна прописная буква A, C, G или T.

Выходные данные

Одна буква: консенсус или N.

Пример

Разберем пример

Ввод G
A
G
→
Вывод G

Буква G встретилась в двух прочтениях из трех, а для консенсуса достаточно двух. Три разные буквы дали бы N.

Примеры
ВводВывод
 
G
A
G
G
C
T
A
N
Контекст

Чтобы буква стала консенсусом, она должна встретиться хотя бы дважды. Достаточно проверить совпадения: если first_base совпадает с second_base или с third_base, консенсус — first_base; иначе проверяют second_base и third_base; третий случай — все буквы разные.

Основные определения

  • Прочтение — участок ДНК, который секвенатор прочитал за один раз.
  • Секвенатор — прибор для чтения ДНК.
  • Покрытие — число прочтений, которые накрывают одну позицию.
  • Консенсус — буква, которую дали не меньше двух прочтений из трех.
Подсказка
  1. Прочитайте три буквы: first_base = input(), second_base = input(), third_base = input().
  2. Если first_base == second_base или first_base == third_base, консенсус — first_base.
  3. Иначе проверьте second_base == third_base: тогда консенсус — second_base.
  4. В оставшемся случае выведите N; сверьтесь с примером: G, A и G дают G, а C, T и A — N.

Задача со звездочкой 3.5. Вид мутации

Условие задачи

Сравнивают последовательность гена до мутации и после нее. Будем считать, что мутация одна и она одного из трех видов: замена (буквы меняются, длина та же), вставка (в ген добавлены нуклеотиды) или делеция (часть нуклеотидов удалена). Ген читают подряд тройками нуклеотидов, кодонами. Если число вставленных или удаленных нуклеотидов не делится на 3, все тройки после места мутации сдвигаются. Если последовательности совпадают, мутации нет. Даны последовательности до и после мутации. Выведите вид мутации, а для вставки и делеции еще и то, сдвинута ли рамка.

Входные данные

Две строки: последовательность до мутации и после нее, из прописных букв A, C, G, T, длиной от 1 до 100 каждая.

Выходные данные

Одна строка: без изменений, замена, вставка в рамке, вставка со сдвигом рамки, делеция в рамке или делеция со сдвигом рамки.

Пример

Разберем пример

Ввод ATGGCCAAA
ATGGCTTTAAA
→
Вывод вставка в рамке

Последовательность после мутации длиннее на 3 нуклеотида: это вставка. Три делится на 3, поэтому рамка не сдвигается — «вставка в рамке».

Примеры
ВводВывод
 
ATGGCCAAA
ATGGCCTTTAAA
вставка в рамке
ATGGCCAAA
ATGCCAAA
делеция со сдвигом рамки
Контекст

Вид мутации определяет разность длин: нуль — замена, плюс — вставка, минус — делеция. Кратность разности трем показывает, сохранилась ли рамка считывания: тройки после места мутации не смещаются.

Основные определения

  • Замена — буквы меняются, а длина последовательности та же.
  • Вставка — в ген добавлены нуклеотиды.
  • Делеция — часть нуклеотидов удалена.
  • Кодон — тройка подряд идущих нуклеотидов.
  • Рамка считывания — разбиение последовательности на кодоны с первого нуклеотида.
  • Сдвиг рамки — смещение разбиения на кодоны после вставки или делеции, не кратной трем.
Подсказка
  1. Прочитайте обе последовательности: before = input(), after = input().
  2. Разность длин: diff = len(after) - len(before).
  3. Вид: if before == after — без изменений, elif diff == 0 — замена, elif diff > 0 — вставка, иначе делеция.
  4. Допишите к виду хвост: при diff % 3 != 0 — « со сдвигом рамки», иначе при diff != 0 — « в рамке»; выведите строку и сверьтесь с примером: ATGGCCTTTAAA длиннее на три буквы — вставка в рамке, а ATGCCAAA короче на одну — делеция со сдвигом рамки.
