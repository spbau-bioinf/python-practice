Практика 3›Вложенные условия, цепочка сравнений, условное выражение

Упрощение проверок

20 минутЕрофеев А. И.

Научиться заменять вложенные условия плоской цепочкой, записывать двойное сравнение цепочкой a <= x <= b и выбирать одно из двух значений условным выражением.

1. Вложенные условия

Теория

Проверка данных обычно состоит из нескольких правил: заголовок начинается с >, в идентификаторе нет пробелов, идентификатор не длиннее 25 символов. Самый прямой способ записать такие правила: вложить каждую проверку в предыдущую. Это работает, но с каждым правилом код уходит вправо лесенкой.

Внутри ветви может стоять другая инструкция if со своим блоком и своим отступом. Такое условие называют вложенным. Вложенные условия работают правильно, но их трудно читать: чтобы понять, когда печатается сообщение из ветви else, приходится искать ее if по отступу на много строк выше. Сообщение о нарушении правила оказывается далеко от проверки этого правила.

Вложенное условие — условная инструкция внутри ветви другой условной инструкции.

Пример

Проверка заголовка: лесенка

По правилам NCBI строка-определение FASTA начинается с >, а идентификатор после нее не содержит пробелов и не длиннее 25 символов. В учебном примере заголовок состоит только из идентификатора.

ladder.py
header = ">Seq1"
sid = header[1:]
if header.startswith(">"):
    if " " not in sid:
        if len(sid) <= 25:
            print("OK")  # → OK
        else:
            print("длина ID")
    else:
        print("пробел в ID")
else:
    print("нет >")
Вывод
OK
  1. Строки 3–5: три правила вложены друг в друга, каждое на своем уровне отступа.
  2. Строки 7–12: три сообщения об ошибках стоят в обратном порядке, и каждое далеко от своей проверки. Сообщение «нет >» в последней строке относится к условию в строке 3.

Незаметная ошибка лесенки

Та же программа для заголовка из одного знака >. Предскажите вывод.

ladder_empty.py
header = ">"
sid = header[1:]
if header.startswith(">"):
    if " " not in sid:
        if len(sid) <= 25:
            print("OK")  # → OK
        else:
            print("длина ID")
    else:
        print("пробел в ID")
else:
    print("нет >")
Вывод
OK

Идентификатор пустой, но все три проверки проходят: знак > есть, пробела в пустой строке нет, длина 0 не больше 25. В лесенке не хватает правила «идентификатор не пустой». В плоской записи следующего раздела его легко добавить: нижняя граница в цепочке сравнений 1 <= len(sid) <= 25.

Практика

Запустите лесенку для заголовков ">seq 1" и "Seq1". Найдите в коде строку, которая печатает каждое из сообщений.

2. Плоская цепочка и цепочка сравнений

Теория

Лесенку можно выпрямить, сохранив все ее проверки, а заодно добавить недостающее правило о пустом идентификаторе. Приемов три, и все они опираются на то, что уже знакомо: and со страницы 02, цепочку elif со страницы 05 и новую запись двойного сравнения.

Вложенный if без else заменяют одним условием с and: if a: и внутри if b: равносильно if a and b:. Проверки с сообщениями об ошибках переворачивают и ставят первыми ветвями плоской цепочки elif: каждая ветвь проверяет нарушение правила и тут же сообщает о нем, а верному случаю достается последняя ветвь else. Цепочка останавливается на первом нарушенном правиле.

Двойное сравнение записывают как в математике: 1 <= n <= 25 означает 1 <= n and n <= 25, только n вычисляется один раз. Сравнения связывают сильнее not, поэтому not 1 <= n <= 25 читается как not (1 <= n <= 25).

Цепочка сравнений — запись нескольких сравнений подряд, например a < b <= c; она истинна, если истинны все соседние сравнения.

БылоСталоПрием
if a: / if b:if a and b:вложенность заменена and

Пример

Проверка заголовка: плоская цепочка

flat.py
header = ">Seq1"
sid = header[1:]
if not header.startswith(">"):
    print("нет >")
elif " " in sid:
    print("пробел в ID")
elif not 1 <= len(sid) <= 25:
    print("длина ID")
else:
    print("OK")  # → OK
Вывод
OK
  1. Строки 3–8: каждое правило стоит рядом со своим сообщением, и читать их можно сверху вниз, как список требований.
  2. Условия перевернулись: вместо «начинается с >» стоит «не начинается», потому что ветвь описывает ошибку.
  3. Строка 7: цепочка 1 <= len(sid) <= 25 отсекает и пустой идентификатор, который пропускала лесенка.

Вложенность заменена and

Предскажите, напечатают ли обе программы одно и то же.

nested_and.py
gc = 0.47
if gc > 0.4:
    if gc < 0.6:
        print("средний GC")  # → средний GC
if 0.4 < gc < 0.6:
    print("средний GC")      # → средний GC
Вывод
средний GC
средний GC

Строки 2–4 и строки 5–6 проверяют одно и то же. Во второй записи один уровень отступа и одно условие, которое читается как математическое неравенство.

Подробнее: необычные цепочки сравнений

Цепочку можно составить из любых операторов сравнения: 1 < x > 3 означает 1 < x and x > 3, а a == b == c проверяет, что равны все три значения. Такие записи допустимы, но читаются плохо. Пишите цепочки только в виде a < x < b или a <= x <= b, как неравенство в математике. В большинстве других языков, например в C и JavaScript, запись 1 < x < 10 означает совсем другое, поэтому опытные программисты иногда избегают ее и в Python.

Практика

Перепишите условие цепочкой сравнений и проверьте его на значениях 0.3, 0.5 и 0.6.

try_chain.py
gc = 0.5
if gc >= 0.4 and gc <= 0.6:
    print("средний GC")  # → средний GC
else:
    print("вне диапазона")
Вывод
средний GC

3. Условное выражение

Теория

Часто ветви if и else отличаются только значением, которое получает переменная. Четыре строки ради выбора одного из двух слов выглядят тяжеловесно, и для этого случая в Python есть запись в одну строку.

Условное выражение a if условие else b дает значение a, если условие истинно, и b, если ложно. Сначала вычисляется условие, затем только одно из двух значений. Часть else обязательна: выражение должно дать значение в любом случае. Условное выражение уместно в простых случаях, когда нужно выбрать одно из двух значений; если ветви длинные или вариантов больше двух, пишите обычный if.

Пример

Выбор одного из двух слов

cond_expr.py
seq = "ATGNNCGT"
status = "чистая" if "N" not in seq else "есть N"
print(status)  # → есть N
line = ">Seq1"
print("заголовок" if line.startswith(">") else "последовательность")  # → заголовок
Вывод
есть N
заголовок
  1. Строка 2: условие ложно, переменная получает значение после else.
  2. Строка 5: условное выражение можно сразу передать в print().

Типичная ошибка: условное выражение без else

Неверно: SyntaxError
gc = 0.5
status = "высокий" if gc > 0.6
print(status)
Сообщение об ошибке
  File "cond.py", line 2
    status = "высокий" if gc > 0.6
             ^^^^^^^^^^^^^^^^^^^^^
SyntaxError: expected 'else' after 'if' expression
Верно
gc = 0.5
status = "высокий" if gc > 0.6 else "не высокий"
print(status)  # → не высокий
Вывод
не высокий

Инструкция if может пропустить блок, а выражение обязано дать значение. Без else Python не знает, что положить в status при ложном условии.

Практика

Замените четыре строки с if и else одной строкой с условным выражением. Проверьте на длинах 15 и 30.

try_cond.py
length = 15
if length < 20:
    kind = "короткая"
else:
    kind = "длинная"
print(kind)  # → короткая
Вывод
короткая

Упражнение 3.8.1. Лунка планшета

Что нужно сделать

Лунку 96-луночного планшета обозначают строкой из буквы ряда от A до H и двузначного номера столбца от 01 до 12, например B07. Лунки нумеруют по рядам: A01 имеет номер 1, A12 номер 12, B01 номер 13, H12 номер 96. Дано обозначение лунки. Проверьте его и выведите номер лунки или сообщение о первой найденной ошибке.

Подсказка

Строки тоже сравниваются цепочкой: "A" <= row <= "H". Номер ряда дает функция ord(). Прежде чем превращать столбец в число, проверьте методом isdigit(), что в нем одни цифры: "07".isdigit() дает True, "7a".isdigit() дает False.

Входные данные

Одна строка длиной от 0 до 10 символов.

Выходные данные

Номер лунки от 1 до 96. Если обозначение неверно, сообщение о первой ошибке в таком порядке проверки: неверная длина, если длина не равна 3; неверный ряд, если первый символ не прописная буква от A до H; неверный столбец, если два последних символа не число от 01 до 12.
