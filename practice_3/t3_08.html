Практика 3›Вложенные условия, цепочка сравнений, условное выражение

Упрощение проверок

20 минутЕрофеев А. И.

Научиться заменять вложенные условия плоской цепочкой, записывать двойное сравнение цепочкой a <= x <= b и выбирать одно из двух значений условным выражением.

1. Вложенные условия

Теория

Проверка данных обычно состоит из нескольких правил: заголовок начинается с >, в идентификаторе нет пробелов, идентификатор не длиннее 25 символов. Самый прямой способ записать такие правила: вложить каждую проверку в предыдущую. Это работает, но с каждым правилом код уходит вправо лесенкой.

Внутри ветви может стоять другая инструкция if со своим блоком и своим отступом. Такое условие называют вложенным. Вложенные условия работают правильно, но их трудно читать: чтобы понять, когда печатается сообщение из ветви else, приходится искать ее if по отступу на много строк выше. Сообщение о нарушении правила оказывается далеко от проверки этого правила.

Вложенное условие — условная инструкция внутри ветви другой условной инструкции.

Пример

Проверка заголовка: лесенка

По правилам NCBI строка-определение FASTA начинается с >, а идентификатор после нее не содержит пробелов и не длиннее 25 символов. В учебном примере заголовок состоит только из идентификатора.

ladder.py
header = ">Seq1"
sid = header[1:]
if header.startswith(">"):
    if " " not in sid:
        if len(sid) <= 25:
            print("OK")  # → OK
        else:
            print("длина ID")
    else:
        print("пробел в ID")
else:
    print("нет >")
Вывод
OK
  1. Строки 3–5: три правила вложены друг в друга, каждое на своем уровне отступа.
  2. Строки 7–12: три сообщения об ошибках стоят в обратном порядке, и каждое далеко от своей проверки. Сообщение «нет >» в последней строке относится к условию в строке 3.

Незаметная ошибка лесенки

Та же программа для заголовка из одного знака >. Предскажите вывод.

ladder_empty.py
header = ">"
sid = header[1:]
if header.startswith(">"):
    if " " not in sid:
        if len(sid) <= 25:
            print("OK")  # → OK
        else:
            print("длина ID")
    else:
        print("пробел в ID")
else:
    print("нет >")
Вывод
OK

Идентификатор пустой, но все три проверки проходят: знак > есть, пробела в пустой строке нет, длина 0 не больше 25. В лесенке не хватает правила «идентификатор не пустой». В плоской записи следующего раздела его легко добавить: нижняя граница в цепочке сравнений 1 <= len(sid) <= 25.

Практика

Запустите лесенку для заголовков ">seq 1" и "Seq1". Найдите в коде строку, которая печатает каждое из сообщений.

2. Плоская цепочка и цепочка сравнений

Теория

Лесенку можно выпрямить, сохранив все ее проверки, а заодно добавить недостающее правило о пустом идентификаторе. Приемов три, и все они опираются на то, что уже знакомо: and со страницы 02, цепочку elif со страницы 05 и новую запись двойного сравнения.

Вложенный if без else заменяют одним условием с and: if a: и внутри if b: равносильно if a and b:. Проверки с сообщениями об ошибках переворачивают и ставят первыми ветвями плоской цепочки elif: каждая ветвь проверяет нарушение правила и тут же сообщает о нем, а верному случаю достается последняя ветвь else. Цепочка останавливается на первом нарушенном правиле.

Двойное сравнение записывают как в математике: 1 <= n <= 25 означает 1 <= n and n <= 25, только n вычисляется один раз. Сравнения связывают сильнее not, поэтому not 1 <= n <= 25 читается как not (1 <= n <= 25).

Цепочку образует любое сравнение, и == тоже. Python режет цепочку на соседние пары и соединяет их через and, поэтому gc > 0.4 == True означает gc > 0.4 and 0.4 == True и ложно при любом gc: 0.4 не равно True. Если нужен другой порядок, ставят скобки, но с True через == обычно не сравнивают совсем: достаточно gc > 0.4.

Цепочка сравнений — запись нескольких сравнений подряд, например a < b <= c; она истинна, если истинны все соседние сравнения.

Пример

Проверка заголовка: плоская цепочка

flat.py
header = ">Seq1"
sid = header[1:]
if not header.startswith(">"):
    print("нет >")
elif " " in sid:
    print("пробел в ID")
elif not 1 <= len(sid) <= 25:
    print("длина ID")
else:
    print("OK")  # → OK
Вывод
OK
  1. Строки 3–8: каждое правило стоит рядом со своим сообщением, и читать их можно сверху вниз, как список требований.
  2. Условия перевернулись: вместо «начинается с >» стоит «не начинается», потому что ветвь описывает ошибку.
  3. Строка 7: цепочка 1 <= len(sid) <= 25 отсекает и пустой идентификатор, который пропускала лесенка.

Вложенность заменена and

Предскажите, напечатают ли обе программы одно и то же.

nested_and.py
gc = 0.47
if gc > 0.4:
    if gc < 0.6:
        print("средний GC")  # → средний GC
if 0.4 < gc < 0.6:
    print("средний GC")      # → средний GC
Вывод
средний GC
средний GC

Строки 2–4 и строки 5–6 проверяют одно и то же. Во второй записи один уровень отступа и одно условие, которое читается как математическое неравенство.

Цепочка с ==

Предскажите вывод, прежде чем открыть его.

chain_eq.py
gc = 0.5
print(0.4 < gc < 0.6)      # → True
print(gc > 0.4 == True)    # → False
print((gc > 0.4) == True)  # → True
Вывод
True
False
True
  1. Строка 2: обычное двойное сравнение, 0.4 < gc and gc < 0.6.
  2. Строка 3: тоже цепочка, gc > 0.4 and 0.4 == True. Первая пара истинна, вторая ложна, и все условие ложно.
  3. Строка 4: скобки вычисляют сравнение первым, и его результат True равен True.
Подробнее: необычные цепочки сравнений

Из правила «цепочку образует любое сравнение» следуют и странные записи: 1 < x > 3 означает 1 < x and x > 3, а a == b == c проверяет, что равны все три значения. Такие записи допустимы, но читаются плохо. Пишите цепочки только в виде a < x < b или a <= x <= b, как неравенство в математике. В большинстве других языков, например в C и JavaScript, запись 1 < x < 10 означает совсем другое, поэтому опытные программисты иногда избегают ее и в Python.

Практика

Перепишите условие цепочкой сравнений и проверьте его на значениях 0.3, 0.5 и 0.6.

try_chain.py
gc = 0.5
if gc >= 0.4 and gc <= 0.6:
    print("средний GC")  # → средний GC
else:
    print("вне диапазона")
Вывод
средний GC

3. Условное выражение

Теория

Часто ветви if и else отличаются только значением, которое получает переменная. Четыре строки ради выбора одного из двух слов выглядят тяжеловесно, и для этого случая в Python есть запись в одну строку.

Условное выражение a if условие else b дает значение a, если условие истинно, и b, если ложно. Сначала вычисляется условие, затем только одно из двух значений. Часть else обязательна: выражение должно дать значение в любом случае. Условное выражение уместно в простых случаях, когда нужно выбрать одно из двух значений; если ветви длинные или вариантов больше двух, пишите обычный if.

Пример

Выбор одного из двух слов

cond_expr.py
seq = "ATGNNCGT"
status = "чистая" if "N" not in seq else "есть N"
print(status)  # → есть N
line = ">Seq1"
print("заголовок" if line.startswith(">") else "последовательность")  # → заголовок
Вывод
есть N
заголовок
  1. Строка 2: условие ложно, переменная получает значение после else.
  2. Строка 5: условное выражение можно сразу передать в print().

Типичная ошибка: условное выражение без else

Неверно: SyntaxError
gc = 0.5
status = "высокий" if gc > 0.6
print(status)
Сообщение об ошибке
  File "cond.py", line 2
    status = "высокий" if gc > 0.6
             ^^^^^^^^^^^^^^^^^^^^^
SyntaxError: expected 'else' after 'if' expression
Верно
gc = 0.5
status = "высокий" if gc > 0.6 else "не высокий"
print(status)  # → не высокий
Вывод
не высокий

Инструкция if может пропустить блок, а выражение обязано дать значение. Без else Python не знает, что положить в status при ложном условии.

Практика

Замените четыре строки с if и else одной строкой с условным выражением. Проверьте на длинах 15 и 30.

try_cond.py
length = 15
if length < 20:
    kind = "короткая"
else:
    kind = "длинная"
print(kind)  # → короткая
Вывод
короткая
Задача

Упражнение 3.8.1. Лунка планшета

Условие задачи

Планшет — пластина с углублениями, лунками, в которые ставят пробы. Лунку 96-луночного планшета обозначают строкой из буквы ряда от A до H и двузначного номера столбца от 01 до 12, например B07. Лунки нумеруют по рядам: A01 имеет номер 1, A12 номер 12, B01 номер 13, H12 номер 96. Дано обозначение лунки. Проверьте его и выведите номер лунки или сообщение о первой найденной ошибке.

Входные данные

Одна строка длиной от 0 до 10 символов.

Выходные данные

Номер лунки от 1 до 96. Если обозначение неверно, сообщение о первой ошибке в таком порядке проверки: неверная длина, если длина не равна 3; неверный ряд, если первый символ не прописная буква от A до H; неверный столбец, если два последних символа не число от 01 до 12.

Пример

Разберем пример

Ввод B07
→
Вывод 19

Ряд B второй, перед ним 12 лунок ряда A; столбец 07 седьмой: 12 + 7 = 19.

Примеры
ВводВывод

I05
неверный ряд
Контекст

Номер лунки считают по рядам: номер = (ряд − A) · 12 + столбец. Проверки идут по порядку, и первая ошибка отменяет остальные; столбец проверяют через isdigit() и диапазон 1–12.

Основные определения

  • Планшет — пластина с углублениями, лунками, в которые ставят пробы.
  • Лунка — одно углубление планшета.
  • Ряд и столбец — ряд обозначают буквой от A до H, столбец — номером от 01 до 12.
  • Метод isdigit() — проверяет, что строка состоит только из цифр.
  • Функция ord() — возвращает код символа; разность кодов дает номер буквы в алфавите.
Подсказка
  1. Прочитайте обозначение: well = input().
  2. Проверки по порядку: длина len(well) != 3, затем ряд not "A" <= well[0] <= "H", затем столбец — well[1:].isdigit() и номер от 1 до 12.
  3. Если ошибок нет, номер считают по рядам: ord(well[0]) - ord("A") умножить на 12 и прибавить int(well[1:]).
  4. Выведите номер или сообщение о первой ошибке; сверьтесь с примером: B07 дает 19, а I05 — неверный ряд.

Задача со звездочкой 3.8. Проверка праймера

Условие задачи

В лаборатории праймер проверяют по трем правилам в таком порядке: длина от 18 до 25 нуклеотидов включительно; GC-состав, то есть доля букв G и C в процентах от длины, от 40 до 60 включительно; последняя буква G или C. Дана последовательность праймера. Выведите сообщение о первом нарушенном правиле: длина, GC-состав или конец. Если все правила выполнены, выведите подходит.

Входные данные

Одна строка: последовательность из прописных букв A, C, G, T длиной от 1 до 40.

Выходные данные

Одно слово: длина, GC-состав, конец или подходит.

Пример

Разберем пример

Ввод ATGCAGTCCAGTACGGATCC
→
Вывод подходит

Длина 20 попадает в 18–25, GC-состав 11 из 20 = 55 % попадает в 40–60, последняя буква C. Все три правила выполнены.

Контекст

GC-состав считают как (G + C) / длина · 100. Правила проверяют по порядку, поэтому сообщение дает первое нарушенное; последнюю букву проверяют через индекс -1.

Основные определения

  • ПЦР — полимеразная цепная реакция: многократное копирование участка ДНК.
  • Праймер — короткая последовательность нуклеотидов, с которой начинается копирование.
  • GC-состав — доля букв G и C в процентах от длины последовательности.
  • Индекс -1 — последний символ строки.
  • Порядок проверок — первое нарушенное правило задает сообщение.
Подсказка
  1. Прочитайте последовательность: primer = input().
  2. Сосчитайте GC-состав: сложите primer.count("G") и primer.count("C"), поделите на len(primer), умножьте на 100 и запишите в gc.
  3. Проверки по порядку: not 18 <= len(primer) <= 25, затем not 40 <= gc <= 60, затем конец: primer[-1] != "G" and primer[-1] != "C".
  4. Выведите сообщение о первом нарушенном правиле или подходит; сверьтесь с примером: ATGCAGTCCAGTACGGATCC подходит, а ATTAGCATTAATCAT — длина.

Задача со звездочкой 3.8. Обозначение лунки

Условие задачи

Планшетом называют пластину с углублениями, лунками, в которые ставят пробы. В 96-луночном планшете 8 рядов от A до H и 12 столбцов. Лунку обозначают буквой ряда и двузначным номером столбца от 01 до 12, например B07. Лунки нумеруют по рядам: A01 имеет номер 1, A12 номер 12, B01 номер 13, H12 номер 96. Дан номер лунки. Выведите ее обозначение или слова неверный номер, если лунки с таким номером в планшете нет.

Входные данные

Одна строка: целое число от −10 до 200.

Выходные данные

Обозначение лунки (буква и двузначный номер столбца) или слова неверный номер.

Пример

Разберем пример

Ввод 31
→
Вывод C07

Считая с нуля, номер 31 становится 30: 30 // 12 = 2 — это третий ряд C, а 30 % 12 = 6 — седьмой столбец 07.

Примеры
ВводВывод
 
31
C07
0
неверный номер
Контекст

Обозначение собирают обратно из номера: ряд — целая часть от деления number − 1 на 12, столбец — остаток от деления плюс 1. Двузначный номер столбца дополняют нулем слева через условное выражение.

Основные определения

  • Планшет — пластина с углублениями, лунками, в которые ставят пробы.
  • Лунка — одно углубление планшета.
  • Ряд и столбец — ряд обозначают буквой от A до H, столбец — номером от 01 до 12.
  • Функция chr() — возвращает символ по его коду.
  • Оператор // — целочисленное деление: отбрасывает дробную часть.
Подсказка
  1. Прочитайте номер: number = int(input()).
  2. Номер допустим, если 1 <= number <= 96.
  3. Сохраните ряд и столбец: row = chr(ord("A") + (number - 1) // 12), column = (number - 1) % 12 + 1.
  4. Соберите обозначение, дописав ноль перед однозначным столбцом: row, затем "0", если column < 10, и str(column); сверьтесь с примером: 31 дает C07, а 0 — неверный номер.

Задача со звездочкой 3.8. Поворот планшета

Условие задачи

Планшетом называют пластину с углублениями, лунками, в которые ставят пробы. В 96-луночном планшете 8 рядов от A до H и 12 столбцов. Лунку обозначают буквой ряда и двузначным номером столбца от 01 до 12, например B07. Если планшет поставить в прибор повернутым на 180 градусов, лунка A01 окажется на месте H12, а A02 на месте H11: ряд A меняется местами с H, B с G и так далее, а столбец 1 со столбцом 12, 2 с 11 и так далее. Дано обозначение лунки. Проверьте его и выведите обозначение лунки, на месте которой она окажется, или сообщение о первой найденной ошибке.

Входные данные

Одна строка длиной от 0 до 10 символов.

Выходные данные

Обозначение лунки после поворота (буква и двузначный номер столбца). Если обозначение неверно, сообщение о первой ошибке в таком порядке проверки: неверная длина, если длина не равна 3; неверный ряд, если первый символ не прописная буква от A до H; неверный столбец, если два последних символа не число от 01 до 12.

Пример

Разберем пример

Ввод B03
→
Вывод G10

Ряд B зеркален ряду G, а столбец 03 — столбцу 10 (в сумме 13). После поворота лунка B03 оказывается на месте G10.

Примеры
ВводВывод
 
B03
G10
C1
неверная длина
Контекст

При повороте на 180 градусов ряд A переходит в H, B в G, и так далее: номер буквы заменяется на 8 минус его номер. Столбец 1 переходит в 12, 2 в 11: новый номер — 13 минус старый.

Основные определения

  • Планшет — пластина с углублениями, лунками, в которые ставят пробы.
  • Лунка — одно углубление планшета.
  • Поворот на 180 градусов — ряд A меняется местами с H, B с G; столбец 1 с 12, 2 с 11.
  • Функции chr() и ord() — переводят код в символ и обратно.
Подсказка
  1. Прочитайте обозначение: well = input().
  2. Проверки по порядку, как в упражнении 3.8.1: длина, ряд, столбец; при ошибке выведите сообщение и остановитесь.
  3. Новый ряд: chr(ord("A") + ord("H") - ord(well[0])); новый столбец: 13 - int(well[1:]).
  4. Соберите обозначение с нулем перед однозначным столбцом и выведите; сверьтесь с примером: B03 дает G10, а C1 — неверная длина.
