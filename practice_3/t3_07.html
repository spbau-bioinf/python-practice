None и is

20 минутЕрофеев А. И.

Научиться обозначать отсутствие значения через None, проверять его оператором is и не путать отсутствие значения с нулем и пустой строкой.

1. Значения нет: None

Теория

Пустая строка означает «строка есть, но в ней ничего нет». Ноль означает «измерили и получили ноль». А бывает, что значения нет совсем: анализ еще не проводили, прибор не дал результата, поле не заполнили. Такой случай нужно отличать от пустого и от нулевого значения.

Отсутствие значения в Python обозначает специальный объект None. Это единственный объект типа NoneType: во всей программе None один. Он не равен ни 0, ни "", хотя в условии, как и они, ложен (страница 06).

None возвращает функция, которая ничего не возвращает явно. Например, print() печатает текст, но результата не отдает: после result = print("A") в переменной result лежит None. Свои функции вы будете писать в теме 7 «Функции и декомпозиция».

Чаще всего None служит начальным значением переменной, которая получит настоящее значение только в одной из ветвей: mass = None, а затем mass = float(text), если поле заполнено.

В биоинформатических программах None встречается часто. Функция readfq Хэна Ли, которую разбирает книга В. Буффало «Bioinformatics Data Skills», читает записи файлов FASTA и FASTQ и для каждой возвращает идентификатор, последовательность и строку качества прочтения. У записи FASTA качества нет, и вместо него приходит None.

Пример

Что такое None

Предскажите вывод.

none.py
result = print("A")           # → A
print(result)                 # → None
print(type(None))             # → <class 'NoneType'>
print(None == 0, None == "")  # → False False
Вывод
A
None
<class 'NoneType'>
False False
  1. Строка 1: print() печатает A и возвращает None.
  2. Строка 2: None печатается словом None.
  3. Строка 4: None не равен ни нулю, ни пустой строке.
Практика

Введите в поле ввода число, а затем запустите программу с пустым вводом. Что напечатано во втором случае?

try_none.py
text = input()
mass = None
if text:
    mass = float(text)
print(mass)  # → 2.5
Вывод
2.5
2.5

2. == и is

Теория

Два близнеца одинаковы, но это два разных человека. Так и с объектами: два значения могут быть равны и при этом быть разными объектами в памяти. Ссылочную модель, в которой имя указывает на объект, вы видели на странице 04 первой практики.

Оператор == отвечает на вопрос «равны ли значения». Оператор is отвечает на вопрос «один ли это объект». Равные значения не обязаны быть одним объектом. is not дает противоположный ответ.

None существует в одном экземпляре, поэтому его проверяют через is: x is None и x is not None. Во всех остальных случаях значения сравнивают через ==.

Проверка x == None тоже работает, но руководство по стилю PEP 8 требует сравнивать с None только через is или is not и никогда через ==: вопрос «это он?» точнее вопроса «равен ли ему». Проверка на None почти единственный частый случай, где нужен is. Если сомневаетесь, пишите ==.

Пример

Проверка на None

is_none.py
quality = None
print(quality is None)      # → True
print(quality is not None)  # → False
reads = 0
print(reads is None)        # → False
Вывод
True
False
False
  1. Строки 2–3: строки качества нет, и is None это подтверждает.
  2. Строка 5: ноль прочтений это значение, а не его отсутствие.
Подробнее: почему is с числами «иногда работает»

Для списков a = [1, 2, 3] и b = [1, 2, 3] выражение a == b истинно, а a is b ложно: это два разных списка с одинаковым содержимым (списки разбираются в теме 5 «Списки и кортежи»). С небольшими целыми числами is иногда отвечает True: интерпретатор CPython заранее создает целые от −5 до 256 в одном экземпляре. Для больших чисел и для строк ответ зависит от того, как получено значение. Полагаться на это нельзя, поэтому значения сравнивают через ==.

Практика

Поставьте в seq_id значение None, затем пустую строку. Для какого из двух значений is None дает True?

try_is.py
seq_id = "NM_000546"
print(seq_id is None)  # → False
print(seq_id == "")    # → False
Вывод
False
False

3. not x и x is None

Теория

Проверка if not x: истинна для всех ложных значений сразу: для None, для нуля и для пустой строки. Поэтому она не отличает «значения нет» от «значение равно нулю». Последовательность из одних A и T имеет GC-состав ровно 0.0, и это честный результат; if not gc: примет его за отсутствие результата.

Если ноль или пустая строка могут быть настоящим значением, отсутствие значения проверяют через x is None, а не через not x.

Пример

GC-состав равен нулю

Предскажите, сколько раз программа напечатает сообщение.

not_vs_none.py
gc = 0.0
if not gc:
    print("GC не посчитан")  # → GC не посчитан
if gc is None:
    print("GC не посчитан")
Вывод
GC не посчитан
  1. Строка 2: not 0.0 истинно, и программа ошибочно сообщает, что результата нет.
  2. Строка 4: 0.0 не None, и вторая проверка отвечает верно.

Три состояния одного поля

Программа ждет ввода. Пользователь набирает 0 и нажимает Enter.

three_states.py
text = input()
reads = None
if text:
    reads = int(text)
if reads is None:
    print("не измерено")
else:
    print("прочтений:", reads)  # → прочтений: 0
Вывод
0
прочтений: 0

У поля три состояния: пустое (значения нет, reads остается None), ноль и положительное число. Проверка is None отделяет первое состояние от двух других. С if not reads: ноль прочтений превратился бы в «не измерено».

Практика

Программа считает ноль прочтений отсутствием измерения. Замените проверку на is None и запустите с вводом 0 и с пустым вводом.

try_zero.py
text = input()
reads = None
if text:
    reads = int(text)
if not reads:
    print("не измерено")  # → не измерено
else:
    print("прочтений:", reads)
Вывод
0
не измерено

Что нужно сделать

Выходные данные

Упражнение 3.7.1. Первый цикл выше порога

Что нужно сделать

Флуоресценцию измерили в циклах 0, 1 и 2, но некоторые измерения могли не записаться: их поля пустые. Найдите номер первого цикла, в котором измерение есть и оно строго больше порога. Если такого цикла нет, выведите нет сигнала.

Подсказка

Незаписанное измерение удобно хранить как None, но сравнивать None с числом нельзя: сначала проверьте, что значение есть (страница 03). Найденный номер цикла тоже можно хранить в переменной, начав с None. Подумайте, чем опасна проверка if not cycle:.
