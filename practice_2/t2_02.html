Срезы

30 минутЕрофеев А. И.

Научиться вырезать из строки участок по границам, пропускать границы, брать символы с шагом и разворачивать строку.

1. Срез: границы между символами

Теория

Индекс дает один символ. Первые три буквы можно достать тремя индексами и склеить, но для первых трехсот так уже не сделать. Нужен способ сказать сразу «от сих до сих»: так из последовательности берут кодон, праймер, участок гена.

Срез — часть строки между двумя границами, которую записывают s[start:stop].

Индексы удобно представлять не под символами, а на границах между ними, как метки на линейке. Метка 0 стоит перед первым символом, метка 6 после последнего символа строки "Python". Срез s[2:5] режет строку по меткам 2 и 5, внутри оказываются символы с индексами 2, 3 и 4.

Схема: индексы как метки на линейке
метка   0   1   2   3   4   5   6
        │ P │ y │ t │ h │ o │ n │
s[2:5]          └───────────┘
                    'tho'

Символ с индексом start входит в срез, символ с индексом stop не входит. Если обе границы неотрицательные, не выходят за пределы строки и start не больше stop, в срезе ровно stop − start символов.

Правило «start входит, stop нет» кажется странным, пока индексы стоят под буквами. На линейке оно очевидно: режем по двум меткам и берем то, что между ними. Отсюда и проверка длиной: у среза s[2:5] длина 5 − 2 = 3. Если в ответе получилось четыре символа, где-то ошибка на единицу.

Позиции в биологии нумеруют с 1 и указывают включительно: «участок с позиции 7 по позицию 12». Начальная позиция 7 соответствует индексу 6, а конечная граница среза остается 12, потому что stop в срез не входит. Получается срез s[6:12] длиной 12 − 7 + 1 = 6.

Пример

Кодоны срезами

codons.py
seq = "ATGCGTACCTGA"
print(seq[0:3])       # → ATG
print(seq[3:6])       # → CGT
print(seq[9:12])      # → TGA
print(len(seq[3:6]))  # → 3
Вывод
ATG
CGT
TGA
3
  1. Последовательность из четырех кодонов, 12 нуклеотидов.
  2. Первый кодон: символы с индексами 0, 1 и 2.
  3. Второй кодон начинается там, где закончился первый: граница 3 общая.
  4. Четвертый кодон: индексы 9, 10 и 11; граница 12 совпадает с длиной строки.
  5. Проверка длиной: 6 − 3 = 3 символа.

Участок по позициям

Участок гена задан позициями с 7 по 12 включительно, нумерация с 1.

region.py
gene = "TTGACAATGGCTAAAGGT"
start = 7
end = 12
region = gene[start - 1:end]
print(region)       # → ATGGCT
print(len(region))  # → 6
Вывод
ATGGCT
6
  1. Строка 4: начальная позиция переводится в индекс вычитанием единицы, конечная граница остается 12.
  2. Строки 5–6: шесть нуклеотидов, столько и должно быть в участке с 7 по 12.

Типичная ошибка: stop считают последним символом среза

Неверно: два символа вместо трех
seq = "ATGCGTACCTGA"
print(seq[0:2])  # → AT
Вывод
AT
Верно
seq = "ATGCGTACCTGA"
print(seq[0:3])  # → ATG
Вывод
ATG

Кажется, что seq[0:2] берет символы от 0 до 2 включительно. Но символ с индексом stop в срез не входит. Проверка длиной сразу показывает ошибку: 2 − 0 = 2, а в кодоне три нуклеотида.

Практика

Измените границы так, чтобы программа напечатала кодон CCC, а затем стоп-кодон TAA в конце последовательности.

try_slice.py
seq = "ATGAAACCCGGGTAA"
print(seq[0:3])  # → ATG
Вывод
ATG

2. Пропуск границ, шаг и разворот

Теория

Чаще всего нужен не участок в середине, а начало, конец или вся строка, прочитанная по-особому: каждый третий нуклеотид, последовательность с конца. Для этого у среза есть сокращения и третье число, шаг.

Любую из границ можно не указывать. Без start срез идет от начала строки, без stop до конца: s[:3] дает первые три символа, s[3:] все символы начиная с индекса 3. Границы бывают отрицательными: s[-3:] дает три последних символа при любой длине строки.

Третье число задает шаг: s[start:stop:step]. Срез s[::2] берет каждый второй символ начиная с первого. Шаг -1 проходит строку справа налево, поэтому s[::-1] разворачивает строку.

Срез не выдает IndexError: граница за пределами строки просто останавливается на ее конце, и s[2:100] дает все символы начиная с индекса 2. Если при положительном шаге граница start стоит на линейке не левее stop, срез пустой: s[3:3] и s[4:2] дают ''.

Срезы строки s = "Python":

СрезЧто беретРезультат
s[:3]первые три символа'Pyt'
s[3:]все начиная с индекса 3'hon'
s[-3:]три последних символа'hon'
s[:]всю строку целиком'Python'
s[3:3]ничего, пустая строка''
s[::2]каждый второй с индекса 0'Pto'
s[1::2]каждый второй с индекса 1'yhn'
s[::-1]строку в обратном порядке'nohtyP'
s[2:100]все с индекса 2, без ошибки'thon'

При отрицательном шаге срез идет справа налево, и границы читаются в обратном порядке: start стоит правее stop. Срез "Python"[4:1:-1] берет символы с индексами 4, 3 и 2, получается 'oht'. Линейка здесь уже не помогает: символ с индексом start по-прежнему входит в срез, а символ с индексом stop нет.

Разворот [::-1] понадобится для обратной комплементарной цепи ДНК на странице 05: вторую цепь читают в обратном направлении.

Пример

Начало, конец, шаг

slices.py
seq = "ATGCGTACCTGA"
print(seq[:3])     # → ATG
print(seq[-3:])    # → TGA
print(seq[::2])    # → AGGACG
print(seq[::-1])   # → AGTCCATGCGTA
print(seq[5:100])  # → TACCTGA
Вывод
ATG
TGA
AGGACG
AGTCCATGCGTA
TACCTGA
  1. Строки 2–3: первый и последний кодон без вычисления длины.
  2. Строка 4: символы с индексами 0, 2, 4, 6, 8, 10.
  3. Строка 5: вся последовательность справа налево.
  4. Строка 6: граница 100 далеко за концом строки, но ошибки нет: срез заканчивается на последнем символе.

Отрицательный шаг и пустой срез

negative_step.py
text = "Python"
print(text[4:1:-1])    # → oht
print(text[::-2])      # → nhy
print(text[:])         # → Python
print(len(text[3:3]))  # → 0
Вывод
oht
nhy
Python
0
  1. Строка 2: справа налево от индекса 4 до индекса 1, сам символ с индексом 1 не входит.
  2. Строка 3: каждый второй символ, начиная с последнего.
  3. Строка 4: пропущены обе границы, получена вся строка.
  4. Строка 5: границы совпадают, в срезе нет символов, длина 0.

Типичная ошибка: -1 как конец строки

Неверно: последний символ потерян
seq = "ATGCGTACCTGA"
print(seq[-3:-1])  # → TG
Вывод
TG
Верно
seq = "ATGCGTACCTGA"
print(seq[-3:])  # → TGA
Вывод
TGA

Граница -1 стоит перед последним символом, а не после него, поэтому последний символ в срез не попадает. Чтобы дойти до конца строки, конечную границу пропускают.

Практика

Поменяйте шаг на -2, затем на 3. Предскажите результат до запуска и сравните.

print(seq[::-1])  # → AGTCCATGCGTA
Вывод
