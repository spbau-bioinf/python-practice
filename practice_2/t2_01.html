Строки и индексы

20 минутЕрофеев А. И.

Научиться записывать строки с кавычками и специальными символами, брать символ строки по индексу с начала и с конца и находить длину строки.

Как устроены упражнения. Программа читает данные функцией input() без текста приглашения, каждое значение со своей строки. Функция input() и так возвращает строку, поэтому последовательность читают просто: seq = input(). Число преобразуют сразу при вводе: p = int(input()).

1. Строка и кавычки

Теория

Имя файла reads_01.fastq, идентификатор записи, последовательность ДНК, строка таблицы: для Python это значения одного типа str. Числа складывают, а текст режут, в нем ищут, из него собирают. Эта страница о том, как строку записать и как добраться до отдельного символа.

Строка (тип str) — неизменяемая последовательность символов.

Символы стоят в строгом порядке, у каждого есть номер: строки "ACG" и "GCA" состоят из одних букв, но это разные строки. Отдельного типа «символ» нет: один символ тоже строка, только длины 1. Что значит «неизменяемая», разобрано на странице 03.

Строку пишут в одинарных или двойных кавычках: для Python они равноправны, нужно только, чтобы строка начиналась и заканчивалась кавычкой одного вида. Внутри одинарных кавычек можно писать двойные, и наоборот. Две кавычки подряд, "", дают пустую строку: в ней нет ни одного символа.

Обратный слеш \ в строке говорит Python, что следующий знак особый. \n переносит строку, \t ставит табуляцию; на вид это два знака, а в строке один символ. \\ дает сам обратный слеш, \" кавычку внутри строки в таких же кавычках. Такая запись называется экранированием. Текст из нескольких строк удобно писать в тройных кавычках """…""": переносы сохраняются как есть.

Запись в строкеЧто означаетСтрока в кодеСимволов в ней
\nперевод строки"A\nT"3
\tтабуляция"A\tT"3
\\обратный слеш"C:\\data"7
\"двойная кавычка"\"ok\""4
\'одинарная кавычка'it\'s'4

Кавычки в коде только прямые. «Елочки» и “лапки”, которые подставляет текстовый редактор, Python кавычками не считает, и программа завершается ошибкой SyntaxError. Выберите для своей программы один вид кавычек и держитесь его; в этой практике строки записаны в двойных.

Функция print() печатает строку без кавычек. Когда Python показывает строку как значение (например, в интерактивном режиме), он добавляет кавычки, обычно одинарные: так видно, где строка начинается и где кончается.

Пример

Как создать строку

create.py
sample_id = "S12"
species = 'Homo sapiens'
empty = ""
print(type(sample_id))  # → <class 'str'>
print(bool(empty))      # → False
label = 'Проба "контроль"'
print(label)            # → Проба "контроль"
Вывод
<class 'str'>
False
Проба "контроль"
  1. Строка в двойных кавычках.
  2. Строка в одинарных кавычках: тип тот же, str.
  3. Пустая строка: две кавычки подряд, символов нет.
  4. Тип значения str.
  5. Пустая строка считается ложью (страница 05 первой практики), поэтому bool() дает False.
  6. Внутри одинарных кавычек стоят двойные, экранировать их не нужно.
  7. print() печатает строку без внешних кавычек.

Специальные символы

escape.py
print("GAT\tCCA")               # → GAT	CCA
print("5 мкл\n10 мкл")
print("C:\\data\\reads.fastq")  # → C:\data\reads.fastq
print("Файл \"gene.fasta\"")    # → Файл "gene.fasta"
Вывод
GAT	CCA
5 мкл
10 мкл
C:\data\reads.fastq
Файл "gene.fasta"
  1. Строка 1: \t заменился табуляцией, между частями широкий отступ.
  2. Строка 2: \n перенес вторую часть на новую строку, поэтому одна команда print() напечатала две строки.
  3. Строка 3: каждая пара \\ дала один обратный слеш.
  4. Строка 4: \" позволил поставить двойные кавычки внутри строки в двойных кавычках.

Типичная ошибка: путь Windows без экранирования

Неверно: \n и \t внутри пути
path = "C:\new_data\table.txt"
print(path)
Вывод
C:
ew_data	able.txt
Верно
path = "C:\\new_data\\table.txt"
print(path)  # → C:\new_data\table.txt
Вывод
C:\new_data\table.txt

Сочетания \n и \t в пути сработали как перевод строки и табуляция. Сообщения об ошибке нет, неверен только вывод, поэтому такую ошибку легко пропустить. Каждый обратный слеш в пути пишут двойным.

Замените \n на \t и запустите: сколько строк теперь напечатано? Затем уберите специальный символ совсем и сравните все три вывода.

2. Индекс символа

Теория

Строка хранит одно значение, но составное: внутри шесть букв слова "Python", и каждую можно достать отдельно. Для этого у каждого символа есть номер.

Индекс — номер символа в строке.

Индекс считают с нуля: он показывает, на сколько шагов символ отстоит от начала строки, а первый символ отстоит на ноль шагов. Символ получают записью строка[индекс]: text[0] дает первый символ.

У каждого символа есть и второй индекс, отрицательный: счет с конца начинается с -1. Запись text[-1] дает последний символ, какой бы длины ни была строка, text[-2] дает предпоследний. Нуля среди отрицательных индексов нет: он уже занят первым символом.

По порядку1-й2-й3-й4-й5-й6-й
СимволPython
Индекс с начала012345
Индекс с конца−6−5−4−3−2−1

Счет с нуля удобен тем, что индекс равен смещению от начала строки. Так устроены индексы в большинстве языков программирования, и к нему быстро привыкают.

Биологи нумеруют позиции нуклеотидов с единицы: позиция 1 соответствует индексу 0, позиция 10 индексу 9. Если в условии или в описании гена дана позиция, перед обращением к строке из нее вычитают единицу.

Пример

Символ по индексу

index.py
seq = "ATGCGTAC"
print(seq[0])   # → A
print(seq[3])   # → C
print(seq[-1])  # → C
print(seq[-3])  # → T
Вывод
A
C
C
T
  1. Строка 2: индекс 0 дает первый нуклеотид.
  2. Строка 3: индекс 3 дает четвертый нуклеотид: перед ним три символа.
  3. Строка 4: индекс −1 дает последний нуклеотид.
  4. Строка 5: индекс −3 дает третий с конца.

Один символ, два индекса

two_indexes.py
text = "Python"
print(text[2])            # → t
print(text[-4])           # → t
print(text[-2])           # → o
print(text[5], text[-1])  # → n n
Вывод
t
t
o
n n
  1. Строки 2–3: индексы 2 и −4 указывают на один и тот же символ, это видно и по таблице выше.
  2. Строка 4: −1 дает n, −2 дает o: счет с конца начинается с −1, поэтому −2 указывает на предпоследний символ.
  3. Строка 5: последний символ доступен и индексом 5, и индексом −1.

Типичная ошибка: счет с единицы

Неверно: это второй нуклеотид
seq = "ATGCGTAC"
print(seq[1])  # → T
Вывод
T
Верно
seq = "ATGCGTAC"
print(seq[0])  # → A
Вывод
A

Первый нуклеотид отстоит от начала на ноль шагов, поэтому его индекс 0. Программа печатает второй символ и не сообщает ни о какой ошибке.

Практика

Напечатайте предпоследний нуклеотид двумя способами: индексом с начала и индексом с конца.

try_index.py
seq = "ATGCGTAC"
print(seq[0])  # → A
Вывод
A

3. Длина и границы строки

Теория

Длина последовательности нужна почти в каждом расчете: GC-состав, число кодонов, доля позиций. Функцию len() вы уже встречали на странице 05 первой практики; здесь важно, как длина связана с индексами.

Функция len() возвращает число символов строки, включая пробелы и невидимые символы: len("A\tT") дает 3. Индексы с начала идут от 0 до len(s) - 1, с конца от -len(s) до -1. Поэтому последний символ можно получить и как s[len(s) - 1], но запись s[-1] короче.

Индекс за пределами строки дает ошибку IndexError. Индекс обязан быть целым числом: s[1.5] и даже s[2.0] дают TypeError.

Сообщение об ошибке читают по последней строке. IndexError: string index out of range говорит, что индекс вышел за пределы строки. В строке из восьми символов индексы от 0 до 7, и символа с индексом 8 уже нет. Это ошибка на единицу: длина строки на единицу больше ее последнего индекса.

Индекс типа float не подходит, даже если его значение целое: Python не округляет индекс сам. Это важно, когда индекс получается вычислением: результат деления / всегда float (страница 06 первой практики), а // при целых операндах дает int.

Подробнее: текст ошибки в разных версиях Python

С версии 3.11 сообщение о нецелом индексе заканчивается названием типа: not 'float'. В Python 3.10 и более ранних версиях этой части нет, сообщение короче: string indices must be integers. Тип ошибки TypeError при этом тот же, поэтому искать причину по последней строке можно в любой версии.

Пример

Длина и последний индекс

length.py
seq = "ATGCGTAC"
print(len(seq))           # → 8
print(seq[len(seq) - 1])  # → C
print(seq[-len(seq)])     # → A
print(seq[8])
Вывод
8
C
A
Сообщение об ошибке
Traceback (most recent call last):
  File "length.py", line 5, in <module>
    print(seq[8])
          ~~~^^^
IndexError: string index out of range
  1. Строка 2: в строке восемь символов.
  2. Строка 3: последний индекс на единицу меньше длины, 8 − 1 = 7.
  3. Строка 4: самый маленький отрицательный индекс −8 указывает на первый символ.
  4. Строка 5: индекса 8 в строке нет, программа завершается ошибкой IndexError.

Нецелый индекс

float_index.py
seq = "ATGCGTAC"
print(seq[2])  # → G
print(seq[2.0])
Вывод
G
Сообщение об ошибке
Traceback (most recent call last):
  File "float_index.py", line 3, in <module>
    print(seq[2.0])
          ~~~^^^^^
TypeError: string indices must be integers, not 'float'
  1. Строка 2: целый индекс 2 дает третий символ.
  2. Строка 3: число 2.0 равно 2, но имеет тип float, и Python отказывается брать символ.
Практика

Программа завершается ошибкой. Исправьте выражение в квадратных скобках так, чтобы она печатала последний нуклеотид. Затем допишите в последовательность несколько букв: работает ли исправление при другой длине?

try_last.py
seq = "ATGCGTAC"
print(seq[len(seq)])
Сообщение об ошибке
Traceback (most recent call last):
  File "try_last.py", line 2, in <module>
    print(seq[len(seq)])
          ~~~^^^^^^^^^^
IndexError: string index out of range

Упражнение 2.1.1. Индекс с конца

Что нужно сделать

Позиции нуклеотидов биологи нумеруют с 1: первый нуклеотид стоит в позиции 1. Дана последовательность и позиция p. Выведите нуклеотид в этой позиции и отрицательный индекс, по которому к тому же нуклеотиду можно обратиться с конца строки.
