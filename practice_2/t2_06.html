split() и join()

20 минутЕрофеев А. И.

Научиться разбирать строку на части методом split(), брать нужную часть по индексу и собирать строку из частей методом join().

1. Разбор строки

Теория

В одной строке часто лежит сразу несколько значений: строка таблицы, заголовок записи, перечень идентификаторов. Можно найти разделители методом find() и отрезать куски срезами, но каждое новое поле добавляет еще один поиск и еще один срез.

Метод split(sep) режет строку по разделителю sep и возвращает список кусков. Сам разделитель в куски не попадает. Список в выводе выглядит как значения в квадратных скобках через запятую; что с ним делать, разобрано в разделе 2.

Без аргумента split() делит строку по любым пробельным символам, даже по нескольким подряд, а пробелы по краям пустых кусков не дают. С явным разделителем каждый разделитель режет строку, поэтому два пробела подряд при split(" ") дают пустой кусок.

Аргумент maxsplit ограничивает число разрезов: split(maxsplit=1) режет только по первому пробелу, и во втором куске остается вся остальная строка. Так отделяют идентификатор записи от комментария (страница 09).

Если разделителя в строке нет, split() возвращает список из одного куска, всей исходной строки. Разделитель может состоять из нескольких символов: split("; ") режет по точке с запятой вместе со следующим за ней пробелом.

Типичная ошибка: split(" ") при нескольких пробелах

Неверно: появился пустой кусок
line = "S12  blood 2.5"
print(line.split(" "))  # → ['S12', '', 'blood', '2.5']
Вывод
['S12', '', 'blood', '2.5']
Верно
line = "S12  blood 2.5"
print(line.split())  # → ['S12', 'blood', '2.5']
Вывод
['S12', 'blood', '2.5']

Между S12 и blood два пробела. Разделитель " " режет по каждому из них, и между ними оказывается пустая строка. Без аргумента split() считает несколько пробелов одним разделителем.

Пример

Разбор строки

split.py
line = "S12;blood;2.5"
parts = line.split(";")
print(parts)                     # → ['S12', 'blood', '2.5']
print("S12  blood 2.5".split())  # → ['S12', 'blood', '2.5']
header = "gene_1 length=231 type=dna"
print(header.split(maxsplit=1))  # → ['gene_1', 'length=231 type=dna']
Вывод
['S12', 'blood', '2.5']
['S12', 'blood', '2.5']
['gene_1', 'length=231 type=dna']
  1. Строки 2–3: строка разрезана по точкам с запятой на три куска, сами точки с запятой пропали.
  2. Строка 4: без аргумента два пробела подряд сработали как один разделитель.
  3. Строка 6: разрез только по первому пробелу, во втором куске пробел остался.
Практика

Посмотрите на пробелы в начале второго и третьего куска. Измените разделитель так, чтобы пробелов в кусках не осталось.

try_split.py
ids = "S1, S2, S3"
print(ids.split(","))  # → ['S1', ' S2', ' S3']
Вывод
['S1', ' S2', ' S3']

2. Список: результат split()

Необходимый минимум

Здесь только то, что нужно для работы с результатом split(). Подробно списки разбираются в теме 5 «Списки и кортежи».

Теория

Список — упорядоченный набор значений, который записывают в квадратных скобках через запятую: ["S12", "blood", "2.5"].

К элементу списка обращаются по индексу, как к символу строки: счет с нуля, отрицательные индексы считают с конца. parts[0] дает первый кусок, parts[-1] последний; индекс за пределами списка дает IndexError.

Каждый элемент списка, который вернул split(), — обычная строка. У него есть все методы строк: parts[1].upper(). Число из куска получают явно: float(parts[2]).

print() показывает список так, как его пишут в коде, поэтому строки внутри видны в кавычках. Отдельный элемент print() печатает как обычную строку, без кавычек.

Пример

Элементы списка

list_items.py
parts = "S12;blood;2.5".split(";")
print(parts[0])          # → S12
print(parts[-1])         # → 2.5
print(parts[1].upper())  # → BLOOD
volume = float(parts[2])
print(volume * 2)        # → 5.0
Вывод
S12
2.5
BLOOD
5.0
  1. Список из трех строк.
  2. Первый элемент, индекс 0, напечатан без кавычек.
  3. Последний элемент, индекс −1.
  4. У элемента есть методы строк.
  5. Кусок "2.5" превращен в число.
  6. С числом можно считать.
Практика

Выведите предпоследний элемент списка, а затем число символов в этом элементе функцией len().

try_list.py
parts = "P7;liver;frozen;0.8".split(";")
print(parts[1])  # → liver
Вывод
liver

3. Сборка строки

Теория

Метод join() делает обратное: склеивает куски в одну строку и вставляет между ними разделитель. Вызывают его у разделителя, а куски передают в скобках: ", ".join(parts). Разделитель может быть любой строкой, в том числе пустой: "".join(parts) склеивает куски вплотную.

Чтобы сменить разделитель, строку разбирают по старому и сразу собирают с новым: "-".join(line.split(";")).

Кажется естественным взять список и попросить его склеиться, но join() принадлежит строке, и эта строка служит разделителем. Так устроено потому, что собрать можно любой набор строк, не только список. Запомните порядок: сначала то, что встанет между кусками, потом точка и join, в скобках то, что склеивают.

Собирать можно только строки. Если среди кусков есть число, join() завершается ошибкой TypeError; число сначала превращают в строку функцией str().

Пример

Сборка с разделителем

join.py
names = ["S12", "S13", "S14"]
print(", ".join(names))           # → S12, S13, S14
print("".join(names))             # → S12S13S14
line = "ATG;GCC;TAA"
print("-".join(line.split(";")))  # → ATG-GCC-TAA
Вывод
S12, S13, S14
S12S13S14
ATG-GCC-TAA
  1. Строка 2: между элементами встала запятая с пробелом, после последнего разделителя нет.
  2. Строка 3: пустой разделитель склеил элементы вплотную.
  3. Строка 5: строка разобрана по точкам с запятой и собрана через дефис.

Типичная ошибка: join() у списка

Неверно: AttributeError
names = ["S12", "S13", "S14"]
print(names.join(", "))
Сообщение об ошибке
Traceback (most recent call last):
  File "join_error.py", line 2, in <module>
    print(names.join(", "))
          ^^^^^^^^^^
AttributeError: 'list' object has no attribute 'join'
Верно
names = ["S12", "S13", "S14"]
print(", ".join(names))  # → S12, S13, S14
Вывод
S12, S13, S14

У списка нет метода join. Разделитель пишут перед точкой, а список передают в скобках.

4. Собираем все вместе

Теория

Настоящая строка данных редко бывает аккуратной: поля разделены точкой с запятой, вокруг них лишние пробелы, регистр любой. Разбирают ее по шагам: очистить края и разрезать, взять куски по индексу и очистить каждый, поле с числом перевести функцией float(), результат собрать f-строкой.

Поля очищают по одному, потому что strip() убирает пробелы только по краям строки. Пробелы рядом с точкой с запятой стоят внутри записи, и после split(";") они оказываются на краях полей. Регистр приводят к одному виду у тех значений, которые потом сравнивают или печатают единообразно, как код пробы в примере.

Пример

Запись о пробе

record.py
record = "  s12 ; blood;  2.5 ; Vasilisa  "
parts = record.strip().split(";")
print(parts)
sample = parts[0].strip().upper()
tissue = parts[1].strip()
volume = float(parts[2].strip())
author = parts[3].strip()
print(f"{sample}: {tissue}, {volume} мл, записала {author}")  # → S12: blood, 2.5 мл, записала Vasilisa
Вывод
['s12 ', ' blood', '  2.5 ', ' Vasilisa']
S12: blood, 2.5 мл, записала Vasilisa
  1. Одна строка, четыре поля через точку с запятой, лишние пробелы.
  2. Сначала убраны пробелы по краям всей строки, затем строка разрезана на поля.
  3. У полей остались пробелы у разделителей: strip() всей строки их не трогает.
  4. Код пробы очищен и переведен в заглавные буквы.
  5. Название ткани очищено.
  6. Объем очищен и переведен в число.
  7. Имя очищено.
  8. Результат собран f-строкой.

Типичная ошибка: поле после split() не очищено

Неверно: пробел остался в поле
record = "S12; blood; 2.5"
parts = record.split(";")
print(parts[1] == "blood")  # → False
Вывод
False
Верно
record = "S12; blood; 2.5"
parts = record.split(";")
print(parts[1].strip() == "blood")  # → True
Вывод
True

После разрезания второе поле равно " blood", с пробелом в начале, и сравнение " blood" == "blood" дает False. Сообщения об ошибке нет: проверка просто не срабатывает. Очищайте каждое поле методом strip() сразу после split().

Что нужно сделать

Одна строка: не меньше трех полей через точку с запятой, без пробелов вокруг разделителей. Поле с тканью не пустое.

Упражнение 2.6.1. Сокращенное название вида

Что нужно сделать

В тексте статьи название вида после первого упоминания сокращают: от рода остается заглавная первая буква с точкой, вид пишут полностью строчными буквами, например H. sapiens. Название ввели небрежно: регистр любой, пробелы лишние. Выведите сокращенное название.

Подсказка

Элемент списка, который вернул split(), — обычная строка: у него есть и индексы, и методы строк.

Входные данные

Одна строка: род и вид латинскими буквами в любом регистре, между словами один или несколько пробелов, по краям могут быть пробелы.

Выходные данные

Сокращенное название: заглавная первая буква рода, точка, пробел, вид строчными буквами.

Примеры
Входные данныеВыходные данные
 
Homo sapiens
H. sapiens
  escherichia   COLI 
E. coli
