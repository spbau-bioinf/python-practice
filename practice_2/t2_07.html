f-строки

20 минутЕрофеев А. И.

Научиться вставлять в f-строку выражения, задавать число знаков, проценты и разделители разрядов, ширину поля и выравнивание.

1. Выражение в фигурных скобках

Теория

f-строки вы уже встречали на странице 09 первой практики: перед кавычкой стоит буква f, а в фигурных скобках значение, которое Python подставит в текст. В скобках может стоять любое выражение: имя, арифметика, индекс, вызов метода. Например, f"{name.upper()}: {len(seq)}".

Если после выражения поставить знак =, Python выведет и само выражение, и его значение: f"{gc=}" превращается в gc=37.5. Так удобно быстро проверить промежуточные значения.

Строковое значение в такой записи выводится в кавычках, как его пишут в коде: sample='s12'. Так видно, что это строка, и видны пробелы по ее краям, если они есть.

Пример

Выражения в f-строке

fstring.py
sample = "s12"
seq = "ATGCGTAA"
print(f"{sample.upper()}: {len(seq)} нт")  # → S12: 8 нт
print(f"{seq[:3]} ... {seq[-3:]}")         # → ATG ... TAA
gc = 37.5
print(f"{gc=}")                            # → gc=37.5
print(f"{sample=}, {gc=}")                 # → sample='s12', gc=37.5
Вывод
S12: 8 нт
ATG ... TAA
gc=37.5
sample='s12', gc=37.5
  1. Строка 3: в скобках вызов метода и функция len().
  2. Строка 4: в скобках срезы, начало и конец последовательности.
  3. Строки 6–7: знак = выводит имя и значение, строка показана в кавычках.

2. Формат числа

Теория

После выражения можно поставить двоеточие и описание формата. Формат .2f оставляет два знака после точки. Формат % переводит долю в проценты: умножает на 100 и добавляет знак %; .1% делает то же с одним знаком после точки. Формат , разделяет разряды числа запятыми, + всегда выводит знак числа.

ФорматЧто делаетЗаписьЧто получится
.2fдва знака после точкиf"{3.14159:.2f}"3.14
.1%проценты с одним знакомf"{0.4768:.1%}"47.7%
,разделитель разрядовf"{1234567:,}"1,234,567
+знак у любого числаf"{2.5:+}"+2.5

Формат меняет только вид числа в тексте: значение переменной не округляется и не меняется.

ФорматЧто делаетЗаписьЧто получится
%проценты, по умолчанию шесть знаковf"{0.75:%}"75.000000%
_разряды через подчеркиваниеf"{1234567:_}"1_234_567
.1eэкспоненциальная записьf"{1000000:.1e}"1.0e+06
dцелое число, только для intf"{42:d}"42
b, o, xдвоичная, восьмеричная, шестнадцатеричная записьf"{255:x}"ff
пробелпробел на месте знака у положительного числаf"{42: }" 42

Формат d подходит только для целых чисел: f"{2.5:d}" завершается ошибкой ValueError. Пробел на месте знака нужен, чтобы положительные и отрицательные числа в столбце стояли ровно.

Пример

Проценты, знаки, разряды

formats.py
gc = 0.4768
reads = 1234567
print(f"{gc:.1%}")        # → 47.7%
print(f"{gc * 100:.2f}")  # → 47.68
print(f"{reads:,}")       # → 1,234,567
print(f"{-0.25:+.2f}")    # → -0.25
print(f"{0.25:+.2f}")     # → +0.25
Вывод
47.7%
47.68
1,234,567
-0.25
+0.25
  1. Строка 3: доля 0,4768 выведена в процентах с одним знаком.
  2. Строка 4: то же число можно умножить на 100 самим и вывести с двумя знаками, но знак % тогда не добавится.
  3. Строка 5: разряды отделены запятыми.
  4. Строки 6–7: знак выведен у обоих чисел.
Практика

Выведите долю сначала без знаков после точки, затем с тремя знаками. Потом замените формат процентов на .3f: чем отличается результат?

try_percent.py

Вывод

3. Ширина поля и выравнивание

Теория

Число в описании формата задает ширину поля: сколько символов займет значение вместе с пробелами. Знак < прижимает значение к левому краю поля, > к правому, ^ ставит по центру. Строки по умолчанию прижимаются влево, числа вправо. Так выводят ровные колонки отчета.

Перед знаком выравнивания можно поставить символ-заполнитель: он займет место пробелов. Ширину и формат числа пишут вместе: f"{gc:>8.2f}" выводит число с двумя знаками в поле шириной 8. Части формата идут в таком порядке: заполнитель, выравнивание, ширина, разделитель разрядов, точность и тип, например f"{n:>12,}". Если значение длиннее поля, поле расширяется, и значение не обрезается.

Результаты для x = "test", вертикальная черта показывает конец поля:

ЗнакВыравниваниеЗаписьЧто получится
<по левому краюf"{x:<8}|"test    |
>по правому краюf"{x:>8}|"    test|
^по центруf"{x:^8}|"  test  |
символ перед знакомзаполнитель вместо пробеловf"{x:*^8}|"**test**|

Пробелы в конце строки на экране не видны. Поэтому в примерах после поля стоит вертикальная черта: по ней видно, где поле кончается. Если внутри f-строки нужна строка в кавычках, берут кавычки другого вида: f"{'S12':<8}". Так код работает и в версиях Python до 3.12, где кавычки того же вида внутри f-строки не допускались.

Пример

Поля и заполнители

align.py
print(f"{'S12':<8}|")           # → S12     |
print(f"{'S12':>8}|")           # →      S12|
print(f"{'S12':-^8}|")          # → --S12---|
print(f"{42:>6}|")              # →     42|
print(f"{47.6:>8.2f}|")         # →    47.60|
print(f"{'Sample_00012':<6}|")  # → Sample_00012|
Вывод
S12     |
     S12|
--S12---|
    42|
   47.60|
Sample_00012|
  1. Строки 1–2: строка из трех символов в поле шириной 8, пять пробелов справа или слева.
  2. Строка 3: заполнитель - вместо пробелов; лишний символ при нечетном остатке ушел вправо.
  3. Строка 4: число прижато вправо.
  4. Строка 5: ширина 8 и два знака после точки вместе.
  5. Строка 6: значение длиннее поля, поле расширилось.
Практика

Добавьте в обе строки разделитель разрядов для чисел и третью колонку: GC-состав 0.476 и 0.52 в процентах с одним знаком, в поле шириной 8.

try_table.py
print(f"{'S12':<6}{12500:>8}")  # → S12      12500
print(f"{'S7':<6}{980:>8}")     # → S7         980
Вывод
S12      12500
S7         980

Упражнение 2.7.1. Строка таблицы

Что нужно сделать

Выведите строку сводной таблицы по пробе из трех колонок: код пробы, число прочтений, GC-состав. Ширина колонок задана, поэтому строки разных проб встают одна под другой ровно.

Входные данные

Три строки: код пробы (латинские буквы, цифры и знак подчеркивания), число прочтений (целое, от 0 до 999 999 999), GC-состав долей (вещественное число от 0 до 1).

Выходные данные

Одна строка из трех полей подряд, без разделителей. Код пробы прижат влево в поле шириной 10. Число прочтений с разделителем разрядов , прижато вправо в поле шириной 12. GC-состав в процентах с одним знаком после точки прижат вправо в поле шириной 8. Если значение длиннее поля, поле расширяется и значение не обрезается.

Упражнение 2.7.1. Шкала GC-состава

Что нужно сделать

В текстовом отчете GC-состав показывают шкалой из 20 клеток в квадратных скобках. Каждые полные 5 % дают одну клетку #, остальные клетки заняты точками. После шкалы через пробел стоит сам процент, прижатый вправо в поле шириной 3, и знак %. Например, 47 % выглядят так: [#########...........]  47%.

Подсказка

Строку из знаков # можно получить повторением. Оставшиеся клетки заполнит точками формат с заполнителем и шириной 20.

Входные данные

Одна строка: целое число p от 0 до 100, GC-состав в процентах.

Выходные данные

Шкала из 20 клеток в квадратных скобках, пробел, процент в поле шириной 3 и знак %.
