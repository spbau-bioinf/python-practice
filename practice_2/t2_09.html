Последовательности ДНК

20 минутЕрофеев А. И.

Научиться считать длину, состав и GC-состав последовательности ДНК, разбирать строку описания записи FASTA и собирать строку отчета.

1. Состав и GC-состав

Теория

Для Python последовательность ДНК — обычная строка из букв A, C, G, T, и к ней применимо все, что было на предыдущих страницах. Длину дает len(), число каждого нуклеотида count().

GC-состав — доля гуанина и цитозина среди всех нуклеотидов последовательности, обычно в процентах: (число G + число C) / длина · 100.

В записях геномов строчными буквами помечают повторы (страница 04), а count("G") строчную g не видит. Поэтому перед подсчетом последовательность приводят к одному регистру. Результат округляют только при выводе, в f-строке.

Пара G–C связана тремя водородными связями, пара A–T двумя, и соседние GC-пары взаимодействуют сильнее. Участки, богатые GC, прочнее, и по GC-составу праймера оценивают температуру его плавления.

Приведенную к заглавным буквам копию кладут в отдельную переменную: исходная строка с пометками повторов может еще понадобиться (страница 05). Проверить подсчет удобно суммой: числа A, C, G и T вместе дают длину последовательности, если в ней нет других букв.

Пример

Длина и GC-состав

gc_content.py
raw = "GGCATTACGGATgccg"
print(raw.count("G"))             # → 4
seq = raw.upper()
print(len(seq))                   # → 16
gc = seq.count("G") + seq.count("C")
gc_percent = gc / len(seq) * 100
print(f"GC: {gc_percent:.1f} %")  # → GC: 62.5 %
Вывод
4
16
GC: 62.5 %
  1. Последовательность с повтором в конце, записанным строчными буквами.
  2. Подсчет без приведения регистра пропускает строчные g.
  3. Копия заглавными буквами.
  4. Длина последовательности.
  5. Число G и C вместе.
  6. Доля в процентах; значение не округляется.
  7. Округление до одного знака только при выводе.
Практика

Добавьте подсчет G и C и проверьте, что сумма четырех чисел равна длине последовательности.

print(len(seq))                        # → 17
Вывод

2. Строка описания FASTA и строка отчета

Теория

Последовательности хранят в формате FASTA, и почти любой анализ заканчивается таблицей: по строке на запись, в строке идентификатор и посчитанные величины. На этом шаге сходится вся практика: срезы, методы, split() и f-строки.

Запись FASTA начинается со строки описания: первым символом в ней стоит >, дальше до первого пробела идет идентификатор, после пробела свободный комментарий. Следом идет сама последовательность.

Метод removeprefix(">") убирает угловую скобку, только если строка с нее начинается. Затем split(maxsplit=1) разрезает описание по первому пробелу (страница 06): идентификатор попадает в элемент с индексом 0, а весь комментарий попадает в элемент с индексом 1, даже если в нем тоже есть пробелы.

Строку отчета собирают f-строкой, а колонки разделяют табуляцией \t. Такие таблицы открывают и электронные таблицы, и программы для анализа данных.

Метод removeprefix() появился в Python 3.9. Он убирает ровно одну приставку. Метод strip(">") работает иначе: он убирает с обоих краев все символы >, сколько бы их ни было.

Если в строке описания нет комментария, split(maxsplit=1) возвращает список из одного элемента, и обращение к элементу с индексом 1 дает IndexError. Идентификатор с индексом 0 есть всегда.

Пример

Разбор строки описания и строка отчета

fasta_report.py
header = ">gene_00284728 length=231;type=dna"
seq = "GAGAACTGATTCTGTTACCGCAGGGCATTCGG"
body = header.removeprefix(">")
parts = body.split(maxsplit=1)
seq_id = parts[0]
print(seq_id)                             # → gene_00284728
print(parts[1])                           # → length=231;type=dna
gc = (seq.count("G") + seq.count("C")) / len(seq) * 100
print(f"{seq_id}\t{len(seq)}\t{gc:.1f}")  # → gene_00284728	32	53.1
Вывод
gene_00284728
length=231;type=dna
gene_00284728	32	53.1
  1. Строка описания записи FASTA.
  2. Начало последовательности этой записи.
  3. Угловая скобка убрана.
  4. Разрез только по первому пробелу.
  5. Идентификатор.
  6. Печатается идентификатор.
  7. Печатается комментарий целиком.
  8. GC-состав последовательности.
  9. Строка отчета: три колонки через табуляцию.

Типичная ошибка: идентификатор вместе с >

Неверно: в идентификаторе осталась скобка
header = ">gene_00284728 length=231;type=dna"
print(header.split()[0])  # → >gene_00284728
Вывод
>gene_00284728
Верно
header = ">gene_00284728 length=231;type=dna"
print(header.removeprefix(">").split()[0])  # → gene_00284728
Вывод
gene_00284728

Угловая скобка обозначает начало записи и в идентификатор не входит. Сначала ее убирают, потом режут строку.

Упражнение 2.9.1. GC-состав

Условие задачи

Посчитайте GC-состав последовательности в процентах. Повторы в ней записаны строчными буквами: приведите последовательность к заглавным буквам до подсчета.

Входные данные

Одна строка: последовательность из букв A, C, G, T в любом регистре, длина от 1 до 100.

Выходные данные

GC-состав в процентах с одним знаком после точки, без знака %.

Разберем пример

Ввод GATTACA

Вывод 28.6

Контекст

GC-состав — доля букв G и C среди всех нуклеотидов; его считают по последовательности, приведенной к одному регистру. Долю переводят в проценты умножением на 100.

Основные определения

  • GC-состав — доля букв G и C среди всех нуклеотидов последовательности.

  • len() — возвращает число символов в строке.

  3. Доля в процентах: сумму seq.count("G") + seq.count("C") поделите на len(seq) и умножьте на 100.

Упражнение 2.9.1. Строка отчета

Условие задачи

Дана запись FASTA: строка описания и последовательность, в которой повторы записаны строчными буквами. Выведите строку отчета: идентификатор записи, длину последовательности и ее GC-состав.

Входные данные

Две строки. В первой строка описания: символ >, идентификатор без пробелов и, возможно, пробел и комментарий. Во второй последовательность из букв A, C, G, T в любом регистре, длина от 1 до 100.

Выходные данные

Одна строка из трех колонок через табуляцию: идентификатор без >, длина, GC-состав в процентах с одним знаком после точки.

ATGAAAccgggtTTTGGC
→
Вывод chr2_frag       18      50.0

GC-состав считают после приведения к заглавным: в последовательности из 18 нуклеотидов 9 — G или C, это 50.0 %.

Запись FASTA начинается строкой описания с символом >, за ней идет последовательность. В отчете идентификатор отделяют от комментария пробелом, а колонки — табуляцией.

Основные определения

  • FASTA — формат записи последовательностей: строка описания с символом > и последовательность.
  • Строка описания — первая строка записи: символ >, идентификатор и, возможно, комментарий.

  • Табуляция — символ разделения колонок, записывается как \t.
  • Метод removeprefix() — убирает заданное начало строки, если оно есть.
  • Метод split() — делит строку по разделителю; с maxsplit=1 делит только по первому пробелу.

  1. Прочитайте строку описания и последовательность: header = input(), seq = input().upper().

  3. Отделите идентификатор от комментария по первому пробелу: .split(maxsplit=1)[0].
  4. Посчитайте GC-состав и выведите три колонки через \t: f"{seq_id}\t{len(seq)}\t{gc:.1f}"; сверьтесь с примером: chr2_frag, 18, 50.0.

Упражнение 2.9.1. Отчет с GC3

Условие задачи

GC3 — GC-состав третьих позиций кодонов, по нему сравнивают, как организмы используют синонимичные кодоны. Дана запись FASTA с кодирующей последовательностью, которую читают кодонами с первого нуклеотида. Выведите строку отчета: идентификатор, длину, GC-состав и GC3.

Входные данные

Две строки. В первой строка описания: символ >, идентификатор без пробелов и, возможно, пробел и комментарий. Во второй последовательность из букв A, C, G, T в любом регистре, длина от 3 до 100; длина может не делиться на 3.

Выходные данные

Одна строка из четырех колонок через табуляцию: идентификатор без >, длина, GC-состав и GC3 в процентах с одним знаком после точки.

Пример

Разберем пример

Ввод >TP53_cds first 9 codons
ATGGAGGAGCCGCAGTCAGATCCTAGC
→
Вывод TP53_cds        27      59.3    66.7

В последовательности из 27 нуклеотидов 16 — G или C, это 59.3 %; третьи позиции девяти кодонов дают строку GGGGGATTC, в ней шесть G или C — 66.7 %.

Примеры
ВводВывод
 
>TP53_cds first 9 codons
ATGGAGGAGCCGCAGTCAGATCCTAGC
TP53_cds	27	59.3	66.7
>frag_7 partial
atgcatgcatgca
frag_7	13	46.2	50.0
Контекст

Третьи позиции кодонов идут через две: индексы 2, 5, 8 и так далее. Срез seq[2::3] выбирает их все сразу; если длина не делится на 3, последний неполный кодон третьей позиции не дает.

Основные определения

  • GC3 — GC-состав третьих позиций кодонов.
  • Кодон — тройка подряд идущих нуклеотидов.
  • Синонимичные кодоны — разные кодоны, которые кодируют одну и ту же аминокислоту.
  • Срез с шагом — seq[2::3] берет символы с индекса 2 через каждые три.
  • Табуляция — символ разделения колонок, записывается как \t.
Подсказка
  1. Прочитайте запись: header = input(), seq = input().upper(); идентификатор — как в предыдущем упражнении.
  2. Обычный GC-состав считается по всей длине, как раньше.
  3. Третьи позиции кодонов выбирает срез third = seq[2::3].
  4. GC3 — это сумма third.count("G") + third.count("C"), деленная на len(third) и умноженная на 100; выведите четыре колонки через \t; сверьтесь с примером: TP53_cds, 27, 59.3, 66.7.

Задача со звездочкой 2.9. GC-перекос последовательности

Условие задачи

GC-перекос (его также называют GC-асимметрией) показывает, каких нуклеотидов больше на цепи, G или C: он равен (count_g − count_c) / (count_g + count_c), где count_g и count_c — числа гуанинов и цитозинов. Повторы в последовательности записаны строчными буквами.

Входные данные

Одна строка: последовательность из букв A, C, G, T в любом регистре, длина от 1 до 100. В ней есть хотя бы одна буква G или C.

Выходные данные

GC-перекос с тремя знаками после точки.

Пример

Разберем пример

Ввод GGGCATTgc
→
Вывод 0.333

В GGGCATTgc четыре G и два C: (4 − 2) / (4 + 2) = 0.333.

Примеры
ВводВывод
 
GGGCATTgc
0.333
ATCCa
-1.000
Контекст

Перекос считают по последовательности: сначала считают G и C по отдельности, затем подставляют в формулу. В практике 1, в упражнении 1.10.1 среднего уровня, перекос считали по готовым числам, а здесь их нужно получить из последовательности.

Основные определения

  • GC-перекос — величина (count_g − count_c) / (count_g + count_c), показывающая перевес гуанина или цитозина.
  • Гуанин и цитозин — нуклеотиды G и C; их число считают методом count().
  • Метод upper() — переводит все буквы строки в заглавные.
  • Формат .3f — запись числа с тремя знаками после точки.
Подсказка
  1. Прочитайте последовательность: seq = input().upper().
  2. Сосчитайте буквы по отдельности: count_g = seq.count("G"), count_c = seq.count("C").
  3. Подставьте в формулу: разность count_g - count_c, деленную на сумму count_g + count_c.
  4. Выведите с тремя знаками после точки: разность count_g - count_c, деленную на сумму count_g + count_c, с форматом :.3f; сверьтесь с примером: GGGCATTgc дает 0.333.

Задача со звездочкой 2.9. GC-состав с пропусками

Условие задачи

Если секвенатор не смог определить нуклеотид, на его месте в последовательности ставят букву N. Такие позиции в GC-составе не учитывают: долю букв G и C считают только среди определенных нуклеотидов A, C, G, T. Дана запись FASTA. Выведите строку отчета: идентификатор записи, число позиций N и GC-состав среди определенных нуклеотидов.

Входные данные

Две строки. В первой строка описания: символ >, идентификатор без пробелов и, возможно, пробел и комментарий. Во второй последовательность из букв A, C, G, T, N в любом регистре длиной от 1 до 100; хотя бы одна буква в ней не N.

Выходные данные

Одна строка из трех колонок через табуляцию: идентификатор без >, число позиций N, GC-состав в процентах с одним знаком после точки.

Пример

Разберем пример

Ввод >ctg12 draft assembly
ATGNNNGCcgTA
→
Вывод ctg12   3       55.6

Три позиции N не учитывают; среди оставшихся девяти нуклеотидов пять — G или C, это 55.6 %.

Примеры
ВводВывод
 
>ctg12 draft assembly
ATGNNNGCcgTA
ctg12	3	55.6
>s1
nnGC
s1	2	100.0
Контекст

Пропуски N не относят ни к какому нуклеотиду, поэтому знаменатель доли — это длина без позиций N. Если их не исключить, GC-состав окажется заниженным.

Основные определения

  • Секвенатор — прибор для чтения ДНК.
  • N (пропуск) — буква на месте нуклеотида, который секвенатор не смог определить.
  • FASTA — формат записи: строка описания с символом > и последовательность.
  • Идентификатор — короткое имя записи без пробелов.
  • Табуляция — символ разделения колонок, записывается как \t.
Подсказка
  1. Прочитайте запись: header = input(), seq = input().upper(); идентификатор — как в упражнении 2.9.1.
  2. Число пропусков: count_n = seq.count("N").
  3. Определенных нуклеотидов len(seq) - count_n, поэтому GC-состав — сумма seq.count("G") + seq.count("C"), деленная на это число и умноженная на 100.
  4. Выведите три колонки через \t; сверьтесь с примером: ctg12, 3 пропуска, 55.6.

Задача со звездочкой 2.9. Пары CG

Условие задачи

Пара CpG состоит из соседних нуклеотидов C и G: в цепи за C сразу идет G, и в записи она выглядит как CG. Для поиска CpG-островков считают отношение наблюдаемого числа пар к ожидаемому: O/E = (число пар CG · длина) / (число C · число G) (источник: Gardiner-Garden, Frommer, 1987). Дана запись FASTA, повторы в последовательности записаны строчными буквами. Выведите идентификатор, GC-состав и отношение O/E.

Входные данные

Две строки. В первой строка описания: символ >, идентификатор без пробелов и, возможно, пробел и комментарий. Во второй последовательность из букв A, C, G, T в любом регистре длиной от 2 до 100; в ней есть хотя бы одна буква C и хотя бы одна буква G.

Выходные данные

Одна строка из трех колонок через табуляцию: идентификатор без >, GC-состав в процентах с одним знаком после точки, отношение O/E с двумя знаками после точки.

Пример

Разберем пример

Ввод ACGTTCGCGATCGGCCATG
→
Вывод isl_4   63.2    2.11

В последовательности 12 G или C из 19 — это 63.2 %; пар CG четыре, а C и G по шесть: (4 · 19) / (6 · 6) = 2.11.

Контекст

В геноме позвоночных пар CpG меньше, чем можно ожидать по числу букв C и G: цитозин в паре часто метилирован и со временем заменяется. Участки, где пар больше ожидаемого, называют CpG-островками; их ищут по отношению O/E.

Основные определения

  • CpG — пара соседних нуклеотидов C и G; в записи выглядит как CG.
  • CpG-островок — участок, где пар CpG больше ожидаемого по числу букв C и G.
  • Ожидаемое число пар — доля, которую составили бы пары CG при случайном расположении букв: (число C · число G) / длина.
  • Метод count() — считает вхождения подстроки; seq.count("CG") считает пары.
  • Табуляция — символ разделения колонок, записывается как \t.
Подсказка
  1. Прочитайте запись: header = input(), seq = input().upper(); идентификатор — как в упражнении 2.9.1.
  2. Сосчитайте count_c = seq.count("C"), count_g = seq.count("G") и число пар seq.count("CG").
  3. GC-состав — сумма count_c + count_g, деленная на len(seq) и умноженная на 100; отношение — seq.count("CG") * len(seq), деленное на count_c * count_g.
  4. Выведите три колонки: f"{seq_id}\t{gc:.1f}\t{ratio:.2f}"; сверьтесь с примером: isl_4, 63.2, 2.11.
