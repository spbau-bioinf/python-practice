Последовательности ДНК

20 минутЕрофеев А. И.

Научиться считать длину, состав и GC-состав последовательности ДНК, разбирать строку описания записи FASTA и собирать строку отчета.

1. Состав и GC-состав

Теория

Для Python последовательность ДНК — обычная строка из букв A, C, G, T, и к ней применимо все, что было на предыдущих страницах. Длину дает len(), число каждого нуклеотида count().

GC-состав — доля гуанина и цитозина среди всех нуклеотидов последовательности, обычно в процентах: (число G + число C) / длина · 100.

В записях геномов строчными буквами помечают повторы (страница 04), а count("G") строчную g не видит. Поэтому перед подсчетом последовательность приводят к одному регистру. Результат округляют только при выводе, в f-строке.

Пара G–C связана тремя водородными связями, пара A–T двумя, и соседние GC-пары взаимодействуют сильнее. Участки, богатые GC, прочнее, и по GC-составу праймера оценивают температуру его плавления.

Приведенную к заглавным буквам копию кладут в отдельную переменную: исходная строка с пометками повторов может еще понадобиться (страница 05). Проверить подсчет удобно суммой: числа A, C, G и T вместе дают длину последовательности, если в ней нет других букв.

Пример

Длина и GC-состав

gc_content.py
raw = "GGCATTACGGATgccg"
print(raw.count("G"))             # → 4
seq = raw.upper()
print(len(seq))                   # → 16
gc = seq.count("G") + seq.count("C")
gc_percent = gc / len(seq) * 100
print(f"GC: {gc_percent:.1f} %")  # → GC: 62.5 %
Вывод
4
16
GC: 62.5 %
  1. Последовательность с повтором в конце, записанным строчными буквами.
  2. Подсчет без приведения регистра пропускает строчные g.
  3. Копия заглавными буквами.
  4. Длина последовательности.
  5. Число G и C вместе.
  6. Доля в процентах; значение не округляется.
  7. Округление до одного знака только при выводе.
Практика

Добавьте подсчет G и C и проверьте, что сумма четырех чисел равна длине последовательности.

Вывод

2. Строка описания FASTA и строка отчета

Теория

Последовательности хранят в формате FASTA, и почти любой анализ заканчивается таблицей: по строке на запись, в строке идентификатор и посчитанные величины. На этом шаге сходится вся практика: срезы, методы, split() и f-строки.

Запись FASTA начинается со строки описания: первым символом в ней стоит >, дальше до первого пробела идет идентификатор, после пробела свободный комментарий. Следом идет сама последовательность.

Метод removeprefix(">") убирает угловую скобку, только если строка с нее начинается. Затем split(maxsplit=1) разрезает описание по первому пробелу (страница 06): идентификатор попадает в элемент с индексом 0, а весь комментарий попадает в элемент с индексом 1, даже если в нем тоже есть пробелы.

Строку отчета собирают f-строкой, а колонки разделяют табуляцией \t. Такие таблицы открывают и электронные таблицы, и программы для анализа данных.

Метод removeprefix() появился в Python 3.9. Он убирает ровно одну приставку. Метод strip(">") работает иначе: он убирает с обоих краев все символы >, сколько бы их ни было.

Если в строке описания нет комментария, split(maxsplit=1) возвращает список из одного элемента, и обращение к элементу с индексом 1 дает IndexError. Идентификатор с индексом 0 есть всегда.

Пример

Разбор строки описания и строка отчета

fasta_report.py
header = ">gene_00284728 length=231;type=dna"
seq = "GAGAACTGATTCTGTTACCGCAGGGCATTCGG"
body = header.removeprefix(">")
parts = body.split(maxsplit=1)
seq_id = parts[0]
print(seq_id)                             # → gene_00284728
print(parts[1])                           # → length=231;type=dna
gc = (seq.count("G") + seq.count("C")) / len(seq) * 100
print(f"{seq_id}\t{len(seq)}\t{gc:.1f}")  # → gene_00284728	32	53.1
Вывод
gene_00284728
length=231;type=dna
gene_00284728	32	53.1
  1. Строка описания записи FASTA.
  2. Начало последовательности этой записи.
  3. Угловая скобка убрана.
  4. Разрез только по первому пробелу.
  5. Идентификатор.
  6. Печатается идентификатор.
  7. Печатается комментарий целиком.
  8. GC-состав последовательности.
  9. Строка отчета: три колонки через табуляцию.

Типичная ошибка: идентификатор вместе с >

Неверно: в идентификаторе осталась скобка
header = ">gene_00284728 length=231;type=dna"
print(header.split()[0])  # → >gene_00284728
Вывод
>gene_00284728
Верно
header = ">gene_00284728 length=231;type=dna"
print(header.removeprefix(">").split()[0])  # → gene_00284728
Вывод
gene_00284728

Угловая скобка обозначает начало записи и в идентификатор не входит. Сначала ее убирают, потом режут строку.

Упражнение 2.9.1. Отчет с GC3

Что нужно сделать

GC3 — GC-состав третьих позиций кодонов, по нему сравнивают, как организмы используют синонимичные кодоны. Дана запись FASTA с кодирующей последовательностью, которую читают кодонами с первого нуклеотида. Выведите строку отчета: идентификатор, длину, GC-состав и GC3.

Подсказка

Третьи позиции всех полных кодонов можно одним срезом собрать в отдельную строку (страница 02). GC3 считают от длины этой строки, а не всей последовательности.

Входные данные

Две строки. В первой строка описания: символ >, идентификатор без пробелов и, возможно, пробел и комментарий. Во второй последовательность из букв A, C, G, T в любом регистре, длина от 3 до 100; длина может не делиться на 3.

Выходные данные

Одна строка из четырех колонок через табуляцию: идентификатор без >, длина, GC-состав и GC3 в процентах с одним знаком после точки.
