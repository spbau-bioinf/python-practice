Unicode и байты

15 минутЕрофеев А. И.

Научиться переводить символ в его номер Unicode и обратно, переводить строку в байты и объяснять, почему текст в чужой кодировке превращается в набор странных символов.

1. Символ и его номер

Теория

Python одинаково работает и с латиницей, и с кириллицей, хотя компьютер умеет хранить только числа. Значит, каждой букве кто-то присвоил номер. Этим занимается стандарт Unicode, общий для всего мира.

Кодовая точка — номер символа в стандарте Unicode.

Строка Python состоит из символов Unicode, поэтому ей все равно, на каком языке текст. Функция ord() возвращает номер символа: ord("П") дает 1055. Функция chr() делает обратное и возвращает символ по номеру: chr(1055) возвращает букву П.

Номера объясняют сравнение строк (страница 03): у заглавных латинских букв номера от 65 до 90, у строчных от 97 до 122, поэтому "Zebra" < "apple". Латинские буквы идут подряд, поэтому к номеру буквы можно прибавить число и получить букву дальше по алфавиту.

Кодовые точки лежат в диапазоне от 0 до 1 114 111. В документации их записывают шестнадцатеричным числом с приставкой U+: латинская A имеет номер U+0041, то есть 65, буква П номер U+041F, то есть 1055.

Функция ord() принимает ровно один символ. Строка из двух символов дает ошибку TypeError, как и пустая строка.

Пример

Номера символов

codepoints.py
print(ord("A"), ord("a"))  # → 65 97
print(ord("П"))            # → 1055
print(chr(1055))           # → П
print(chr(ord("A") + 2))   # → C
print("Zebra" < "apple")   # → True
Вывод
65 97
1055
П
C
True
  1. Строка 1: у заглавной и строчной A разные номера.
  2. Строки 2–3: ord() и chr() переводят символ в номер и обратно.
  3. Строка 4: номер A плюс 2 дает номер буквы на два места дальше.
  4. Строка 5: 90 меньше 97, поэтому Z стоит раньше a.

2. Байты и кодировка

Теория

В файл и в сеть текст уходит байтами. Правило, по которому символы переводят в байты, называют кодировкой. Самая распространенная кодировка UTF-8 записывает латинские буквы, цифры, пробел и знаки с клавиатуры одним байтом, русскую букву двумя.

Метод encode("utf-8") переводит строку в байты, тип bytes. Метод decode("utf-8") переводит байты обратно в строку. Функция len() у строки считает символы, а у bytes считает байты.

Если байты расшифровать не той кодировкой, текст превращается в набор странных символов. Данные при этом целы: их нужно прочитать в той кодировке, в которой их записали.

Значение типа bytes Python показывает с буквой b перед кавычками. Байты вне латиницы записаны через \x и две шестнадцатеричные цифры: b'\xd0\x9f' — это два байта буквы П.

UTF-8 записывает символ одним, двумя, тремя или четырьмя байтами, в зависимости от его номера. Символы с номерами до 127, то есть латиница, цифры и знаки клавиатуры, занимают один байт, русские буквы два, знак евро три. Старые кодировки, например cp1251 в Windows, отводят каждому символу один байт и поэтому умеют записать только часть символов Unicode. Когда появятся файлы, кодировку при их открытии будут указывать явно.

Пример

Символы и байты

bytes_demo.py
text = "Проба S12"
data = text.encode("utf-8")
print(len(text))              # → 9
print(type(data))             # → <class 'bytes'>
print(len(data))              # → 14
print(data[:4])               # → b'\xd0\x9f\xd1\x80'
print(data.decode("utf-8"))   # → Проба S12
print(data.decode("cp1251"))  # → РџСЂРѕР±Р° S12
Вывод
9
<class 'bytes'>
14
b'\xd0\x9f\xd1\x80'
Проба S12
РџСЂРѕР±Р° S12
  1. Строка 3: девять символов, считая пробел.
  2. Строки 4–5: в байтах 14, потому что каждая из пяти русских букв заняла два байта, а остальные четыре символа по одному.
  3. Строка 6: первые четыре байта, это буквы П и р.
  4. Строка 7: расшифровка той же кодировкой вернула текст.
  5. Строка 8: те же байты прочитаны как cp1251, и русская часть превратилась в набор странных символов; латиница не пострадала.
Практика

Посчитайте, сколько байтов в UTF-8 занимают слово ген и знак евро €. Сравните с числом символов.

try_bytes.py

Вывод

Задача со звездочкой 2.8. Верные концы прочтения

Что нужно сделать

Прочтением называют участок ДНК, который секвенатор, прибор для чтения ДНК, прочитал за один раз. В формате FASTQ качество каждого нуклеотида записано символом; в схеме Sanger оценка качества Q по шкале Phred равна номеру символа минус 33. Оценка связана с вероятностью ошибки p формулой p = 10−Q/10: оценке 20 соответствует ошибка с вероятностью 0,01 (источник: Ewing, Green, 1998). Дана строка качества прочтения. Найдите вероятность того, что первый и последний нуклеотиды прочитаны верно. Ошибки в разных позициях считайте независимыми: искомая вероятность равна произведению (1 − p1) · (1 − p2).

Входные данные

Одна строка качества длиной от 2 до 100 из символов с номерами от 33 до 126.

Выходные данные

Вероятность с четырьмя знаками после точки.
