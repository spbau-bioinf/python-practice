Регистр и поиск

30 минутЕрофеев А. И.

Научиться вызывать методы строк, менять регистр текста, искать и считать подстроки и проверять начало и конец строки.

1. Что такое метод

Теория

Индексами и срезами можно сделать почти все, но долго. Чтобы исправить название, набранное с нажатым Caps Lock, пришлось бы разбирать каждую букву. Для частых задач у строки есть готовые инструменты.

Метод — функция, которая принадлежит объекту и вызывается через точку после него: seq.upper().

Скобки после имени метода обязательны, даже если внутри пусто. Метод строки не меняет строку: строка неизменяема (страница 03). Он возвращает результат: новую строку, число, True или False. Поэтому результат сохраняют в переменную: seq = seq.upper().

Методов у строки несколько десятков, учить их наизусть не нужно. Список имен показывает dir(str), справку по одному методу help(str.upper). По группе метода сразу понятно, что он вернет.

ГруппаМетодыЧто возвращают
Регистрlower, upper, capitalize, title, swapcaseновую строку
Поиск и подсчетfind, rfind, countчисло
Начало и конецstartswith, endswithTrue или False
Проверка содержимогоisalpha, isdigit, isalnum, isspace, islower, isupperTrue или False
Очистка и заменаstrip, lstrip, rstrip, replaceновую строку

Первые три группы разобраны на этой странице, две последние на странице 05.

Метод похож на функцию: принимает аргументы и возвращает значение. Отличие в записи. У функции сначала ее имя, а объект в скобках: len(seq). У метода сначала объект, потом точка, имя метода и скобки с аргументами: seq.count("G").

Если в интерактивном режиме или в своем редакторе выполнить print(dir(str)), появится список из нескольких десятков имен. Имена с двойным подчеркиванием по краям, например __len__, служебные; остальные и есть методы, которыми пользуются в программах.

Пример

Метод возвращает новую строку

method.py
seq = "atgcgt"
print(seq.upper())  # → ATGCGT
print(seq)          # → atgcgt
seq = seq.upper()
print(seq)          # → ATGCGT
Вывод
ATGCGT
atgcgt
ATGCGT
  1. Последовательность записана строчными буквами.
  2. upper() возвращает новую строку заглавными буквами, print() ее печатает.
  3. Сама строка seq не изменилась.
  4. Результат метода присвоен имени seq: теперь оно указывает на новую строку.
  5. Печатается новая строка.

Типичная ошибка: результат метода не сохранен

Неверно: название не изменилось
name = "HOMO SAPIENS"
name.lower()
print(name)  # → HOMO SAPIENS
Вывод
HOMO SAPIENS
Верно
name = "HOMO SAPIENS"
name = name.lower()
print(name)  # → homo sapiens
Вывод
homo sapiens

Во второй строке метод вызван правильно, но его результат никуда не попал. Строка name прежняя, и программа дальше работает со старым значением.

Типичная ошибка: метод без скобок

Неверно: напечатан сам метод
text = "ACGT"
print(text.lower)
Верно
text = "ACGT"
print(text.lower())  # → acgt
Вывод
acgt

Без скобок метод не вызывается. Python не сообщает об ошибке, а печатает описание самого метода, например <built-in method lower …>, с адресом в памяти, который каждый раз разный.

2. Регистр

Теория

Данные набирают люди и готовят чужие программы, поэтому регистр в них бывает любым: atgc, ATGC, AtGc. Для Python это разные строки, и сравнение или поиск без приведения регистра дают неверный ответ.

Методы регистра возвращают новую строку. lower() и upper() переводят все буквы в строчные или в заглавные. capitalize() делает заглавной только первую букву строки, остальные строчными; title() делает так с каждым словом. swapcase() меняет регистр каждой буквы на противоположный.

Результаты для строки s = "dNA sequence":

ВызовРезультат
s.lower()'dna sequence'
s.upper()'DNA SEQUENCE'
s.capitalize()'Dna sequence'
s.title()'Dna Sequence'
s.swapcase()'Dna SEQUENCE'

Регистр важен при сравнении и поиске (страница 03). Поэтому перед сравнением или подсчетом текст приводят к одному регистру: a.lower() == b.lower().

capitalize() и title() не знают правил языка: сокращение DNA в таблице превратилось в Dna. Кроме того, title() считает началом слова любую букву после не-буквы, в том числе после цифры: "cd8a".title() дает 'Cd8A'. Для заголовков такие методы удобны, а для названий по строгим правилам их результат нужно проверять.

В геномных данных регистр иногда несет смысл. В записях генома строчными буквами часто помечают повторы: это мягкое маскирование. Если такую последовательность привести к заглавным буквам, пометка пропадет, поэтому исходную строку сохраняют, а приведенную кладут в отдельную переменную.

Пример

Название, набранное с Caps Lock

case.py
name = "eSCHERICHIA cOLI"
print(name.swapcase())                             # → Escherichia Coli
print(name.capitalize())                           # → Escherichia coli
print(name.title())                                # → Escherichia Coli
print(name.lower() == "Escherichia coli".lower())  # → True
Вывод
Escherichia Coli
Escherichia coli
Escherichia Coli
True
  1. Строка 2: swapcase() исправил регистр каждой буквы, но вид пишут со строчной буквы: нужно coli, а не Coli.
  2. Строка 3: capitalize() дает правильную запись латинского названия: род с заглавной, вид со строчной.
  3. Строка 4: title() пишет с заглавной оба слова.
  4. Строка 5: после приведения к одному регистру названия совпали.

3. Поиск и подсчет

Теория

Оператор in отвечает только «да» или «нет». Часто нужно больше: где мотив стоит, сколько раз он встречается, с чего начинается последовательность. На это отвечают методы поиска.

find(sub) возвращает индекс, с которого подстрока входит в строку первый раз, rfind(sub) индекс последнего вхождения, count(sub) число вхождений. Если подстроки нет, find() и rfind() возвращают -1, а count() возвращает 0.

Число −1 выбрано потому, что подстрока не может начинаться с такого индекса; 0 не подошел бы, это законный индекс первого символа. Но в роли индекса −1 означает последний символ. Поэтому результат find() нельзя сразу ставить в квадратные скобки: если подстроки нет, программа без сообщения об ошибке возьмет не тот символ.

startswith(prefix) и endswith(suffix) проверяют начало и конец строки и дают True или False. Все методы поиска учитывают регистр.

count() считает вхождения без перекрытий: найдя подстроку, он продолжает поиск после ее конца. Поэтому "AAAA".count("AA") дает 2, хотя пара AA начинается в трех местах.

У find() есть родственный метод index(): он тоже возвращает индекс первого вхождения, но если подстроки нет, завершает программу ошибкой ValueError. Какой из них выбрать, зависит от того, нормально ли для задачи отсутствие подстроки.

Методы можно вызывать цепочкой, один за другим: seq.upper().count("G") сначала переводит последовательность в заглавные буквы, затем считает в результате букву G. Цепочки подробнее разобраны на странице 05.

Пример

Где мотив и сколько его

search.py
seq = "ATGCGATCGATCGATCG"
print(seq.find("GATC"))       # → 4
print(seq.rfind("GATC"))      # → 12
print(seq.count("GATC"))      # → 3
print(seq.find("TTT"))        # → -1
print(seq.startswith("ATG"))  # → True
print(seq.endswith("TAA"))    # → False
Вывод
4
12
3
-1
True
False
  1. Строка 2: первое вхождение GATC начинается с индекса 4.
  2. Строка 3: последнее вхождение начинается с индекса 12.
  3. Строка 4: мотив встречается три раза.
  4. Строка 5: мотива TTT нет, поэтому −1.
  5. Строки 6–7: последовательность начинается со старт-кодона, но не заканчивается стоп-кодоном TAA.

Подсчет без перекрытий и ловушка −1

search_traps.py
print("AAAA".count("AA"))      # → 2
dna = "ATgcGC"
print(dna.count("G"))          # → 1
print(dna.upper().count("G"))  # → 2
seq = "ATGCGATCG"
print(seq[seq.find("TTT")])    # → G
Вывод
2
1
2
G
  1. Строка 1: вхождения не перекрываются, поэтому два, а не три.
  2. Строки 3–4: строчная g не считается буквой G, пока строку не привели к заглавным.
  3. Строка 6: find() вернул −1, и выражение взяло последний символ. Программа не остановилась, но результат бессмысленный.
