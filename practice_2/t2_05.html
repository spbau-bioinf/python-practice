Очистка и замена

20 минутЕрофеев А. И.

Научиться чистить края строки, заменять подстроки методом replace(), выстраивать методы цепочкой и проверять, из каких символов состоит строка.

1. Очистка краев и цепочка методов

Теория

Пользователь поставил пробел после логина, и система его не узнала: для человека это одно и то же слово, для программы нет. Такие невидимые различия встречаются везде, где данные набирал человек или готовила чужая программа. Поэтому данные сначала чистят, а потом сравнивают или считают.

Данные приходят с лишним: пробелы по краям, перевод строки в конце, табуляция. На экране "ACGT " и "ACGT" неотличимы, а для Python это разные строки (страница 03).

Метод strip() убирает пробелы, табуляции и переводы строки с обоих краев строки, но не внутри нее. lstrip() чистит только левый край, rstrip() только правый. Как и все методы строк, они возвращают новую строку.

У строки, которую вернул метод, снова есть методы. Поэтому вызовы ставят цепочкой, друг за другом: input().strip().upper() читает строку, убирает пробелы по краям и переводит буквы в заглавные. Цепочка читается слева направо, как конвейер: каждый метод работает с результатом предыдущего.

Исходные данные не портят: очищенный результат сохраняют в отдельной переменной, особенно если исходная строка еще понадобится. Так поступают и с файлами чужих данных: исходный файл не трогают, результат очистки кладут рядом.

Порядок в цепочке важен, потому что каждый метод видит только результат предыдущего. Цепочка seq.upper().count("g") ищет строчную букву в строке, где строчных букв уже нет, и всегда дает 0.

Пример

Пробелы по краям

strip.py
sample = "  S12 blood  "
print("[" + sample.strip() + "]")     # → [S12 blood]
print("[" + sample.lstrip() + "]")    # → [S12 blood  ]
print("[" + sample.rstrip() + "]")    # → [  S12 blood]
print(sample.strip() == "S12 blood")  # → True
Вывод
[S12 blood]
[S12 blood  ]
[  S12 blood]
True
  1. Строки 2–4: квадратные скобки приклеены к строке, чтобы пробелы по краям стали видны.
  2. Строка 2: strip() убрал пробелы с обоих краев, а пробел между словами остался.
  3. Строки 3–4: lstrip() и rstrip() чистят по одному краю.
  4. Строка 5: после очистки строка совпадает с образцом.

Ввод и цепочка методов

Программа ждет ввода. Пользователь набирает   gattaca   с пробелами по краям и нажимает Enter.

chain.py
seq = input().strip().upper()
print(seq)       # → GATTACA
print(len(seq))  # → 7
Вывод
  gattaca  
GATTACA
7
  1. input() возвращает строку с пробелами, strip() их убирает, upper() переводит буквы в заглавные.
  2. Печатается очищенная последовательность.
  3. Длина 7: пробелы в нее не попали.

Типичная ошибка: цепочка в неверном порядке

Неверно: строчных букв уже нет
seq = "atgGCgc"
print(seq.upper().count("g"))  # → 0
Вывод
0
Верно
seq = "atgGCgc"
print(seq.upper().count("G"))  # → 3
Вывод
3

После upper() в строке остались только заглавные буквы, и подсчет строчной g дает 0. Ошибки нет, неверен только ответ. Искать нужно ту букву, которая есть в результате предыдущего метода.

Практика

Замените strip() на rstrip(), затем на lstrip(). Как меняется длина очищенной строки и почему?

try_strip.py

seq = raw.strip().upper()
print(len(raw), len(seq))  # → 10 7
Вывод
10 7

2. Замена

Теория

Заменить нужно часто и помногу: T на U при переводе ДНК в РНК, дефисы и пробелы на пустое место при очистке, старое обозначение на новое. Менять по одному символу срезами долго, для этого есть метод replace().

Метод replace(old, new) возвращает новую строку, в которой все вхождения old заменены на new. Именно все, а не первое: заменяя S1 на X1, легко испортить и S12. Третий аргумент ограничивает число замен: replace(old, new, 1) меняет только первое вхождение.

Замена на пустую строку удаляет подстроку: seq.replace(" ", "") убирает все пробелы, в том числе внутри строки, чего strip() не делает. Методы replace() тоже ставят цепочкой; каждая следующая замена работает с результатом предыдущей.

Если old в строке не встречается, replace() возвращает строку без изменений, ошибки нет. Исходная строка, как всегда, остается прежней, поэтому результат присваивают.

replace() ищет подстроку, а не позицию. Заменить нуклеотид в заданной позиции им нельзя: он заменит такую же букву везде. Для замены в позиции собирают новую строку из срезов (страница 03).

Пример

Все вхождения или только первое

replace.py
ids = "S1 S12 S13"
print(ids.replace("S1", "X1"))     # → X1 X12 X13
print(ids.replace("S1", "X1", 1))  # → X1 S12 S13
seq = "ATG CGT ACC"
print(seq.replace(" ", ""))        # → ATGCGTACC
Вывод
X1 X12 X13
X1 S12 S13
ATGCGTACC
  1. Строка 2: S1 заменен везде, в том числе внутри S12 и S13.
  2. Строка 3: с третьим аргументом 1 заменено только первое вхождение.
  3. Строка 5: замена пробела на пустую строку убрала пробелы внутри последовательности.

Типичная ошибка: replace() вместо замены в позиции

Неверно: заменены все G
seq = "ATGCGATCG"
print(seq.replace(seq[2], "A"))  # → ATACAATCA
Вывод
ATACAATCA
Верно
seq = "ATGCGATCG"
print(seq[:2] + "A" + seq[3:])  # → ATACGATCG
Вывод
ATACGATCG

Нужно было заменить третий нуклеотид. Выражение seq[2] дало букву G, и replace() заменил все буквы G в последовательности, а не одну в нужной позиции.

Практика

Уберите дефисы совсем, заменив их пустой строкой. Затем добавьте третий аргумент и уберите только первый дефис.

try_replace.py
codons = "ATG-GCC-TAA"
print(codons.replace("-", " "))  # → ATG GCC TAA
Вывод
ATG GCC TAA

3. Проверка содержимого

Теория

Прежде чем считать, данные полезно проверить: номер пробы из одних ли цифр, нет ли в последовательности посторонних знаков. Для этого есть методы, имя которых начинается с is.

Методы is… отвечают, из каких символов состоит строка, и дают True или False. isdigit() проверяет, что в строке только цифры, isalpha() только буквы, isalnum() буквы и цифры, isspace() только пробельные символы. islower() и isupper() проверяют регистр букв. Пробел не буква и не цифра: "S12 blood".isalpha() дает False. У пустой строки все эти методы дают False.

Пока результат проверки можно только напечатать. Условием для выбора действия он станет вместе с ветвлениями.

isdigit() проверяет цифры, а не число: "-5".isdigit() и "2.5".isdigit() дают False, хотя int("-5") и float("2.5") работают.

islower() и isupper() смотрят только на буквы: "abc1".islower() дает True, а "123".islower() дает False, потому что букв в строке нет. isalpha() считает буквами не только латинские, но и русские.

Пример

Из чего состоит строка

checks.py
print("2026".isdigit())       # → True
print("S12".isalnum())        # → True
print("S12 blood".isalpha())  # → False
print("gattaca".islower())    # → True
print("-5".isdigit())         # → False
Вывод
True
True
False
True
False
  1. Строка 1: только цифры.
  2. Строка 2: буквы и цифры.
  3. Строка 3: пробел не буква, поэтому False.
  4. Строка 4: все буквы строчные.
  5. Строка 5: минус не цифра, хотя "-5" и записывает число.
