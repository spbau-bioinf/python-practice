Практика 6›Словари и множества

Множества

25 минутЕрофеев А. И.

Строить множества, выполнять над ними объединение, пересечение и разность и проверять, входит ли одно множество в другое.

1. Множество и его создание

Теория

Иногда важно не сколько раз встречается элемент, а только есть ли он. В "GATTACA" встречаются буквы A, C, G и T, и для такого ответа счетчики не нужны. Для таких вопросов есть множество.

Множество (тип set) хранит различные элементы без порядка. Элементы множества должны быть хешируемыми, как ключи словаря.

Функция set() строит множество из элементов строки, списка или другой коллекции, и каждый повтор остается один раз: set("GATTACA") дает множество из четырех букв. Непустое множество можно записать и в фигурных скобках: {"A", "T"}.

Пустое множество создают только вызовом set(). Пустые фигурные скобки {} дают пустой словарь.

Оператор in проверяет, есть ли элемент, а функция len() дает число элементов. Метод add() добавляет элемент; если элемент уже есть, множество не меняется. Метод discard() удаляет элемент, а отсутствующий пропускает без ошибки.

Порядок, в котором Python печатает множество, не гарантирован и может не совпасть с порядком появления букв. Поэтому множество печатают через sorted(): sorted(bases) дает список элементов по возрастанию.

Множество устроено как словарь без значений, на той же хеш-таблице, что на странице 02. Поэтому его элементы обязаны быть хешируемыми, а проверка in быстрая при любом размере. Метод remove() тоже удаляет элемент, но для отсутствующего, в отличие от discard(), останавливает программу ошибкой KeyError.

Пример

Пример 1. Создание множества

bases.py
seq = "GATTACA"
bases = set(seq)
print(len(seq), len(bases))  # → 7 4
print(sorted(bases))         # → ['A', 'C', 'G', 'T']
print("N" in bases)          # → False
bases.add("N")
bases.add("A")
print(len(bases))            # → 5
Вывод
7 4
['A', 'C', 'G', 'T']
False
5

В строке 7 букв, а разных среди них 4. sorted() печатает их по алфавиту. После add("N") элементов 5; add("A") ничего не меняет: A уже есть.

Типичная ошибка: пустое множество через {}

Неверно: получился словарь
bases = {}
bases.add("A")
Верно
bases = set()
bases.add("A")

Пустые скобки {} создают словарь, у словаря нет метода add(), и программа останавливается ошибкой AttributeError.

Практика

Замените "GATTACA" на "GATTACAG" и запустите: число разных букв не должно измениться.

bases.py
seq = "GATTACA"
bases = set(seq)
print(len(seq), len(bases))  # → 7 4
Вывод
7 4

2. Операции над множествами

Теория

Буквы, общие для двух последовательностей, и буквы, которые есть только в одной из них, находят операциями над множествами, как в математике. Их записывают знаками, и каждая операция строит новое множество, а исходные не меняет.

ЗаписьНазваниеКакие элементы
a | bобъединениеесть хотя бы в одном
a & bпересечениеесть в обоих
a - bразностьесть в a, нет в b
a ^ bсимметрическая разностьесть ровно в одном

Разность зависит от порядка: если множества a и b не равны, то a - b и b - a дают разные множества. Объединение, пересечение и симметрическая разность от порядка не зависят.

У каждой операции есть метод: union(), intersection(), difference(), symmetric_difference(). Метод принимает любую коллекцию, например список, а оператору нужны два множества: {1, 2} | [3] останавливает программу ошибкой TypeError.

Пример

Пример 2. Операции над множествами

sets.py
a = set("GATTACA")
b = set("TTGN")
print(sorted(a | b))  # → ['A', 'C', 'G', 'N', 'T']
print(sorted(a & b))  # → ['G', 'T']
print(sorted(a - b))  # → ['A', 'C']
print(sorted(b - a))  # → ['N']
print(sorted(a ^ b))  # → ['A', 'C', 'N']
Вывод
['A', 'C', 'G', 'N', 'T']
['G', 'T']
['A', 'C']
['N']
['A', 'C', 'N']

Общие буквы — G и T. Только в первой строке — A и C, только во второй — N; вместе они дают симметрическую разность.

Типичная ошибка: оператор со списком

Неверно: список как операнд
a = {1, 2, 3}
print(a | [3, 4])
Верно
a = {1, 2, 3}
print(sorted(a.union([3, 4])))  # → [1, 2, 3, 4]

Оператору | нужны два множества, со списком программа останавливается ошибкой TypeError. Метод union() принимает и список.

Практика

Замените "TTGN" на "CCCC" и запустите: пересечение должно стать ['C'].

sets.py
a = set("GATTACA")
b = set("TTGN")
print(sorted(a & b))  # → ['G', 'T']
Вывод
['G', 'T']
Задача

Повторить разобранное в примере.

3. Подмножество и проверка алфавита

Теория

Проверка, что строка состоит только из букв A, C, G и T, сводится к тому, входит ли множество букв строки в множество {"A", "C", "G", "T"} целиком.

Если каждый элемент множества a есть в множестве b, то a называют подмножеством b. Проверяет это оператор <=: для строки из правильных букв set(seq) <= set("ACGT") дает True.

Разность с алфавитом показывает лишние буквы: set(seq) - set("ACGT"). Если разность пустая, лишних букв нет. Метод isdisjoint() отвечает на другой вопрос, нет ли у двух множеств ни одного общего элемента: a.isdisjoint(b) дает True, если пересечение пустое.

Множество, как и список, можно построить включением, только в фигурных скобках: {base for base in seq if base != "N"}. Обычное множество изменяемо, поэтому оно не может быть ключом словаря или элементом другого множества. Неизменяемый вариант frozenset хешируем и годится в ключи.

Пример

Пример 3. Проверка алфавита

dna.py
dna = set("ACGT")
seq = "GATNACA"
print(set(seq) <= dna)                  # → False
print(sorted(set(seq) - dna))           # → ['N']
print(set("GAT") <= dna)                # → True
print(set("AT").isdisjoint(set("CG")))  # → True
Вывод
False
['N']
True
True

В GATNACA есть буква N, поэтому строка не проходит проверку, а разность показывает именно N. "GAT" проходит: лишних букв нет, хотя C отсутствует. У AT и CG общих букв нет.

Типичная ошибка: равенство вместо подмножества

Неверно: равенство
print(set(seq) == dna)
Верно
print(set(seq) <= dna)

Равенство требует, чтобы в строке были все четыре буквы. Подмножество пропускает и строку, где букв меньше, лишь бы не было лишних.

Практика

Замените "GATNACA" на "GATTACA" и запустите: проверка должна дать True.

dna.py
dna = set("ACGT")
seq = "GATNACA"
print(set(seq) <= dna)  # → False
Вывод
False

Необязательная задача, в зачет не входит. За решение дается дополнительный опыт в игровом режиме.

Задача со звездочкой 6.5. Все четыре нуклеотида

Условие задачи

Выведите через пробел в порядке ввода последовательности, в которых есть все четыре буквы A, C, G, T. Буква N этому не мешает. Если таких последовательностей нет, выведите нет.

Входные данные

Одна строка: от 1 до 100 последовательностей через пробел, каждая из букв A, C, G, T, N длиной от 1 до 100.

Выходные данные

Последовательности через пробел или слово нет.

Пример

Разберем пример

Ввод GATTACA AAT ACGTN

Вывод GATTACA ACGTN

Контекст

Иногда нужно отобрать последовательности, в которых встречаются все четыре нуклеотида. Проверка сводится к вопросу, входит ли одно множество в другое.

Основные определения

  • Алфавит ДНК — буквы A, C, G, T.
  • Функция set() — множество различных элементов; set(seq) дает множество букв строки.

Задача со звездочкой 6.5. Пары без общих букв

Условие задачи

Посчитайте, сколько пар последовательностей из строки не имеют ни одной общей буквы. Пару составляют две последовательности с разными номерами в строке, и каждая пара считается один раз.

Входные данные

Одна строка: от 1 до 100 последовательностей через пробел, каждая из букв A, C, G, T, N длиной от 1 до 100.

Выходные данные

Целое число: число пар.

Пример

Разберем пример

Ввод AA CG GT
→
Вывод 2

Общих букв нет у пар AA и CG, AA и GT. У CG и GT общая буква G. Ответ 2.

Примеры
ВводВывод
 
AA CG GT
2
A A
0
Контекст

Здесь нужно перебрать все пары последовательностей и для каждой проверить, есть ли у них общие буквы. Множества букв сравнивает метод isdisjoint(), а пары с разными номерами перебирают двумя вложенными циклами.

Основные определения

  • Функция set() — множество различных элементов; set(seq) дает множество букв строки.
  • Метод isdisjoint() — True, если у двух множеств нет общих элементов.
  • Пары с разными номерами — второй цикл начинается с first_index + 1, поэтому каждая пара считается один раз.
Подсказка
  1. Постройте список множеств букв: [set(seq) for seq in input().split()].
  2. Переберите пары номеров двумя циклами: внешний по first_index, внутренний по second_index от first_index + 1. Так каждая пара встретится один раз.
  3. Метод isdisjoint() отвечает, нет ли у двух множеств общих элементов. Считайте пары, для которых он дает True.
  4. Сверьтесь с примером: для ввода AA CG GT программа печатает 2.
