Counter и defaultdict

25 минутЕрофеев А. И.

Подключать модуль collections, считать частоты классом Counter, складывать и вычитать счетчики и строить словари с умолчаниями классом defaultdict.

1. Модули и Counter

Теория

Модуль — единица, из которой импортируют имена; стандартная библиотека состоит из модулей, которые устанавливаются вместе с интерпретатором, и collections один из них.

Инструкция from collections import Counter подключает из модуля одно имя, после чего пишут просто Counter. Инструкция import collections подключает модуль целиком, и к имени обращаются через точку: collections.Counter. Инструкции import ставят в начало программы.

Counter — подкласс словаря из модуля collections для подсчета хешируемых объектов: элементы хранятся как ключи, их количества как значения.

Counter поддерживает основные операции словаря и добавляет методы счета. Если ключа нет, c[key] дает 0, а c.get(key) работает по правилам словаря и без второго аргумента возвращает None.

Метод most_common(n) возвращает до n самых частых пар, от более частых к менее частым; если различных букв меньше n, список короче. Элементы с равными счетчиками идут в порядке первого появления. Без аргументов метод возвращает все пары от самой частой к самой редкой. Метод total() возвращает сумму всех счетчиков; для последовательности это ее длина. Счетчик можно построить не только из последовательности, но и из словаря или из именованных аргументов, например Counter(a=3, b=1).

Пример

Пример 1. Подсчет букв с помощью Counter

counter.py
from collections import Counter
c = Counter("GATTACA")
print(c)
print(c["A"], c["N"])    # → 3 0
print(c.most_common(2))  # → [('A', 3), ('T', 2)]
print(c.total())         # → 7
Вывод
Counter({'A': 3, 'T': 2, 'G': 1, 'C': 1})
3 0
[('A', 3), ('T', 2)]
7

Счетчик построен одной строкой из последовательности. Для отсутствующей буквы N он возвращает 0. most_common(2) дает две самые частые пары, а total() сумму всех счетчиков.

Типичная ошибка: Counter вместо import

Неверно: без import
c = Counter("GATTACA")
Верно
from collections import Counter
c = Counter("GATTACA")

Без инструкции import имя Counter не определено: интерпретатор поднимает NameError. Имя нужно сначала подключить из модуля collections.

Практика

Василиса считает буквы другой последовательности. Замените "GATTACA" на "ACGTACGT" и запустите: каждый счетчик должен стать 2.

counter.py
from collections import Counter
c = Counter("GATTACA")
print(c)
Вывод
Counter({'A': 3, 'T': 2, 'G': 1, 'C': 1})

2. Сложение и вычитание счетчиков

Теория

Счетчики можно складывать и вычитать. Сумма счетчиков дает общий состав: числа одинаковых букв складываются. Разность вычитает счетчики соответствующих элементов, но в результат попадают только положительные числа: результаты, равные нулю или отрицательные, отбрасываются.

Метод elements() выполняет обратное преобразование: он перечисляет элементы, повторяя каждый столько раз, каков его счетчик, в порядке первого появления; элементы с нулевыми и отрицательными счетчиками пропускаются.

Метод update() у Counter прибавляет новые счетчики к старым, а не заменяет их, как update() обычного словаря. Кроме сложения и вычитания, счетчики поддерживают пересечение & и объединение |: пересечение берет для каждого элемента меньший из двух счетчиков, объединение больший. Такие результаты называют мультимножествами: в них остаются только элементы с положительными счетчиками.

Пример

Пример 2. Сложение и вычитание счетчиков

reads.py
from collections import Counter
r1 = Counter("AACG")
r2 = Counter("ACCT")
print(r1 + r2)
print(r1 - r2)  # → Counter({'A': 1, 'G': 1})
r1.update("GG")
print(r1)       # → Counter({'G': 3, 'A': 2, 'C': 1})
Вывод
Counter({'A': 3, 'C': 3, 'G': 1, 'T': 1})
Counter({'A': 1, 'G': 1})
Counter({'G': 3, 'A': 2, 'C': 1})

Сумма дает общий состав двух прочтений. В разности у буквы C (1 − 2) и у буквы T (0 − 1) ничего не осталось: нулевые и отрицательные результаты отбрасываются. update() прибавил два G к старым счетчикам.

Типичная ошибка: вычитание в обратную сторону

Неверно: вычитаем наоборот
print(r2 - r1)
Верно
print(r1 - r2)

Разность несимметрична: r2 - r1 показывает, чего во втором прочтении больше, чем в первом. Порядок операндов определяется вопросом задачи.

Практика

Прохор сравнивает прочтения. Замените "ACCT" на "ACGT" и запустите: в разности должна остаться буква G.

reads.py
from collections import Counter
r1 = Counter("AACG")
r2 = Counter("ACCT")
print(r1 - r2)  # → Counter({'A': 1, 'G': 1})
Вывод
Counter({'A': 1, 'G': 1})

3. defaultdict

Теория

defaultdict — подкласс словаря из модуля collections, который умеет сам создавать значение для отсутствующего ключа; каким оно будет, решает переданная фабрика.

Каким будет значение, решает аргумент, называемый фабрикой: то, что вызывается без аргументов и возвращает значение по умолчанию. Фабрика int дает 0, фабрика list дает пустой список. Передают сам тип, без скобок, а не результат его вызова. Фабрика срабатывает только при обращении квадратными скобками: groups[key] создает значение, а groups.get(key) и key in groups этого не делают. Без фабрики defaultdict() ведет себя как обычный словарь: обращение к отсутствующему ключу вызывает KeyError.

Счетчик и группировка со страницы 04 сокращаются до одной строки в теле цикла: counts[b] += 1 и groups[len(s)].append(s).

Группировка через defaultdict(list) проще и быстрее, чем запись через setdefault(): при setdefault(key, []) пустой список вычисляется при каждом вызове, а фабрика list создает список только по необходимости.

Пример

Пример 3. Счетчик и группировка с defaultdict

defaults.py
from collections import defaultdict
counts = defaultdict(int)
for b in "GATTACA":
    counts[b] += 1
print(dict(counts))     # → {'G': 1, 'A': 3, 'T': 2, 'C': 1}
groups = defaultdict(list)
for s in ["ATG", "GC", "TAA"]:
    groups[len(s)].append(s)
print(dict(groups))     # → {3: ['ATG', 'TAA'], 2: ['GC']}
print(groups.get("x"))  # → None
print(groups["x"])      # → []
print(list(groups))     # → [3, 2, 'x']
Вывод
{'G': 1, 'A': 3, 'T': 2, 'C': 1}
{3: ['ATG', 'TAA'], 2: ['GC']}
None
[]
[3, 2, 'x']

Для новой буквы counts[b] сам создает нулевой счетчик, и += 1 делает его единицей. Для новой длины groups[len(s)] сам создает пустой список, и append() дописывает название. Вызов dict(...) нужен только для короткой печати. Метод get("x") вернул None и ничего не создал, а обращение groups["x"] добавило ключ с пустым списком: в конце в словаре появился ключ "x".

Типичная ошибка: фабрика со скобками

Неверно: list()
groups = defaultdict(list())
for s in seqs:
    groups[len(s)].append(s)
Верно
groups = defaultdict(list)
for s in seqs:
    groups[len(s)].append(s)

Фабрикой передают сам тип без скобок. Вызов list() создает один конкретный список, который не может быть фабрикой: интерпретатор поднимет TypeError.

Практика

Василиса группирует образцы. Замените фабрику int на list и перепишите цикл под группировку по длине, затем запустите.

defaults.py
from collections import defaultdict
counts = defaultdict(int)
for b in "GATTACA":
    counts[b] += 1
print(dict(counts))  # → {'G': 1, 'A': 3, 'T': 2, 'C': 1}
Вывод
{'G': 1, 'A': 3, 'T': 2, 'C': 1}
