Counter и defaultdict

25 минутЕрофеев А. И.

Подключать имена из модуля collections, считать элементы счетчиком Counter, складывать и вычитать счетчики и группировать с defaultdict.

1. Модуль collections и Counter

Теория

На странице 04 счетчик букв строили циклом. Подсчет нужен так часто, что в Python для него есть готовый инструмент. Он лежит в модуле стандартной библиотеки.

Модуль (module) представляет собой файл с готовыми функциями и типами, которые можно подключить к своей программе.

Модуль collections входит в стандартную библиотеку и устанавливается вместе с Python, скачивать его не нужно. Инструкция from collections import Counter подключает из него имя Counter, и дальше это имя пишут без приставки. Инструкции import ставят в начало программы.

Counter строит словарь-счетчик из элементов коллекции: ключами становятся элементы, значениями числа их вхождений.

Вызов Counter("GATTACA") одной строкой строит тот же счетчик, что цикл со страницы 04. Какие буквы самые частые? Метод most_common(n) возвращает список не более чем из n пар «элемент, число», начиная с самого частого. Элементы с равными числами идут в порядке первого появления, по тому же правилу ничьей, что во всей практике.

У Counter отсутствующий ключ в квадратных скобках дает 0, а не ошибку KeyError: Counter("GATTACA")["N"] равно 0.

Инструкция import collections подключает модуль целиком, и тогда имя пишут через точку: collections.Counter. Метод total() (с Python 3.10) возвращает сумму всех чисел счетчика; для последовательности это ее длина.

Пример

Пример 1. Подсчет букв с помощью Counter

counter.py
from collections import Counter
counts = Counter("GATTACA")
print(counts)
print(counts["A"], counts["N"])  # → 3 0
print(counts.most_common(2))     # → [('A', 3), ('T', 2)]
Вывод
Counter({'A': 3, 'T': 2, 'G': 1, 'C': 1})
3 0
[('A', 3), ('T', 2)]

При печати счетчик показывает пары от самой частой. Буквы N нет, и counts["N"] дает 0. most_common(2) — две самые частые буквы с числами.

Типичная ошибка: Counter без import

Неверно: без import
counts = Counter("GATTACA")
Верно
from collections import Counter
counts = Counter("GATTACA")

Без инструкции import имя Counter не определено, и программа останавливается ошибкой NameError.

Практика

Замените most_common(2) на most_common(1) и запустите: в списке должна остаться одна пара ('A', 3).

counter.py
from collections import Counter
counts = Counter("GATTACA")
print(counts.most_common(2))  # → [('A', 3), ('T', 2)]
Вывод
[('A', 3), ('T', 2)]

2. Сложение и вычитание счетчиков

Теория

Как сравнить состав двух прочтений одного участка? Счетчики можно складывать и вычитать, как числа, только операция выполняется для каждого элемента отдельно.

Сумма first + second дает общий состав: числа одинаковых элементов складываются. Разность first - second вычитает числа, но оставляет только положительные. Элемент, у которого получился ноль или отрицательное число, в результат не попадает.

Разность счетчиков зависит от порядка: first - second показывает, чего в первом счетчике больше, чем во втором, а second - first показывает обратное.

Пустой счетчик в условии if ложен, как пустой словарь. Поэтому if first - second: проверяет, есть ли хоть одна лишняя буква.

Метод update() у Counter прибавляет числа к прежним, а не заменяет их, как update() обычного словаря. Пересечение & берет для каждого элемента меньшее из двух чисел, а объединение | большее.

Пример

Пример 2. Сложение и вычитание счетчиков

reads.py
from collections import Counter
first = Counter("AACG")
second = Counter("ACCT")
print(first + second)
print(first - second)  # → Counter({'A': 1, 'G': 1})
print(second - first)  # → Counter({'C': 1, 'T': 1})
Вывод
Counter({'A': 3, 'C': 3, 'G': 1, 'T': 1})
Counter({'A': 1, 'G': 1})
Counter({'C': 1, 'T': 1})

В сумме A и C по три. В разности first - second остались A (2 − 1) и G (1 − 0); у C разность 1 − 2 отрицательна, у T 0 − 1 тоже, их нет. Обратная разность показывает C и T.

Типичная ошибка: вычитание в обратную сторону

Неверно: операнды наоборот
print(second - first)
Верно
print(first - second)

Порядок операндов задает вопрос задачи: «чего в первом больше» — first - second.

Практика

Замените "ACCT" на "AACG" и запустите: разность должна стать пустым счетчиком Counter().

reads.py
from collections import Counter
first = Counter("AACG")
second = Counter("ACCT")
print(first - second)  # → Counter({'A': 1, 'G': 1})
Вывод
Counter({'A': 1, 'G': 1})
Задача

Повторить разобранное в примере.

3. defaultdict

Теория

На странице 04 группировка требовала проверки: если группы еще нет, под нее сначала кладут пустой список. Можно ли обойтись без этой проверки? Можно, если словарь сам создаст значение для отсутствующего ключа.

defaultdict из модуля collections работает как словарь, но для отсутствующего ключа сам создает значение.

Каким будет новое значение, решает аргумент: defaultdict(int) создает 0, а defaultdict(list) пустой список. Передают сам тип, без скобок. С таким словарем счетчик и группировка со страницы 04 записываются короче, без проверки ключа: counts[base] += 1 и groups[length].append(seq).

Значение создается при любом обращении квадратными скобками, даже если его просто читают. groups.get(key) и key in groups ничего не создают. Поэтому есть ли ключ, проверяют через in, а не чтением groups[key].

Пример

Пример 3. Счетчик и группировка с defaultdict

default.py
from collections import defaultdict
counts = defaultdict(int)
for base in "GATTACA":
    counts[base] += 1
print(dict(counts))  # → {'G': 1, 'A': 3, 'T': 2, 'C': 1}
groups = defaultdict(list)
for seq in ["ATG", "GC", "TAA"]:
    groups[len(seq)].append(seq)
print(dict(groups))  # → {3: ['ATG', 'TAA'], 2: ['GC']}
Вывод
{'G': 1, 'A': 3, 'T': 2, 'C': 1}
{3: ['ATG', 'TAA'], 2: ['GC']}

Для новой буквы фабрика int создала 0, и += 1 сделал его единицей; для новой длины фабрика list создала пустой список. dict() печатает результат как обычный словарь.

Пример 4. Чтение создает ключ

trap.py
from collections import defaultdict
groups = defaultdict(list)
print(groups.get(5))             # → None
print(5 in groups)               # → False
print(groups[5])                 # → []
print(5 in groups, len(groups))  # → True 1
Вывод
None
False
[]
True 1

get() и in ключ 5 не создали. Чтение groups[5] создало пару «5 : пустой список», и после него in дает True.

Типичная ошибка: фабрика со скобками

Неверно: list()
groups = defaultdict(list())
Верно
groups = defaultdict(list)

Фабрикой передают сам тип. list() — уже готовый пустой список, а не то, что создает списки, и программа останавливается ошибкой TypeError.

Практика

Перенесите строку print(groups[5]) в конец программы и запустите: первая строка вывода должна стать False 0.

trap.py
from collections import defaultdict
groups = defaultdict(list)
print(groups[5])                 # → []
print(5 in groups, len(groups))  # → True 1
Вывод
[]
True 1

ВводВывод

Задача со звездочкой 6.6. Хватит ли букв

Условие задачи

Можно ли составить слово из второй строки, переставляя буквы набора из первой строки? Каждую букву набора можно взять не больше одного раза. Выведите да или нет. При ответе нет во второй строке выведите недостающие буквы парами «буква:число» по алфавиту через пробел.

Входные данные

Две строки из заглавных латинских букв длиной от 1 до 1000: набор букв и слово.

Выходные данные

да или нет и строка недостающих букв.

Пример

Разберем пример

Ввод GATTACA
GGT
→
Вывод нет
G:1

В наборе GATTACA одна буква G, а в слове GGT их две, поэтому не хватает одной G.

Контекст

Так проверяют, хватит ли нуклеотидов в смеси, чтобы собрать нужную короткую цепочку: из счетчика нужных букв вычитают счетчик имеющихся.

Основные определения

  • Класс Counter — словарь-счетчик из модуля collections: Counter(seq) считает элементы за один вызов.
  • Разность счетчиков first - second — числа вычитаются, остаются только ключи с положительной разностью.
  • Пустое множество или счетчик в if — считается ложью, непустое считается истиной.
Подсказка
  1. Постройте счетчики набора и слова.
  2. Недостающие буквы дает разность Counter(word) - Counter(letters).
  3. Пустой счетчик в условии ложен: если разность пустая, ответ да, иначе нет и пары «буква:число» по алфавиту.
  4. Сверьтесь с примером: для ввода GATTACA и GGT программа печатает нет и G:1.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.
