Счетчик и группировка

25 минутЕрофеев А. И.

Считать элементы словарем-счетчиком, группировать их по признаку и пользоваться методами, которые меняют словарь.

1. Словарь-счетчик

Теория

Сколько раз в последовательности встречается каждая буква? Какие буквы встретятся, заранее неизвестно: кроме A, C, G и T в прочтении бывают и другие буквы, например N. Поэтому заводить по переменной на каждую букву неудобно. Удобнее словарь, в котором ключом служит буква, а значением число ее вхождений.

Словарь-счетчик хранит пары «элемент : сколько раз он встретился». Его начинают пустым и заполняют в цикле по элементам.

В лекции шаг счетчика записан проверкой: если буква уже есть в словаре, ее значение увеличивают на 1, иначе для нее записывают 1. Метод get() со вторым аргументом 0 сокращает проверку до одной строки: counts[base] = counts.get(base, 0) + 1.

Почему эта строка работает в обоих случаях? Для новой буквы get() дает 0, и в словарь записывается 1. Для встреченной буквы get() дает прежнее число, и записывается число на единицу больше.

Ключи счетчика идут в порядке первого появления букв. Поэтому из нескольких одинаково частых букв первой среди ключей окажется та, что раньше встретилась в последовательности.

Пример

Пример 1. Счетчик букв

counts.py
seq = "GATTACA"
counts = {}
for base in seq:
    counts[base] = counts.get(base, 0) + 1
print(counts)              # → {'G': 1, 'A': 3, 'T': 2, 'C': 1}
print(counts.get("N", 0))  # → 0
Вывод
{'G': 1, 'A': 3, 'T': 2, 'C': 1}
0

В словаре четыре пары, ключи в порядке первого появления: G, A, T, C. Буквы N в последовательности нет, и get() дает 0.

Пример 2. Счетчик проверкой, как в лекции

counts_if.py
seq = "GATTACA"
counts = {}
for base in seq:
    if base in counts:
        counts[base] += 1
    else:
        counts[base] = 1
print(counts)  # → {'G': 1, 'A': 3, 'T': 2, 'C': 1}
Вывод
{'G': 1, 'A': 3, 'T': 2, 'C': 1}

Результат тот же, что в примере 1: ветка else записывает 1 для новой буквы, ветка if увеличивает прежнее число.

Типичная ошибка: счетчик без увеличения

Неверно: без + 1
for base in seq:
    counts[base] = counts.get(base, 0)
Верно
for base in seq:
    counts[base] = counts.get(base, 0) + 1

Без + 1 прочитанное число записывается обратно без изменения, и все счетчики остаются нулями.

Практика

Замените "GATTACA" на "GGATCG" и запустите: у G должно быть 3.

counts.py
seq = "GATTACA"
counts = {}
for base in seq:
    counts[base] = counts.get(base, 0) + 1
print(counts)  # → {'G': 1, 'A': 3, 'T': 2, 'C': 1}
Вывод
{'G': 1, 'A': 3, 'T': 2, 'C': 1}
Задача

Повторить разобранное в примере.

2. Группировка

Теория

Как разложить последовательности по длине, чтобы последовательности одной длины оказались вместе? Нужен словарь, в котором ключом служит длина, а значением список последовательностей этой длины.

Группировка собирает элементы с общим признаком в один список. Словарь группировки хранит пары «признак : список элементов».

Каждый элемент обрабатывают в два шага. Если группы с таким признаком еще нет, под нее кладут пустой список: groups[length] = []. Затем элемент дописывают в список группы: groups[length].append(seq). Первый шаг нужен, потому что дописать элемент в список, которого еще нет, нельзя: без него append() вызовет ошибку KeyError.

Метод setdefault(key, default) возвращает значение ключа, а если ключа нет, сначала вставляет в словарь пару key: default и возвращает default.

Поэтому оба шага помещаются в одну строку: к результату groups.setdefault(length, []) сразу применяют .append(seq). Метод возвращает список группы, новый или уже существующий, и элемент дописывается в него. Обе записи дают один и тот же словарь, это показывает пример 4.

Похожим образом обращают словарь: значения исходного словаря становятся ключами нового, а ключи собираются в списки. Словарь {"s1": 8, "s2": 12, "s3": 8} обращается в {8: ["s1", "s3"], 12: ["s2"]}. Списки нужны, потому что значения исходного словаря могут повторяться, а ключи нового повторяться не могут.

Пример

Пример 3. Группировка по длине

groups.py
seqs = ["ATG", "GC", "TAA", "AT"]
groups = {}
for seq in seqs:
    length = len(seq)
    if length not in groups:
        groups[length] = []
    groups[length].append(seq)
print(groups)             # → {3: ['ATG', 'TAA'], 2: ['GC', 'AT']}
print(groups.get(5, []))  # → []
Вывод
{3: ['ATG', 'TAA'], 2: ['GC', 'AT']}
[]

Длина 3 встретилась первой, поэтому ее группа идет первой. Группы длины 5 нет, и get() возвращает пустой список.

Пример 4. То же через setdefault()

setdefault.py
seqs = ["ATG", "GC", "TAA", "AT"]
groups = {}
for seq in seqs:
    groups.setdefault(len(seq), []).append(seq)
print(groups)  # → {3: ['ATG', 'TAA'], 2: ['GC', 'AT']}
Вывод
{3: ['ATG', 'TAA'], 2: ['GC', 'AT']}

Словарь тот же, что в примере 3. setdefault() возвращает список группы — новый пустой или уже накопленный, и append() дописывает в него последовательность.

Типичная ошибка: группа без списка

Неверно: присваивание вместо append()
groups[len(seq)] = seq
Верно
if len(seq) not in groups:
    groups[len(seq)] = []
groups[len(seq)].append(seq)

В неверном варианте каждая следующая последовательность той же длины заменяет предыдущую, и в группе остается одна. Элементы дописывают в список.

Практика

Добавьте в список "GATTACA" и запустите: должна появиться группа длины 7.

groups.py
seqs = ["ATG", "GC", "TAA", "AT"]
groups = {}
for seq in seqs:
    length = len(seq)
    if length not in groups:
        groups[length] = []
    groups[length].append(seq)
print(groups)  # → {3: ['ATG', 'TAA'], 2: ['GC', 'AT']}
Вывод
{3: ['ATG', 'TAA'], 2: ['GC', 'AT']}
Задача

Повторить разобранное в примере.

Упражнение 6.4.2. Группа по длине

Условие задачи

Сгруппируйте последовательности по длине в словарь «длина : список последовательностей» и выведите через пробел последовательности, длина которых равна числу из второй строки, в порядке ввода. Если таких нет, выведите пустую строку.

Входные данные

В первой строке последовательности через пробел, от 1 до 100 штук, каждая из букв A, C, G, T длиной от 1 до 20. Во второй строке целое число от 1 до 20.

Выходные данные

Последовательности через пробел или пустая строка.

Пример

Разберем пример

Ввод ATG GC TAA AT
3
→
Вывод ATG TAA

Длину 3 имеют последовательности ATG и TAA.

Примеры
ВводВывод

ATG TAA
ATG GC TAA AT
5
(пустая строка)
Контекст

Короткие последовательности, например праймеры, удобно разбирать по длине: последовательности одной длины обрабатывают вместе.

Основные определения

  • Праймер — короткая затравка, с которой начинается копирование ДНК.
  • Группировка — словарь «признак : список»; новый признак сначала получает пустой список, затем элемент дописывается в него.
  • Запись groups.get(length, []) — список группы или пустой список, если такой группы нет.
  • Метод join() — склеивает строки списка через разделитель; " ".join(d) у словаря склеивает ключи.
Подсказка
  1. Заведите пустой словарь групп и переберите последовательности.
  2. Если группы такой длины еще нет, положите под нее пустой список: groups[length] = []. Затем допишите последовательность: groups[length].append(seq).
  3. Прочитайте число и напечатайте группу через пробел. Отсутствующую группу дает groups.get(length, []).
  4. Сверьтесь с примером: для ввода ATG GC TAA AT и 3 программа печатает ATG TAA.

3. Методы update(), pop() и fromkeys()

Теория

У словаря есть еще несколько полезных методов. Метод update() добавляет в словарь пары другого словаря, а значения совпавших ключей заменяет: после counts.update({"N": 2}) в счетчике появляется пара для буквы N.

Метод pop(key) удаляет пару и возвращает ее значение. Он делает то же, что del, только значение не теряется. Для отсутствующего ключа pop() без второго аргумента останавливает программу ошибкой KeyError, а со вторым аргументом возвращает его: counts.pop("N", 0) дает 0.

Метод dict.fromkeys(keys, value) строит словарь, в котором у всех ключей одно и то же значение. Для числа это удобно: dict.fromkeys("ACGT", 0) дает счетчик с нулями {'A': 0, 'C': 0, 'G': 0, 'T': 0}.

Если значение в dict.fromkeys() список, получается ловушка: у всех ключей оказывается один и тот же список, и элемент, добавленный в одну группу, появляется во всех.

Методы, которые только меняют словарь, например update(), возвращают None, как и методы списка. Начиная с Python 3.9 два словаря объединяют оператором |: выражение d | other строит новый словарь, а при совпадении ключей берет значение из правого.

Пример

Пример 5. update() и pop()

methods.py
gene = {"id": "BRCA1"}
gene.update({"chromosome": 17, "protein_length": 1863})
print(len(gene))                   # → 3
print(gene.pop("protein_length"))  # → 1863
print(gene.pop("organism", None))  # → None
print(gene)                        # → {'id': 'BRCA1', 'chromosome': 17}
Вывод
3
1863
None
{'id': 'BRCA1', 'chromosome': 17}

update() добавил две пары. pop() удалил длину белка и вернул ее; ключа "organism" нет, и pop() вернул второй аргумент None.

Пример 6. Один список на все ключи

fromkeys.py
groups = dict.fromkeys(["A", "C"], [])
groups["A"].append("ATG")
print(groups)  # → {'A': ['ATG'], 'C': ['ATG']}
Вывод
{'A': ['ATG'], 'C': ['ATG']}

Строка дописала "ATG" только в группу "A", а он появился и в "C": у обоих ключей один и тот же список. Пустые списки для групп создают отдельно — в цикле или через setdefault().

Типичная ошибка: общий список из fromkeys()

Неверно: fromkeys() со списком
groups = dict.fromkeys(["A", "C"], [])
Верно
groups = {}
for key in ["A", "C"]:
    groups[key] = []

В верном варианте каждый проход цикла создает новый пустой список, и группы независимы.

Практика

Добавьте пару "organism": "Homo sapiens" методом update() и запустите: len(gene) должно стать 3.

gene.py

Вывод
2
