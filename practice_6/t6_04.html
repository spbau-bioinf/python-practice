Счетчик и группировка

25 минутЕрофеев А. И.

Строить словарь-счетчик циклом с методом get(), собирать группы в словарь списков методом setdefault() и пользоваться методами update() и pop().

1. Словарь-счетчик

Теория

Задача «сколько раз встречается каждый элемент» решается шаблоном-счетчиком: словарем, в котором ключом служит элемент, а значением число вхождений. Заранее неизвестно, какие элементы встретятся, поэтому словарь строят в цикле.

Для буквы, которой еще нет, counts.get(b, 0) дает 0, для встреченной буквы возвращается прежнее число. Результат увеличивается на единицу и записывается обратно: counts[b] = counts.get(b, 0) + 1. Это распространенная идиома Python.

Ту же задачу можно решить без словаря: завести 26 переменных и выбирать нужную цепочкой условий, или список из 26 счетчиков и вычислять индекс по коду буквы. Все три способа выполняют одно вычисление, но у словаря два преимущества: не нужно заранее знать, какие буквы встретятся, и место отводится только под встреченные буквы. Для последовательностей это важно: кроме A, C, G, T в них бывают буква N и другие коды неоднозначности, и словарь учтет их без изменения кода. Нуклеотид — звено цепи ДНК, в записи последовательности это одна буква A, C, G или T; буква N обозначает неизвестный нуклеотид.

Пример

Пример 1. Счетчик букв

counts.py
seq = "GATTACA"
counts = {}
for b in seq:
    counts[b] = counts.get(b, 0) + 1
print(counts)              # → {'G': 1, 'A': 3, 'T': 2, 'C': 1}
print(len(counts))         # → 4
print(counts.get("N", 0))  # → 0
Вывод
{'G': 1, 'A': 3, 'T': 2, 'C': 1}
4
0

В цикле каждая буква увеличивает свой счетчик: для новой буквы get(b, 0) дает 0, для встреченной возвращается прежнее число. len(counts) это число разных букв, а буквы N в строке не было, поэтому get("N", 0) возвращает 0.

Типичная ошибка: счетчик без увеличения

Неверно: без + 1
for b in seq:
    counts[b] = counts.get(b, 0)
Верно
for b in seq:
    counts[b] = counts.get(b, 0) + 1

Без + 1 все счетчики останутся нулями: прочитанное значение записывается обратно без изменения. Каждая встреченная буква должна увеличивать свой счетчик на единицу.

Практика

2. Группировка

Теория

Второй шаблон, группировка, собирает элементы по общему признаку. Значением словаря служит список, в который дописываются элементы группы. Если группы еще нет, под нее сначала кладут пустой список.

Строка groups.setdefault(n, []).append(s) делает то же одной строкой: setdefault() возвращает список ключа, а если ключа нет, сначала вставляет пустой список. Так ключ ищется в словаре один раз, а запись с проверкой in, вставкой и чтением ищет его два или три раза.

Метод setdefault() похож на get(), но если ключа нет, он не только возвращает запасное значение, но и вставляет его в словарь.

Частный случай группировки называется обращением словаря: значения исходного словаря становятся ключами нового, а ключи собираются в списки, например {"s1": 8, "s2": 8} обращается в {8: ["s1", "s2"]}. Списки нужны потому, что ключи словаря уникальны, а значения нет.

Пример

Пример 2. Группировка по длине

groups.py
seqs = ["ATG", "GC", "TAA", "AT"]
groups = {}
for s in seqs:
    groups.setdefault(len(s), []).append(s)
print(groups)             # → {3: ['ATG', 'TAA'], 2: ['GC', 'AT']}
print(groups.get(3, []))  # → ['ATG', 'TAA']
Вывод
{3: ['ATG', 'TAA'], 2: ['GC', 'AT']}
['ATG', 'TAA']

Для каждой длины setdefault() возвращает список этой группы, вставляя переданный пустой список при первом появлении длины. groups.get(3, []) возвращает группу длины 3; для отсутствующей длины вернулся бы пустой список.

Типичная ошибка: группа без списка

Неверно: без append
groups.setdefault(len(s), [])
groups[len(s)] = s
Верно
groups.setdefault(len(s), []).append(s)

В неверном варианте каждый следующий образец той же длины затирает предыдущий: в группе остается одно название. Элементы группы дописывают в список методом append().

Практика

3. Методы, которые меняют словарь

Теория

Методы, которые только меняют словарь, возвращают None, как методы списка. Метод update() добавляет пары другого словаря, совпавшие ключи перезаписывает. Метод pop() удаляет пару и возвращает ее значение; для отсутствующего ключа без второго аргумента он вызвал бы KeyError, а со вторым возвращает его.

Метод setdefault() читает значение ключа, а если ключа нет, вставляет запасное значение и возвращает его. Первый вызов в примере находит ключ "id" и словарь не меняет, второй вставляет новую пару "organism".

Начиная с Python 3.9 два словаря можно объединить операторами: d | other создает новый словарь из пар обоих, при совпадении ключей побеждает значение из правого операнда, а d |= other обновляет d на месте. Метод fromkeys() вызывают у самого типа dict: у всех созданных им ключей одно и то же значение-объект, поэтому изменяемый объект, например пустой список, в качестве значения не используют; для разных значений есть словарное включение.

Пример

Пример 3. update(), pop() и setdefault()

ann.py
ann = {"id": "BRCA1"}
ann.update({"chromosome": 17, "aa": 1863})
print(len(ann))                             # → 3
print(ann.pop("aa"))                        # → 1863
print(ann.pop("gc", None))                  # → None
print(ann.setdefault("id", "?"))            # → BRCA1
print(ann.setdefault("organism", "human"))  # → human
print(ann)
Вывод
3
1863
None
BRCA1
human
{'id': 'BRCA1', 'chromosome': 17, 'organism': 'human'}

update() добавил две пары, pop("aa") удалил одну и вернул ее значение, pop("gc", None) вернул запасной None. Первый вызов setdefault() нашел ключ "id", второй вставил пару "organism".

Типичная ошибка: get() вместо setdefault()

Неверно: ключ не появится
print(ann.get("organism", "human"))
print(len(ann))
Верно
print(ann.setdefault("organism", "human"))
print(len(ann))

get() возвращает запасное значение, но ключ в словарь не вставляет: len(ann) не меняется. Если пара должна появиться, нужен setdefault().
