Мера Жаккара

25 минутЕрофеев А. И.

Удалять повторы с сохранением порядка и без него, сравнивать наборы операциями множеств и считать меру Жаккара.

1. Удаление повторов

Теория

Список названий, собранный из нескольких файлов, часто содержит повторы: один и тот же образец записан дважды. Как убирать повторы, зависит от того, важен ли порядок.

Если порядок не важен, повторы убирает set(), а для вывода множество сортируют: sorted(set(names)).

Если названия должны идти так, как впервые встретились, помогает словарь. Вызов dict.fromkeys(names) делает названия ключами. Повторное название новой пары не создает, а словарь хранит порядок вставки. Значения при этом не нужны, и fromkeys() ставит у всех None. Функция list() от такого словаря дает список ключей.

Множество не хранит порядок появления, поэтому для вывода в порядке первого появления оно не подходит. Здесь нужен dict.fromkeys().

Пример

Пример 1. Повторы с сохранением порядка и без него

unique.py
names = ["s2", "s1", "s2", "s1"]
print(len(names), len(set(names)))  # → 4 2
print(sorted(set(names)))           # → ['s1', 's2']
print(list(dict.fromkeys(names)))   # → ['s2', 's1']
Вывод
4 2
['s1', 's2']
['s2', 's1']

Различных названий два. Множество через sorted() дает их по алфавиту, словарь — в порядке первого появления: s2 раньше s1.

Практика

Добавьте в начало списка "s3" и запустите: список должен начинаться с 's3'.

unique.py
names = ["s2", "s1", "s2", "s1"]
print(list(dict.fromkeys(names)))  # → ['s2', 's1']
Вывод
['s2', 's1']

2. Общие и различающиеся элементы

Теория

Два набора, например гены, которые работают в двух образцах ткани, сравнивают по трем вопросам: какие гены общие, какие есть только в первом образце, какие ровно в одном. Наборы хранят множествами, и на эти вопросы отвечают операции со страницы 05: пересечение &, разность - и симметрическая разность ^.

Если для образца хранится словарь «ген : число прочтений», превращать его в множество не нужно. Представление keys() поддерживает те же операции: counts1.keys() & counts2.keys() дает множество общих генов. Названия генов в примере настоящие, а данные условные.

Пример

Пример 2. Сравнение наборов генов

genes.py
first = {"BRCA1", "TP53", "EGFR"}
second = {"TP53", "KRAS", "EGFR"}
print(sorted(first & second))  # → ['EGFR', 'TP53']
print(sorted(first - second))  # → ['BRCA1']
print(sorted(first ^ second))  # → ['BRCA1', 'KRAS']
Вывод
['EGFR', 'TP53']
['BRCA1']
['BRCA1', 'KRAS']

Общие гены — EGFR и TP53. Только в первом наборе — BRCA1. Ровно в одном — BRCA1 и KRAS.

Практика

Добавьте во второй набор "BRCA1" и запустите: разность должна стать пустым списком.

genes.py
first = {"BRCA1", "TP53", "EGFR"}
second = {"TP53", "KRAS", "EGFR"}
print(sorted(first - second))  # → ['BRCA1']
Вывод
['BRCA1']

3. Мера Жаккара

Теория

Операции показывают, какие элементы общие. Но насколько похожи два набора в целом? Для ответа нужна одна величина, которая растет вместе с долей общих элементов.

Мера Жаккара (Jaccard index) равна доле общих элементов среди всех различных элементов двух наборов.

J(A, B) = |A ∩ B| / |A ∪ B|. Здесь |A ∩ B| означает число общих элементов, а |A ∪ B| число различных элементов обоих наборов. В задачах наборы непустые, поэтому знаменатель больше нуля.

Мера равна 1 для одинаковых наборов и 0 для наборов без общих элементов. Для генов из примера 2 общих генов два, а различных четыре, поэтому J = 2 / 4 = 0.5. В Python это len(a & b) / len(a | b).

Последовательности сравнивают по множествам их k-меров. Каждое окно добавляют в множество методом add(): срез добавляется целиком, одним элементом, а повторное окно ничего не меняет.

Для меры Жаккара нужно множество k-меров, а не счетчик: счетчик окон со страницы 07 хранит число повторов, а множество хранит каждый k-мер один раз.

На мере Жаккара основаны программы быстрого сравнения геномов, например Mash. Они оценивают меру по небольшой выборке k-меров и не строят множества целиком.

Пример

Пример 3. Мера Жаккара наборов k-меров

jaccard.py
first = "ACGTACGT"
second = "ACGTTCGT"
k = 3
kmers1 = set()
for start in range(len(first) - k + 1):
    kmers1.add(first[start:start + k])
kmers2 = set()
for start in range(len(second) - k + 1):
    kmers2.add(second[start:start + k])
print(sorted(kmers1 & kmers2))  # → ['ACG', 'CGT']
print(len(kmers1 | kmers2))  # → 7
print(round(len(kmers1 & kmers2) / len(kmers1 | kmers2), 2))  # → 0.29
Вывод
['ACG', 'CGT']
7
0.29

Общих 3-меров два, ACG и CGT; различных всего семь. Мера 2 / 7 ≈ 0.29.

Типичная ошибка: сумма размеров вместо объединения

Неверно: len(a) + len(b)
print(len(a & b) / (len(a) + len(b)))
Верно
print(len(a & b) / len(a | b))

В сумме размеров общие элементы посчитаны дважды, и мера одинаковых наборов получается 0.5 вместо 1.

Практика

Замените значение second на "ACGTACGT" и запустите: мера должна стать 1.0.

jaccard.py
first = "ACGTACGT"
second = "ACGTTCGT"
k = 3
kmers1 = set()
for start in range(len(first) - k + 1):
    kmers1.add(first[start:start + k])

    kmers2.add(second[start:start + k])

Вывод
0.29

Упражнение 6.9.2. Мера Жаккара

Условие задачи

Посчитайте меру Жаккара двух наборов генов и выведите ее, округленную функцией round() до двух знаков после точки.

Входные данные

Две строки: два набора генов, названия через пробел, в каждой строке от 1 до 100 названий. Внутри строки названия могут повторяться.

Выходные данные

Число от 0 до 1 в том виде, в каком его печатает print() после round(): 0.5, а не 0.50.

Пример

Разберем пример

Ввод BRCA1 TP53 EGFR
TP53 KRAS EGFR
→
Вывод 0.5

Общих генов два, EGFR и TP53, а различных генов четыре: 2 / 4 = 0.5.

Примеры
ВводВывод

TP53 KRAS EGFR
0.5
A B

Контекст

Образцы разных тканей сравнивают по тому, какие гены в них работают. Чем больше у двух образцов общих активных генов, тем больше они похожи.

Основные определения

  • Ген — участок ДНК, по которому клетка строит белок; ген работает, если клетка сейчас строит по нему белок.
  • Набор активных генов — гены, которые работают в образце ткани.
  • Мера Жаккара — число общих элементов двух наборов, деленное на число всех различных элементов.
  • Оператор & — пересечение: элементы, которые есть в обоих множествах.
  • Оператор | — объединение: все различные элементы двух множеств.
  • Функция round(x, n) — округляет до n знаков после точки.
Подсказка
  1. Постройте множества генов обеих строк.
  2. Числитель меры равен размеру пересечения &, знаменатель размеру объединения |.
  3. Округлите частное до двух знаков: round(..., 2), и напечатайте.
  4. Сверьтесь с примером: для ввода BRCA1 TP53 EGFR, TP53 KRAS EGFR программа печатает 0.5.

Контекст

Из многих образцов отбирают похожие на эталон: мера Жаккара сравнивается с порогом 0.5.

Основные определения

  • Эталонная последовательность — последовательность, с которой сравнивают остальные.
  • k-мер — подстрока длины k; k-меры берут во всех позициях с шагом 1, поэтому соседние перекрываются.
  • Мера Жаккара — число общих элементов двух наборов, деленное на число всех различных элементов.
  • Сравнение без деления — 2 * len(common) >= len(union) то же, что len(common) / len(union) >= 0.5.
Подсказка
  1. Постройте множество k-меров эталона так же, как в среднем варианте.
  2. Для каждого образца постройте его множество k-меров тем же кодом.
  3. Сравнивайте без деления: 2 * len(common) >= len(union). Так сравнение обходится целыми числами.
  4. Соберите подходящие образцы. Если их нет, выведите нет.
  5. Сверьтесь с примером: для ввода ACGTACGT, 3, ACGTAC TTTT CGTACG программа печатает ACGTAC CGTACG.
