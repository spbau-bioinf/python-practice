1. Удаление повторов

Теория

Набор идентификаторов, генов или прочтений часто содержит повторы, а порядок элементов в нем может быть как важен, так и безразличен. Если порядок не важен, повторы удаляет set().

Если порядок важен, например идентификаторы должны идти так, как в исходном файле, помогает словарь: dict.fromkeys() делает элементы ключами, повторный ключ новой пары не создает, а словарь хранит порядок вставки. Вызов list() от словаря возвращает список ключей в порядке вставки.

Те же средства работают и для значений словаря. Если словарь «образец → ткань» содержит повторяющиеся ткани, set(d.values()) дает набор различных тканей, а sorted() от этого множества возвращает отсортированный список для предсказуемого вывода. Образец (sample) — биологический материал, последовательность которого читают (страница 05).

Пример

Пример 1. Повторы с сохранением порядка и без него

dedup.py
ids = ["s2", "s1", "s2", "s1"]
print(len(ids), len(set(ids)))   # → 4 2
print(sorted(set(ids)))          # → ['s1', 's2']
print(list(dict.fromkeys(ids)))  # → ['s2', 's1']
Вывод
4 2
['s1', 's2']
['s2', 's1']

Из четырех идентификаторов осталось два различных. sorted(set(ids)) дает алфавитный порядок, dict.fromkeys(ids) сохраняет порядок первого появления: s2, затем s1.

Типичная ошибка: порядок от множества

Неверно: порядок не гарантирован
print(list(set(ids)))
Верно
print(list(dict.fromkeys(ids)))

Множество не сохраняет порядок: на разных запусках порядок его элементов может отличаться. Если порядок первого появления важен, повторы удаляют словарем dict.fromkeys().

Практика

Василиса чистит список образцов. Добавьте в список еще один "s1" и запустите: число различных идентификаторов не должно измениться.

2. Общие и различающиеся элементы

Теория

Пусть в двух образцах ткани найдены наборы активных генов. Вопросы «какие гены общие», «какие есть только в первом образце», «какие есть ровно в одном» решаются операциями множеств: пересечением &, разностью - и симметрической разностью ^.

Если для образца хранится словарь «ген → число прочтений», превращать его в множество не нужно: представление keys() реализует операции множеств &, |, - и ^, а результат таких операций является обычным множеством.

Названия генов в примере настоящие (BRCA1, TP53, EGFR, KRAS), но данные условные. Ген — участок ДНК, по которому клетка строит белок или молекулу РНК; BRCA1, TP53, EGFR и KRAS — примеры белок-кодирующих генов.

Пример

Пример 2. Сравнение наборов генов

genes.py
a = {"BRCA1", "TP53", "EGFR"}
b = {"TP53", "KRAS", "EGFR"}
print(sorted(a & b))          # → ['EGFR', 'TP53']
print(sorted(a - b))          # → ['BRCA1']
print(sorted(a ^ b))          # → ['BRCA1', 'KRAS']
c1 = {"TP53": 5, "EGFR": 2}
c2 = {"EGFR": 7, "KRAS": 1}
print(c1.keys() & c2.keys())  # → {'EGFR'}
Вывод
['EGFR', 'TP53']
['BRCA1']
['BRCA1', 'KRAS']
{'EGFR'}

Общие гены двух образцов: EGFR и TP53; только в первом BRCA1; ровно в одном BRCA1 и KRAS. Для словарей «ген → число прочтений» пересечение ключей дает общий ген EGFR.

Типичная ошибка: разность в обратную сторону

Неверно: вычитаем наоборот
print(sorted(b - a))
Верно
print(sorted(a - b))

Разность несимметрична: b - a показывает гены второго образца, которых нет в первом. Порядок операндов определяется вопросом задачи.

Практика

Прохор сравнивает образцы. Добавьте ген "KRAS" в первый набор и запустите: в разности a - b должен остаться только BRCA1.

Вывод

3. Мера Жаккара

Теория

Окно добавляют в множество методом add(): после windows = set() и windows.add("ACGT"[0:2]) множество содержит строку "AC" целиком — add() кладет срез как один элемент, а не по буквам. Счетчик окон со страницы 07 хранит число повторов каждого k-мера, а множество окон — по одной копии: для меры Жаккара важен сам факт присутствия окна.

Мера Жаккара (Jaccard index) — доля общих элементов среди всех различных элементов двух наборов.

J(A, B) = |A ∩ B| / |A ∪ B| при непустом объединении |A ∪ B| > 0; |A ∩ B| — число общих элементов, |A ∪ B| — число различных элементов обоих наборов. В упражнениях этого раздела объединение всегда непустое.

Программа Mash оценивает сходство геномов: индекс Жаккара их наборов k-меров (страница 07) оценивается по эскизам — небольшой выборке хешей, а из оценки вычисляется расстояние Mash.

Пример

Пример 3. Мера Жаккара наборов k-меров

jaccard.py
s1 = "ACGTACGT"
s2 = "ACGTTCGT"
a = {s1[i:i + 3] for i in range(len(s1) - 2)}
b = {s2[i:i + 3] for i in range(len(s2) - 2)}
print(len(a & b) / len(a | b))  # → 0.2857142857142857
print(sorted(a & b))            # → ['ACG', 'CGT']
Вывод
0.2857142857142857
['ACG', 'CGT']

Две короткие последовательности разбиты на 3-меры. Наборы из четырех и пяти k-меров имеют два общих, поэтому мера Жаккара равна 2 / 7. Значение печатается в том виде, в каком его печатает Python.

Типичная ошибка: деление на меньший набор

Неверно: доля от одного набора
print(len(a & b) / len(a))
Верно
print(len(a & b) / len(a | b))

Деление на размер одного набора даст долю покрытия, а не меру Жаккара. Делить нужно на размер объединения: общие элементы среди всех различных.

Практика

Василиса сравнивает одинаковые строки. Замените "ACGTTCGT" на "ACGTACGT" и запустите: мера должна стать 1.0.
