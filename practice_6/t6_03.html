Перебор словаря

25 минутЕрофеев А. И.

Перебирать ключи, значения и пары словаря, выводить их в нужном порядке и строить словарь из двух последовательностей.

1. Перебор ключей, значений и пар

Теория

Список перебирают циклом for по элементам. Что же перебирает цикл по словарю, ведь в словаре пары? Цикл for key in counts: перебирает ключи. Значение по ключу внутри цикла достают как обычно: counts[key].

Если нужны только значения, их дает метод values(). Если нужны и ключ, и значение, удобнее метод items(). Он дает пары «ключ, значение», и пару сразу распаковывают в две переменные в заголовке цикла: for base, count in counts.items():. Распаковка работает так же, как у кортежа в практике 5.

Методы keys(), values() и items() возвращают не списки, а представления (view). Представление не копирует данные: оно смотрит в сам словарь и меняется вместе с ним. Если нужен настоящий список, его получают вызовом list(), например list(counts.values()).

Во время цикла по словарю нельзя добавлять и удалять ключи: Python остановит программу ошибкой RuntimeError. Чтобы удалить часть ключей, перебирают их копию, список ключей: for key in list(counts):.

ЗаписьЧто перебирает
for key in d:ключи, как d.keys()
for value in d.values():значения
for key, value in d.items():пары, распакованные в две переменные
Пример

Пример 1. Ключи, значения и пары

items.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}
print(list(counts))          # → ['A', 'T', 'G', 'C']
print(sum(counts.values()))  # → 46
for base, count in counts.items():
    if count > 10:
        print(base, count)
Вывод
['A', 'T', 'G', 'C']
46
A 12
G 15
C 11

list(counts) дает список ключей. Сумма значений, 46, — число нуклеотидов в прочтении. Цикл по items() получает сразу букву и число и печатает буквы, встретившиеся больше 10 раз.

Пример 2. Удаление ключей при переборе

remove.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}
for base in list(counts):
    if counts[base] < 10:
        del counts[base]
print(counts)  # → {'A': 12, 'G': 15, 'C': 11}
Вывод
{'A': 12, 'G': 15, 'C': 11}

Цикл идет по списку ключей, а удаление меняет словарь, поэтому ошибки нет. Если написать for base in counts:, первая же инструкция del остановит программу ошибкой RuntimeError с сообщением «dictionary changed size during iteration» — словарь изменился во время перебора.

Практика

Измените условие так, чтобы печатались буквы, встретившиеся меньше 10 раз, и запустите: должна напечататься T 8.

items.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}
for base, count in counts.items():
    if count > 10:
        print(base, count)
Вывод
A 12
G 15
C 11

2. Порядок вставки и sorted()

Теория

В каком порядке цикл выдает ключи? В том, в каком их добавляли в словарь. Этот порядок называют порядком вставки. Python гарантирует его начиная с версии 3.7, поэтому утверждение «словарь не хранит порядок» из старых книг сегодня неверно.

Порядок вставки не обязан быть алфавитным: ключ "T", добавленный первым, и напечатан будет первым. Если нужен алфавитный порядок, ключи сортируют функцией sorted(). Она не меняет словарь, а строит новый список ключей: sorted(counts) дает ['A', 'C', 'G', 'T'], а сам counts остается прежним.

Чтобы напечатать пары по алфавиту ключей, перебирают отсортированный список ключей и по каждому ключу берут значение: for base in sorted(counts):, а в теле цикла print(base, counts[base]).

Пример

Пример 3. Порядок вставки и sorted()

order.py
counts = {"T": 8, "A": 12}
counts["G"] = 15
counts["T"] = 9
print(list(counts))    # → ['T', 'A', 'G']
print(sorted(counts))  # → ['A', 'G', 'T']
for base in sorted(counts):
    print(base, counts[base])
Вывод
['T', 'A', 'G']
['A', 'G', 'T']
A 12
G 15
T 9

Замена значения "T" не сдвинула его место: list(counts) дает порядок вставки. sorted(counts) — новый список ключей по алфавиту, а цикл по нему печатает пары в алфавитном порядке.

Типичная ошибка: sorted() вместо словаря

Неверно: counts = sorted(counts)
counts = {"T": 8, "A": 12}
counts = sorted(counts)
print(counts["A"])
Верно
counts = {"T": 8, "A": 12}
keys = sorted(counts)
print(counts["A"])  # → 12

В неверном варианте имя counts стало списком ключей, и обращение по ключу останавливает программу ошибкой TypeError. Результат sorted() сохраняют в отдельную переменную.

Практика

Добавьте строку, которая печатает sorted(counts), и запустите: должно появиться ['A', 'G', 'T'].

order.py
counts = {"T": 8, "A": 12, "G": 15}
print(list(counts))  # → ['T', 'A', 'G']
Вывод
['T', 'A', 'G']

3. Словарь из двух последовательностей

Теория

Данные часто приходят двумя списками одинаковой длины: в одном названия образцов, в другом длины их последовательностей в том же порядке. Как получить из них словарь «название : длина»?

Функция zip() составляет пары из элементов с одинаковыми номерами: первый с первым, второй со вторым. Например, zip(["s1", "s2"], [5, 12]) дает пары ("s1", 5) и ("s2", 12). Из таких пар функция dict() строит словарь, как на странице 01: dict(zip(names, lengths)).

Если ключ встречается несколько раз, в словаре остается последнее значение: каждая следующая пара с тем же ключом заменяет предыдущую.

Словарь можно построить и словарным включением. Оно устроено как списковое включение из практики 5, только записано в фигурных скобках и содержит два выражения через двоеточие, для ключа и для значения: {s: len(s) for s in seqs} строит словарь «строка : ее длина».

Пример

Пример 4. Словарь из двух списков

build.py
ids = ["s1", "s2", "s3"]
lengths = [8, 12, 8]
length_of = dict(zip(ids, lengths))
print(length_of)                  # → {'s1': 8, 's2': 12, 's3': 8}
print(length_of["s2"])            # → 12
seqs = ["ATG", "GATTACA"]
print({s: len(s) for s in seqs})  # → {'ATG': 3, 'GATTACA': 7}
Вывод
{'s1': 8, 's2': 12, 's3': 8}
12
{'ATG': 3, 'GATTACA': 7}

zip(ids, lengths) составляет пары ("s1", 8), ("s2", 12), ("s3", 8), и dict() строит из них словарь. Включение строит словарь «строка : длина» прямо из списка строк.

Пример 5. Повтор ключа

repeat.py
pairs = [("s1", 8), ("s2", 12), ("s1", 5)]
print(dict(pairs))  # → {'s1': 5, 's2': 12}
Вывод
{'s1': 5, 's2': 12}

Ключ "s1" встретился дважды: в словаре осталось последнее значение 5. Место ключа — место его первого появления.

Практика

Допишите в оба списка образец "s4" длиной 20 и напечатайте length_of["s4"].

build.py
ids = ["s1", "s2", "s3"]
lengths = [8, 12, 8]
length_of = dict(zip(ids, lengths))
print(length_of)  # → {'s1': 8, 's2': 12, 's3': 8}
Вывод
{'s1': 8, 's2': 12, 's3': 8}

Контекст

Образец иногда читают повторно, и в списках его название встречается дважды. Словарь из пар оставляет для повторного ключа последнее значение, поэтому верная длина получается сама.

Основные определения

  • Образец — биологический материал, последовательность которого прочитали; у образца есть название.

  4. Сверьтесь с примером: для ввода s1 s2 s1 и 8 12 5 и s1 программа печатает 2 и 5.

Чтобы отобрать образцы нужной длины, перебирают пары словаря и оставляют названия с подходящим значением. Отобранные названия затем упорядочивают по алфавиту.

  • Образец — биологический материал, последовательность которого прочитали; у образца есть название.

  • Метод join() — склеивает строки списка через разделитель; " ".join(d) у словаря склеивает ключи.

  3. Напечатайте отсортированный список через пробел: " ".join(sorted(result)).
  4. Сверьтесь с примером: для ввода s3 s1 s2 и 8 12 8 и 8 программа печатает s2 s3.

Задача со звездочкой 6.3. Убрать короткие

Условие задачи

Названия образцов различны. Удалите из словаря «название : длина» инструкцией del образцы, длина которых меньше порога из третьей строки. Выведите названия оставшихся образцов через пробел в порядке ввода. Если не осталось ни одного, выведите пустую строку.

Входные данные

В первой строке названия образцов через пробел, во второй столько же длин последовательностей через пробел, в том же порядке. Длины являются целыми числами от 1 до 10000. В третьей строке порог, целое число от 1 до 10000.

Выходные данные

Названия через пробел или пустая строка.

Пример

10

Вывод s2

Порог 10: образцы s1 и s3 короче, их удаляют, и остается s2.

Контекст

Короткие последовательности часто отбрасывают: по ним трудно что-то надежно определить. Удалять пары прямо в цикле по словарю нельзя, поэтому перебирают копию списка ключей.

Основные определения

  • Инструкция del d[key] — удаляет пару вместе с ключом.
  • Список ключей list(d) — копия ключей; по ней можно удалять пары в цикле.
  • Ошибка RuntimeError — удаление ключей в цикле прямо по словарю: словарь изменился во время перебора.
  • Метод join() — склеивает строки списка через разделитель; " ".join(d) у словаря склеивает ключи.
Подсказка
  1. Постройте словарь и прочитайте порог.
  2. Во время цикла по словарю удалять ключи нельзя. Перебирайте копию ключей: for name in list(length_of):.
  3. Удаляйте пару инструкцией del, если длина меньше порога.
  4. Напечатайте оставшиеся ключи через пробел: " ".join(length_of).
  5. Сверьтесь с примером: для ввода s1 s2 s3 и 8 12 8 и 10 программа печатает s2.

Задача со звездочкой 6.3. Сводка по длинам

Условие задачи

Названия образцов могут повторяться, и для повторного образца верна последняя длина. Для каждой длины, которая есть у образцов, выведите, сколько образцов имеют эту длину. Пары «длина:число» выведите через пробел по возрастанию длины.

Входные данные

В первой строке названия образцов через пробел, во второй столько же длин последовательностей через пробел, в том же порядке. Длины являются целыми числами от 1 до 10000.

Выходные данные

Пары «длина:число» через пробел.

Пример

Ввод s1 s2 s3

→

Контекст

Сводка по длинам показывает, каких образцов больше, коротких или длинных. Это тот же подсчет, только считаются не буквы, а значения словаря.

Основные определения

  • Образец — биологический материал, последовательность которого прочитали; у образца есть название.
  • Метод values() — значения словаря без ключей.
  • Метод get(key, default) — значение ключа или default, если ключа нет; словарь не меняется.
  • Функция sorted() — новый список по возрастанию; у словаря сортирует ключи.
Подсказка
  1. Сначала постройте словарь «название : длина»: так повторный образец будет учтен один раз.
  2. Затем посчитайте его значения вторым словарем «длина : число образцов».
  3. Переберите длины по возрастанию: sorted(count_of), и соберите пары str(length) + ":" + str(...).
  4. Напечатайте пары через пробел.
  5. Сверьтесь с примером: для ввода s1 s2 s3 и 8 12 8 программа печатает 8:2 12:1.
