Перебор словаря

25 минутЕрофеев А. И.

Перебирать ключи, значения и пары словаря, получать ключи в нужном порядке функцией sorted() и строить словарь из двух последовательностей.

1. Перебор ключей, значений и пар

Теория

Цикл for по словарю перебирает его ключи. Значения возвращает метод values(), пары «ключ, значение» кортежами возвращает метод items(). Пару удобно сразу распаковать в заголовке цикла: for b, n in counts.items():.

Методы keys(), values() и items() возвращают не списки, а представления: они не копируют данные и меняются вместе со словарем. Если нужен список, его получают вызовом list().

Почему это удобно: данные о последовательности часто считают по словарю — например, сумма значений счетчика нуклеотидов равна длине последовательности. Цикл по парам items() дает сразу и ключ, и значение, без повторного обращения к словарю.

ЗаписьЧто перебирает
for k in d:ключи (то же, что d.keys())
for v in d.values():значения
for k, v in d.items():пары, распакованные в две переменные
Пример

Пример 1. Ключи, значения и пары

counts.py
counts = {"A": 12, "T": 8,
          "G": 15, "C": 11}
print(list(counts))          # → ['A', 'T', 'G', 'C']
print(sorted(counts))        # → ['A', 'C', 'G', 'T']
print(sum(counts.values()))  # → 46
for b, n in counts.items():
    print(b, n, end="; ")
Вывод
['A', 'T', 'G', 'C']
['A', 'C', 'G', 'T']
46
A 12; T 8; G 15; C 11;

list(counts) дает список ключей, sorted(counts) — те же ключи по алфавиту. Если счетчики получены подсчетом букв последовательности, сумма значений, здесь 46, равна ее длине. В цикле пара распаковывается: буква попадает в b, число в n.

Пример 2. Представление меняется вместе со словарем

keys.py
d = {"T": 8, "A": 12}
keys = d.keys()
d["G"] = 15
print(keys)        # → dict_keys(['T', 'A', 'G'])
del d["T"]
d["T"] = 1
print(list(keys))  # → ['A', 'G', 'T']
Вывод
dict_keys(['T', 'A', 'G'])
['A', 'G', 'T']

Представление keys получено до изменений, но видит новый ключ "G". После удаления и повторного добавления ключ "T" встал в конец. Обратиться к представлению по индексу нельзя: если нужен список, его получают вызовом list().

counts.py

    print(b, n, end="; ")
Вывод

2. Порядок вставки и sorted()

Теория

Словарь сохраняет порядок вставки: ключи перебираются в том порядке, в каком их добавляли. Замена значения существующего ключа порядок не меняет, а ключ, добавленный после удаления, встает в конец. Это гарантировано в Python 3.7 и новее.

Порядок вставки не обязан быть алфавитным. Если нужен алфавитный порядок (или любой другой), ключи сортируют функцией sorted(). Она не меняет словарь, а строит новый список: sorted(counts) — это список ключей по алфавиту, сам counts остается прежним.

Хеш помогает искать место для ключа (страница 02), а порядок обхода задает вставка: при одинаковом порядке вставки он один и тот же при каждом обращении и в каждом запуске.

Утверждение «словарь не хранит порядок» встречается в книгах о Python 2 и для современных версий неверно. Меняться между запусками может порядок множества — оно перебирается по ячейкам, а хеши строк зависят от запуска. Поэтому для предсказуемого вывода порядок задают сами: функцией sorted().

Пример

Пример 3. Порядок вставки и sorted()

order.py
counts = {"T": 8, "A": 12}
keys = counts.keys()
counts["G"] = 15
counts["T"] = 9
print(keys)            # → dict_keys(['T', 'A', 'G'])
del counts["T"]
counts["T"] = 1
print(list(keys))      # → ['A', 'G', 'T']
print(sorted(counts))  # → ['A', 'G', 'T']
Вывод
dict_keys(['T', 'A', 'G'])
['A', 'G', 'T']
['A', 'G', 'T']

Замена значения ключа "T" не сдвинула его место, а после удаления и повторного добавления он встал в конец. sorted(counts) строит новый список по алфавиту; сам словарь не изменился.

Типичная ошибка: sorted() вместо списка

Неверно: ожидание словаря
counts = {"T": 8, "A": 12}
counts = sorted(counts)
print(counts["A"])
Верно
counts = {"T": 8, "A": 12}
keys = sorted(counts)
print(counts["A"])  # → 12

В неверном варианте counts стал списком ключей, и обращение по ключу поднимает TypeError. Результат sorted() сохраняют в отдельную переменную: это новый список, а не словарь.

3. Построение словаря из данных

Теория

Данные часто приходят двумя параллельными списками: названия образцов и их длины. Функция zip() составляет из них пары, а dict() строит из пар словарь. Образец (sample) — биологический материал, последовательность которого читают (страница 05).

Второй способ — словарное включение: оно устроено как списковое, только скобки фигурные и вместо одного выражения два через двоеточие: ключ и значение.

Если при построении словаря ключ встречается несколько раз, в словаре остается последнее значение.

Словарные включения появились в языке по предложению PEP 274. Включение удобно, когда значение вычисляется из самого ключа: {s: len(s) for s in seqs} строит словарь «название: длина названия» без второго списка.

Пример

Пример 4. Словарь из двух списков

zip.py
ids = ["s1", "s2", "s3"]
lens = [8, 12, 8]
d = dict(zip(ids, lens))
print(d)                          # → {'s1': 8, 's2': 12, 's3': 8}
seqs = ["ATG", "GATTACA"]
print({s: len(s) for s in seqs})  # → {'ATG': 3, 'GATTACA': 7}
Вывод
{'s1': 8, 's2': 12, 's3': 8}
{'ATG': 3, 'GATTACA': 7}

zip(ids, lens) составляет пары ("s1", 8), ("s2", 12), ("s3", 8), и dict() строит из них словарь. Включение строит словарь «название: длина» прямо из списка строк.

Пример 5. Повтор ключа

dups.py
pairs = [("s1", 8), ("s2", 12), ("s1", 5)]
print(dict(pairs))  # → {'s1': 5, 's2': 12}
Вывод
{'s1': 5, 's2': 12}

Ключ "s1" встретился дважды: в словаре осталось последнее значение 5, а не первое 8. Это работает и для dict(zip(...)), и для включений.
