Частоты и k-меры

25 минутЕрофеев А. И.

Считать нуклеотидный и GC-состав, находить самый частый элемент счетчика и считать k-меры с учетом перекрытий.

1. Нуклеотидный состав и GC-состав

Теория

Разбор прочитанной последовательности начинают с подсчета букв. В задаче DNA сборника Rosalind нужно посчитать, сколько раз встречаются A, C, G и T, и вывести четыре числа именно в этом порядке.

Counter считает все буквы за один проход. Порядок вывода задают сами обращения counts["A"], counts["C"] и так далее, а для буквы, которой в последовательности нет, счетчик дает 0.

GC-состав (GC content) показывает, какую долю всех нуклеотидов последовательности составляют G и C, в процентах.

Его считают по счетчику: сумму counts["G"] и counts["C"] делят на длину последовательности и умножают на 100. В GATTACA букв G и C две из семи, то есть примерно 28.6 процента.

GC-состав различается у разных организмов и у разных участков генома. По нему, например, проверяют, не попала ли в образец чужая ДНК.

Пример

Пример 1. Состав и GC-состав

gc.py
from collections import Counter
seq = "AGCTTTTCATTCTGAC"
counts = Counter(seq)
print(counts["A"], counts["C"], counts["G"], counts["T"])  # → 3 4 2 7
gc = counts["G"] + counts["C"]
print(round(gc / len(seq) * 100, 1))  # → 37.5
Вывод
3 4 2 7
37.5

Четыре числа идут в порядке A, C, G, T, а не в порядке появления букв. Букв G и C шесть из шестнадцати: 37.5 процента.

Типичная ошибка: доля вместо процентов

Неверно: без * 100
print(round(gc / len(seq), 1))
Верно
print(round(gc / len(seq) * 100, 1))

Без умножения на 100 получается доля от 0 до 1, а округление до одного знака еще и съедает точность.

Практика

Замените последовательность на "GGCCATGC" и запустите: GC-состав должен стать 75.0.

gc.py
from collections import Counter
seq = "AGCTTTTCATTCTGAC"
counts = Counter(seq)
gc = counts["G"] + counts["C"]
print(round(gc / len(seq) * 100, 1))  # → 37.5
Вывод
37.5
Задача

2. Самый частый элемент

Теория

Самую частую букву хочется найти вызовом max(counts). Но функция max() от словаря перебирает ключи и сравнивает сами ключи. Для счетчика букв она вернет последнюю букву по алфавиту, а не самую частую.

Чтобы сравнивать ключи по их значениям, передают аргумент key. Запись max(counts, key=counts.get) для каждого ключа вызывает counts.get, сравнивает полученные числа и возвращает ключ с наибольшим числом. Метод передают без скобок, так же как key=len при сортировке строк по длине.

При равных числах max() возвращает ключ, который идет раньше, то есть букву, встретившуюся раньше. Это то же правило ничьей, что во всей практике.

Тот же аргумент работает в sorted(): с key=counts.get и reverse=True она дает ключи от самого частого к самому редкому. Сортировка устойчива, поэтому равные элементы остаются в прежнем порядке и при reverse=True.

Пример

Пример 2. Самый частый элемент

top.py
from collections import Counter
counts = Counter("GATTACA")
print(max(counts))                  # → T
print(max(counts, key=counts.get))  # → A
print(counts.most_common(1))        # → [('A', 3)]
Вывод
T
A
[('A', 3)]

Без key ответ — T, последняя по алфавиту. С key=counts.get — A, у нее 3. most_common(1) дает список из одной пары «буква, число».

Практика

Замените "GATTACA" на "GGATCG" и запустите: ответом должна стать G.

top.py
from collections import Counter
counts = Counter("GATTACA")
print(max(counts, key=counts.get))  # → A
Вывод
A

3. k-меры

Теория

Буквы считают по одной. Повторяющиеся участки из нескольких букв, например тройки, ищут иначе: строку разбирают на короткие участки одной длины.

k-мер (k-mer) состоит из k подряд идущих букв строки. Например, в GATTACA первый 3-мер GAT, а второй ATT.

k-меры берут во всех позициях. Окно длины k сдвигается по строке на одну букву, поэтому соседние окна перекрываются. В строке длины n таких окон n - k + 1, а окно с началом start дает срез text[start:start + k].

Вхождения k-мера считают с учетом перекрытий: в GATATAT 3-мер ATA встречается дважды, хотя эти два вхождения делят букву.

Самые частые k-меры находят счетчиком окон. Пустой Counter() с операцией += 1 работает так же, как defaultdict(int): новый k-мер начинает с 0.

Метод строки count() перекрывающиеся вхождения не считает: "AAAA".count("AA") дает 2, а окон AA три. Поэтому вхождения с перекрытием считают окнами.

Пример

Пример 3. Самые частые k-меры

kmers.py
from collections import Counter
text = "ACGTTGCATGTCGCATGATGCATGAGAGCT"
k = 4
counts = Counter()
for start in range(len(text) - k + 1):
    counts[text[start:start + k]] += 1
top = max(counts.values())
print(top)  # → 3
for kmer, count in counts.items():
    if count == top:
        print(kmer)
Вывод
3
GCAT
CATG

Это пример задачи BA1B сборника Rosalind. Наибольшее число вхождений 3; его набирают два 4-мера, и они печатаются в порядке первого появления.

Типичная ошибка: окна без перекрытия

Неверно: шаг k
for start in range(0, len(text) - k + 1, k):
    counts[text[start:start + k]] += 1
Верно
for start in range(len(text) - k + 1):
    counts[text[start:start + k]] += 1

С шагом k окна не перекрываются, и часть k-меров не посчитана. k-меры берут во всех позициях, с шагом 1.

Практика

Замените k = 4 на k = 2 и запустите: самым частым станет 2-мер с пятью вхождениями.

kmers.py
from collections import Counter
text = "ACGTTGCATGTCGCATGATGCATGAGAGCT"
k = 4
counts = Counter()
for start in range(len(text) - k + 1):
    counts[text[start:start + k]] += 1
print(counts.most_common(1))  # → [('GCAT', 3)]
Вывод
[('GCAT', 3)]
Задача

Повторить разобранное в примере.

Контекст

На k-мерах основаны сборка генома из прочтений и быстрое сравнение последовательностей. Первый вопрос о любой строке: сколько в ней разных k-меров.

Основные определения

  • k-мер — подстрока длины k; k-меры берут во всех позициях с шагом 1, поэтому соседние перекрываются.
  • Запись range(len(text) - k + 1) — начала всех окон длины k, последнее окно кончается на последней букве.
  • Срез text[start:start + k] — подстрока длины k с позиции start.
  • Метод add() — добавляет элемент в множество; повторный элемент ничего не меняет.
Подсказка
  1. Окна начинаются в позициях от 0 до len(text) - k включительно: for start in range(len(text) - k + 1):.
  2. Добавляйте каждое окно text[start:start + k] в множество: повторное окно ничего не меняет.
  3. Напечатайте размер множества.
  4. Сверьтесь с примером: для ввода GATATAT, 3 программа печатает 3.

  4. Сверьтесь с примером: для ввода GATATAT, 3 программа печатает ATA TAT.

Задача со звездочкой 6.7. Сортировка по частоте

Условие задачи

Выведите без пробелов буквы последовательности, отсортированные от самой частой к самой редкой, каждую букву один раз. Буквы с равным числом идут в порядке первого появления.

Входные данные

Последовательность нуклеотидов: строка из букв A, C, G, T длиной от 1 до 1000.

Выходные данные

Строка из различных букв.

Пример

Разберем пример

Ввод GATTACA
→
Вывод ATGC

Буква A встречается 3 раза, T 2 раза, G и C по одному. G встретилась раньше C, поэтому ответ ATGC.

Примеры
ВводВывод
 
GATTACA
ATGC
CCCA
CA
Контекст

Порядок букв по частоте позволяет быстро сравнить состав двух последовательностей на глаз.

Основные определения

  • Класс Counter — словарь-счетчик из модуля collections: Counter(seq) считает элементы за один вызов.
  • Аргумент key=counts.get — сортирует ключи по их значениям; reverse=True ставит большие значения первыми, а равные остаются в прежнем порядке.
  • Метод join() — склеивает строки списка через разделитель.
Подсказка
  1. Постройте Counter букв.
  2. Отсортируйте его ключи по значениям: sorted(counts, key=counts.get) с аргументом reverse=True. Сортировка устойчива, и равные остаются в порядке первого появления.
  3. Склейте буквы без пробелов: "".join(...).
  4. Сверьтесь с примером: для ввода GATTACA программа печатает ATGC.
