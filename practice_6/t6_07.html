Частоты и k-меры

25 минутЕрофеев А. И.

Строить нуклеотидный состав и GC-состав счетчиком, находить самый частый элемент и считать k-меры с перекрывающимися окнами.

1. Нуклеотидный состав и GC-состав

Теория

Задача DNA сборника Rosalind требует посчитать, сколько раз в последовательности ДНК встречаются символы A, C, G и T, и вывести четыре числа в этом порядке. Counter проходит по строке один раз и считает все буквы сразу.

Цикл по строке "ACGT" задает порядок вывода; если какой-то буквы в последовательности нет, Counter даст для нее 0. Порядок первого появления букв здесь не подходит: задача требует алфавитный.

GC-состав — доля нуклеотидов G и C в процентах среди всех нуклеотидов последовательности. Считается из двух счетчиков: (c["G"] + c["C"]) / len(seq) * 100.

Счетчики и GC-состав нужны, чтобы сравнить распределение GC-состава прочтений с ожидаемым для данного материала. Прочтение — последовательность, полученная при секвенировании. Ручной расчет из примера: в GATTACA две буквы G или C из семи, то есть примерно 28.6 процента.

Пример
Счетчики и GC-состав
dna.py
from collections import Counter
seq = "AGCTTTTCATTCTGAC"
c = Counter(seq)
print(c["A"], c["C"], c["G"], c["T"])  # → 3 4 2 7
gc = c["G"] + c["C"]
print(round(gc / len(seq) * 100, 1))   # → 37.5
Вывод
3 4 2 7
37.5

Один вызов print() с четырьмя аргументами печатает счетчики в алфавитном порядке букв. GC-состав — доля букв G и C: их шесть из шестнадцати, то есть 37.5 процента.

Типичная ошибка: GC-состав без длины

Неверно: деление на 4
gc = c["G"] + c["C"]
print(gc / 4 * 100)
Верно
gc = c["G"] + c["C"]
print(gc / len(seq) * 100)

Деление на 4 дало бы долю среди четырех видов букв, а не среди всех букв последовательности. Делить нужно на длину последовательности.

2. Самый частый элемент

Теория

Функция max() по словарю перебирает ключи и сравнивает их самих: для счетчика букв она вернула бы последнюю букву по алфавиту, а не самую частую. Чтобы сравнивать ключи по их значениям, функции передают аргумент key.

Аргументом key служит метод c.get, записанный без скобок: передается сама функция, как key=len при сортировке строк по длине. Для каждой буквы c.get возвращает ее счетчик, и max() сравнивает счетчики, а возвращает букву. При равных счетчиках max() возвращает букву, встретившуюся раньше; на странице 04 при равенстве выбиралась первая по алфавиту — поэтому на входе TTAA ответы этих правил расходятся, и выбор задает условие задачи.

Третье средство, c.most_common(1), возвращает список из одной пары; чтобы получить ключ, из списка берут первую пару, а из пары ее первый элемент.

Пример

Пример 2. Самый частый элемент

freq.py
from collections import Counter
c = Counter("GATTACA")
print(max(c, key=c.get))    # → A
print(sorted(c, key=c.get,  # → ['A', 'T', 'G', 'C']
             reverse=True))
print(c.most_common(1))     # → [('A', 3)]
Вывод
A
['A', 'T', 'G', 'C']
[('A', 3)]

Три строки решают одну задачу разными средствами. max() с аргументом key=c.get возвращает самую частую букву A. Сортировка по частоте ставит ее первой. Метод c.most_common(1) возвращает список с одной парой; в этом примере print выводит [('A', 3)].

Типичная ошибка: max() без key

Неверно: сравниваются ключи
print(max(c))
Верно
print(max(c, key=c.get))

Без аргумента key функция max() сравнивает сами ключи и вернет последнюю букву по алфавиту. Сравнивать нужно счетчики: key=c.get.

Практика

Прохор ищет частую букву. Замените "GATTACA" на "ACGTACGT" и запустите: самой частой должна стать буква A.

Вывод

3. k-меры

Теория

k-мер — участок строки из k подряд идущих букв.

Кодоны читают без перекрытия, с шагом 3. k-меры берут во всех позициях подряд: окно сдвигается на одну букву, поэтому соседние окна перекрываются, и вхождения k-мера считаются с учетом перекрытий. В строке длины n таких окон n − k + 1.

Самые частые k-меры находят тем же счетчиком окон. Пустой Counter() с операцией += 1 работает так же, как defaultdict(int).

Задача BA1B сборника Rosalind называет k-мер самым частым, если число его вхождений максимально среди всех k-меров строки, и требует найти все такие k-меры. Если их несколько, выводятся все.

Пример

Пример 3. Самые частые k-меры

kmers.py
from collections import Counter
text = ("ACGTTGCATGTCGCA"
        "TGATGCATGAGAGCT")
k = 4
c = Counter()
for i in range(len(text) - k + 1):
    c[text[i:i + k]] += 1
top = max(c.values())
print(top)                            # → 3
print([w for w in c if c[w] == top])  # → ['GCAT', 'CATG']
Вывод
3
['GCAT', 'CATG']

В строке длины 30 при k = 4 окон 27. Максимальный счетчик равен 3, и его имеют два 4-мера, GCAT и CATG. Цикл сдвигает окно на одну букву, поэтому вхождения перекрываются.

Типичная ошибка: окон на одно меньше

Неверно: окон меньше на одно
for i in range(len(text) - k):
    c[text[i:i + k]] += 1
Верно
for i in range(len(text) - k + 1):
    c[text[i:i + k]] += 1

Последний k-мер начинается за k букв до конца строки, поэтому окон на одно больше: n − k + 1.

Практика

Сложнее продвинутого упражнения.

Задача со звездочкой 6.7. k-меры с двумя вхождениями

Что нужно сделать

Считайте строку из букв и число k. Выведите все k-меры, которые встречаются ровно два раза, через пробел в порядке появления; если таких нет, выведите пустую строку. Окна сдвигаются на одну букву и перекрываются, счетчик постройте вызовом Counter() в цикле for.

Входные данные

Две строки: строка из 1–100 букв и число k от 1 до длины строки.

Выходные данные

k-меры через пробел или пустая строка.
