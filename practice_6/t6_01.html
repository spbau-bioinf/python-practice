Словарь и ключи

25 минутЕрофеев А. И.

Создавать словарь, читать и менять значения по ключу, добавлять и удалять пары и обрабатывать отсутствующий ключ без ошибки.

1. Пары «ключ : значение»

Теория

Список хранит значения по номерам: rec[2], и смысл позиции нужно помнить. Словарь хранит значения по ключам: gene["protein_length"], и по записи видно, что это длина белка. Ключ должен быть хешируемым: строки, целые числа и кортежи из хешируемых элементов подходят, списки ключами быть не могут (страница 02). Ключи в словаре не повторяются, значения могут повторяться. В примере запись о белок-кодирующем гене: участке ДНК, по которому клетка строит белок; BRCA1 — название одного из белок-кодирующих генов человека.

Словарь (тип dict) — набор пар «ключ : значение», в котором по ключу находят связанное с ним значение.

Словарь записывают в фигурных скобках: пары перечисляются через запятую, ключ и значение в паре разделяются двоеточием. Значение достают квадратными скобками, как элемент списка, но внутри скобок стоит ключ. Функция len() возвращает число пар, а не число символов.

Зачем это нужно: биологические данные почти всегда записывают парами: название образца и его длина, нуклеотид и его количество, кодон и аминокислота. Словарь хранит такую пару целиком, и по названию значение находится сразу, без перебора. В практике 5 для этого пришлось бы просматривать список.

СпособЗаписьКогда удобен
Литерал{"A": 12, "T": 8}пары известны заранее
Из списка парdict([("A", 12), ("T", 8)])пары собраны в список
Именованные аргументыdict(A=12, T=8)ключи простые имена
Пример

Пример 1. Запись о гене

gene.py
gene = {"id": "BRCA1",
        "chromosome": 17,
        "protein_length": 1863,
        "organism": "Homo sapiens"}
print(gene["id"])              # → BRCA1
print(gene["protein_length"])  # → 1863
print(len(gene))               # → 4
print(gene["chromosome"] + 1)  # → 18
Вывод
BRCA1
1863
4
18

Длинный словарь записан на нескольких строках: пока скобка не закрыта, интерпретатор считает это одной инструкцией. Значение ведет себя как обычный объект своего типа: к номеру хромосомы прибавляется единица. len(gene) возвращает 4 пары.

Пример 2. Три способа создать словарь

ways.py
pairs = [("A", 12), ("T", 8)]
print(dict(pairs))        # → {'A': 12, 'T': 8}
print(dict(A=12, T=8))    # → {'A': 12, 'T': 8}
print({"A": 12, "T": 8})  # → {'A': 12, 'T': 8}
Вывод
{'A': 12, 'T': 8}
{'A': 12, 'T': 8}
{'A': 12, 'T': 8}

Три строки дают один и тот же словарь. У именованных аргументов ключи записываются без кавычек и должны быть простыми именами; у литерала и списка пар ключом может быть любое выражение.

Типичная ошибка: обращение к словарю по номеру

Неверно: gene[0]
print(gene[0])
Верно
print(gene["id"])

У словаря нет номеров позиций, как у списка. gene[0] ищет ключ 0 и поднимает KeyError: 0. Обращаются по ключу.

2. Добавление, замена и удаление

Теория

Словарь изменяемый. Присваивание по ключу работает двумя способами: если ключа еще нет, в словаре появляется новая пара; если ключ уже есть, прежнее значение забывается и заменяется новым. Инструкция del удаляет пару вместе с ключом.

Нуклеотид — звено цепи ДНК, в записи последовательности это одна буква A, C, G или T; примеры ниже считают такие буквы (страница 04).

Присваивание по существующему ключу не добавляет вторую пару: число пар не меняется, меняется только значение.

Обратите внимание на порядок ключей в выводе примера: ключ "A" остался первым, хотя его значение меняли. Словарь сохраняет порядок вставки: замена значения ключ не сдвигает, а ключ, добавленный после удаления, встает в конец. Подробно порядок и перебор разбираются на странице 03.

Пример

Пример 3. Добавление, замена и удаление

counts.py
counts = {"A": 12, "T": 8}
counts["G"] = 15
counts["A"] = 13
del counts["T"]
print(counts)       # → {'A': 13, 'G': 15}
print(len(counts))  # → 2
Вывод
{'A': 13, 'G': 15}
2

Строка counts["A"] = 13 не добавила вторую пару с ключом "A": ключи не повторяются, поэтому изменилось только значение. После удаления пары "T" остались две пары.

Пример 4. Удаление пары

del.py
counts = {"A": 12, "T": 8, "G": 15}
del counts["T"]
counts["T"] = 1
print(counts)  # → {'A': 12, 'G': 15, 'T': 1}
Вывод
{'A': 12, 'G': 15, 'T': 1}

После удаления и повторного добавления ключ "T" встал в конец: место в порядке вставки при удалении не сохраняется.

Типичная ошибка: замена значения как «вторая пара»

Неверно: ожидание 3 пар
counts = {"A": 12, "T": 8}
counts["A"] = 13
print(len(counts))  # → 2
Верно: пар осталось 2
counts = {"A": 12, "T": 8}
counts["A"] = 13
print(len(counts))  # → 2

Код одинаковый, разница в ожидании: выводится 2, а не 3. Замена значения новую пару не создает.

Практика

Прохор обновляет счетчик. Замените значение "A" на 13 и добавьте пару "G": 15, затем запустите: вывод должен стать {'A': 13, 'G': 15}.

counts.py
counts = {"A": 12, "T": 8}
counts["A"] = 13
del counts["T"]
print(counts)  # → {'A': 13}
Вывод
{'A': 13}

3. Отсутствующий ключ

Теория

Обращение по ключу, которого в словаре нет, останавливает программу ошибкой KeyError, и в сообщении указан сам ключ. Ожидание, что отсутствующий ключ даст None или 0, для квадратных скобок неверно: так ведет себя только метод get().

Ошибки можно избежать двумя способами. Оператор in проверяет, есть ли ключ в словаре. Метод get() возвращает значение ключа, а если ключа нет, возвращает None или свой второй аргумент; сам ключ в словарь не добавляется.

Оператор in для словаря проверяет только ключи, а не значения: 12 in counts для словаря {"A": 12, "T": 8} дает False, хотя значение 12 в словаре есть. Среди значений ищут так: 12 in counts.values(); представление values() разбирается на странице 03.

Разница важна и для скорости: проверка ключа через in работает почти одинаково быстро при любом размере словаря, а поиск среди значений просматривает их по одному, как в списке. Причина этой разницы — на странице 02. Когда запрошенного ключа может не оказаться, берите значение методом get(), а не квадратными скобками.

Пример

Пример 5. Проверка ключа и метод get()

get.py
counts = {"A": 12, "T": 8}
print("N" in counts)       # → False
print(counts.get("N"))     # → None
print(counts.get("N", 0))  # → 0
print(counts.get("T", 0))  # → 8
Вывод
False
None
0
8

Ключа "N" в словаре нет: in дает False, get() без второго аргумента возвращает None, с нулем 0. Для ключа "T" возвращается его значение 8, а не второй аргумент.

Пример 6. Ошибка KeyError

keyerror.py
counts = {"A": 12, "T": 8}
print(counts["N"])
Сообщение об ошибке
KeyError: 'N'

Квадратные скобки не спрашивают, есть ли ключ: они сразу поднимают KeyError, и в сообщении указан сам ключ. Для списка аналогичная ситуация, индекс за концом, вызывает IndexError.

Типичная ошибка: значение вместо ключа

Неверно: ищем значение 12
counts = {"A": 12, "T": 8}
print(12 in counts)  # → False
Верно
counts = {"A": 12, "T": 8}
print(12 in counts.values())  # → True

Первый вариант выводит False: in ищет только среди ключей, а 12 — значение. Правильная проверка ключа: "A" in counts. Поиск среди значений методом values() разбирается на странице 03.

Практика

Василиса исправляет падение программы. Замените counts["N"] на counts.get("N", 0) и запустите: программа должна напечатать 0.

Сообщение об ошибке
