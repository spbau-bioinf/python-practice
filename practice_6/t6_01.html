Словарь и ключи

25 минутЕрофеев А. И.

Создавать словарь, читать значения по ключу, добавлять, заменять и удалять пары и обрабатывать отсутствующий ключ без ошибки.

1. Пары «ключ : значение»

Теория

В практике 5 запись о гене хранили списком: ["BRCA1", 17, 1863]. Чтобы прочитать длину белка, нужно помнить, что она стоит под индексом 2. В записи из трех полей это нетрудно. В записи из двадцати полей индексы путаются, а строка rec[13] ничего не говорит тому, кто читает код. Удобнее обращаться к значению по имени.

Список находит значение по номеру позиции, а словарь по имени. Имя значения называют ключом.

Словарь (тип dict) хранит пары «ключ : значение» и находит значение по ключу.

Словарь записывают в фигурных скобках. Пары разделяют запятыми, а ключ от значения отделяет двоеточие: {"A": 12, "T": 8}. Запись {} означает пустой словарь. Значение достают квадратными скобками, как элемент списка, только в скобках стоит ключ: counts["A"] дает 12.

Функция len() возвращает число пар. Ключи в словаре не повторяются, а значения могут повторяться: в словаре {"A": 12, "C": 12} две пары с одинаковым значением.

Данные о последовательностях почти всегда приходят парами: название образца и его длина, буква и число ее вхождений, кодон и аминокислота. Словарь хранит такие пары целиком и находит значение по названию сразу, не перебирая все записи.

СпособЗаписьКогда удобен
Литерал{"A": 12, "T": 8}пары известны заранее
Из списка парdict([("A", 12), ("T", 8)])пары собраны в список
Именованные аргументыdict(A=12, T=8)ключи пишутся как имена переменных
Пример

Пример 1. Запись о гене

gene.py
gene = {"id": "BRCA1",
        "chromosome": 17,
        "protein_length": 1863}
print(gene["id"])                     # → BRCA1
print(gene["protein_length"])         # → 1863
print(len(gene))                      # → 3
print(gene["protein_length"] > 1000)  # → True
Вывод
BRCA1
1863
3
True

Запись описывает ген человека BRCA1 из хромосомы 17. Длинный словарь записан на нескольких строках: пока фигурная скобка не закрыта, Python считает все строки одной инструкцией. Значение по ключу ведет себя как обычное число, его можно сравнить с 1000. len(gene) возвращает 3, это число пар.

Пример 2. Три способа создать словарь

ways.py
pairs = [("A", 12), ("T", 8)]
print(dict(pairs))        # → {'A': 12, 'T': 8}
print(dict(A=12, T=8))    # → {'A': 12, 'T': 8}
print({"A": 12, "T": 8})  # → {'A': 12, 'T': 8}
print({1: "A", 2: "C"})   # → {1: 'A', 2: 'C'}
Вывод
{'A': 12, 'T': 8}
{'A': 12, 'T': 8}
{'A': 12, 'T': 8}
{1: 'A', 2: 'C'}

Первые три строки дают один и тот же словарь, записанный тремя способами.

  • dict(pairs) строит словарь из списка пар: каждый кортеж ("A", 12) становится парой «ключ : значение».
  • dict(A=12, T=8) передает пары функции dict() именованными аргументами. Именованный аргумент записывают в виде имя=значение, как sep=" " у print(). Имя слева от знака = становится ключом-строкой: A=12 дает пару 'A': 12. Поэтому ключ здесь пишется без кавычек и должен годиться в имя переменной: dict(1=12) или dict(stop-codon=1) Python не примет.
  • {"A": 12, "T": 8} — литерал словаря, то есть словарь, записанный прямо в коде, как строка "ATG" или число 12. У литерала и у списка пар ключом может быть и строка, и число: последняя строка печатает словарь с ключами 1 и 2.

Типичная ошибка: обращение к словарю по номеру

Неверно: gene[0]
print(gene[0])
Верно
print(gene["id"])

У словаря нет номеров позиций. gene[0] ищет ключ 0 и останавливает программу ошибкой KeyError: 0. Обращаются по ключу.

Практика

Добавьте в словарь пару "organism": "Homo sapiens" и запустите: len(gene) должно стать 4.

gene.py
gene = {"id": "BRCA1",
        "chromosome": 17,
        "protein_length": 1863}
print(len(gene))  # → 3
Вывод
3

2. Добавление, замена и удаление

Теория

В примерах этой практики словарь counts хранит, сколько раз каждая буква встретилась в последовательности: {"A": 12, "T": 8} значит, что буква A встретилась 12 раз, а буква T — 8 раз. Когда к последовательности добавляются новые буквы, эти числа приходится увеличивать, а для новой буквы заводить пару. Поэтому словарь, как и список, можно менять после создания.

Новое значение записывают присваиванием по ключу: counts["G"] = 15. Что при этом произойдет, зависит от того, есть ли такой ключ.

Если ключа еще нет, в словаре появляется новая пара. Если ключ уже есть, второй пары с тем же ключом не появляется: прежнее значение заменяется новым, и число пар не меняется.

Инструкция del удаляет пару вместе с ключом: del counts["T"]. Ключ, которого нет, удалить нельзя: del останавливает программу той же ошибкой KeyError, что и чтение (раздел 3).

Словарь помнит, в каком порядке добавлялись ключи, и печатает пары в этом порядке. Замена значения не меняет место ключа. Ключ, который удалили и добавили снова, встает в конец.

Присваивание не копирует словарь. После saved = counts у одного словаря два имени, так же как у списка в практике 5 на странице 02. Изменение через counts видно и через saved. Отдельную копию делает метод copy(): saved = counts.copy().

Пример

Пример 3. Добавление, замена и удаление

counts.py
counts = {"A": 12, "T": 8}
counts["G"] = 15
counts["A"] = 13
del counts["T"]
print(counts)       # → {'A': 13, 'G': 15}
print(len(counts))  # → 2
Вывод
{'A': 13, 'G': 15}
2

Строка counts["G"] = 15 добавила новую пару. Строка counts["A"] = 13 не добавила вторую пару с ключом "A": ключи не повторяются, поэтому изменилось только значение, а "A" остался первым. После удаления "T" остались две пары.

Пример 4. Ключ после удаления встает в конец

order.py
counts = {"A": 12, "T": 8, "G": 15}
del counts["T"]
counts["T"] = 1
print(counts)  # → {'A': 12, 'G': 15, 'T': 1}
Вывод
{'A': 12, 'G': 15, 'T': 1}

После удаления и повторного добавления ключ "T" оказался последним: прежнее место ключа при удалении не сохраняется.

Типичная ошибка: второе имя вместо копии

Неверно: saved = counts
saved = counts
counts["A"] = 0
print(saved["A"])
Верно
saved = counts.copy()
counts["A"] = 0
print(saved["A"])

После saved = counts оба имени указывают на один словарь, поэтому «сохраненное» значение тоже стало 0. Копию делает copy().

Практика

Добавьте пару "C": 11 после удаления "T" и запустите: в выводе должно быть три пары, "C" последней.

counts.py
counts = {"A": 12, "T": 8}
counts["G"] = 15
counts["A"] = 13
del counts["T"]
print(counts)  # → {'A': 13, 'G': 15}
Вывод
{'A': 13, 'G': 15}

Упражнение 6.1.1. Новое значение

Условие задачи

В словаре counts хранятся количества нуклеотидов в прочтении:

counts.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}

Считайте букву и число и запишите число в словарь под этой буквой. Если буква уже есть, ее значение заменится, а если ее нет, появится новая пара. Выведите число пар в словаре и значение введенной буквы.

Входные данные

Две строки: буква (A, C, G, T или N) и целое число от 0 до 1000.

Выходные данные

Две строки: число пар в словаре после записи и значение введенной буквы.

Пример

Разберем пример

Ввод G
20
→
Вывод 4
20

Буква G уже есть в словаре, поэтому ее значение 15 заменяется на 20, а пар остается четыре.

Примеры
ВводВывод

Контекст

Прибор-секвенатор читает ДНК кусками, и после каждого прочтения счетчики нуклеотидов обновляют. Присваивание по ключу делает это одной строкой: новая буква добавляется, у известной буквы меняется значение.

Основные определения

  • Прочтение — участок последовательности, который прибор-секвенатор прочитал за один раз.
  • Нуклеотид — звено цепи ДНК; в записи последовательности это одна из букв A, C, G, T.
  • Присваивание по ключу d[key] = value — добавляет пару, если ключа нет, и заменяет значение, если ключ есть.
  • Функция len() — у словаря возвращает число пар, у списка число элементов.
Подсказка
  1. Прочитайте букву и число: letter = input(), number = int(input()).
  2. Запишите число под буквой: counts[letter] = number. Эта строка и заменяет значение, и добавляет пару.
  3. Напечатайте len(counts) и counts[letter].
  4. Сверьтесь с примером: для ввода G, 20 программа печатает 4, 20.

Упражнение 6.1.1. Прибавить к счетчику

Условие задачи

В словаре counts хранятся количества нуклеотидов в прочтении:

counts.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}

В новом прочтении одна из букв встретилась еще несколько раз. Считайте букву и число и прибавьте число к значению этой буквы в словаре. Выведите новое значение буквы и сумму значений всех четырех букв.

Входные данные

Две строки: буква (A, C, G или T) и целое число от 0 до 1000.

Выходные данные

Две строки: новое значение буквы и сумма значений всех четырех букв.

Пример

Разберем пример

Ввод A
3
→
Вывод 15
49

К значению A прибавляется 3: было 12, стало 15. Сумма всех значений равна 15 + 8 + 15 + 11, то есть 49.

Контекст

Счетчики нуклеотидов обновляют по мере того, как прибор читает новые участки последовательности. Новое число не заменяет старое, а прибавляется к нему.

Основные определения

  • Прочтение — участок последовательности, который прибор-секвенатор прочитал за один раз.
  • Запись d[key] = d[key] + number — справа читает прежнее значение, слева записывает новое.
  • Чтение по ключу d[key] — значение ключа; если ключа нет, программа останавливается ошибкой KeyError.
  • Функция int() — переводит строку в целое число.
Подсказка
  1. Прочитайте букву и число, число переведите функцией int().
  2. Запишите под той же буквой сумму прежнего значения и числа: counts[letter] = counts[letter] + number.
  3. Сумму четырех значений считайте уже после изменения словаря и напечатайте оба числа.
  4. Сверьтесь с примером: для ввода A, 3 программа печатает 15, 49.

Упражнение 6.1.1. Правки словаря

Условие задачи

В словаре counts хранятся количества нуклеотидов в прочтении:

counts.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}

Правки к словарю записаны одной строкой, например A:15 T:0 N:2. Правка «буква:число» записывает число под буквой: заменяет значение или добавляет пару. Число 0 означает, что букву нужно удалить из словаря. Правка с нулем приходит только для буквы, которая в этот момент есть в словаре. Примените правки слева направо и выведите получившийся словарь.

Входные данные

Одна строка из 1–10 правок через пробел. Правка состоит из заглавной латинской буквы, двоеточия и целого числа от 0 до 1000.

Выходные данные

Словарь после всех правок в том виде, в каком его выводит print().

Пример

Разберем пример

Ввод A:15 T:0 N:2
→
Вывод {'A': 15, 'G': 15, 'C': 11, 'N': 2}

A получает значение 15 и остается на своем месте, T удаляется, а N добавляется в конец.

Примеры
ВводВывод
 
A:15 T:0 N:2
{'A': 15, 'G': 15, 'C': 11, 'N': 2}
T:0 T:5
{'A': 12, 'G': 15, 'C': 11, 'T': 5}
Контекст

Правки приходят одной строкой, и каждую нужно разобрать на букву и число. Порядок пар в выводе словаря совпадает с порядком добавления ключей; замена значения место ключа не меняет.

Основные определения

  • Метод split() — разрезает строку на части по пробелам; split(":") режет по двоеточию.
  • Присваивание по ключу d[key] = value — добавляет пару, если ключа нет, и заменяет значение, если ключ есть.
  • Инструкция del d[key] — удаляет пару вместе с ключом.
  • Вывод print(d) — печатает пары в фигурных скобках в порядке добавления ключей.
Подсказка
  1. Переберите правки: for edit in input().split():.
  2. Разделите правку по двоеточию: letter, text = edit.split(":"), число переведите функцией int().
  3. Если число равно 0, удалите пару инструкцией del, иначе запишите число под буквой.
  4. Напечатайте словарь целиком: print(counts). Буква, которую удалили и добавили снова, окажется в конце.
  5. Сверьтесь с примером: для ввода A:15 T:0 N:2 программа печатает {'A': 15, 'G': 15, 'C': 11, 'N': 2}.

3. Отсутствующий ключ

Теория

Ключа, о котором спрашивают, в словаре может не оказаться. Квадратные скобки в этом случае не возвращают ни None, ни 0. Программа останавливается ошибкой KeyError, и в сообщении стоит сам ключ.

Ошибки избегают двумя способами. Оператор in проверяет, есть ли ключ: "N" in counts дает True или False. Метод get() возвращает значение ключа, а для отсутствующего ключа возвращает None или свой второй аргумент: counts.get("N", 0) дает 0. Ни in, ни get() словарь не меняют.

ЗаписьКлюч естьКлюча нет
counts[key]значениеошибка KeyError
key in countsTrueFalse
counts.get(key)значениеNone
counts.get(key, 0)значение0

Оператор in у словаря ищет только среди ключей: для словаря {"A": 12, "T": 8} выражение 12 in counts дает False, хотя значение 12 в словаре есть.

В словаре из десяти пар и в словаре из миллиона пар проверка ключа через in занимает одинаковое время. Почему так, объясняет страница 02. Поиск среди значений, 12 in counts.values(), просматривает значения по одному, как в списке. Метод values() разбирается на странице 03.

Пример

Пример 5. Проверка ключа и метод get()

get.py
counts = {"A": 12, "T": 8}
print("N" in counts)       # → False
print(counts.get("N"))     # → None
print(counts.get("N", 0))  # → 0
print(counts.get("T", 0))  # → 8
print(len(counts))         # → 2
Вывод
False
None
0
8
2

Ключа "N" нет: in дает False, get() без второго аргумента возвращает None, а со вторым аргументом 0. Для ключа "T" возвращается его значение 8. Число пар осталось 2: get() ничего не добавил.

Пример 6. Ошибка KeyError

keyerror.py
counts = {"A": 12, "T": 8}
print(counts["N"])
Сообщение об ошибке
KeyError: 'N'

Квадратные скобки не проверяют, есть ли ключ: программа сразу останавливается, и в сообщении стоит отсутствующий ключ 'N'.

Типичная ошибка: значение вместо ключа

Неверно: поиск значения через in
counts = {"A": 12, "T": 8}
print(12 in counts)  # → False
Верно
counts = {"A": 12, "T": 8}
print("A" in counts)  # → True

in ищет только среди ключей, а 12 здесь значение. Проверяют ключ.

Практика

Замените counts["N"] на counts.get("N", 0) и запустите: программа должна напечатать 0.

fix.py
counts = {"A": 12, "T": 8}
print(counts["N"])
Сообщение об ошибке
KeyError: 'N'
Задача

Повторить разобранное в примере.

Упражнение 6.1.2. Поле записи

Условие задачи

В словаре protein хранится запись о белке p53:

protein.py
protein = {"id": "P04637", "name": "p53", "length": 393,
           "organism": "Homo sapiens", "gene": "TP53"}

Задача со звездочкой 6.1. Какая буква чаще

Условие задачи

В словаре counts хранятся количества нуклеотидов в прочтении:

counts.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}

Считайте две буквы и выведите ту, у которой значение больше. Буква, которой нет в словаре, считается встретившейся 0 раз. Если значения равны, выведите первую букву.

Входные данные

Две строки, в каждой одна заглавная латинская буква.

Контекст

Прибор отмечает буквой N нуклеотид, который не смог определить, поэтому в запросе может прийти буква, которой в словаре счетчиков нет. Метод get() отвечает на такой запрос числом по умолчанию, а не ошибкой.

  2. Возьмите их значения методом get() с нулем: counts.get(first, 0).
  3. Если значение второй буквы строго больше, напечатайте вторую, иначе первую: так при равенстве выводится первая.

Задача со звездочкой 6.1. Добавки к счетчикам

Условие задачи

В словаре counts хранятся количества нуклеотидов в прочтении:

counts.py
counts = {"A": 12, "T": 8, "G": 15, "C": 11}

Добавки записаны одной строкой, например A:3 N:2. Добавка «буква:число» прибавляет число к значению буквы. Если буквы в словаре нет, она появляется со значением, равным добавке. Примените добавки слева направо и выведите получившийся словарь.

Входные данные

Одна строка из 1–10 добавок через пробел. Добавка состоит из заглавной латинской буквы, двоеточия и целого числа от 0 до 1000.

Выходные данные

Словарь после всех добавок в том виде, в каком его выводит print().

Пример

Разберем пример

Ввод A:3 N:2
→
Вывод {'A': 15, 'T': 8, 'G': 15, 'C': 11, 'N': 2}

К A прибавляется 3, получается 15. Буквы N в словаре не было, поэтому она появляется в конце со значением 2.

Примеры
ВводВывод
 
A:3 N:2
{'A': 15, 'T': 8, 'G': 15, 'C': 11, 'N': 2}
N:1 N:1
{'A': 12, 'T': 8, 'G': 15, 'C': 11, 'N': 2}
Контекст

Так объединяют счетчики нескольких прочтений одной последовательности: добавка к известной букве складывается с ее значением, а новая буква появляется в словаре.

Основные определения

  • Прочтение — участок последовательности, который прибор-секвенатор прочитал за один раз.
  • Метод get(key, default) — значение ключа или default, если ключа нет; словарь не меняется.
  • Метод split() — разрезает строку на части по пробелам; split(":") режет по двоеточию.
  • Присваивание по ключу d[key] = value — добавляет пару, если ключа нет, и заменяет значение, если ключ есть.
Подсказка
  1. Переберите добавки и разделите каждую по двоеточию.
  2. Новое значение равно counts.get(letter, 0) + int(text): для буквы, которой еще нет, get() дает 0.
  3. Запишите его под буквой и после цикла напечатайте словарь.
  4. Сверьтесь с первым примером из таблицы «Примеры»: программа должна напечатать ровно его вывод.

Задача со звездочкой 6.1. Синонимы полей

Условие задачи

В словаре protein хранится запись о белке p53, а в словаре aliases — другие названия некоторых полей:

protein.py
protein = {"id": "P04637", "name": "p53", "length": 393,
           "organism": "Homo sapiens", "gene": "TP53"}
aliases = {"len": "length", "size": "length",
           "symbol": "gene", "species": "organism"}

Считайте строку с названиями полей. Название может быть ключом записи или ключом словаря aliases, который указывает на настоящее поле. Выведите через пробел значения полей в порядке ввода. Если поле не нашлось ни в записи, ни в aliases, выведите вместо его значения знак ?.

Входные данные

Одна строка из 1–10 названий через пробел.

Выходные данные

Значения через пробел.

Пример

Разберем пример

Ввод len symbol id
→
Вывод 393 TP53 P04637

len указывает на поле length, symbol на поле gene, а id и есть поле записи.

Примеры
ВводВывод
 
len symbol id
393 TP53 P04637
species mass
Homo sapiens ?
Контекст

В разных базах данных одно и то же поле называют по-разному, поэтому программы держат словарь синонимов.

Основные определения

  • Синоним поля — другое название того же поля записи.
  • Запись aliases.get(word, word) — дает настоящее название поля, а если синонима нет, само слово.
  • Метод get(key, default) — значение ключа или default, если ключа нет; словарь не меняется.
  • Функция str() — переводит число в строку, чтобы склеить его с другими строками.
  • Метод join() — склеивает строки списка через разделитель.
Подсказка
  1. Переберите названия из строки.
  2. Замените название на настоящее поле, если оно есть в aliases: field = aliases.get(word, word). Если синонима нет, остается само слово.
  3. Возьмите значение поля с запасным ответом: protein.get(field, "?"), переведите его в строку и добавьте в список.
  4. Напечатайте список через пробел.
  5. Сверьтесь с примером: для ввода len symbol id программа печатает 393 TP53 P04637.
