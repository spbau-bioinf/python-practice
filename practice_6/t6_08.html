Кодоны и трансляция

25 минутЕрофеев А. И.

Строить таблицу генетического кода словарем, переводить мРНК в белок с остановкой на стоп-кодоне и находить синонимичные кодоны обращением словаря.

1. Генетический код

Теория

Сначала комплекс белков РНК-полимераза синтезирует по матричной цепи гена короткую молекулу матричной РНК (мРНК); при сравнении с кодирующей цепью вместо T в записи РНК стоит U. Затем рибосомы читают в мРНК кодоны, тройки соседних нуклеотидов, один за другим: каждый кодон задает аминокислоту или сигнал завершения.

Кодон — тройка подряд идущих нуклеотидов, читаемая в заданной рамке. Трансляция — перевод информации с четырехбуквенного алфавита РНК на двадцатибуквенный алфавит белков. Стоп-кодон — кодон UAA, UAG или UGA, на котором чтение заканчивается; в таблице его обозначают знаком *.

В стандартном коде 64 кодона и 20 обычных аминокислот, поэтому код вырожден: некоторые аминокислоты записываются несколькими разными кодонами, а у метионина и триптофана кодон один.

NCBI записывает каждый код таблицы строкой из 64 символов, где i-й символ относится к i-му кодону, если кодоны перечислять в порядке U, C, A, G по первой, второй и третьей позиции. Такой порядок дают три вложенных цикла: внешний перебирает первую букву, внутренний третью, поэтому третья буква меняется чаще всех. Букву для тройки находят по месту в этом порядке: например, тройка CCC стоит в списке кодонов 22-й, и 22-й символ строки — P. Строку удобно разбить на четыре куска по 16 символов: соседние строковые литералы в скобках Python склеивает в одну строку. Таблица NCBI записана буквами ДНК: там, где в записи РНК стоит U, в таблице T. Стандартный код не единственный: NCBI перечисляет таблицы для митохондрий и ряда организмов.

Пример

Пример 1. Таблица кодонов словарем

code.py
bases = "UCAG"
codons = [a + b + c for a in bases for b in bases for c in bases]
aas = ("FFLLSSSSYY**CC*W"
       "LLLLPPPPHHQQRRRR"
       "IIIMTTTTNNKKSSRR"
       "VVVVAAAADDEEGGGG")
code = dict(zip(codons, aas))
print(len(codons), codons[:4])   # → 64 ['UUU', 'UUC', 'UUA', 'UUG']
print(code["AUG"], code["UAA"])  # → M *
Вывод
64 ['UUU', 'UUC', 'UUA', 'UUG']
M *

Одна строка перечисляет 64 кодона в порядке NCBI; тот же порядок дают три вложенных цикла из теории — именно вложенные циклы отрабатывают упражнения этой страницы, а включение здесь лишь короткая запись того же построения. Функции zip() и dict() строят словарь. Кодон AUG кодирует метионин M, кодон UAA — стоп. То же построение вложенными циклами:

То же построение вложенными циклами
codons = []
for a in bases:
    for b in bases:
        for c in bases:
            codons.append(a + b + c)

Типичная ошибка: порядок циклов

Неверно: третья буква снаружи
for c in bases:
    for b in bases:
        for a in bases:
            codons.append(a + b + c)
Верно
for a in bases:
    for b in bases:
        for c in bases:
            codons.append(a + b + c)

Строка аминокислот NCBI записана для кодонов, где быстрее всего меняется третья буква. Если третья буква во внешнем цикле, порядок кодонов не совпадет со строкой, и таблица перепутается.

2. Трансляция

Теория

Программная трансляция повторяет работу рибосомы: идет по мРНК с шагом в один кодон и ищет аминокислоту в таблице. По договоренности в упражнениях первая буква мРНК считается началом выбранной рамки считывания, а стоп-кодон останавливает трансляцию в этой рамке.

Индекс идет с шагом 3, срез из трех букв дает кодон, словарь дает аминокислоту. На стоп-кодоне цикл прерывается инструкцией break, иначе буква дописывается к белку.

Буква N — обозначение неизвестного основания в записи входа; в упражнениях такой кодон целиком помечают знаком вопроса. Обращение квадратными скобками вызовет KeyError; устойчивее запись code.get(кодон, "?").

Задача PROT сборника Rosalind требует по строке мРНК получить закодированную в ней строку белка; по договоренности чтение начинается с первой буквы, а на стоп-кодоне в выбранной рамке заканчивается.

Пример

Пример 2. Трансляция мРНК

translate.py
code = {'UUU': 'F', 'UUC': 'F', 'UUA': 'L', 'UUG': 'L', 'UCU': 'S', 'UCC': 'S', 'UCA': 'S', 'UCG': 'S', 'UAU': 'Y', 'UAC': 'Y', 'UAA': '*', 'UAG': '*', 'UGU': 'C', 'UGC': 'C', 'UGA': '*', 'UGG': 'W', 'CUU': 'L', 'CUC': 'L', 'CUA': 'L', 'CUG': 'L', 'CCU': 'P', 'CCC': 'P', 'CCA': 'P', 'CCG': 'P', 'CAU': 'H', 'CAC': 'H', 'CAA': 'Q', 'CAG': 'Q', 'CGU': 'R', 'CGC': 'R', 'CGA': 'R', 'CGG': 'R', 'AUU': 'I', 'AUC': 'I', 'AUA': 'I', 'AUG': 'M', 'ACU': 'T', 'ACC': 'T', 'ACA': 'T', 'ACG': 'T', 'AAU': 'N', 'AAC': 'N', 'AAA': 'K', 'AAG': 'K', 'AGU': 'S', 'AGC': 'S', 'AGA': 'R', 'AGG': 'R', 'GUU': 'V', 'GUC': 'V', 'GUA': 'V', 'GUG': 'V', 'GCU': 'A', 'GCC': 'A', 'GCA': 'A', 'GCG': 'A', 'GAU': 'D', 'GAC': 'D', 'GAA': 'E', 'GAG': 'E', 'GGU': 'G', 'GGC': 'G', 'GGA': 'G', 'GGG': 'G'}
rna = "AUGGCCAUGGCGCCC"
protein = ""
for i in range(0, len(rna), 3):
    aa = code[rna[i:i + 3]]
    if aa == "*":
        break
    protein = protein + aa
print(protein)  # → MAMAP
Вывод
MAMAP

Таблица кодонов записана готовым словарем — такой же словарь строят в примере 1. Индекс идет с шагом 3, срез из трех букв дает кодон, словарь дает аминокислоту. Стоп-кодонов в примере нет, поэтому переведены все пять кодонов.

Типичная ошибка: стоп-кодон в белке

Неверно: без break
for i in range(0, len(rna), 3):
    protein = protein + code[rna[i:i + 3]]
Верно
for i in range(0, len(rna), 3):
    aa = code[rna[i:i + 3]]
    if aa == "*":
        break
    protein = protein + aa

Без break знак стопа попадет в белок. На стоп-кодоне чтение должно закончиться, и цикл прерывается.

Практика

Прохор переводит другую мРНК. Замените "AUGGCCAUGGCGCCC" на "UUUCCCUAAGGG" и запустите: белок должен стать FP — после стопа UAA остается полная тройка GGG, и она не переводится.

translate.py

codons = [a + b + c for a in bases for b in bases for c in bases]
aas = ("FFLLSSSSYY**CC*W"
       "LLLLPPPPHHQQRRRR"
       "IIIMTTTTNNKKSSRR"
       "VVVVAAAADDEEGGGG")
code = dict(zip(codons, aas))
rna = "AUGGCCAUGGCGCCC"
protein = ""
for i in range(0, len(rna), 3):
    aa = code[rna[i:i + 3]]
    if aa == "*":
        break
    protein = protein + aa
print(protein)  # → MAMAP
Вывод
MAMAP

3. Синонимичные кодоны

Теория

Таблица кодонов отвечает на вопрос, какая аминокислота соответствует кодону. Обратный вопрос, какими кодонами записывается аминокислота, решает обращение словаря: значения становятся ключами, а кодоны собираются в списки.

Синонимичные кодоны — кодоны, которые кодируют одну и ту же аминокислоту.

В обращенном словаре 21 ключ: 20 аминокислот и знак стопа. У метионина один кодон, у лейцина шесть. Обращение строят defaultdict(list), дописывая кодон в список его аминокислоты.

Частоты использования кодонов для тысяч организмов собраны по полным белок-кодирующим последовательностям базы GenBank. Подсчет таких частот сводится к счетчику кодонов, построенному так же, как счетчик нуклеотидов на странице 07: последовательность читают с шагом 3 и каждый кодон отправляют в Counter.

Пример

Пример 3. Обращение таблицы кодонов

syn.py
from collections import defaultdict
bases = "UCAG"
codons = [a + b + c for a in bases for b in bases for c in bases]
aas = ("FFLLSSSSYY**CC*W"
       "LLLLPPPPHHQQRRRR"
       "IIIMTTTTNNKKSSRR"
       "VVVVAAAADDEEGGGG")
code = dict(zip(codons, aas))
syn = defaultdict(list)
for codon, aa in code.items():
    syn[aa].append(codon)
print(len(syn))                 # → 21
print(syn["M"], len(syn["L"]))  # → ['AUG'] 6
print(syn["*"])                 # → ['UAA', 'UAG', 'UGA']
Вывод
21
['AUG'] 6
['UAA', 'UAG', 'UGA']

В обращенном словаре 21 ключ. У метионина один кодон, у лейцина шесть, у стопа три. Кодоны одной аминокислоты называют синонимичными. Обращение словаря — частный случай группировки со страницы 04.

Типичная ошибка: обращение без списков

Неверно: значение-строка
syn = {}
for codon, aa in code.items():
    syn[aa] = codon
Верно
syn = defaultdict(list)
for codon, aa in code.items():
    syn[aa].append(codon)

Присваивание оставляет у каждой аминокислоты один, последний кодон. Кодонов несколько, поэтому значения собирают в списки через defaultdict(list).

Практика

Василиса проверяет синонимы. Добавьте строку, которая печатает syn["F"], и запустите: должны вывестись два кодона фенилаланина.
