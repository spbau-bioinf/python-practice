Кодоны и трансляция

25 минутЕрофеев А. И.

Строить генетический код словарем, переводить мРНК в белок до стоп-кодона и находить синонимичные кодоны.

1. Генетический код

Теория

До сих пор словари хранили отдельные записи. Но один словарь есть в каждой живой клетке: он сопоставляет тройкам букв мРНК аминокислоты белка. В Python его можно записать в несколько строк.

мРНК — рабочая копия гена: копия участка ДНК, в которой вместо T стоит U. По ней клетка строит белок, цепочку аминокислот. Клетка читает мРНК тройками букв. По каждой тройке она выбирает следующую аминокислоту белка или останавливается. мРНК записывают буквами A, C, G и U, а аминокислоты заглавными латинскими буквами: M означает метионин, L лейцин.

Кодон (codon) состоит из трех подряд идущих букв мРНК, которые читаются вместе. Стоп-кодон (UAA, UAG или UGA) заканчивает чтение; в таблице его обозначают знаком *.

Кодоны читают без перекрытия, с шагом 3. С какой буквы начать чтение, задает рамка считывания: если сдвинуть начало на одну букву, получатся совсем другие кодоны. В задачах этой страницы чтение начинается с первой буквы.

Генетический код удобно хранить словарем «кодон : аминокислота» из 64 пар. Перечислять 64 пары вручную долго, и легко ошибиться. Вместо этого три вложенных цикла по строке "UCAG" дают все 64 кодона в порядке таблицы, а строка из 64 букв дает их аминокислоты в том же порядке. Функция zip() со страницы 03 соединяет их в пары: dict(zip(codons, amino_acids)).

Аминокислот 20, а кодонов 64, поэтому многие аминокислоты записываются несколькими кодонами: у лейцина их шесть, у метионина и триптофана по одному. Строкой из 64 букв генетический код записывает база NCBI; кодоны в ней перечислены в порядке U, C, A, G по первой, второй и третьей букве (в записи NCBI вместо U стоит T).

Пример

Пример 1. Таблица кодонов словарем

table.py
bases = "UCAG"
codons = []
for first in bases:
    for second in bases:
        for third in bases:
            codons.append(first + second + third)
amino_acids = ("FFLLSSSSYY**CC*W"
               "LLLLPPPPHHQQRRRR"
               "IIIMTTTTNNKKSSRR"
               "VVVVAAAADDEEGGGG")
code = dict(zip(codons, amino_acids))
print(len(code))                 # → 64
print(codons[:4])                # → ['UUU', 'UUC', 'UUA', 'UUG']
print(code["AUG"], code["UAA"])  # → M *
Вывод
64
['UUU', 'UUC', 'UUA', 'UUG']
M *

Внешний цикл перебирает первую букву, внутренний — третью, поэтому первые четыре кодона отличаются третьей буквой. В словаре 64 пары; AUG — метионин, UAA — стоп.

Типичная ошибка: кодоны в обратном порядке букв

Неверно: третья буква первой
codons.append(third + second + first)
Верно
codons.append(first + second + third)

Порядок кодонов в списке должен совпадать с порядком букв в строке аминокислот, иначе zip() соединит кодоны с чужими аминокислотами.

Практика

Добавьте строку, которая печатает code["UGG"], и запустите: должна появиться буква W — триптофан.

2. Трансляция

Теория

Чтобы получить белок из мРНК, проходят по мРНК кодон за кодоном и для каждого кодона находят аминокислоту в словаре генетического кода.

Трансляция (translation) переводит мРНК в белок кодон за кодоном по генетическому коду.

Программа повторяет то, что делает клетка. Цикл for start in range(0, len(rna), 3) идет по началам кодонов с шагом 3, срез rna[start:start + 3] дает кодон, а словарь дает его аминокислоту.

На стоп-кодоне чтение заканчивается: цикл прерывают инструкцией break, и сам стоп в белок не попадает. Остальные аминокислоты дописывают к белку по порядку.

В прочитанной мРНК бывает буква N. Кодона с ней в словаре нет, и code[codon] останавливает программу ошибкой KeyError. Запись code.get(codon, "?") вместо этого дает знак вопроса.

Это задача PROT сборника Rosalind: по строке мРНК получить строку белка.

Пример

Пример 2. Трансляция мРНК

translate.py
bases = "UCAG"
codons = []
for first in bases:
    for second in bases:
        for third in bases:
            codons.append(first + second + third)
amino_acids = ("FFLLSSSSYY**CC*W"
               "LLLLPPPPHHQQRRRR"
               "IIIMTTTTNNKKSSRR"
               "VVVVAAAADDEEGGGG")
code = dict(zip(codons, amino_acids))
rna = "AUGUUUGGCUAAGCU"
protein = ""
for start in range(0, len(rna), 3):
    amino_acid = code[rna[start:start + 3]]
    if amino_acid == "*":
        break
    protein = protein + amino_acid
print(protein)  # → MFG
Вывод
MFG

Кодоны AUG, UUU, GGC дают M, F, G. Четвертый кодон UAA — стоп: цикл прерывается, и последний кодон GCU не читается.

Типичная ошибка: шаг 1 вместо 3

Неверно: шаг 1
for start in range(len(rna) - 2):
    codon = rna[start:start + 3]
Верно
for start in range(0, len(rna), 3):
    codon = rna[start:start + 3]

С шагом 1 кодоны перекрываются, как k-меры, и белок получается втрое длиннее и неверный.

Практика

Замените UAA в мРНК на UAC и запустите: стопа больше нет, и белок станет MFGYA.

Упражнение 6.8.2. Трансляция до стопа

Условие задачи

Постройте словарь генетического кода, как в примере 1: кодоны перечислите тремя вложенными циклами for по строке "UCAG", затем составьте словарь dict(zip(codons, amino_acids)) со строкой:

table.py
amino_acids = ("FFLLSSSSYY**CC*W"
               "LLLLPPPPHHQQRRRR"
               "IIIMTTTTNNKKSSRR"
               "VVVVAAAADDEEGGGG")

Переведите мРНК в белок, начиная с первой буквы. На первом стоп-кодоне трансляция заканчивается, и сам стоп в белок не входит. Если стоп-кодон первый, выведите пустую строку.

Входные данные

Одна строка: мРНК из букв U, C, A, G. Длина от 3 до 300 и делится на 3.

Выходные данные

Строка белка или пустая строка.

Пример

Разберем пример

Ввод AUGGCCUAAAUU
→
Вывод MA

После AUG и GCC идет стоп-кодон UAA, поэтому кодон AUU после него не читается.

Примеры
ВводВывод

AUGGCC
MA
Контекст

Трансляция останавливается на стоп-кодоне: все, что после него, в белок не попадает.

Основные определения

  • Белок — цепочка аминокислот, которую клетка строит по гену.
  • Трансляция — перевод мРНК в белок: кодоны читают подряд с первой буквы, без перекрытия.
  • Стоп-кодон — кодон UAA, UAG или UGA, на котором трансляция заканчивается.
  • Запись range(0, len(rna), 3) — начала кодонов: 0, 3, 6, ...
  • Инструкция break — сразу завершает цикл.
Подсказка
  1. Идите по кодонам, как в базовом варианте.
  2. Если аминокислота кодона равна "*", прервите цикл инструкцией break.
  3. Иначе допишите аминокислоту к белку. После цикла напечатайте белок.
  4. Сверьтесь с примером: для ввода AUGGCCUAAAUU программа печатает MA.

Упражнение 6.8.2. Трансляция с буквой N

Условие задачи

Постройте словарь генетического кода, как в примере 1: кодоны перечислите тремя вложенными циклами for по строке "UCAG", затем составьте словарь dict(zip(codons, amino_acids)) со строкой:

В мРНК может встретиться буква N: так отмечен нуклеотид, который прибор не определил. Кодон с буквой N переведите знаком ?. На первом стоп-кодоне трансляция заканчивается. Выведите белок.

Входные данные

Одна строка: мРНК из букв U, C, A, G, N. Длина от 3 до 300 и делится на 3.

Выходные данные

Строка белка из букв и знаков ? или пустая строка.

Пример

Разберем пример

Ввод AUGGNCUUUUAGCCC
→
Вывод M?F

Кодон GNC неизвестен, поэтому вместо него знак ?. На кодоне UAG трансляция заканчивается.

Примеры
ВводВывод

Контекст

В прочитанной мРНК бывают нуклеотиды, которые прибор не определил. Белок по такой мРНК все равно записывают, а неизвестную аминокислоту отмечают знаком вопроса.

Основные определения

  • Буква N — нуклеотид, который прибор не смог определить.
  • Белок — цепочка аминокислот, которую клетка строит по гену.

  • Трансляция — перевод мРНК в белок: кодоны читают подряд с первой буквы, без перекрытия.
Подсказка

  2. Кодона с N в словаре нет. Берите аминокислоту методом get() с запасным ответом: code.get(codon, "?").
  3. На стоп-кодоне прервите цикл, иначе допишите аминокислоту и после цикла напечатайте белок.
  4. Сверьтесь с примером: для ввода AUGGNCUUUUAGCCC программа печатает M?F.

3. Синонимичные кодоны

Теория

Таблица кодонов отвечает на вопрос, какая аминокислота у кодона. Обратный вопрос — какими кодонами записана аминокислота.

Синонимичные кодоны (synonymous codons) записывают одну и ту же аминокислоту, хотя сами кодоны разные.

Найти их помогает обращение словаря: значения становятся ключами, а кодоны собираются в списки. В обращенном словаре 21 ключ: 20 аминокислот и знак стопа.

Пример

Пример 3. Обращение таблицы кодонов

synonyms.py
from collections import defaultdict
bases = "UCAG"
codons = []
for first in bases:
    for second in bases:
        for third in bases:
            codons.append(first + second + third)
amino_acids = ("FFLLSSSSYY**CC*W"
               "LLLLPPPPHHQQRRRR"
               "IIIMTTTTNNKKSSRR"
               "VVVVAAAADDEEGGGG")
code = dict(zip(codons, amino_acids))
synonyms = defaultdict(list)
for codon, amino_acid in code.items():
    synonyms[amino_acid].append(codon)
print(len(synonyms))       # → 21
print(synonyms["M"])       # → ['AUG']
print(len(synonyms["L"]))  # → 6
Вывод
21
['AUG']
6

Ключей 21. У метионина один кодон AUG, у лейцина шесть.

Практика

Замените "M" на "*" и запустите: должны напечататься три стоп-кодона.

synonyms.py
