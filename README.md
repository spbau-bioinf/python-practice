# Язык программирования Python: практические работы

Сайт с практическими работами. Страницы собраны Skill practice-html; этот репозиторий
только публикует готовые файлы.

## Как опубликовать

1. Создайте на GitHub репозиторий `python-practice` (публичный) и загрузите в него
   содержимое этой папки целиком, включая скрытый файл `.nojekyll`.
2. Settings → Pages → Build and deployment: Source «Deploy from a branch»,
   Branch `main`, папка `/ (root)`, Save.
3. Через минуту сайт доступен по адресу `https://<имя>.github.io/python-practice/`.
   Этот адрес дайте студентам.

## Как обновлять

Новую практику или исправленную версию получите от Skill и замените папку
`practice_X/` и файл `index.html`. Остальные практики не трогайте: прогресс
студентов хранится в их браузерах и не пропадет.

## Чего здесь нет

Эталонных решений, спецификаций тестов и отчетов о тестах: они лежат в закрытой
копии `python-practice-for-teacher`. Проверка решений работает прямо в браузере, поэтому
тесты каждой задачи есть в `practice_X/data/`.

Решения студентов сдаются не сюда, а в их личные закрытые репозитории
(`projects_X/tX_YY/`).
