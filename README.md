# Язык программирования Python: практические работы

Интерактивный сайт с практическими работами курса «Язык программирования Python»
(профиль «Биоинформатика», Академический университет им. Ж. И. Алферова, 2026).

**Сайт:** https://spbau-bioinf.github.io/python-practice/

За семестр студенты шаг за шагом собирают сквозной проект «Анализ биологических
последовательностей»: от первых программ до разбора файлов FASTA.

Практики открываются по мере прохождения лекций.

## Что есть на сайте

- **Теория, примеры и упражнения** на каждой странице: шаги «Теория», «Пример»,
  «Практика», «Задача».
- **Запуск кода прямо в браузере.** Любой пример можно изменить и запустить,
  устанавливать Python не нужно.
- **Проверка решений.** Решение упражнения проверяется на примерах из условия и на
  скрытых тестах; при ошибке появляется подсказка к типичной ошибке.
- **Три уровня сложности:** базовый, средний и продвинутый. У каждого упражнения три
  варианта, первым открывается вариант выбранного уровня.
- **Теория кратко или подробно**: переключатель в шапке каждой страницы.
- **Команды терминала для Windows, macOS и Linux** с переключателем системы.
- **Прогресс**: отметки о решенных упражнениях и кольцо прогресса на главной.
- **Светлая и темная темы, игровой режим.**

## Как пользоваться

1. Откройте сайт и начните с обзора практики: там цели, устройство занятия и правила
   сдачи.
2. Выберите свой уровень в меню ⚙ или кнопкой «Сделать моим уровнем» у любого
   упражнения.
3. Проходите страницы по порядку. Решения сохраняйте в свой репозиторий: какие файлы и
   куда, написано в блоке «Сдача работы» в конце каждой страницы с упражнениями.
4. Практика засчитывается после сдачи преподавателю; правила сдачи описаны на обзоре
   практики.

**Что нужно:** современный браузер (Chrome, Firefox, Edge, Safari) и интернет. Python для
запуска кода загружается в браузер при первом запуске, это занимает 10–30 секунд.

**Где хранится прогресс.** Только в вашем браузере, на сервер ничего не отправляется.
Чтобы продолжить на другом компьютере, в меню ⚙ → «Прогресс» сохраните файл и загрузите
его там.

## Устройство репозитория

| Путь | Что это |
|------|---------|
| `index.html`, `home.js` | главная страница со списком практик |
| `practice_N/tN_00.html` | обзор практики N |
| `practice_N/tN_01.html` … | тематические страницы |
| `practice_N/data/` | данные для проверки упражнений |
| `practice_N/style.css`, `*.js` | оформление и работа страниц |
| `practice_N/fonts/` | шрифты Golos Text и JetBrains Mono (лицензия SIL OFL) |
| `.nojekyll` | GitHub Pages отдает файлы как есть, без сборки Jekyll |

Сайт статический: сервер не нужен, все работает в браузере.

## Для преподавателя: публикация и обновление

Страницы собираются Skill `practice-html` и проверяются его скриптами; вручную файлы
не правятся, иначе проверки и данные упражнений разойдутся.

- **Публикация:** Settings → Pages → «Deploy from a branch», ветка `main`, папка
  `/ (root)`.
- **Обновление:** скопируйте файлы нового выпуска поверх старых и отправьте изменения
  (`git add .`, `git commit`, `git push`). Сайт обновится через 1–2 минуты; если видна
  старая версия, обновите страницу с Ctrl+F5.
- **Чего здесь нет:** эталонных решений, спецификаций тестов, отчетов и страницы
  преподавателя; они хранятся в закрытой копии `python-practice-for-teacher`.
  Решения студентов сдаются не сюда, а в их личные закрытые репозитории.
