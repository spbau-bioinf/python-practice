Распаковка

20 минутЕрофеев А. И.

Раскладывать запись по переменным одной строкой, собирать остаток именем со звездочкой и распаковывать записи прямо в заголовке цикла.

1. Распаковка записи

Теория

Запись о последовательности хранится кортежем ("Rosalind_1", 8, 50.0). Чтобы работать с полями, их удобно положить в переменные с понятными именами. Через индексы это три строки: name = rec[0], length = rec[1], gc = rec[2]; они длинные, и номер поля легко перепутать.

Если слева от = стоят несколько имен через запятую, Python раскладывает по ним элементы последовательности справа: первый элемент в первое имя, второй во второе и так далее.

Распаковка (unpacking) — присваивание элементов последовательности нескольким именам сразу: name, length, gc = rec.

Справа годится любая последовательность: кортеж, список, строка. Имен должно быть столько же, сколько элементов, иначе ValueError. Поэтому строку из трех полей читают так: name, length, gc = input().split(); все три значения при этом строки, числа из них получают через int() и float().

Запись a, b = b, a меняет значения местами. Справа b, a образует кортеж (это называют упаковкой), и только потом он распаковывается в a и b. Правая часть вычисляется целиком до присваивания, поэтому старое значение не теряется и временная переменная не нужна.

Пример

Поля записи

unpack.py
rec = ("Rosalind_1", 8, 50.0)
name, length, gc = rec
print(name)        # → Rosalind_1
print(length, gc)  # → 8 50.0
x, y = "AT"
print(y, x)        # → T A
Вывод
Rosalind_1
8 50.0
T A
  1. Строка 2: три элемента кортежа раскладываются по трем именам слева направо.
  2. Строка 5: строка тоже последовательность, ее буквы раскладываются по двум именам.

Типичная ошибка: имен меньше, чем элементов

Неверно: три поля, два имени
rec = ("Rosalind_1", 8, 50.0)
name, length = rec
Сообщение об ошибке
ValueError: too many values to unpack (expected 2, got 3)
Верно
rec = ("Rosalind_1", 8, 50.0)
name, length, gc = rec
print(name, length)  # → Rosalind_1 8
Вывод
Rosalind_1 8

Python 3.14 пишет в сообщении и сколько элементов было (got 3), Python 3.12 и 3.13 только сколько ожидалось. Если элементов меньше, чем имен, сообщение другое: not enough values to unpack.

Обмен значений в цикле

Предскажите вывод, затем откройте его.

swap.py
a, b = 0, 1
for i in range(5):
    a, b = b, a + b
print(a, b)  # → 5 8
Вывод
5 8
  1. Строка 1: тоже распаковка, a получает 0, b получает 1.
  2. Строка 3: правая часть b, a + b считается по старым a и b, затем обе переменные получают новые значения.
Практика

Добавьте в строку в кавычках четвертое поле, например 42, и запустите: какую ошибку покажет Python? Затем добавьте четвертое имя слева.

try_unpack.py
name, length, gc = "seq_5 120 41.5".split()
print(name, int(length) + 1, float(gc))  # → seq_5 121 41.5
Вывод
seq_5 121 41.5

2. Звездочка: *rest

Теория

Если элементов больше, чем имен, одно имя можно пометить звездочкой. Оно получит все элементы, которые не достались остальным именам.

Имя со звездочкой всегда получает список, даже если распаковывается строка или кортеж, и даже если остатка нет: тогда список пустой.

Звездочка может стоять в любой позиции: first, *rest = seq, *body, last = seq, head, *mid, tail = seq. В одной распаковке звездочка одна.

Так удобно разбирать строку заголовка, где первое слово особенное, а остальных может быть сколько угодно или не быть вовсе: first, *rest = line.split(). Обычная распаковка требует точного числа элементов и на таких строках дает ValueError.

Пример

Первый, последний и остаток

star.py
seq = "ATGCGTAA"
first, *rest = seq
print(first, rest)  # → A ['T', 'G', 'C', 'G', 'T', 'A', 'A']
*body, last = [1, 2, 3]
print(body, last)   # → [1, 2] 3
head, *mid, tail = "AT"
print(mid)          # → []
Вывод
A ['T', 'G', 'C', 'G', 'T', 'A', 'A']
[1, 2] 3
[]
  1. Строка 2: first получил первую букву, rest список остальных букв.
  2. Строка 4: звездочка стоит первой, поэтому остаток собирается из начала.
  3. Строка 6: двум обычным именам досталось по букве, на mid ничего не осталось: пустой список.

Остаток из строки

Предскажите вывод, затем откройте его.

rest.py
first, *rest = "ACG"
x, *y = "A"
print(rest, y)  # → ['C', 'G'] []
Вывод
['C', 'G'] []
  1. Строка 1: остаток строки собирается не в строку "CG", а в список букв.
  2. Строка 2: после буквы для x букв не осталось, поэтому y пустой список, а не пустая строка.
Практика

Уберите из строки в кавычках все слова после идентификатора и запустите: что получит words?

try_star.py
ident, *words = ">seq_1 human chromosome 7".split()
print(ident, words, len(words))  # → >seq_1 ['human', 'chromosome', '7'] 3
Вывод
>seq_1 ['human', 'chromosome', '7'] 3

3. Распаковка в цикле

Теория

Переменная цикла может быть несколькими именами через запятую. Если в списке лежат записи одинаковой длины, например пары «имя, GC-состав», цикл for name, gc in records: на каждом шаге берет запись и сразу раскладывает ее по именам.

Распаковка в заголовке цикла подчиняется тем же правилам: имен столько, сколько полей в каждой записи. Если в списке лежат строки, а не пары, for name, seq in seqs: пытается разложить каждую строку на буквы: строка из восьми букв дает ValueError, а строка из двух букв без ошибки разложится на две буквы, и результат будет молча неверным.

В заголовке цикла можно ставить и звездочку. Тогда записи могут быть разной длины: for name, *nums in recs: кладет первое поле в name, а остальные, сколько бы их ни было, в список nums.

Пример

Записи в цикле

records.py
records = [("Rosalind_1", 50.0),
           ("Rosalind_2", 62.5),
           ("Rosalind_3", 37.5)]
for name, gc in records:
    if gc > 45:
        print(name, gc)
Вывод
Rosalind_1 50.0
Rosalind_2 62.5
  1. Строки 1–3: список кортежей, каждая запись из двух полей.
  2. Строка 4: на каждом шаге запись распаковывается в name и gc; индексы rec[0] и rec[1] не нужны.

Типичная ошибка: распаковать строку в цикле

Неверно: элементы списка не пары
seqs = ["ATCCAGCT", "GGGCAACT"]
for name, seq in seqs:
    print(name)
Сообщение об ошибке
ValueError: too many values to unpack (expected 2)
Верно
seqs = ["ATCCAGCT", "GGGCAACT"]
for seq in seqs:
    print(seq)
Вывод
ATCCAGCT
GGGCAACT

Строка из восьми букв тоже последовательность, и Python пытается раздать ее буквы двум именам. Сколько было букв, сообщение для строки не называет даже в Python 3.14. Если нужны и номер, и элемент, поможет функция enumerate() со страницы 05.

Звездочка в заголовке цикла

Предскажите вывод, затем откройте его.

star_loop.py
recs = [("R1", 2, 3), ("R2", 5), ("R3",)]
for name, *nums in recs:
    print(name, nums, sum(nums))
Вывод
R1 [2, 3] 5
R2 [5] 5
R3 [] 0
  1. Строка 2: у записей разная длина, но имя со звездочкой забирает любой остаток; у R3 он пустой.
  2. Строка 3: sum() пустого списка равна 0.
Практика

Поменяйте порог в строке 3 на 40 и запустите снова.

try_records.py
records = [("chr1", 41.5), ("chr2", 38.0), ("chrX", 39.9)]
for name, gc in records:
    if gc < 39:
        print(name)  # → chr2
Вывод
chr2

Упражнение 5.4.1. Число букв G и C

Условие задачи

Запись о последовательности содержит три поля через пробел: имя, длину и GC-состав в процентах. Выведите имя и число букв G и C: длину, умноженную на GC-состав и деленную на 100. Например, у последовательности длины 8 с GC-составом 37,5 % букв G и C 8 · 37,5 / 100 = 3. Результат вещественного вычисления бывает чуть меньше целого: у длины 375 и GC-состава 18,4 % получается 68.99999999999999. Переведите его в целое функцией round(), а не int(): int() отбрасывает дробную часть и дал бы 68.

Входные данные

Одна строка: имя (латинские буквы, цифры и знак _), длина от 1 до 1000 и GC-состав от 0 до 100 с одной цифрой после точки. Гарантируется, что число букв G и C получается целым.

Выходные данные

В первой строке имя, во второй число букв G и C целым числом.

Пример

Разберем пример

Ввод Rosalind_12 8 37.5
→
Вывод Rosalind_12
3

8 · 37,5 / 100 = 3: длина и GC-состав дают ровно 3 буквы G и C, а имя выводится как есть.

Примеры
ВводВывод
 
Rosalind_12 8 37.5
Rosalind_12
3
seq_7 20 0.0
seq_7
0
Контекст

Распаковка name, length, gc = input().split() присваивает три части строки трем переменным сразу. Части приходят строками, поэтому выражение переводит их: int(length) * float(gc) / 100. Деление всегда дает float, а round() возвращает ближайшее целое.

Основные определения

  • Распаковка — несколько переменных слева от знака = и столько же частей справа.
  • GC-состав — доля букв G и C в процентах от длины последовательности.
  • Функция float() — переводит строку в вещественное число.
  • Функция round() — округляет до ближайшего целого.
  • Функция int() — отбрасывает дробную часть.
Подсказка
  1. Прочитайте строку и разложите ее одной распаковкой: name, length, gc = input().split().
  2. Переведите поля в числа: int(length) и float(gc).
  3. Соберите выражение: длина умножить на состав и разделить на 100.
  4. Напечатайте имя и round(...); сверьтесь с примером: Rosalind_12 8 37.5 дают Rosalind_12 и 3, а seq_7 20 0.0 — 0.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.

Упражнение 5.4.1. Заголовок FASTA

Условие задачи

Строка заголовка FASTA начинается со знака >, сразу за ним идет идентификатор, затем через пробел может идти описание из нескольких слов. Выведите идентификатор без знака > и число слов в описании. Если описания нет, число слов 0.

Входные данные

Одна строка заголовка FASTA длиной до 200 символов. Слова разделены одним пробелом.

Выходные данные

В первой строке идентификатор, во второй число слов описания.

Пример

Разберем пример

Ввод >Rosalind_0498 Homo sapiens chromosome 1
→
Вывод Rosalind_0498
4

first, *rest = input().split() отделяет первое слово — идентификатор; после удаления знака > остается Rosalind_0498, а в описании четыре слова: Homo, sapiens, chromosome, 1.

Примеры
ВводВывод
 
>Rosalind_0498 Homo sapiens chromosome 1
Rosalind_0498
4
>seq_2
seq_2
0
Контекст

Распаковка со звездочкой first, *rest = input().split() кладет первое слово в first, а все остальные — списком в rest. Даже при пустом описании rest получает пустой список, поэтому len(rest) всегда дает число слов описания. Знак > отрезают срезом first[1:].

Основные определения

  • Идентификатор — имя последовательности без пробелов, сразу за знаком >.
  • Распаковка со звездочкой — first, *rest = ... — последняя переменная забирает остаток списка.
  • Срез строки — first[1:] — строка без первого символа.
  • Пустой список — у пустого описания rest пуст, и len(rest) равно 0.
Подсказка
  1. Прочитайте строку и разложите ее распаковкой со звездочкой: first, *rest = input().split().
  2. В first лежит идентификатор вместе со знаком >; отрежьте знак срезом first[1:].
  3. Число слов описания — это len(rest).
  4. Напечатайте идентификатор и число; сверьтесь с примером: >Rosalind_0498 Homo sapiens chromosome 1 дают Rosalind_0498 и 4, а >seq_2 — seq_2 и 0.

Упражнение 5.4.1. Перекрытие прочтений

Условие задачи

Даны два прочтения; положение каждого задано номерами первой и последней позиции на геноме, обе включительно. Прочтение с другой цепи записано от большей позиции к меньшей: запись 30 21 означает позиции с 21 по 30. Выведите, сколько позиций генома входят в оба прочтения; если прочтения не перекрываются, выведите 0.

Входные данные

Две строки, в каждой запись прочтения: имя, затем две позиции через пробел, целые числа от 1 до 1000.

Выходные данные

Одно целое число: число общих позиций.

Пример

Разберем пример

Ввод r1 10 30
r2 25 40
→
Вывод 6

Общий участок начинается с большего начала — 25 — и кончается на меньшем конце 30: позиции 25–30, всего 30 − 25 + 1 = 6.

Примеры
ВводВывод
 
r1 10 30
r2 25 40
6
r1 30 21
r2 18 24
4
Контекст

Каждое прочтение — отрезок на геноме. Запись от большей позиции к меньшей сначала приводят к обычному виду, меняя концы местами. Общая часть двух отрезков начинается с большего из начал и кончается меньшим из концов; число позиций равно end - start + 1, а у непересекающихся отрезков конец раньше начала, и max(0, ...) превращает разность в 0.

Основные определения

  • Прочтение — участок ДНК, который прибор прочитал за один раз.
  • Геном — вся ДНК организма; позиции в нем нумеруются подряд с 1.
  • Перекрытие — позиции генома, входящие в оба прочтения.
  • Обратная цепь — в выводе программы BLAST прочтение с другой цепи записано от большей позиции к меньшей.
  • Функция max() — возвращает большее из значений.
Подсказка
  1. Прочитайте обе записи: name1, start1, end1 = input().split(), name2, start2, end2 = input().split().
  2. Переведите позиции в числа; если start1 больше end1 (или start2 больше end2), поменяйте концы местами — запись с обратной цепи станет обычной.
  3. Общая часть: начало max(start1, start2), конец min(end1, end2).
  4. Выведите max(0, end - start + 1); сверьтесь с примером: 10 30 и 25 40 дают 6, а 30 21 и 18 24 — 4.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.

Задача со звездочкой 5.4. Записи выше порога

Условие задачи

Даны порог и записи «имя, GC-состав». Выведите имена записей, у которых GC-состав не меньше порога, в том порядке, в каком идут записи. Если таких нет, выведите слово нет.

Входные данные

В первой строке порог, число от 0 до 100. Во второй число записей count от 1 до 20. Дальше count строк: имя и GC-состав через пробел; GC-состав записан с одной цифрой после точки.

Выходные данные

Имена через пробел одной строкой или слово нет.

Пример

Разберем пример

Ввод 50
3
Rosalind_1 48.5
Rosalind_2 50.0
Rosalind_3 62.5
→
Вывод Rosalind_2 Rosalind_3

48,5 меньше порога 50 и отбрасывается; 50,0 и 62,5 не меньше порога, поэтому в ответ идут Rosalind_2 и Rosalind_3.

Примеры
ВводВывод
 
50
3
Rosalind_1 48.5
Rosalind_2 50.0
Rosalind_3 62.5
Rosalind_2 Rosalind_3
70

A 10.0

нет
Контекст

Порог читают как float, состав каждой записи тоже float; сравнение float(gc) >= threshold нестрогое, поэтому запись ровно на пороге проходит. Имена накапливают в списке, а слово нет печатают, когда список остался пустым.

Основные определения

  • Порог — граничное значение GC-состава.
  • Нестрогое сравнение — >= пропускает и равные значения.
  • Метод append() — дописывает элемент в конец списка.
  • Функция float() — переводит строку в вещественное число.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте порог и число записей: threshold = float(input()), count = int(input()); заведите names = [].
  2. Переберите записи: for index in range(count): — первой строкой тела name, gc = input().split().
  3. Отбирайте по нестрогому условию: если float(gc) >= threshold, вызовите names.append(name).
  4. Если names непуст, напечатайте " ".join(names), иначе слово нет; сверьтесь с примером: порог 50 и записи 48.5, 50.0, 62.5 дают Rosalind_2 Rosalind_3.

Задача со звездочкой 5.4. Записи разной длины

Условие задачи

В каждой записи сначала имя пробы, затем от 0 до 5 результатов измерений (целые числа). Найдите запись с наибольшей суммой измерений; сумма записи без измерений равна 0. Если таких записей несколько, выберите первую. Выведите имя и сумму через пробел.

Входные данные

В первой строке число записей count от 1 до 20, дальше count строк: имя и числа от 0 до 1000 через пробел.

Выходные данные

Имя и сумма через пробел.

Суммы записей: у A 1 + 2 + 3 = 6, у B 10, у C измерений нет и сумма 0; наибольшая сумма у B, поэтому ответ B 10.

Контекст

Распаковка со звездочкой name, *values = input().split() отделяет имя от всех чисел записи: values получает список строк, и цикл складывает их как int. У записи без измерений values пуст, и сумма остается 0. Лучшую сумму заменяют только при строгом >, поэтому при равенстве остается первая запись.

Основные определения

  • Распаковка со звездочкой — name, *values = ... — values забирает все числа записи.
  • Пустой список — у записи без измерений values пуст, сумма равна 0.
  • Строгое сравнение — > не пропускает равную сумму.
  • Функция int() — переводит строку в целое число.

  2. Разбирайте запись распаковкой со звездочкой: name, *values = input().split().
  3. Сумму считайте циклом по values: total = total + int(value); у пустого values она остается 0.
  4. При total > best_sum запоминайте имя и сумму; напечатайте их через пробел; сверьтесь с примером: A 1 2 3, B 10 и C дают B 10, а x 5 5 и y 7 3 — x 10.

Задача со звездочкой 5.4. Смертные кролики

Условие задачи

Кролики живут lifespan месяцев: пара, родившаяся в месяце birth_month, есть в месяцах birth_month, birth_month + 1, …, birth_month + lifespan - 1, а в месяце birth_month + lifespan ее уже нет. В первом месяце есть одна новорожденная пара. В каждом следующем месяце рождается столько новых пар, сколько пар в прошлом месяце были в возрасте хотя бы одного месяца. Сколько пар будет в месяце month? Не путайте номер месяца с числом пар.

Пример. При month = 6 и lifespan = 3 ответ 4: в шестом месяце четыре пары. Первое число задает номер месяца, второе показывает, сколько месяцев живет одна пара. Не путайте номер месяца с числом пар.

Входные данные

Одна строка: целые числа month от 1 до 60 (номер месяца) и lifespan от 2 до 20 (сколько месяцев живет одна пара) через пробел.

Выходные данные

Одно целое число: число пар в месяце month.

Пример

Разберем пример

Ввод 6 3
→
Вывод 4

Потомство дают пары со второго месяца жизни, а пары возрастом 3 месяца (lifespan) исчезают. Число пар по месяцам: 1, 1, 2, 2, 3, 4 — в шестом месяце 4.

Примеры
ВводВывод
 
6 3
4
2 2
1
Контекст

Список ages хранит число пар каждого возраста: ages[0] — новорожденные, последний элемент — самые старые. Новые пары приносят все, кому уже есть месяц: newborn = sum(ages[1:]). Затем все стареют на месяц: [newborn] + ages[:-1] ставит новорожденных в начало и убирает самый старый возраст — так пара исчезает после lifespan месяцев.

Основные определения

  • Возраст пары — сколько полных месяцев она прожила; у новорожденной возраст 0.
  • Список возрастов — ages[age] — число пар этого возраста.
  • Новорожденные — ages[0]; в первом месяце такая пара одна.
  • Сумма списка — sum() складывает все элементы.
  • Сдвиг возрастов — [newborn] + ages[:-1] старит всех на месяц и убирает самый старый возраст.
Подсказка
  1. Прочитайте числа: month, lifespan = input().split(); переведите оба в int.
  2. Заведите возрасты: ages = [1], затем допишите нули, чтобы длина стала lifespan — в первом месяце одна новорожденная пара.
  3. Каждый следующий месяц (цикл повторяется month - 1 раз) считайте newborn = sum(ages[1:]) и сдвигайте: ages = [newborn] + ages[:-1].
  4. Выведите sum(ages); сверьтесь с примером: 6 и 3 дают 4, а 2 и 2 — 1.
