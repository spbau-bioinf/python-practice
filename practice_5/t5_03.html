Срезы и методы

30 минутЕрофеев А. И.

Брать части списка срезами, добавлять и удалять элементы методами списка и удалять элементы при обходе без пропусков.

1. Срезы списка

Теория

Из семи последовательностей часто нужны только первые три или только каждая вторая. Для строк такую задачу решал срез из темы 2 «Строки и текстовые данные». У списка срезы устроены так же.

Срез списка seqs[начало:конец:шаг] работает как срез строки: начало входит, конец не входит, шаг задает, через сколько элементов брать следующий. Пропущенное начало означает начало списка, пропущенный конец означает конец списка. Работают и отрицательные индексы: seqs[-2:] дает два последних элемента.

Срез списка дает новый список. Изменение среза не меняет исходный список; поэтому seqs[:] дает копию (страница 02).

Индекс и срез по-разному ведут себя за концом списка. Индекс просит один элемент: seqs[3] у списка из трех элементов дает IndexError. Срез берет столько, сколько найдется: seqs[1:20] без сообщения об ошибке вернет элементы с индекса 1 до конца.

СрезЧто берет
seqs[:3]первые три элемента
seqs[3:]все, кроме первых трех
seqs[-2:]два последних
seqs[::2]элементы с индексами 0, 2, 4…
seqs[1::2]элементы с индексами 1, 3, 5…
seqs[::-1]все элементы в обратном порядке

Если при обращении по индексу возникла IndexError, напечатайте список или его длину: обычно индекс отличается от нужного на единицу. Последний элемент надежнее брать как seqs[-1], а не seqs[len(seqs) - 1].

Пример

Части списка

slices.py
seqs = ["ATCC", "GGGC", "ATGG", "AAGC", "TTGG"]
print(seqs[:3])   # → ['ATCC', 'GGGC', 'ATGG']
print(seqs[-2:])  # → ['AAGC', 'TTGG']
print(seqs[::2])  # → ['ATCC', 'ATGG', 'TTGG']
top = seqs[:3]
top[0] = "NNNN"
print(seqs[0])    # → ATCC
Вывод
['ATCC', 'GGGC', 'ATGG']
['AAGC', 'TTGG']
['ATCC', 'ATGG', 'TTGG']
ATCC
  1. Строки 2–4: первые три, два последних и каждый второй элемент, начиная с индекса 0.
  2. Строки 5–7: срез top отдельный список; замена в нем не трогает seqs.

Типичная ошибка: индекс за концом списка

Неверно: элемента с индексом 3 нет
seqs = ["ATCC", "GGGC", "ATGG"]
print(seqs[3])
Сообщение об ошибке
IndexError: list index out of range
Верно
seqs = ["ATCC", "GGGC", "ATGG"]
print(seqs[-1])    # → ATGG
print(seqs[1:20])  # → ['GGGC', 'ATGG']
Вывод
ATGG
['GGGC', 'ATGG']

У трех элементов индексы 0, 1, 2. Последний элемент берет индекс -1, а срез за концом списка ошибки не дает.

Практика

Замените срез в строке 2 на seqs[1::2], затем на seqs[::-1] и запустите каждый раз.

Вывод

Упражнение 5.3.1. Начало и конец набора

Срез списка возвращает новый список: seqs[:count] берет элементы с номерами от 0 до count - 1, seqs[-count:] отсчитывает count элементов от конца. Когда count равно длине набора, оба среза дают весь набор.

Условие задачи

Контекст

Третий элемент среза задает шаг: seqs[::2] берет элементы через один начиная с первого — это номера 1, 3, 5 при счете с единицы. Срез seqs[1::2] начинает со второго элемента и тоже шагает через один; у набора из одного элемента он дает пустой список, и join печатает пустую строку.

  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка

2. Методы списка

Теория

Методы, которые меняют список (append(), extend(), insert(), pop(), remove(), reverse()), меняют тот список, на котором вызваны, и возвращают None; исключение pop(), он возвращает удаленный элемент. Методы index() и count() список не меняют и возвращают число, а copy() со страницы 02 возвращает новый список.

ВызовЧто делаетЧто возвращает
a.append(x)добавляет x в конецNone
a.extend(b)дописывает все элементы bNone
a.insert(i, x)вставляет x перед индексом iNone
a.pop(), a.pop(i)удаляет последний или i-й элементудаленный элемент
a.remove(x)удаляет первое x; если x нет, ValueErrorNone
a.index(x), a.count(x)ищет индекс первого x (если x нет, ValueError), считает xчисло
a.reverse()разворачивает списокNone
del a[i]удаляет элемент по индексу или срезинструкция, не метод

Метод append() кладет свой аргумент одним элементом, даже если это список. Несколько элементов дописывают extend() или +=; оба меняют список на месте. Оператор + строит новый список. Запись x += y означает «прибавить и сохранить»: для чисел n += 1 то же, что n = n + 1.

Метод, который меняет список, вызывают отдельной строкой: seqs.append(x). Запись seqs = seqs.append(x) теряет список, потому что метод возвращает None.

Список строят и из других последовательностей: list("ACGT") дает список букв, list(range(5)) список чисел от 0 до 4. Сам range списком не является, поэтому print(range(5)) печатает range(0, 5), а не числа.

Привычка из темы 2 здесь подводит. Методы строк возвращают новую строку, и мы писали s = s.upper(). Методы списка меняют сам список и возвращают None нарочно: так их не спутать с операциями, которые строят новый объект. Для списка b += [x] меняет список на месте, а b = b + [x] строит новый: если у списка было второе имя, после += оно видит изменение, а после + нет.

Пример

append, extend, + и +=

add.py
a = ["ATCC"]
a.append(["GGGC", "TTGG"])
print(a, len(a))  # → ['ATCC', ['GGGC', 'TTGG']] 2
b = ["ATCC"]
b.extend(["GGGC", "TTGG"])
print(b, len(b))  # → ['ATCC', 'GGGC', 'TTGG'] 3
c = b + ["AAAA"]
print(c is b)     # → False
b += ["CCCC"]
print(b)          # → ['ATCC', 'GGGC', 'TTGG', 'CCCC']
Вывод
['ATCC', ['GGGC', 'TTGG']] 2
['ATCC', 'GGGC', 'TTGG'] 3
False
['ATCC', 'GGGC', 'TTGG', 'CCCC']
  1. Строка 2: append() положил список целиком одним элементом: в a два элемента, второй сам список.
  2. Строка 5: extend() дописал элементы по одному: в b три элемента.
  3. Строки 7–8: + построил новый список c, это не b.
  4. Строка 9: += дописал элемент в тот же список b.

pop() и remove()

  3. Строка 7: функции sum() и max() работают со списком чисел.

3. Удаление при обходе

Теория

Цикл for идет по позициям списка: сначала берет элемент с индексом 0, потом с индексом 1 и так далее. Если в теле цикла удалить элемент из того же списка, все следующие элементы сдвигаются влево на одну позицию, и цикл перешагивает через тот, который встал на место удаленного.

Если в цикле удаляются элементы, обходите копию списка, for s in seqs[:]:, а удаляйте из самого списка. Другой способ: собрать нужные элементы в новый список.

Ошибка коварна тем, что программа не падает и часто дает верный ответ: пропуск случается, только если два удаляемых элемента стоят подряд. Поэтому проверяйте такую программу на данных, где подходящие элементы идут один за другим.

Пример

Типичная ошибка: удалять из списка, который обходишь

Неверно: NNAT уцелел
seqs = ["NNNN", "NNAT", "ATCC"]
for s in seqs:
    if "N" in s:
        seqs.remove(s)
print(seqs)  # → ['NNAT', 'ATCC']
Вывод
['NNAT', 'ATCC']
Верно
seqs = ["NNNN", "NNAT", "ATCC"]
for s in seqs[:]:
    if "N" in s:
        seqs.remove(s)
print(seqs)  # → ['ATCC']
Вывод
['ATCC']

На первом шаге цикл смотрит на позицию 0 и удаляет "NNNN". Элементы сдвигаются, "NNAT" встает на позицию 0, а цикл переходит к позиции 1 и видит уже "ATCC". Копия seqs[:] не меняется, поэтому цикл по ней видит все элементы.

Практика

Уберите [:] в строке 2 и запустите: какой элемент уцелеет?

try_remove.py
seqs = ["A", "CC", "G", "T", "GGG"]
for s in seqs[:]:
    if len(s) == 1:
        seqs.remove(s)
print(seqs)  # → ['CC', 'GGG']
Вывод
['CC', 'GGG']
Задача

Упражнение 5.3.2. Первая в очереди

Условие задачи

Последовательности обрабатывают по очереди, начиная с первой. Удалите из набора первую последовательность и выведите ее, а затем оставшийся набор.

Входные данные

Одна строка: от 2 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30.

Выходные данные

В первой строке удаленная последовательность, во второй оставшийся набор через пробел.

Пример

Разберем пример

Ввод ATG CCA TTTT
→
Вывод ATG
CCA TTTT

pop(0) удаляет первую последовательность ATG и возвращает ее; в наборе остаются CCA и TTTT.

Примеры
ВводВывод

ATG
CCA TTTT

Контекст

Метод pop(0) удаляет элемент с индексом 0 и возвращает его, поэтому удаленное значение сохраняют в переменной. После удаления оставшиеся элементы сдвигаются влево, и первой в наборе становится вторая последовательность.

Основные определения

  • Метод pop() — удаляет элемент по индексу и возвращает его.
  • pop(0) — удаляет первый элемент.
  • Индекс — номер элемента в списке; нумерация начинается с 0.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор: seqs = input().split().
  2. Удалите первую последовательность и сохраните ее: first = seqs.pop(0).
  3. Напечатайте удаленную последовательность первой строкой.
  4. Второй строкой напечатайте " ".join(seqs); сверьтесь с примером: ATG CCA TTTT дают ATG и CCA TTTT.

Упражнение 5.3.2. Отбраковка коротких

Условие задачи

Слишком короткие последовательности не годятся для анализа. Удалите из набора все последовательности короче min_length букв; последовательность ровно такой длины остается. Выведите оставшийся набор в исходном порядке. Если не осталось ни одной последовательности, выведите слово нет.

Входные данные

В первой строке набор: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Во второй строке целое число min_length от 1 до 30.

Выходные данные

Оставшиеся последовательности через пробел одной строкой или слово нет.

Пример

Разберем пример

Ввод ACGT GA TTTTT C GGCC
3
→
Вывод ACGT TTTTT GGCC

GA и C короче 3 букв и удаляются; ACGT, TTTTT и GGCC остаются в исходном порядке.

Примеры
ВводВывод
 
ACGT GA TTTTT C GGCC
3
ACGT TTTTT GGCC
AC GT
5
нет
Контекст

Удалять элементы из списка во время обычного цикла for нельзя: номера сдвигаются, и часть элементов цикл пропустит. Поэтому перебирают копию seqs[:], а удаляют из исходного списка методом remove(). Условие len(sequence) < min_length строгое: последовательность ровно такой длины остается.

Основные определения

  • Метод remove() — удаляет первое вхождение элемента.
  • Копия списка — перебор копии не мешает удалению из исходного списка.
  • Строгое сравнение — len(sequence) < min_length не трогает последовательность ровно такой длины.
  • Пустой список — у пустого списка условие if seqs ложно.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор и порог: seqs = input().split(), min_length = int(input()).
  2. Перебирайте копию: for sequence in seqs[:]:.
  3. Короткие удаляйте из исходного списка: если len(sequence) < min_length, вызовите seqs.remove(sequence).
  4. Если seqs непуст, напечатайте " ".join(seqs), иначе слово нет; сверьтесь с примером: ACGT GA TTTTT C GGCC при min_length = 3 дают ACGT TTTTT GGCC, а AC GT при min_length = 5 — нет.

Упражнение 5.3.2. Журнал правок

Условие задачи

Набор правят командами. Команда +SEQ дописывает последовательность SEQ в конец набора. Команда -SEQ удаляет из набора первое вхождение SEQ; если такой последовательности в наборе нет, команда пропускается. Выполните все команды по порядку и выведите итоговый набор и число пропущенных команд.

Входные данные

В первой строке набор: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Во второй строке от 1 до 20 команд через пробел; каждая команда состоит из знака + или - и последовательности.

Выходные данные

В первой строке итоговый набор через пробел или слово нет, если набор пустой; во второй число пропущенных команд.

Пример

Разберем пример

Ввод ATG CCA ATG
-ATG +GG -TT
→
Вывод CCA ATG GG
1

-ATG удаляет первое вхождение ATG, +GG дописывает GG в конец, а -TT пропускается: TT в наборе нет. Ответ CCA ATG GG и 1.

Примеры
ВводВывод
 
ATG CCA ATG
-ATG +GG -TT
CCA ATG GG
1
AC
-AC
нет
0
Контекст

Команду разбирают по знаку: cmd[0] — первый символ, cmd[1:] — остальная последовательность. Команда + дописывает через append(), команда - удаляет первое вхождение методом remove(); если элемента нет, remove не вызывают, и команда попадает в счетчик пропущенных.

Основные определения

  • Срез строки — cmd[1:] — вся строка без первого символа.
  • Метод append() — дописывает элемент в конец списка.
  • Метод remove() — удаляет первое вхождение элемента.
  • Пропущенная команда — удалять нечего: такой последовательности в наборе нет.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор: seqs = input().split(); заведите skipped = 0.
  2. Перебирайте команды: for cmd in input().split(): — знак это cmd[0], последовательность — cmd[1:].
  3. На плюс дописывайте последовательность в конец: seqs.append(cmd[1:]).
  4. На минус удаляйте первое вхождение, если оно есть: if cmd[1:] in seqs: seqs.remove(cmd[1:]), иначе увеличивайте skipped; напечатайте набор (или слово нет) и skipped; сверьтесь с примером: ATG CCA ATG с командами -ATG +GG -TT дают CCA ATG GG и 1.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.

Задача со звездочкой 5.3. Без повторов подряд

Условие задачи

Если несколько одинаковых последовательностей стоят подряд, оставьте из них одну. Одинаковые последовательности, которые стоят не подряд, остаются. Выведите набор после этого.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30.

Выходные данные

Набор через пробел одной строкой.

Пример

Разберем пример

Ввод A A C C C A
→
Вывод A C A

Две A подряд дают одну, три C подряд — одну; последняя A отделена от первой, поэтому остается.

Примеры
ВводВывод

AC GT
Контекст

Результат начинают с первого элемента, а каждый следующий сравнивают с последним уже добавленным result[-1]: совпал — пропускают, отличается — дописывают. Повторы, разделенные другими последовательностями, при этом сохраняются.

Основные определения

  • Соседние повторы — одинаковые элементы, стоящие подряд.
  • result[-1] — последний элемент списка.
  • Метод append() — дописывает элемент в конец списка.
  • Срез seqs[1:] — все элементы, кроме первого.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор: seqs = input().split().
  2. Заведите результат с первым элементом: result = [seqs[0]].
  3. Перебирайте остальные: for sequence in seqs[1:]: — при sequence != result[-1] дописывайте sequence в result.
  4. Напечатайте " ".join(result); сверьтесь с примером: A A C C C A дают A C A, а AC GT остаются AC GT.

Задача со звездочкой 5.3. Разворот блоками

Условие задачи

Разбейте набор на блоки по block_size последовательностей подряд; последний блок может быть короче. Разверните порядок последовательностей внутри каждого блока, а блоки оставьте на своих местах. Выведите получившийся набор.

Входные данные

В первой строке набор: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Во второй строке целое число block_size от 1 до 20.

Выходные данные

Набор после разворота через пробел одной строкой.

Пример

Разберем пример

Ввод A C G T AA CC GG
3
→
Вывод G C A CC AA T GG

Блоки A C G и T AA CC разворачиваются внутри себя, а короткий последний блок GG из одной пробы остается как есть.

Примеры
ВводВывод

Контекст

Блок вырезают срезом seqs[index:index + block_size] и разворачивают через [::-1]. Цикл идет с шагом, равным ширине блока, поэтому каждый срез начинается с нового блока, а последний срез обрезается концом списка и может быть короче. Блоки приклеивают к результату оператором +=.

Основные определения

  • Блок — заданное число последовательностей подряд.
  • Срез seqs[index:index + block_size] — block_size элементов начиная с позиции index.
  • Обратный срез [::-1] — разворачивает список.
  • Оператор += — дописывает элементы одного списка в конец другого.
  • Шаг цикла — третий аргумент range задает шаг block_size.
Подсказка
  1. Прочитайте набор и ширину блока: seqs = input().split(), block_size = int(input()); заведите result = [].
  2. Идите по началам блоков: index пробегает range(0, len(seqs), block_size).
  3. Дописывайте развернутый блок: seqs[index:index + block_size] в обратном порядке ([::-1]) прибавляйте к result.
  4. Напечатайте " ".join(result); сверьтесь с примером: A C G T AA CC GG при block_size = 3 дают G C A CC AA T GG.

Задача со звездочкой 5.3. Отбор проб по кругу

Условие задачи

Пробы стоят по кругу в порядке набора. Лаборант начинает счет с первой пробы и отсчитывает step проб, считая ту, с которой начал; на последней из отсчитанных останавливается и забирает ее. Следующий счет начинается с пробы, которая стояла за забранной, а после последней пробы счет продолжается с начала круга. Так забирают все пробы. Выведите пробы в том порядке, в каком их забрали.

Входные данные

В первой строке набор: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Во второй строке целое число step от 1 до 50.

Выходные данные

Пробы в порядке отбора через пробел одной строкой.

Пример

Разберем пример

Ввод A T C GG CC
2
→
Вывод T GG A CC C

Счет начинается с A: первый и второй — A и T, забирают T. Затем счет идет с C: C и GG — забирают GG; дальше по кругу забирают A, CC и последнюю C.

Примеры
ВводВывод
 
A T C GG CC
2
T GG A CC C
AC GT
1
AC GT
Контекст

Номер следующей забранной пробы считают по остатку: index = (index + step - 1) % len(seqs) — счет начинается с текущей пробы, поэтому шагов на единицу меньше. После pop(index) список короче, и следующий счет сам начинается с пробы, стоявшей за забранной. Цикл while seqs идет, пока пробы не кончатся.

Основные определения

  • Проба — последовательность набора.
  • Остаток от деления % — держит номер в пределах длины списка.
  • Метод pop() — удаляет элемент по индексу и возвращает его.
  • Цикл while — идет, пока список не опустеет.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор и шаг счета: seqs = input().split(), step = int(input()); заведите order = [] и index = 0.
  2. Пока в наборе есть пробы (while seqs:), считайте номер: index = (index + step - 1) % len(seqs).
  3. Забирайте пробу: order.append(seqs.pop(index)) — следующий счет начнется с того же номера, то есть со следующей пробы.
  4. Напечатайте " ".join(order); сверьтесь с примером: A T C GG CC при step = 2 дают T GG A CC C, а AC GT при step = 1 — AC GT.
