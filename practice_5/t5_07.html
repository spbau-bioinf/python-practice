Списковые включения

25 минутЕрофеев А. И.

Строить новый список одной строкой списковым включением: преобразовывать элементы, отбирать их условием и перебирать пары двумя for.

1. Включение вместо цикла

Теория

В практике 4 был шаблон накопителя: начальное значение до цикла, обновление в теле, ответ после цикла. Для списка он выглядит так: пустой список, цикл, условие и append(). Такой шаблон встречается почти в каждой задаче этой практики, и для него в Python есть короткая запись.

цикл и включение
lens = []
for s in seqs:
    if "N" not in s:
        lens.append(len(s))
lens = [len(s) for s in seqs if "N" not in s]

Первые четыре строки и последняя строят один и тот же список. Последнюю читают так: «len(s) для каждого s из seqs, если в s нет N».

Списковое включение (list comprehension) — выражение в квадратных скобках, которое строит новый список: [выражение for x in seq if условие].

Сначала пишут то, что кладут в список, затем for, затем необязательное if. Выражение вычисляется для каждого элемента, который прошел условие; без if новый список той же длины, что исходный. Исходный список не меняется.

Переменная цикла for после цикла остается и хранит последний элемент, если цикл выполнился хотя бы раз; после цикла по пустому списку обращение к ней дает NameError, если такой переменной не было раньше. Переменная включения живет только внутри квадратных скобок: после включения обращение к ней дает NameError, если такой переменной не было раньше.

Пример

Новый список из старого

comprehension.py
seqs = ["ATCCAGCT", "GGGCAACT", "TTGG"]
lens = [len(s) for s in seqs]
print(lens)  # → [8, 8, 4]
lo = [s.lower() for s in seqs]
print(lo)    # → ['atccagct', 'gggcaact', 'ttgg']
rich = [s for s in seqs if s.count("G") >= 2]
print(rich)  # → ['GGGCAACT', 'TTGG']
Вывод
[8, 8, 4]
['atccagct', 'gggcaact', 'ttgg']
['GGGCAACT', 'TTGG']
  1. Строки 2 и 4: без условия; получаются длины и те же строки строчными буквами.
  2. Строка 6: условие пропускает только последовательности, где не меньше двух G; в список кладутся сами строки.

Включение с enumerate()

Прочитайте включение вслух, предскажите вывод, затем откройте его.

positions.py
s = "GATTACA"
r = [i for i, b in enumerate(s) if b == "A"]
print(r)  # → [1, 4, 6]
Вывод
[1, 4, 6]
  1. Строка 2: условие проверяет букву b, а в список кладется номер i; enumerate() считает с 0.

Позиции мотива

Включение с условием находит позиции мотива ATAT, как в задаче Rosalind SUBS; позиции считаются с 1, вхождения могут перекрываться.

subs.py
s = "GATATATGCATATACTT"
pos = [i + 1 for i in range(len(s) - 3) if s[i:i + 4] == "ATAT"]
print(pos)  # → [2, 4, 10]
Вывод
[2, 4, 10]

Добавьте в конец включения условие if len(s) > 3 и запустите снова.

seqs = ["ATCC", "GGG", "TTGGA", "AC"]

Вывод

2. Два for во включении

Теория

Во включении может быть несколько for. Они читаются в том же порядке, в каком стояли бы вложенные циклы из практики 4: первый for внешний, второй внутренний. Условие if ставят в конце.

Если во включении больше двух частей for и if, его трудно читать: такой код пишут обычным циклом.

Пример

Все пары

pairs.py
pairs = [(a, b) for a in "AC" for b in "GT"]
print(pairs)
same = [(i, j) for i in range(3) for j in range(3) if i < j]
print(same)  # → [(0, 1), (0, 2), (1, 2)]
Вывод
[('A', 'G'), ('A', 'T'), ('C', 'G'), ('C', 'T')]
[(0, 1), (0, 2), (1, 2)]
  1. Строка 1: для каждой буквы a перебираются все b, как во вложенном цикле.
  2. Строка 3: условие i < j оставляет каждую пару разных номеров один раз.

Типичная ошибка: слишком длинное включение

Неверно: работает, но читать трудно
m = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
r = [x for row in m if sum(row) >= 10 for x in row if x % 3 == 0]
print(r)  # → [6, 9]
Вывод
[6, 9]
Верно
m = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
r = []
for row in m:
    if sum(row) >= 10:
        for x in row:
            if x % 3 == 0:
                r.append(x)
print(r)  # → [6, 9]
Вывод
[6, 9]

Результат одинаковый, но в цикле видно, какое условие к какому for относится.

Где живет переменная

Предскажите вывод, затем откройте его.

scope.py
for x in "ACG":
    print(x, end="")
print()
print(x)  # → G
y = [z for z in "ACG"]
print(y)  # → ['A', 'C', 'G']
Вывод
ACG
G
['A', 'C', 'G']
  1. Строка 4: переменная цикла x осталась после цикла и хранит последнюю букву.
  2. Строка 5: переменная z существует только внутри скобок; строка print(z) после включения дала бы NameError.
Практика

Добавьте в конец включения условие if a != b и запустите: сколько пар осталось?

dinucs = [a + b for a in "ACGT" for b in "ACGT"]

Вывод
16 ['AA', 'AC', 'AG', 'AT', 'CA']

Что нужно сделать

Упражнение 5.7.1. Общие окна

Что нужно сделать

Окно длины k — участок строки из k подряд идущих букв. Сравнивая две последовательности, считают пары окон, одно из первой строки, другое из второй, в которых буквы совпадают: так строят точечную диаграмму сходства (dot plot). Посчитайте число таких пар. Например, у AAA и AA при k = 2 два окна AA в первой строке и одно во второй дают 2 пары. Соберите пары списковым включением с двумя for.

Выходные данные
