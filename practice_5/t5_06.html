Сортировка

30 минутЕрофеев А. И.

Сортировать список методом sort() и функцией sorted(), задавать порядок ключом, сортировать записи-кортежи и находить элемент с наибольшим ключом.

1. Ключ сортировки

Теория

Строки Python сравнивает посимвольно: решает первая различающаяся буква, а если одна строка начало другой, меньше короткая ("AT" < "ATG"). Длина сама по себе порядок не задает, поэтому обычная сортировка списка последовательностей идет по алфавиту. Чтобы упорядочить последовательности по длине, сортировке нужно сказать, что именно сравнивать.

Сортируют двумя способами. Метод a.sort() переставляет элементы того же списка и, как другие методы-изменители (страница 03), возвращает None. Функция sorted(a) не трогает исходный список и возвращает новый; она принимает любую последовательность, например строку или range.

Оба способа принимают параметр key: функцию одного аргумента. Python вызывает ее один раз для каждого элемента и получает ключ. Сравниваются ключи, а в результат попадают сами элементы. Функцию передают без скобок: key=len, а не key=len(). Параметр reverse=True сортирует по убыванию.

Сортировка в Python устойчивая: элементы с равными ключами остаются в том порядке, в каком были до сортировки. Это верно и для reverse=True.

Ключом служит любая функция одного аргумента: встроенная len, метод строки str.lower (вызов str.lower(s) то же, что s.lower()), метод конкретной строки seq.count (вызов seq.count(b) считает букву b в seq). Без ключа строки сравниваются по кодам символов: все прописные буквы раньше строчных, поэтому "TTA" меньше "gc".

Пример

По длине, без учета регистра, по убыванию

sort_key.py
seqs = ["GATTACA", "AT", "gc", "TTA"]
print(sorted(seqs))                         # → ['AT', 'GATTACA', 'TTA', 'gc']
print(sorted(seqs, key=len))                # → ['AT', 'gc', 'TTA', 'GATTACA']
print(sorted(seqs, key=str.lower))          # → ['AT', 'GATTACA', 'gc', 'TTA']
print(sorted(seqs, key=len, reverse=True))  # → ['GATTACA', 'TTA', 'AT', 'gc']
print(seqs)                                 # → ['GATTACA', 'AT', 'gc', 'TTA']
Вывод

['AT', 'gc', 'TTA', 'GATTACA']
['AT', 'GATTACA', 'gc', 'TTA']

['GATTACA', 'AT', 'gc', 'TTA']

  2. Строка 3: ключи 7, 2, 2, 3; у "AT" и "gc" ключи равны, и они остались в исходном порядке.
  3. Строка 5: по убыванию длины; равные по-прежнему в исходном порядке.
  4. Строка 6: sorted() не изменил исходный список.

2. Сортировка записей

Теория

Кортежи Python сравнивает поле за полем: сначала первые поля, если они равны, то вторые, и так далее. Такой порядок называют лексикографическим, так же сравниваются слова в словаре.

Поле, по которому сортируют, ставят в кортеже первым: список записей (gc, name) сортируется по GC-составу, а при равном GC-составе по имени.

reverse=True разворачивает сравнение целиком, по всем полям: при равном GC-составе имена тоже пойдут в обратном порядке.

Если ключ нельзя передать готовой функцией, его кладут в кортеж рядом с элементом: строят список (ключ, элемент), сортируют, затем забирают элементы. В документации Python этот прием называют «декорировать, отсортировать, раздекорировать».

Пример

Записи (gc, name)

sort_tuples.py
recs = [(50.0, "Rosalind_7"),
        (62.5, "Rosalind_2"),
        (50.0, "Rosalind_1")]
recs.sort()
print(recs[0])              # → (50.0, 'Rosalind_1')
print(recs[-1])             # → (62.5, 'Rosalind_2')
print((1, "b") < (2, "a"))  # → True
Вывод
(50.0, 'Rosalind_1')
(62.5, 'Rosalind_2')
True
  1. Строка 4: у двух записей GC 50.0, и порядок между ними решило второе поле, имя.
  2. Строка 7: первые поля уже различаются, до вторых сравнение не доходит.

По убыванию

Предскажите вывод, затем откройте его.

reverse_tuples.py
recs = [(50.0, "R1"), (62.5, "R2"), (50.0, "R3")]
recs.sort(reverse=True)
print(recs)
Вывод
[(62.5, 'R2'), (50.0, 'R3'), (50.0, 'R1')]
  1. Строка 2: первой идет запись с наибольшим GC. У R1 и R3 GC равный, и reverse=True развернул и порядок имен.

3. max() и min() с ключом

Теория

Параметр key есть не только у сортировки, но и у функций max() и min(). max(seqs, key=len) отвечает на вопрос «какая последовательность самая длинная» и возвращает саму последовательность, а не ее длину.

Если наибольший ключ у нескольких элементов, max() возвращает первый из них; так же min().

Ключом может быть и метод конкретной строки: вызов seq.count(b) считает букву b в seq, поэтому max("ACGT", key=seq.count) дает букву, которая чаще всех встречается в seq.

Без ключа max() для строк сравнивает их по алфавиту, а не по длине. Чтобы получить саму длину, ее считают отдельно: len(max(seqs, key=len)).

Пример

Самая длинная и самая короткая

max_key.py
seqs = ["ATCCAGCT", "AT", "GATTACA", "GC"]
print(max(seqs, key=len))  # → ATCCAGCT
print(min(seqs, key=len))  # → AT
print(max(seqs))           # → GC
Вывод
ATCCAGCT
AT
GC
  1. Строка 3: у "AT" и "GC" длина 2, вернулась первая из них.
  2. Строка 4: без ключа строки сравниваются по алфавиту, и наибольшей оказалась "GC".
Практика

Замените max на min и запустите: какая буква самая редкая?

try_max.py
seq = "GATTACAGATT"
print(max("ACGT", key=seq.count))  # → A
Вывод
A

Что нужно сделать

GC-состав — доля букв G и C среди всех букв последовательности, обычно ее записывают в процентах (страница 05 практики 4). Распределите последовательности по местам: место 1 у наибольшего GC-состава. Последовательности с равным GC-составом делят место, а следующее место пропускается: при долях 0,5; 1; 0,5; 0 места 2, 1, 2, 4. Выведите места последовательностей в порядке набора.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30.

Выходные данные

Места через пробел одной строкой.

Примеры
Входные данныеВыходные данные
 
ATGC GGCC ATAT GCAT
2 1 4 2
AAAA
1

Сдача работы

  1. В папке projects_5 создайте папку t5_06 и сохраните в нее решения упражнений этой страницы для своего уровня: Базовый t5_06_1_basic.py и t5_06_2_basic.py.Средний t5_06_1_medium.py и t5_06_2_medium.py.Продвинутый t5_06_1_advanced.py и t5_06_2_advanced.py.
  2. Задача со звездочкой необязательная и в зачет не входит. Если вы ее решили, сохраните решение в ту же папку: Базовый t5_06_star_basic.py.Средний t5_06_star_medium.py.Продвинутый t5_06_star_advanced.py.
  3. Загрузите папку t5_06 в свой репозиторий внутрь папки projects_5 и отправьте изменения до срока. Итоговая проверка добавляет закрытые тесты, которых нет на странице: программа должна правильно работать на любых допустимых входных данных, а не только на примерах.

Выберите свой уровень во вкладках любого упражнения: здесь останутся только имена файлов вашего уровня и появится структура папок.
