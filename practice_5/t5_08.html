Признаки

25 минутЕрофеев А. И.

Разбирать записи FASTA в список пар, описывать последовательность вектором признаков и собирать векторы в матрицу.

1. Записи FASTA в списке

Теория

На этой и следующей странице собирается все, что было в практике: списки, кортежи, срезы, zip(), включения. Данные приходят в формате FASTA, и первым делом их нужно разложить по записям.

FASTA — текстовый формат последовательностей. Запись начинается со строки заголовка: знак >, сразу за ним идентификатор (имя последовательности), затем, через пробел, необязательное описание. Следующая строка содержит саму последовательность.

Если каждая последовательность занимает одну строку, строки текста чередуются: заголовок, последовательность, заголовок, последовательность. Список строк дает метод split(); заголовки стоят на местах с четными индексами 0, 2, 4 (lines[0::2]), последовательности на местах с нечетными индексами (lines[1::2]). Срез [1:] снимает с заголовка знак >, а zip() соединяет имена и последовательности в пары (id, seq).

В упражнениях записи читаются через input(): сначала число записей n, затем по две строки на запись.

Читать файлы мы пока не умеем (это тема 9 «Файлы, исключения, сквозной проект»), поэтому в примере текст FASTA записан строкой в тройных кавычках: такая строка может занимать несколько строк кода, переводы строк входят в нее. Метод split() без аргументов режет и по пробелам, и по переводам строк; если в заголовках есть описание через пробел, текст режут по переводам строк: text.split("\n").

Пример

FASTA в список записей

fasta.py
text = """>Rosalind_1
ATCCAGCT
>Rosalind_2
GGGCAACT
>Rosalind_3
ATGGATCT"""
lines = text.split()
names = [x[1:] for x in lines[0::2]]
seqs = lines[1::2]
recs = list(zip(names, seqs))
print(recs[0])    # → ('Rosalind_1', 'ATCCAGCT')
print(len(recs))  # → 3
Вывод
('Rosalind_1', 'ATCCAGCT')
3
  1. Строки 1–6: текст FASTA из трех записей.
  2. Строка 7: шесть строк текста в одном списке.
  3. Строки 8–9: имена без знака > и последовательности.
  4. Строка 10: zip() собирает пары; list() нужен, чтобы обращаться к ним по индексу.
Практика

Допишите в цикл чтения печать длины: print(name, len(seq)) после строки 5. Программа ждет ввода: пользователь набирает число записей 2, затем две записи FASTA, каждую строку завершая Enter.

2. Векторы и матрица

Теория

На странице 09 мы будем описывать столбцы выравнивания. Здесь, наоборот, нужно описать каждую последовательность целиком несколькими числами, чтобы потом сравнивать последовательности между собой по этим числам.

Признак (feature) сопоставляет объекту число: длину, GC-состав, число букв A. Вектор признаков (feature vector) — список значений признаков одного объекта.

Для последовательности "ATCCAGCT" вектор из чисел букв A, C, G, T равен [2, 3, 1, 2]; его строит включение [s.count(b) for b in "ACGT"]. Список таких векторов образует матрицу признаков: в строках последовательности, в столбцах признаки. Строку матрицы берут индексом X[i], столбец собирают включением [v[2] for v in X] или берут из zip(*X).

Строки матрицы создают включением, а не умножением списка: [[0] * 3] * 2 повторяет ссылку на одну и ту же строку.

Пример

Матрица признаков

features.py
seqs = ["ATCCAGCT", "GGGCAACT", "TTGGAACT"]
X = [[s.count(b) for b in "ACGT"] for s in seqs]
for v in X:
    print(v)
col_g = [v[2] for v in X]
print(col_g)  # → [1, 3, 2]
Вывод
[2, 3, 1, 2]
[2, 2, 3, 1]
[2, 1, 2, 3]
[1, 3, 2]
  1. Строка 2: внутреннее включение строит вектор одной последовательности, внешнее повторяет это для каждой.
  2. Строка 5: из каждой строки берется элемент с индексом 2, число букв G: получается столбец признака.

Типичная ошибка: строки матрицы через *

Неверно: две ссылки на одну строку
bad = [[0] * 3] * 2
bad[0][0] = 5
print(bad)  # → [[5, 0, 0], [5, 0, 0]]
Вывод
[[5, 0, 0], [5, 0, 0]]
Верно
good = [[0] * 3 for i in range(2)]
good[0][0] = 5
print(good)  # → [[5, 0, 0], [0, 0, 0]]
Вывод
[[5, 0, 0], [0, 0, 0]]

[0] * 3 дает три нуля: числа неизменяемы, и повтор ссылки на ноль безопасен. Но * 2 над списком [[0, 0, 0]] не копирует строку, а дважды кладет ссылку на один и тот же список (страница 02). Включение строит каждую строку заново.

Сумма двух столбцов

Предскажите вывод, затем откройте его.

gc_column.py
X = [[2, 3, 1, 2],
     [2, 2, 3, 1],
     [2, 1, 2, 3]]
gc = [v[1] + v[2] for v in X]
print(gc)                 # → [4, 5, 3]
print(sum(gc) / len(gc))  # → 4.0
Вывод
[4, 5, 3]
4.0
  1. Строка 4: для каждой строки складываются столбцы C и G: число букв G и C в последовательности.
  2. Строка 6: среднее по всем последовательностям; деление / всегда дает вещественное число (float), даже если делится нацело.
Практика

Замените в строке 2 строку "ACGT" на "GC" и запустите: какие признаки остались?

try_vector.py
seq = "GATTACAGC"
v = [seq.count(b) for b in "ACGT"]
print(v, sum(v) == len(seq))  # → [3, 2, 2, 2] True
Вывод
[3, 2, 2, 2] True

Упражнение 5.8.1. Вектор признаков

Условие задачи

Опишите последовательность вектором из четырех признаков: числа букв A, C, G и T, именно в таком порядке. Выведите числа вектора через пробел.

Входные данные

Одна строка: последовательность из букв A, C, G, T длиной от 1 до 100.

Выходные данные

Четыре целых числа через пробел.

Пример

Разберем пример

Ввод GATTACA
→
Вывод 3 1 1 2

Буква A встречается 3 раза, C — 1 раз, G — 1 раз, T — 2 раза; вектор выводится в порядке A, C, G, T.

Примеры
ВводВывод
 
GATTACA
3 1 1 2
CCCC
0 4 0 0
Контекст

Включение [str(seq.count(base)) for base in "ACGT"] перебирает буквы строки "ACGT" и для каждой считает вхождения методом count — получается вектор признаков в нужном порядке. str() внутри включения сразу делает числа строками, и join склеивает их через пробел.

Основные определения

  • Вектор признаков — четыре числа букв A, C, G, T по порядку.
  • Списковое включение — список, собранный выражением из строки.
  • Метод count() — считает, сколько раз буква встречается в строке.
  • Функция str() — переводит число в строку.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте последовательность: seq = input().
  2. Перебирайте буквы строки "ACGT" включением: [seq.count(base) for base in "ACGT"] — порядок вектора задает сама строка.
  3. Переведите числа в строки прямо во включении: str(seq.count(base)) для каждой base из "ACGT".
  4. Напечатайте " ".join(vector); сверьтесь с примером: GATTACA дает 3 1 1 2, а CCCC — 0 4 0 0.

Упражнение 5.8.1. Ближе всех к среднему

Условие задачи

Постройте матрицу признаков записей FASTA (числа букв A, C, G, T) и найдите средний вектор: среднее арифметическое каждого столбца. Расстоянием между двумя векторами будем считать сумму модулей разностей их чисел (модуль числа дает функция abs()): у [1, 2, 0, 1] и [2, 2, 1, 1] расстояние 1 + 0 + 1 + 0 = 2. Выведите средний вектор, округлив каждое число функцией round() до двух цифр после точки, и идентификатор записи, ближайшей к среднему вектору; если таких несколько, первой по порядку. Сравнивайте расстояния до неокругленного среднего.

Входные данные

В первой строке число записей count от 1 до 20. Дальше count записей FASTA, каждая в двух строках: строка заголовка, знак > и идентификатор без пробелов, затем последовательность из букв A, C, G, T длиной от 1 до 30.

Выходные данные

В первой строке четыре числа среднего вектора через пробел в том виде, в каком их печатает Python после round(value, 2) (например, 1.33 или 1.0); во второй идентификатор.

Пример

Разберем пример

>s1
ACGT
>s2
AAGG
>s3
CCCT
→
Вывод 1.0 1.33 1.0 0.67
s1

Средний вектор — 1.0 1.33 1.0 0.67; s1 отличается от него на 0,67, а s2 и s3 — на 4, поэтому ближе всех s1.

Примеры

Контекст

Матрицу matrix собирают как список векторов. Средний вектор получают по столбцам: zip(*matrix) разворачивает матрицу, и sum(col) складывает столбец; деление на count выполняют только при печати, а расстояния сравнивают до неокругленного среднего. Расстояние |value - среднее| для каждого признака считают через abs(), а сумму умножают на count, чтобы обойтись без дробей: sum(abs(count * value - column_sum)).

Основные определения

  • Матрица признаков — строка на запись: идентификатор и четыре числа букв.
  • Средний вектор — среднее арифметическое каждого столбца матрицы.
  • Расстояние между векторами — сумма модулей разностей их чисел.
  • Функция abs() — возвращает модуль числа.
  • Функция zip() — разворачивает матрицу по столбцам.
Подсказка
  1. Прочитайте записи: count = int(input()); для каждой сохраните name = input()[1:] и вектор [seq.count(base) for base in "ACGT"] в список matrix.
  2. Соберите суммы столбцов: sum(col) для каждого col из zip(*matrix); zip(*matrix) разворачивает матрицу.
  3. Для каждой строки посчитайте расстояние до среднего без деления на count: сумма модулей разностей abs(count * value - column_sum) по парам value и column_sum из zip(vector, sums).
  4. Выберите первую строку с наименьшим distance (строгое <); напечатайте суммы, округленные round(column_sum / count, 2), и идентификатор; сверьтесь с примером: ACGT, AAGG и CCCT дают 1.0 1.33 1.0 0.67 и s1.

Задача со звездочкой 5.8. Доли букв

Условие задачи

Для каждой записи FASTA выведите идентификатор и доли букв A, C, G, T: число буквы, деленное на длину последовательности, округленное функцией round() до двух цифр после точки.

Входные данные

В первой строке число записей count от 1 до 20. Дальше count записей FASTA, каждая в двух строках: строка заголовка, знак > и идентификатор без пробелов, затем последовательность из букв A, C, G, T длиной от 1 до 30.

Выходные данные

count строк: идентификатор и четыре доли через пробел в том виде, в каком их печатает Python после round(value, 2).

Пример

Вывод s1 0.43 0.14 0.14 0.29

У s1 доли 3/7 ≈ 0,43, 1/7 ≈ 0,14, 1/7 ≈ 0,14 и 2/7 ≈ 0,29; у s2 — 0,0, 0,5, 0,5 и 0,0.

Контекст

Для каждой записи включение строит доли: seq.count(base) / len(seq) для base из "ACGT", вызов round(..., 2) округляет, а str() переводит в строку. Деление / дает float, поэтому доли печатаются как 0.43 или 0.0, даже когда они целые.

Основные определения

  • Доля буквы — число буквы, деленное на длину последовательности.
  • Списковое включение — список, собранный выражением из строки.
  • Функция round() — округляет число; второй аргумент задает число знаков.
  • Функция len() — возвращает длину строки.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте число записей: count = int(input()).
  2. Для каждой записи читайте name = input()[1:] и seq = input().
  3. Соберите доли включением: seq.count(base) разделите на len(seq), округлите до двух знаков (round(..., 2)) и переведите в строку функцией str.
  4. Напечатайте name и " ".join(shares); сверьтесь с примером: GATTACA дает 0.43 0.14 0.14 0.29, а ACGT — 0.25 0.25 0.25 0.25.

Задача со звездочкой 5.8. Ближайшая пара

Условие задачи

Постройте матрицу признаков записей FASTA (числа букв A, C, G, T). Расстояние между векторами — сумма модулей разностей их чисел. Найдите две разные записи с наименьшим расстоянием. Если таких пар несколько, выберите первую: с наименьшим номером первой записи, а при равном с наименьшим номером второй.

Входные данные

В первой строке число записей count от 2 до 20. Дальше count записей FASTA, каждая в двух строках, как в упражнении 5.8.1 среднего уровня: строка заголовка, знак > и идентификатор без пробелов, затем последовательность из букв A, C, G, T длиной от 1 до 30.

Выходные данные

Идентификаторы пары в порядке записей и расстояние через пробел.

Контекст

Пары перебирают двумя вложенными циклами, inner_index начинает с index + 1 — каждая пара встречается один раз. Расстояние считают суммой abs(value - other_value) по zip двух векторов; лучшую пару заменяют строгим <, поэтому при равных расстояниях остается первая по порядку.

Основные определения

  • Расстояние между векторами — сумма модулей разностей их чисел.
  • Матрица признаков — строка на запись: четыре числа букв A, C, G, T.
  • Функция abs() — возвращает модуль числа.
  • Функция zip() — перебирает пары чисел двух векторов.
  • Строгое сравнение — < не пропускает равное расстояние.
Подсказка
  1. Прочитайте записи: count = int(input()); сохраните name = input()[1:] и вектор [seq.count(base) for base in "ACGT"] в список matrix.
  2. Перебирайте пары без повторов: index пробегает range(count), а inner_index — range(index + 1, count).
  3. Считайте расстояние: сумма abs(value - other_value) по парам из matrix[index] и matrix[inner_index].
  4. Заменяйте лучшую пару только при строгом distance < best (лучшее начните с None); напечатайте идентификаторы и distance; сверьтесь с примером: ACGT, AAGG и ACGG дают s1 s3 2, а AAAA и CCCC — a b 8.
