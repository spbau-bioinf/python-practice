Имена и копии

25 минутЕрофеев А. И.

Отличать второе имя списка от его копии, делать копию явно и менять элементы копии по индексу.

1. Два имени, один список

Теория

Со строками и числами вопрос о копиях не возникал: их нельзя изменить. Список изменить можно, и тогда важно, сколько списков существует в программе на самом деле. После b = a кажется, что списков два. Проверим это.

Имя в Python работает как ярлык на объекте. Присваивание a = ["ATCC", "GGGC"] создает список и вешает на него ярлык a. Присваивание b = a не создает второй список: оно вешает на тот же список второй ярлык b.

Псевдоним (alias) — второе имя того же объекта.

Присваивание никогда не копирует данные. Если список изменить через одно имя, изменение видно через все его имена.

Новое присваивание b = ["T"] ничего не меняет в старом списке: оно переклеивает ярлык b на другой список. Так же ведет себя переменная цикла: в цикле for s in seqs: имя s на каждом шаге висит на очередном элементе, и s = "-" только переклеивает ярлык, а список остается прежним.

Почему со строками этого не было видно? После t = s строка тоже одна, с двумя именами. Но изменить ее нельзя: любая операция строит новую строку, и присваивание переклеивает ярлык на нее. Общий объект становится заметен только тогда, когда объект можно изменить на месте, как список методом append().

2. Копия списка

Теория

Если нужен независимый список, его копируют явно. Метод copy() и срез [:] без начала и конца строят новый список с теми же элементами. Изменение копии не трогает оригинал.

Копия списка — новый список с теми же элементами, что у исходного.

Один это объект или два, проверяет is; равны ли значения, проверяет ==. У копии c == a дает True, а c is a дает False.

Чтобы изменить элементы копии в цикле, нужен индекс: for i in range(len(c)): и присваивание c[i] = …. Как сказано в разделе 1, присваивание переменной цикла список не меняет.

Severance в книге «Python for Everybody» называет списки с равными значениями эквивалентными, а один и тот же объект идентичным. Идентичные объекты всегда эквивалентны, обратное неверно: копия равна оригиналу, но это другой объект.

Подробнее: кортеж со списком внутри и копия вложенного списка

Кортеж неизменяем в том смысле, что нельзя заменить его элемент. Если элемент кортежа сам список, этот список менять можно: после t = ("id", [1, 2]) вызов t[1].append(3) работает, и кортеж печатается как ('id', [1, 2, 3]).

Метод copy() и срез [:] делают поверхностную копию: новый внешний список, а элементы те же объекты. Для списка строк этого достаточно, строки неизменяемы. Для списка списков внутренние списки остаются общими: c = m.copy(), затем c[0].append(5) меняет и m[0]. Полную копию вложенных объектов делает функция deepcopy() модуля copy.

Пример

Копия, is и ==

copy_list.py
a = ["ATCC", "GGGC"]
b = a
c = a.copy()
d = a[:]
print(b is a, c is a, d is a)  # → True False False
print(c == a, d == a)          # → True True
c.append("AAGC")
print(a)                       # → ['ATCC', 'GGGC']
print(c)                       # → ['ATCC', 'GGGC', 'AAGC']
Вывод
True False False
True True
['ATCC', 'GGGC']
['ATCC', 'GGGC', 'AAGC']
  1. Строки 3–4: два способа сделать копию; списков в программе теперь три.
  2. Строка 5: b тот же объект, что a; c и d другие.
  3. Строка 6: значения у копий те же, поэтому == дает True.
  4. Строки 7–9: изменение копии c не видно через a.

Типичная ошибка: присвоить переменной цикла

Неверно: список не меняется
seqs = ["ATCC", "NNNN", "GGGC"]
for s in seqs:
    if s == "NNNN":
        s = "-"
print(seqs)  # → ['ATCC', 'NNNN', 'GGGC']
Вывод
['ATCC', 'NNNN', 'GGGC']
Верно
seqs = ["ATCC", "NNNN", "GGGC"]
for i in range(len(seqs)):
    if seqs[i] == "NNNN":
        seqs[i] = "-"
print(seqs)  # → ['ATCC', '-', 'GGGC']
Вывод
['ATCC', '-', 'GGGC']

Строка 4 неверного варианта переклеивает ярлык s на строку "-", а элемент списка остается прежним. Элемент меняют присваиванием по индексу.

Упражнение 5.2.1. Черновик набора

Условие задачи

Перед правкой набор копируют: изменения в копии не должны затрагивать исходный набор. Сделайте копию набора, допишите в конец копии новую последовательность и выведите исходный набор и копию.

Входные данные

В первой строке набор: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Во второй строке новая последовательность из тех же букв.

Выходные данные

В первой строке исходный набор через пробел, во второй копия с добавленной последовательностью.

Пример

Разберем пример

Ввод ATG CCA
TTTT
→
Вывод ATG CCA
ATG CCA TTTT

copy() создает независимую копию: TTTT добавляется только в копию, а исходный набор остается ATG CCA.

Примеры
ВводВывод
 
ATG CCA
TTTT
ATG CCA
ATG CCA TTTT
GATTACA

GATTACA GATTACA
Контекст

Метод copy() создает новый список с теми же элементами, а срез [:] делает то же самое. Присваивание draft = seqs копией не является: обе переменные смотрят на один список, и append в draft изменил бы и seqs.

Основные определения

  • Копия списка — новый список с теми же элементами; изменения в нем не затрагивают исходный.
  • Метод copy() — возвращает копию списка.
  • Срез [:] — копия всего списка.
  • Метод append() — дописывает элемент в конец списка.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор: seqs = input().split().
  2. Сделайте копию: draft = seqs.copy() или draft = seqs[:].
  3. Допишите новую последовательность в копию: draft.append(input()).
  4. Напечатайте " ".join(seqs), затем " ".join(draft); сверьтесь с примером: ATG CCA и TTTT дают ATG CCA, а во второй строке ATG CCA TTTT.

Упражнение 5.2.1. Маскировка в копии

Условие задачи

Буквой N отмечают позицию, которую прибор не смог прочитать. Сделайте копию набора и замените в копии каждую последовательность, в которой есть хотя бы одна буква N, на знак -. Исходный набор должен остаться прежним. Выведите исходный набор и копию.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, N, ее длина от 1 до 30.

Выходные данные

В первой строке исходный набор через пробел, во второй копия после замены.

Пример

Разберем пример

Ввод ACGT ANNT GGNC TTAA
→
Вывод ACGT ANNT GGNC TTAA
ACGT - - TTAA

ANNT и GGNC содержат букву N, поэтому в копии обе заменены на дефис; в исходном наборе они остались прежними.

Контекст

Копию перебирают по индексам: элемент списка можно заменить только по индексу. Условие "N" in masked[index] проверяет всю последовательность целиком, а исходный список seqs при этом остается нетронутым.

Основные определения

  • Копия списка — новый список с теми же элементами; изменения в нем не затрагивают исходный.
  • Метод copy() — возвращает копию списка.
  • Оператор in — проверяет, встречается ли подстрока в строке.
  • Индекс — номер элемента в списке; нумерация начинается с 0.
  • Метод join() — склеивает список строк в одну строку через разделитель.

  3. Если в последовательности есть N ("N" in masked[index]), замените элемент: masked[index] = "-".

Упражнение 5.2.1. Сдвиг по кругу

Условие задачи

Последовательности стоят по кругу. Сдвиньте набор на shift позиций вправо: каждая последовательность переходит на shift мест дальше, а те, что выходят за конец, встают в начало в том же порядке. Выведите набор после сдвига.

Входные данные

В первой строке набор: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Во второй строке целое число shift от 0 до 100; оно может быть больше числа последовательностей.

Выходные данные

Набор после сдвига через пробел одной строкой.

Пример

Разберем пример

Ввод A C G T
1
→
Вывод T A C G

Сдвиг вправо на 1 отправляет последний элемент T в начало, а остальные сдвигает на место вправо; набор переходит в T A C G.

Примеры
ВводВывод
 
A C G T
1
T A C G
ACG TTA
0
ACG TTA
Контекст

Новое место элемента при сдвиге считают остатком от деления: элемент с номером (index - shift) % length встает на место index. Остаток работает и при сдвиге, большем длины списка, поэтому заранее уменьшать сдвиг не нужно; копию заполняют по номерам исходного списка.

Основные определения

  • Сдвиг по кругу — элементы переходят на заданное число мест вправо, вышедшие за конец встают в начало.
  • Остаток от деления % — номер по кругу: (index - shift) % length остается в пределах от 0 до length - 1.
  • Индекс — номер элемента в списке; нумерация начинается с 0.
  • Копия списка — новый список с теми же элементами; его заполняют по номерам исходного.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор и число: seqs = input().split(), shift = int(input()); запомните length = len(seqs).
  2. Заведите копию: shifted = seqs.copy().
  3. Заполните ее по номерам: в цикле for index in range(length): присвойте shifted[index] элемент исходного списка с номером (index - shift) % length.
  4. Напечатайте " ".join(shifted); сверьтесь с примером: A C G T при shift = 1 дает T A C G, а при shift = 0 набор не меняется.

Задача со звездочкой 5.2. Маскировка по номерам

Условие задачи

Сделайте копию набора и замените в копии последовательности с указанными номерами на строку из букв N той же длины. Номера считаются с 1 и могут повторяться. Выведите исходный набор и копию.

Входные данные

В первой строке набор: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Во второй строке номера последовательностей через пробел, от 1 до числа последовательностей.

Выходные данные

В первой строке исходный набор через пробел, во второй копия после замены.

Пример

Разберем пример

Ввод ACGT GGCC TTAA
2
→
Вывод ACGT GGCC TTAA
ACGT NNNN TTAA

Номер 2 указывает на GGCC: в копии эта последовательность заменяется на NNNN той же длины, а исходный набор не меняется.

Примеры

Контекст

Номер из ввода считают с 1, а индексы списка — с 0, поэтому из номера вычитают единицу. Строку из букв N нужной длины получают умножением "N" * len(...). Повторный номер просто еще раз заменит уже замаскированную последовательность.

Основные определения

  • Копия списка — новый список с теми же элементами; изменения в нем не затрагивают исходный.
  • Метод copy() — возвращает копию списка.
  • Номера с 1 — из номера вычитают единицу, чтобы получить индекс.
  • Умножение строки — "N" * 4 дает NNNN.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор и сделайте копию: seqs = input().split(), masked = seqs.copy().
  2. Переберите номера: for num in input().split():.
  3. Переведите номер в индекс: index = int(num) - 1.
  4. Замените элемент: masked[index] = "N" * len(masked[index]); напечатайте обе строки; сверьтесь с примером: AC GT CA и номера 3 1 дают во второй строке NN GT NN.

Задача со звездочкой 5.2. Обмен соседей

Условие задачи

Сделайте копию набора, в которой первая и вторая последовательности поменялись местами, третья и четвертая, и так далее. Если последовательностей нечетное число, последняя остается на месте. Выведите исходный набор и копию.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30.

Выходные данные

В первой строке исходный набор через пробел, во второй копия после обмена.

Пример

Разберем пример

Ввод A C G T
→
Вывод A C G T
C A T G

Пары обмениваются местами: первая со второй, третья с четвертой, поэтому в копии получается C A T G.

Примеры
ВводВывод
 
A C G T
A C G T
C A T G
AT GC CG
AT GC CG
GC AT CG
Контекст

Пары обходят циклом range(0, len(seqs) - 1, 2): шаг 2 перескакивает через пару, а граница len(seqs) - 1 не пускает цикл на последний индекс при нечетном числе. Оба элемента пары берут из исходного списка, поэтому обмен не портит данные.

Основные определения

  • Копия списка — новый список с теми же элементами; изменения в нем не затрагивают исходный.
  • Шаг цикла — третий аргумент range задает шаг: 2 значит через один индекс.
  • Пара соседей — элементы с номерами index и index + 1.
  • Нечетное число элементов — последняя последовательность остается на месте.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор и сделайте копию: seqs = input().split(), swapped = seqs.copy().
  2. Идите по парам: for index in range(0, len(seqs) - 1, 2):.
  3. Поменяйте местами: swapped[index] = seqs[index + 1] и swapped[index + 1] = seqs[index].
  4. Напечатайте обе строки; сверьтесь с примером: A C G T дают во второй строке C A T G, а AT GC CG — GC AT CG.

Задача со звездочкой 5.2. Сдвиг до совпадения

Условие задачи

Даны два набора с одинаковым числом последовательностей. Найдите наименьшее shift от 0, при котором сдвиг первого набора по кругу на shift позиций вправо дает второй набор: каждая последовательность переходит на shift мест дальше, а вышедшие за конец встают в начало в том же порядке. Если такого сдвига нет, выведите -1.

Входные данные

В первой строке первый набор, во второй строке второй набор: от 1 до 20 последовательностей через пробел, число последовательностей в наборах одинаковое. Последовательности состоят из букв A, C, G, T, длина каждой от 1 до 30.

Выходные данные

Одно целое число: наименьший сдвиг или -1.

Пример

Разберем пример

Ввод A C G T
G T A C
→
Вывод 2

После сдвига на 1 получается T A C G, после сдвига на 2 — G T A C; это и есть второй набор, поэтому ответ 2.

Примеры
ВводВывод
 
A C G T
G T A C
2
AT GC
GC GC
-1
Контекст

Перебирают shift от 0 до length - 1: большие сдвиги повторяют уже проверенные, ведь сдвиг на length возвращает набор в исходный вид. Для каждого shift строят сдвинутую копию и сравнивают списки оператором ==; при совпадении запоминают shift и выходят через break, поэтому остается наименьший.

Основные определения

  • Сдвиг по кругу — элементы переходят на shift мест вправо, вышедшие за конец встают в начало.
  • Остаток от деления % — номер по кругу: (index - shift) % length остается в пределах от 0 до length - 1.
  • Сравнение списков — == сравнивает элементы по порядку.
  • Команда break — немедленно завершает цикл.
Подсказка
  1. Прочитайте оба набора: first = input().split(), second = input().split(); заведите answer = -1 и length = len(first).
  2. Перебирайте сдвиги: for shift in range(length):.
  3. Стройте сдвинутую копию: shifted = first.copy(), затем в цикле по index заполните shifted[index] элементом с номером (index - shift) % length.
  4. При shifted == second запишите answer = shift и выйдите через break; выведите answer; сверьтесь с примером: A C G T и G T A C дают 2, а AT GC и GC GC — -1.
