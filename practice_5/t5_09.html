Профиль и консенсус

25 минутЕрофеев А. И.

Получать столбцы выравнивания, считать по ним профиль и строить консенсус функцией max() с ключом.

1. Выравнивание и профиль

Теория

Задача Rosalind CONS: дано несколько последовательностей одинаковой длины, нужно для каждой позиции найти самую частую букву. Так получают одну последовательность, которая представляет весь набор. Решение идет в три шага: последовательности раскладывают по столбцам, в каждом столбце считают буквы, из каждого столбца берут самую частую букву.

Выравнивание — последовательности, записанные друг под другом так, что буквы одной позиции стоят в одном столбце. На этой странице последовательности выравнивания одной длины.

Профиль — таблица, которая показывает, сколько раз каждая буква A, C, G, T стоит в каждом столбце выравнивания.

Пример для трех последовательностей ATG, ACG, TCG. В первом столбце буквы A, A, T: две A и одна T. Во втором T, C, C. В третьем три G.

СтрокаСтолбец 1Столбец 2Столбец 3
ATGATG
ACGACG
TCGTCG
Профиль A200
Профиль C020
Профиль G003
Профиль T110

В коде столбцы дает zip(*seqs) (страница 05): каждый столбец — кортеж букв. У кортежа, как у строки и списка, есть метод count(). Строка профиля для буквы b собирается включением [c.count(b) for c in cols].

Пример

Профиль по столбцам

Семь 8-меров из примера к задаче Rosalind CONS.

profile.py
seqs = ["ATCCAGCT", "GGGCAACT", "ATGGATCT", "AAGCAACC",
        "TTGGAACT", "ATGCCATT", "ATGGCACT"]
cols = list(zip(*seqs))
profile = []
for b in "ACGT":
    r = [c.count(b) for c in cols]
    profile.append(r)
    print(b, r)
print(len(profile))  # → 4
Вывод
A [5, 1, 0, 0, 5, 5, 0, 0]
C [0, 0, 1, 4, 2, 0, 6, 1]
G [1, 1, 6, 3, 0, 1, 0, 0]
T [1, 5, 0, 0, 0, 1, 1, 6]
4
  1. Строка 3: восемь кортежей по семь букв, по одному на позицию.
  2. Строка 6: для текущей буквы b включение считает ее в каждом столбце.
  3. Строка 9: профиль получился списком из четырех списков длины 8.

2. Консенсус

Теория

Консенсус — строка из самых частых букв всех столбцов выравнивания. У выравнивания ATG, ACG, TCG из таблицы выше консенсус ACG.

Самую частую букву столбца находит max() с ключом (страница 06): max("ACGT", key=c.count) перебирает буквы A, C, G, T и для каждой вызывает c.count(буква).

Если наибольшее число набирают несколько букв, max() возвращает первую из них в порядке перебора, то есть в порядке строки "ACGT".

Rosalind в задаче CONS принимает любую из самых частых букв. В упражнениях этой страницы правило строгое: при ничьей берется буква, которая раньше в порядке A, C, G, T; так ответ однозначен.

Пример

Консенсус семи последовательностей

consensus.py
seqs = ["ATCCAGCT", "GGGCAACT", "ATGGATCT", "AAGCAACC",
        "TTGGAACT", "ATGCCATT", "ATGGCACT"]
cons = ""
for c in zip(*seqs):
    cons += max("ACGT", key=c.count)
print(cons)  # → ATGCAACT
Вывод
ATGCAACT
  1. Строка 5: для каждого столбца берется самая частая буква и дописывается в строку cons; запись += для строк тоже работает и строит новую строку.
  2. Ответ совпадает с ответом примера Rosalind CONS.

Ничья

Предскажите вывод, затем откройте его.

tie.py
seqs = ["AC", "GC", "GT", "AT"]
cons = ""
for c in zip(*seqs):
    cons += max("ACGT", key=c.count)
print(cons)  # → AC
Вывод
AC
  1. Первый столбец: две A и две G, побеждает A, она раньше в строке "ACGT".
  2. Второй столбец: две C и две T, побеждает C.

Консенсус включением

Консенсус можно собрать и одной строкой: включение дает список букв, join() склеивает их.

consensus_comp.py
seqs = ["AG", "CG", "TC"]
print("".join([max("ACGT", key=c.count) for c in zip(*seqs)]))  # → AG
Вывод
AG

Упражнение 5.9.1. Расстояния до консенсуса

Условие задачи

Постройте консенсус выравнивания: в каждом столбце самая частая буква; при ничьей берется та, что раньше в порядке A, C, G, T. Затем для каждой последовательности посчитайте расстояние Хэмминга до консенсуса: число позиций, где их буквы различаются. Выведите консенсус и расстояния.

Входные данные

Одна строка: выравнивание, от 1 до 20 последовательностей одной длины через пробел, длина от 1 до 30, буквы A, C, G, T.

Выходные данные

В первой строке консенсус, во второй расстояния через пробел в порядке последовательностей.

Вывод ACGT
0 1 2

Контекст

Консенсус строят по столбцам: max("ACGT", key=col.count) выбирает букву с наибольшим числом вхождений, а при ничьей — первую в строке "ACGT", потому что max оставляет первый из равных. Расстояние до консенсуса считают включением по zip: пара букв различается — единица, сумма таких единиц и есть расстояние.

Основные определения

  • Консенсус — буква на каждой позиции: самая частая, при ничьей первая по порядку A, C, G, T.
  • Ключ key — key=col.count сравнивает буквы по числу вхождений.
  • Функция max() — при равных ключах возвращает первый элемент.
  • Расстояние Хэмминга — число позиций, где буквы различаются.
  • Функция zip() — идет по двум строкам одновременно, выдавая пары букв.
Подсказка
  1. Прочитайте выравнивание: seqs = input().split().
  2. Для каждого столбца берите самую частую букву: max("ACGT", key=col.count) — при ничьей max оставит первую.
  3. Соберите консенсус из букв в порядке столбцов и напечатайте его первой строкой.
  4. Для каждой последовательности посчитайте расстояние включением по zip(sequence, cons) с условием base != consensus_base; напечатайте числа через пробел; сверьтесь с примером: ACGT AAGT CCGA дают консенсус ACGT и расстояния 0 1 2, а одна GATTACA — GATTACA и 0.

Упражнение 5.9.1. Консенсус с неоднозначностью

Условие задачи

В выравнивании бывают пропуски: знак - стоит там, где у последовательности нет буквы. Пропуск не буква и в подсчете не участвует. Постройте консенсус по правилам: в каждом столбце считаются только буквы A, C, G, T; если букв в столбце нет вовсе, в консенсус ставится -; если наибольшее число набирают две буквы или больше, ставится N; иначе ставится самая частая буква. Буква N значит «буква не определена»: в таком столбце нет одной самой частой буквы.

Входные данные

Одна строка: выравнивание, от 1 до 20 последовательностей одной длины через пробел, длина от 1 до 30, знаки A, C, G, T и -.

Выходные данные

Консенсус одной строкой.

Пример

Разберем пример

Ввод AC-T AG-T CG-A
→
Вывод AG-T

В третьем столбце одни пропуски, поэтому в консенсус идет -; в остальных столбцах чаще всего стоят A, G и T.

Примеры
ВводВывод
 
AC-T AG-T CG-A
AG-T
AC GT
NN
Контекст

Для каждого столбца считают [col.count(base) for base in "ACGT"]: пропуски в счет не попадают. Если максимум равен 0, в консенсус идет -, если максимум набрали несколько букв (counts.count(best) > 1) — N, иначе буква по индексу через counts.index(best) в строке "ACGT".

Основные определения

  • Пропуск — знак -: у последовательности в этой позиции нет буквы.
  • Неоднозначность — две буквы или больше набрали поровну — в консенсус ставится N.
  • Буква N — буква не определена.
  • Метод index() — возвращает номер первого вхождения в строке.
  • Метод count() — считает вхождения буквы в строке.
Подсказка
  1. Прочитайте выравнивание: seqs = input().split().
  2. Для каждого столбца посчитайте буквы: соберите в counts числа col.count(base) для каждой буквы из "ACGT" — пропуски не участвуют.
  3. Найдите максимум best = max(counts): при 0 ставьте -, при counts.count(best) > 1 — N.
  4. Иначе возьмите букву "ACGT"[counts.index(best)]; соберите консенсус и напечатайте; сверьтесь с примером: AC-T AG-T CG-A дают AG-T, а AC GT — NN.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.

Задача со звездочкой 5.9. Самый неуверенный столбец

Условие задачи

Чем меньше раз встречается самая частая буква столбца, тем меньше консенсус уверен в этой позиции. Найдите столбец, в котором самая частая буква встречается меньше всего раз, и выведите его номер (с 1) и это число. Если таких столбцов несколько, выберите первый.

Входные данные

Одна строка: выравнивание, от 1 до 20 последовательностей одной длины через пробел, длина от 1 до 30, буквы A, C, G, T.

Выходные данные

Номер столбца и число через пробел.

Пример

Разберем пример

Ввод GTACA GCTCA GTTGA
→
Вывод 2 2

Самая частая буква встречается по 3 раза в первом и пятом столбцах и по 2 раза — во втором, третьем и четвертом; первый столбец с двумя — второй, поэтому ответ 2 2.

Примеры
ВводВывод

AAA AAA
1 2
Контекст

Для каждого столбца берут top — число самой частой буквы через max([col.count(base) for base in "ACGT"]). Лучший столбец заменяют строгим <, поэтому при равных значениях остается первый по порядку; номер печатают как i, потому что enumerate считает с 1.

Основные определения

  • Уверенность консенсуса — чем меньше раз встречается самая частая буква, тем ниже уверенность в позиции.
  • Функция enumerate() — с start=1 дает номера столбцов.
  • Функция max() — находит число самой частой буквы.
  • Строгое сравнение — < не пропускает равное число.
Подсказка
  1. Прочитайте выравнивание: seqs = input().split().
  2. Перебирайте столбцы с номерами: enumerate по zip(*seqs) с start=1 дает номер position и столбец col.
  3. Для каждого столбца найдите число самой частой буквы: max по значениям col.count(base) для букв из "ACGT", запишите в top.
  4. При строгом top < best_count запоминайте номер и число (лучшее начните с len(seqs) + 1); напечатайте их; сверьтесь с примером: GTACA GCTCA GTTGA дают 2 2, а AAA AAA — 1 2.

Задача со звездочкой 5.9. Консенсусы двух групп

Условие задачи

Последовательности разделены на две группы, например образцы из двух лабораторий. Постройте консенсус каждой группы (при ничьей берется буква раньше в порядке A, C, G, T) и выведите позиции (с 1), в которых консенсусы различаются. Если различий нет, выведите слово нет.

Входные данные

В первой строке первая группа, во второй вторая: от 1 до 20 последовательностей через пробел в каждой строке. Все последовательности обеих групп одной длины, от 1 до 30, буквы A, C, G, T.

Выходные данные

Позиции через пробел одной строкой или слово нет.

Пример

Разберем пример

Ввод ACGT ACGA AGGT
TCGT TCAT ACAT
→
Вывод 1 3

Консенсусы групп — ACGT и TCAT; различаются они в первой позиции (A и T) и третьей (G и A), поэтому ответ 1 3.

Примеры

Контекст

Консенсус каждой группы собирают включением: max("ACGT", key=col.count) для каждого столбца, при ничьей побеждает первая буква. Затем zip двух консенсусов идет по позициям, enumerate с start=1 дает номера, и несовпавшие номера копят строками; пустой список означает слово нет.

Основные определения

  • Консенсус группы — буква на каждой позиции: самая частая среди последовательностей группы.
  • Ключ key — key=col.count сравнивает буквы по числу вхождений.
  • Принцип первого при ничьей — max оставляет первую из равных букв в порядке A, C, G, T.
  • Функция enumerate() — дает номера позиций, считая с 1.
  • Функция zip() — идет по двум консенсусам одновременно.
Подсказка
  1. Прочитайте обе группы: group_a = input().split(), group_b = input().split().
  2. Консенсус каждой группы: для каждого столбца col из zip(*group) берем max("ACGT", key=col.count).
  3. Сравнивайте по позициям: enumerate по парам zip(cons_a, cons_b) с start=1 дает номер position и пару base_a и base_b; при base_a != base_b номер идет в ответ.
  4. Напечатайте номера через пробел или слово нет; сверьтесь с примером: ACGT ACGA AGGT и TCGT TCAT ACAT дают 1 3, а AC AC и AC AG AC — нет.

Задача со звездочкой 5.9. Профиль и консенсус по FASTA

Условие задачи

Задача Rosalind CONS целиком. В FASTA длинная последовательность может занимать несколько строк подряд: все строки до следующего заголовка относятся к одной записи и склеиваются. Последовательности всех записей одной длины. Выведите консенсус (при ничьей буква раньше в порядке A, C, G, T) и профиль: четыре строки вида A: 5 1 0 0, для букв A, C, G, T.

Входные данные

В первой строке line_count — число строк текста FASTA, от 2 до 60. Дальше line_count строк: заголовки (знак > и идентификатор) и строки последовательностей из букв A, C, G, T. Записей от 1 до 10, длина последовательности до 50.

Выходные данные

Пять строк: консенсус и строки профиля для A, C, G, T.

Разберем пример

Контекст

Строки FASTA склеивают в записи: заголовок со знаком > начинает новую запись, остальные строки дописывают к последней (seqs[-1] += line). Столбцы дает zip(*seqs), консенсус — max("ACGT", key=column.count), а профиль печатают четырьмя строками: для каждой буквы метод count по столбцам.

Основные определения

  • Запись FASTA из нескольких строк — все строки до следующего заголовка — одна последовательность.
  • Строка профиля — числа одной буквы по всем столбцам.
  • Консенсус — буква на каждой позиции, при ничьей первая по порядку A, C, G, T.
  • Метод startswith() — проверяет, с чего начинается строка.
  • Функция zip() — с распаковкой *seqs собирает буквы одного столбца.
Подсказка
  1. Прочитайте число строк: line_count = int(input()); заведите seqs = [].
  2. Разбирайте строки: если line.startswith(">"), начинайте новую запись seqs.append(""), иначе дописывайте к последней seqs[-1] += line.
  3. Соберите столбцы cols = list(zip(*seqs)) и консенсус: для каждого столбца column из cols берем max("ACGT", key=column.count) и соединяем результаты через "".join.
  4. Профиль печатайте четырьмя строками: для каждой буквы base из "ACGT" строку base + ":" и числа [column.count(base) for column in cols]; сверьтесь с примером: записи ACGT и AAGT дают консенсус AAGT и строку профиля A: 2 1 0 0.
