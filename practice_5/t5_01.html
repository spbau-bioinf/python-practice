Список и кортеж

25 минутЕрофеев А. И.

Хранить набор последовательностей в списке, брать элементы по индексу, менять список и хранить запись из нескольких полей в кортеже.

Как устроены упражнения. Программа читает данные функцией input() без текста приглашения и печатает только ответ. Набор последовательностей вводится одной строкой через пробел: input().split() превращает такую строку в список. Ответ из нескольких последовательностей печатают через пробел методом join() из темы 2 «Строки и текстовые данные»: print(" ".join(seqs)).

1. Список

Теория

В практике 4 программа обрабатывала одну последовательность, записанную в одну переменную. Если последовательностей семь, можно завести семь переменных s1, s2 и так до s7. Но тогда в каждой придется считать букву G отдельной строкой кода: цикл for перебирает элементы одной последовательности, а семь отдельных переменных он не перебирает. Нужен один объект, внутри которого лежат все семь значений.

Список (list) хранит несколько значений по порядку. Значения списка называют элементами; они бывают любого типа.

Список записывают в квадратных скобках через запятую: ["ATCC", "GGGC"]; [] означает пустой список. Индексы, len(), in и for работают почти как у строки: seqs[0] дает первый элемент, seqs[-1] последний, len(seqs) число элементов, а for s in seqs: перебирает элементы по порядку.

Пустой список, как пустая строка, в условии ложен (страница 06 практики 3): if seqs: выполняется, только если в списке есть хотя бы один элемент.

Разница в том, что элемент списка берется целиком. У списка строк seqs[0] дает целую строку, а не букву, и x in seqs ищет элемент, равный x, а не кусок одной из строк.

Список получается и из строки: метод split() из темы 2 «Строки и текстовые данные» возвращает список слов. Поэтому input().split() дает список последовательностей, введенных через пробел. Подробнее о том, откуда берутся списки, на странице 03.

Длинный список можно записать на нескольких строках: пока квадратная скобка не закрыта, Python считает все строки одной инструкцией. При печати print(seqs) показывает список так же, как его пишут в коде: в квадратных скобках, строки в кавычках.

Элемент списка сам может быть последовательностью. Тогда индексы ставят подряд: seqs[0] дает первую строку, а seqs[0][0] первую букву этой строки. Список внутри списка называют вложенным; он понадобится на странице 08 для таблиц.

Пример

Список последовательностей

Пять 8-меров (участков длины 8) хранятся в одном списке. Программа берет первый и последний элемент, считает элементы, ищет элемент и перебирает список циклом.

seqs.py
seqs = ["ATCCAGCT", "GGGCAACT", "ATGGATCT",
        "AAGCAACC", "TTGGAACT"]
print(seqs[0])             # → ATCCAGCT
print(seqs[-1])            # → TTGGAACT
print(len(seqs))           # → 5
print("AAGCAACC" in seqs)  # → True
for s in seqs:
    print(s.count("G"), end=" ")
Вывод
ATCCAGCT
TTGGAACT
5
True
1 3 2 1 2
  1. Строки 1–2: один список из пяти строк; скобка закрывается во второй строке.
  2. Строки 3–4: seqs[0] и seqs[-1] дают целые строки, первую и последнюю.
  3. Строка 5: len() считает элементы списка, а не буквы: их 5.
  4. Строка 6: in нашел элемент, равный "AAGCAACC".
  5. Строки 7–8: цикл перебирает строки списка; для каждой метод count() из темы 2 считает буквы G.

Индекс за индексом

Предскажите вывод, затем откройте его.

nested.py
seqs = ["ATCC", "GGGC", "TTGG"]
print(seqs[0][0], seqs[-1][-1])         # → A G
print("GGG" in seqs, "GGG" in seqs[1])  # → False True
Вывод
A G
False True
  1. Строка 2: seqs[0] дает строку "ATCC", второй индекс [0] берет ее первую букву. Так же seqs[-1][-1] дает последнюю букву последней строки.
  2. Строка 3: в списке нет элемента, равного "GGG", поэтому первое in дает False. Второе in применяется к строке "GGGC" и ищет в ней кусок, как в теме 2.
Практика

Допишите в строку в кавычках еще одну последовательность через пробел и запустите снова.

try_split.py
seqs = "ATCC GGGC TTGG".split()
print(seqs)                 # → ['ATCC', 'GGGC', 'TTGG']
print(len(seqs), seqs[-1])  # → 3 TTGG
Вывод
['ATCC', 'GGGC', 'TTGG']
3 TTGG

2. Список можно изменить

Теория

Строку изменить нельзя: методы строк из темы 2 не меняют строку, а возвращают новую. Список изменить можно: элементу присваивают новое значение, и меняется тот же самый список.

Изменяемый объект (mutable) можно менять после того, как он создан. Список изменяемый; строка и число неизменяемые.

Присваивание seqs[i] = значение заменяет элемент с индексом i. Метод append(x) дописывает x в конец того же списка. Остальные методы списка разобраны на странице 03.

Новый список часто собирают в цикле: начинают с пустого списка [] и на каждом шаге, если элемент подходит, добавляют его методом append().

Метод append() ничего не возвращает: он меняет список, на котором вызван. Поэтому его вызывают отдельной строкой, rich.append(s), без присваивания. Почему запись rich = rich.append(s) ломает программу, разобрано на странице 03.

Пример

Типичная ошибка: заменить букву строки

Неверно: строку изменить нельзя
s = "ATCCAGCT"
s[0] = "T"
Сообщение об ошибке
TypeError: 'str' object does not support item assignment
Верно
s = "ATCCAGCT"
s = "T" + s[1:]
print(s)  # → TTCCAGCT
Вывод
TTCCAGCT

Строка не поддерживает присваивание по индексу. Новую строку собирают из кусков, срез s[1:] берет все буквы, кроме первой. С элементом списка та же запись seqs[0] = "T" работает.

Замена и добавление

change.py
seqs = ["ATCC", "GGGC"]
seqs[0] = "TTCC"
seqs.append("AAGC")
print(seqs)       # → ['TTCC', 'GGGC', 'AAGC']
print(len(seqs))  # → 3
Вывод
['TTCC', 'GGGC', 'AAGC']
3
  1. Строка 2: первый элемент заменен, список тот же.
  2. Строка 3: append() дописал элемент в конец; элементов стало три.

Новый список в цикле

Программа отбирает последовательности, в которых не меньше двух букв G. Предскажите вывод, затем откройте его.

select.py
seqs = ["ATCC", "GGGC", "TTGG", "AAGC"]
rich = []
for s in seqs:
    if s.count("G") >= 2:
        rich.append(s)
print(rich)                  # → ['GGGC', 'TTGG']
print(len(seqs), len(rich))  # → 4 2
Вывод
['GGGC', 'TTGG']
4 2
  1. Строка 2: новый список сначала пустой.
  2. Строки 3–5: каждая последовательность, в которой не меньше двух G, дописывается в rich; остальные пропускаются.
  3. Строка 7: исходный список не изменился, в нем по-прежнему 4 элемента.
Практика

Замените условие в строке 4 на "A" in s и запустите снова.

try_select.py
seqs = ["ATCC", "GGGC", "TTGG", "AAGC"]
picked = []
for s in seqs:
    if s.startswith("A"):
        picked.append(s)
print(picked)  # → ['ATCC', 'AAGC']
Вывод
['ATCC', 'AAGC']

Упражнение 5.1.1. Размер набора

Условие задачи

Набор последовательностей записан одной строкой через пробел. Выведите число последовательностей в наборе и последнюю последовательность. Превратите строку в список методом split(), число элементов дает len(), последний элемент дает индекс -1.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30. Последовательности могут повторяться.

Выходные данные

В первой строке число последовательностей, во второй последняя последовательность.

Пример

Разберем пример

Ввод ATG CCA TTTT
→
Вывод 3
TTTT

split() делит строку по пробелам на три элемента: ATG, CCA и TTTT; len() возвращает 3, а индекс -1 — последний элемент TTTT.

Примеры
ВводВывод
 
ATG CCA TTTT
3
TTTT
GATTACA
1
GATTACA
Контекст

Метод split() режет строку по пробелам и выдает список. Число элементов дает функция len(), индексы списка считаются с нуля, поэтому последний элемент доступен по индексу -1.

Основные определения

  • Список — несколько значений, доступных по индексу.
  • Метод split() — режет строку по пробелам и выдает список слов.
  • Функция len() — возвращает число элементов списка или длину строки.
  • Индекс -1 — последний элемент списка.
Подсказка
  1. Превратите строку в список: seqs = input().split().
  2. Число последовательностей дает len(seqs) — напечатайте его первой строкой.
  3. Последний элемент берите по индексу -1: seqs[-1].
  4. Напечатайте его второй строкой; сверьтесь с примером: ATG CCA TTTT дают 3 и TTTT, а GATTACA — 1 и GATTACA.

Упражнение 5.1.1. Пополнение набора

Условие задачи

В наборе последовательностей нет повторов. Пришла новая партия последовательностей. Допишите в конец набора каждую последовательность партии, которой в наборе еще нет, в том порядке, в каком они идут в партии. Если последовательность встречается в партии несколько раз, она добавляется один раз. Выведите число последовательностей в пополненном наборе и сам набор.

Входные данные

В первой строке набор, во второй партия: от 1 до 20 последовательностей через пробел в каждой строке. Последовательности состоят из букв A, C, G, T, длина каждой от 1 до 30. В наборе повторов нет, в партии могут быть.

Выходные данные

В первой строке число последовательностей в пополненном наборе, во второй сам набор через пробел.

Пример

Разберем пример

Ввод ATG CCA
CCA GGT ATG TTA
→
Вывод 4
ATG CCA GGT TTA

CCA и ATG уже есть в наборе, добавляются только GGT и TTA — в том порядке, в каком идут в партии; получается ATG CCA GGT TTA, всего 4.

Примеры
ВводВывод
 
ATG CCA
CCA GGT ATG TTA

ATG CCA GGT TTA
AAA
AAA
1
AAA
Контекст

Новую партию перебирают циклом и проверяют оператором in по текущему списку. Если последовательности там нет, ее дописывают в конец методом append(); проверка идет по уже пополненному списку, поэтому повторы внутри партии отбрасываются сами.

Основные определения

  • Список — несколько значений, доступных по индексу.
  • Метод split() — режет строку по пробелам и выдает список слов.
  • Оператор in — проверяет, есть ли значение в списке.
  • Метод append() — дописывает элемент в конец списка.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте набор: seqs = input().split().
  2. Переберите партию: for sequence in input().split():.
  3. Дописывайте только новые: при sequence not in seqs вызывайте seqs.append(sequence) — повтор в партии к этому моменту уже лежит в seqs.
  4. Выведите len(seqs) и " ".join(seqs); сверьтесь с примером: ATG CCA и партия CCA GGT ATG TTA дают 4 и ATG CCA GGT TTA.

Упражнение 5.1.1. Повторы в наборе

Условие задачи

Некоторые последовательности встречаются в наборе несколько раз. Выведите все последовательности, которые встречаются больше одного раза, каждую один раз. Последовательность выводится в том порядке, в каком она встретилась второй раз: в наборе T G G T сначала повторилась G, затем T, поэтому ответ G T. Если повторов нет, выведите слово нет.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30.

Выходные данные

Повторяющиеся последовательности через пробел одной строкой или слово нет.

Пример

Разберем пример

Ввод ATG CC ATG GA CC ATG
→
Вывод ATG CC

ATG второй раз встречается на третьей позиции, CC — на пятой; в этом порядке повторы и выводятся, а третье вхождение ATG уже ничего не меняет.

Примеры
ВводВывод
 
ATG CC ATG GA CC ATG
ATG CC
AC GT
нет
Контекст

Список seen хранит все встреченные последовательности, а repeats — уже найденные повторы. Последовательность добавляют в repeats в момент второго вхождения, поэтому порядок ответа задает момент повторения, а проверка not in repeats не дает вывести ее дважды.

Основные определения

  • Список — несколько значений, доступных по индексу.
  • Метод append() — дописывает элемент в конец списка.
  • Оператор in — проверяет, есть ли значение в списке.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Заведите два пустых списка: seen = [] и repeats = [].
  2. Перебирайте последовательности: for sequence in input().split():.
  3. Повтор — это sequence in seen и при этом sequence not in repeats; тогда допишите sequence в repeats, а seen пополняйте всегда.
  4. Если repeats непуст, напечатайте " ".join(repeats), иначе слово нет; сверьтесь с примером: ATG CC ATG GA CC ATG дают ATG CC.

3. Кортеж

Теория

Список удобен для набора однородных значений, которые обрабатывают по одному. Для записи из нескольких разных полей, например имени последовательности, ее длины и GC-состава, в Python есть кортеж.

Кортеж (tuple) хранит несколько значений по порядку, как список, но его нельзя изменить после создания.

Кортеж создает запятая: rec = "Rosalind_1", 8, 50.0. Python печатает кортеж в круглых скобках, и в коде его обычно тоже берут в скобки, но скобки только группируют запись. Индексы, len(), in и for работают так же, как у списка, а присваивание элементу дает TypeError.

Кортеж из одного элемента пишется с запятой: ("ATG",). Запись ("ATG") без запятой дает просто строку.

СписокКортеж
Запись[...]через запятую, обычно в (...)
Изменить элементможнонельзя: TypeError
Что хранитоднородные элементыразные поля одной записи
Как обрабатываютпо одному, в циклецеликом или по полям

Разработчики Python объясняют это разделение в официальном FAQ: кортеж похож на запись, несколько связанных значений, часто разных типов, которые обрабатывают вместе; список похож на массив однородных элементов, которые обрабатывают по одному. Правило не жесткое: в кортеж можно положить однородные числа, а в список разнородные значения. Речь о том, для чего задуман каждый тип.

Подробнее: пустой кортеж и запятая в конце

Единственный кортеж без запятой — пустой: (). Лишняя запятая в конце строки превращает значение в кортеж незаметно: после n = 5, переменная n хранит кортеж (5,), и n + 1 дает TypeError. Поэтому кортеж из одного элемента лучше всегда брать в скобки, чтобы запятая была видна.

Пример

Запись о последовательности

record.py
rec = "Rosalind_1", 8, 50.0
print(rec)               # → ('Rosalind_1', 8, 50.0)
print(rec[0], len(rec))  # → Rosalind_1 3
one = ("ATG",)
print(len(one), one[0])  # → 1 ATG
Вывод
('Rosalind_1', 8, 50.0)
Rosalind_1 3
1 ATG
  1. Строка 1: три значения через запятую образуют кортеж: имя, длина и GC-состав в процентах.
  2. Строка 2: Python печатает кортеж в круглых скобках.
  3. Строка 4: кортеж из одного элемента; его элемент one[0] равен целой строке "ATG".

Типичная ошибка: изменить поле кортежа

Неверно: кортеж изменить нельзя
rec = ("Rosalind_1", 8, 50.0)
rec[1] = 9
Сообщение об ошибке
TypeError: 'tuple' object does not support item assignment
Верно
rec = ("Rosalind_1", 8, 50.0)
rec = (rec[0], 9, rec[2])
print(rec)  # → ('Rosalind_1', 9, 50.0)
Вывод
('Rosalind_1', 9, 50.0)

Если запись нужно поправить, собирают новый кортеж из полей старого. Если поля приходится менять часто, данные лучше хранить в списке.

Скобки или запятая

Предскажите вывод, затем откройте его.

comma.py
a = ("ATG")
b = ("ATG",)
c = "ATG",
print(len(a), len(b), len(c))  # → 3 1 1
print(a[0], b[0])              # → A ATG
Вывод
3 1 1
A ATG
  1. Строка 1: запятой нет, скобки ничего не меняют: a строка из трех букв.
  2. Строки 2–3: запятая есть, поэтому b и c кортежи из одного элемента, в скобках или без них.
  3. Строка 5: a[0] первая буква строки, b[0] единственный элемент кортежа, целая строка.
Практика

Уберите запятую в строке 1 и запустите снова: какой тип и какую длину напечатает программа?

try_tuple.py
one = ("GATTACA",)
print(type(one), len(one))  # → <class 'tuple'> 1
Вывод
<class 'tuple'> 1

Необязательная задача для тех, кому хочется больше. В зачет не входит, за решение дается дополнительный опыт в игровом режиме. Вариант каждого уровня сложнее упражнения этого уровня.

Сложнее базового упражнения.

Задача со звездочкой 5.1. Не короче средней

Условие задачи

Средняя длина набора равна сумме длин всех последовательностей, деленной на их число. Выведите последовательности, длина которых не меньше средней, в том порядке, в каком они идут в наборе.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30.

Выходные данные

Подходящие последовательности через пробел одной строкой.

Пример

Разберем пример

Ввод AT GCA TTTT
→
Вывод GCA TTTT

Длины 2, 3 и 4, средняя (2 + 3 + 4) / 3 = 3; AT короче средней и отбрасывается, GCA и TTTT остаются.

Примеры
ВводВывод
 
AT GCA TTTT
GCA TTTT
AC GT
AC GT
Контекст

Среднюю считают в два прохода: первый накапливает суммарную длину, второй отбирает последовательности. Условие len(sequence) >= average нестрогое, поэтому последовательности ровно средней длины тоже в ответе.

Основные определения

  • Средняя длина — сумма длин всех последовательностей, деленная на их число.
  • Список — несколько значений, доступных по индексу.
  • Метод append() — дописывает элемент в конец списка.
  • Нестрогое сравнение — >= пропускает и равные значения.
Подсказка
  1. Прочитайте набор: seqs = input().split().
  2. В первом проходе накопите суммарную длину: в цикле for sequence in seqs: прибавляйте len(sequence) к total; средняя — total / len(seqs).
  3. Во втором проходе отбирайте подходящие в новый список: при len(sequence) >= average вызывайте result.append(sequence).
  4. Напечатайте " ".join(result); сверьтесь с примером: AT, GCA и TTTT дают GCA TTTT, а AC и GT — обе.

Задача со звездочкой 5.1. Общие последовательности

Условие задачи

Даны два набора последовательностей. Выведите последовательности, которые есть в обоих наборах, каждую один раз, в том порядке, в каком они впервые встречаются в первом наборе. Если общих последовательностей нет, выведите слово нет.

Входные данные

В первой строке первый набор, во второй строке второй набор: от 1 до 20 последовательностей через пробел в каждой строке. Последовательности состоят из букв A, C, G, T, длина каждой от 1 до 30, внутри набора могут повторяться.

Выходные данные

Общие последовательности через пробел одной строкой или слово нет.

Пример

Разберем пример

Ввод ATG CCA GGT TTA
TTA ATG CAT
→
Вывод ATG TTA

Общие последовательности — ATG и TTA; в первом наборе ATG стоит раньше, поэтому ответ ATG TTA. CAT есть только во втором наборе.

Примеры
ВводВывод
 
ATG CCA GGT TTA
TTA ATG CAT
ATG TTA
AC GT
CA TG
нет
Контекст

Общие последовательности ищут проверкой in по второму списку. Порядок вывода задает первый набор, а условие not in common убирает повторы, поэтому каждая общая последовательность выводится один раз.

Основные определения

  • Список — несколько значений, доступных по индексу.
  • Оператор in — проверяет, есть ли значение в списке.
  • Метод append() — дописывает элемент в конец списка.
  • Метод join() — склеивает список строк в одну строку через разделитель.
Подсказка
  1. Прочитайте оба набора: first = input().split(), second = input().split(); заведите common = [].
  2. Перебирайте первый набор: for sequence in first:.
  3. Последовательность общая, если sequence in second; чтобы не повторяться, добавьте условие sequence not in common.
  4. Напечатайте общие через " ".join(common) или слово нет; сверьтесь с примером: ATG CCA GGT TTA и TTA ATG CAT дают ATG TTA.

Задача со звездочкой 5.1. Самая частая последовательность

Условие задачи

Найдите последовательность, которая встречается в наборе чаще всех, и выведите ее и число ее вхождений. Если таких несколько, выберите ту, которая встретилась в наборе раньше. Метода списка, который считает элементы, на этой странице нет: храните рядом два списка, разные последовательности и их счетчики.

Входные данные

Одна строка: от 1 до 20 последовательностей через пробел. Каждая последовательность состоит из букв A, C, G, T, ее длина от 1 до 30.

Выходные данные

Последовательность и число ее вхождений через пробел.

Пример

Разберем пример

Ввод AT GC AT CC GC AT
→
Вывод AT 3

AT встречается трижды, GC — дважды, CC — один раз; чаще всех AT, поэтому ответ AT 3.

Примеры
ВводВывод
 
AT GC AT CC GC AT
AT 3
A C G
A 1
Контекст

Два списка ведут параллельно: uniq хранит разные последовательности, counts — их счетчики по тем же индексам. Новая последовательность получает счетчик 1, известная — прибавление единицы; лучший номер ищут строгим сравнением, чтобы при равенстве остался первый.

Основные определения

  • Список — несколько значений, доступных по индексу.
  • Параллельные списки — элемент с одним индексом в двух списках описывает одно и то же.
  • Счетчик — число вхождений последовательности.
  • Индекс — номер элемента в списке; нумерация начинается с 0.
Подсказка
  1. Прочитайте набор: seqs = input().split(); заведите uniq = [] и counts = [].
  2. Перебирайте последовательности: for sequence in seqs: — новая (sequence not in uniq) получает счетчик 1.
  3. Для известной найдите ее номер циклом for index in range(len(uniq)): и увеличьте counts[index] на единицу.
  4. Лучший номер ищите строгим counts[index] > counts[best]; выведите uniq[best] и его счетчик; сверьтесь с примером: AT GC AT CC GC AT дают AT 3.
