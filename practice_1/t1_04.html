Переменные

15 минутЕрофеев А. И.

Научиться связывать имена со значениями, прослеживать переприсваивание по шагам, различать сравнение значений и тождество объектов и выбирать допустимые понятные имена.

Как устроены задачи. Функцию input() вы изучите на странице 09, поэтому до нее исходные данные задаются в начале программы строками вида count = 5. Имена переменных берите из условия: проверка подставляет в эти строки свои значения и так убеждается, что программа считает, а не печатает готовое число. В поле проверки эти строки уже вставлены.

1. Присваивание

Теория

Программа обрабатывает данные: длины последовательностей, объемы, концентрации. Чтобы к значению можно было вернуться, его связывают с именем. Имя делает код похожим на условие задачи: volume - sample читается легче, чем 100 - 10.

Переменная — имя, связанное с объектом (значением) в памяти.

Связь создает присваивание имя = выражение. Знак = не означает равенство: Python сначала целиком вычисляет выражение справа, а затем привязывает к результату имя слева. Поэтому запись x = x - 1 осмысленна: из старого значения x вычисляется новое, и имя x переходит к нему. Выражение без присваивания (строка x - 1) значение переменной не меняет.

В примерах используются сложение, вычитание и умножение, знакомые по школе; все арифметические операции Python разобраны на странице 06.

Порядок выполнения присваивания обратен порядку чтения. Пусть x связано с числом 43. Строка x = x - 1 выполняется так:

  1. x = x − 1правая часть вычисляется первой, имя x пока связано с 43
  2. x = 43 − 1вместо имени подставлено его значение
  3. x = 42получен новый объект, число 42
  4. x → 42имя x привязывается к нему

Объект существует раньше, чем имя: сначала вычисляется значение, потом к нему привязывается имя. Объявлять переменную заранее не нужно, она появляется при первом присваивании. Если обратиться к имени до присваивания, Python выдаст NameError (страница 01).

Пример

Переприсваивание по шагам

cells.py
cells = 40
cells = cells * 2
cells = cells - 5
print(cells)  # → 75
Вывод
75
  1. Имя cells связывается с числом 40: в пробирке 40 клеток.
  2. Справа вычисляется 40 · 2 = 80, имя cells переходит к 80. Клетки поделились.
  3. Справа 80 − 5 = 75: пять клеток забрали на анализ.
  4. Выводится текущее значение: 75. Промежуточные значения 40 и 80 больше не связаны с именем.

Типичная ошибка: присваивание «справа налево»

Неверно: имя справа от знака =
40 = cells
Сообщение об ошибке
  File "mistake.py", line 1

    ^^

Верно

В математике равенство можно читать в обе стороны, в Python нет: слева от = всегда стоит имя, которое получит значение. Python даже подсказывает, что, возможно, имелось в виду сравнение == (оно разобрано на странице 05).

2. Имя и объект

Теория

Переменная — не коробка, в которую положено значение, а ярлык (наклейка) на объекте. Присваивание b = a не создает копию: на тот же объект наклеивается второй ярлык. Переприсваивание a = a + 1 создает новый объект и переносит на него ярлык a; ярлык b остается на старом объекте.

У каждого объекта есть тождество: оно не меняется за всю его жизнь. Оператор == сравнивает значения, оператор is проверяет, один ли это объект. Результат обоих: True (истина) или False (ложь).

Функция id() возвращает тождество объекта числом. Само число каждый раз разное и ничего не значит, важно только, совпадают ли id двух имен. В обычном коде id() почти не пишут: она нужна при отладке, когда два объекта выглядят одинаково.

Единственный частый случай, когда в коде нужен is, — проверка x is None. Объект None означает «значения нет» и в программе существует в одном экземпляре, поэтому проверяют тождество, а не равенство. Подробно None разбирается в теме 3 «Логика и ветвления».

Пример

Два ярлыка на одном объекте

labels.py
a = 17
b = a
print(a is b)  # → True
a = a + 1
print(a)       # → 18
print(b)       # → 17
Вывод
True
18
17
  1. Строки 1–2: имя b получает тот же объект 17, что и a. Копии нет.
  2. Строка 3: a is b дает True: оба имени наклеены на один объект.
  3. Строка 4: справа вычисляется новый объект 18, и ярлык a переносится на него.
  4. Строки 5–6: a теперь указывает на 18, а b по-прежнему на 17. Число 17 не изменилось: целые числа неизменяемы.

Тождество и None

identity.py
a = 17
b = a
print(id(a) == id(b))  # → True
result = None
print(result is None)  # → True
Вывод
True
True
  1. Строка 3: совпадают числа id, значит, объект один. Сами числа не печатаем: они меняются от запуска к запуску.
  2. Строки 4–5: правильная проверка на отсутствие значения: is None.

3. Изменяемый объект и два имени

Необходимый минимум

В практике 1 списки не нужны для решения задач. Подробно списки разбираются в теме 5 «Списки и кортежи», передача объектов в функции в теме 7 «Функции и декомпозиция».

Теория

Разница между ярлыком и коробкой становится заметной, когда объект можно изменить. Список [1, 2, 3] — изменяемый объект: запись b[0] = 17 меняет его первый элемент. Если на список наклеены два ярлыка, изменение через одно имя видно через другое.

Строки и числа неизменяемы: изменить их через имя нельзя, можно только перенести ярлык на новый объект. Поэтому для них два имени безопасны. Опасно только сочетание «два имени и изменяемый объект».

Пример

Копии не было

alias.py
a = [1, 2, 3]
b = a
b[0] = 17
print(a)  # → [17, 2, 3]
Вывод
[17, 2, 3]
  1. Строка 2: b — второй ярлык того же списка.
  2. Строка 3: список меняется через имя b.
  3. Строка 4: через a видно то же изменение, потому что объект один.

Равны, но не тот же самый

equal_not_same.py
a = [1, 2, 3]
b = a
c = [1, 2, 3]
print(a == c)  # → True
print(a is c)  # → False
print(a is b)  # → True
Вывод
True
False
True
  1. Строка 3 создает второй список с тем же содержимым.
  2. Строки 4–5: значения равны (== дает True), но это разные объекты (is дает False).
  3. Строка 6: a и b — один объект.

4. Правила имен

Теория

Имя переменной состоит из латинских букв, цифр и знака подчеркивания и не начинается с цифры. Регистр важен: LaTeX и latex — разные имена. Нельзя использовать 35 ключевых слов Python (class, if, for, True и другие): они заняты языком. Нарушение правил дает SyntaxError.

ИмяЧто не так
76trombonesначинается с цифры
more@недопустимый символ
classключевое слово
bad nameпробел: Python видит два имени без оператора

Для интерпретатора любое допустимое имя подходит одинаково, для человека нет. Мнемоничное имя напоминает, зачем переменная заведена: read_length, а не x1. По PEP 8 имена пишут строчными буквами через подчеркивание.

Все 35 ключевых слов Python 3.12: False, None, True, and, as, assert, async, await, break, class, continue, def, del, elif, else, except, finally, for, from, global, if, import, in, is, lambda, nonlocal, not, or, pass, raise, return, try, while, with, yield.

Имена встроенных функций (print, type, input) ключевыми словами не являются, и Python разрешит print = 5. Но после этого функция print в программе перестанет работать, поэтому такие имена переменным не дают.

Пример

Три одинаковые программы

abstract.py
a = 35.0
b = 12.50
c = a * b
print(c)  # → 437.5
Вывод
437.5
clear.py
hours = 35.0
rate = 12.50
pay = hours * rate
print(pay)  # → 437.5
Вывод
437.5
  1. Для интерпретатора программы одинаковы: те же числа, то же умножение, тот же вывод.
  2. Для человека нет: во второй сразу видно, что считается оплата, часы умножаются на ставку.
  3. Третий вариант той же программы с именами вроде x1q3z9ahd и x1q3z9afd тоже работал бы, но различить такие имена почти невозможно.

Типичная ошибка: имя с цифры

Неверно: имя начинается с цифры
2nd_sample = 150
Сообщение об ошибке
  File "mistake.py", line 1
    2nd_sample = 150
    ^
SyntaxError: invalid decimal literal
Верно
sample_2 = 150

Имя может содержать цифры, но не в начале: Python принимает 2nd за начало числа.

Практика

Имя переменной записано с пробелом. Исправьте его по правилам PEP 8 и запустите.
