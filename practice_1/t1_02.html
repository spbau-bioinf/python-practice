Экосистема

10 минутЕрофеев А. И.

Научиться различать ядро языка, стандартную библиотеку и сторонние пакеты, подключать модули командой import и оформлять код по соглашению PEP 8.

1. Три слоя экосистемы

Теория

Python выбирают для анализа биологических данных не только за простой синтаксис. Вокруг языка сложилась экосистема: тысячи готовых модулей для чтения форматов последовательностей, запросов к базам данных, вычислений и графиков. Чтобы пользоваться ею, нужно понимать, из каких частей она состоит и откуда что берется.

«Python» на вашем компьютере состоит из трех слоев. Ядро языка небольшое: числа, строки, списки, словари и правила их записи. Стандартная библиотека устанавливается вместе с Python: это модули math, decimal, random, os, sys и многие другие. Сторонние пакеты развиваются отдельно от языка и устанавливаются вручную командой pip из каталога PyPI (pypi.org).

Модуль — файл или набор файлов с готовыми функциями и значениями, которые программа может подключить.

Если подключить пакет, который не установлен, Python выдаст ModuleNotFoundError. Это проблема окружения (на компьютере нет пакета), а не ошибка в коде: ее исправляют установкой, а не правкой программы.

Что чем делается в биоинформатике на Python:

ЗадачаПакет
получить данные из баз NCBI, UniProt, Ensemblrequests
читать файлы FASTA, FASTQ, BED, GFF, VCFBiopython
работать с таблицами, группировать данныеpandas
считать с массивами чиселNumPy
строить научные графикиmatplotlib, seaborn
проверять программу тестамиpytest

Все это материал второго семестра. В первом семестре программы пишутся на чистом Python: кто сам написал подсчет GC-состава, понимает, что за него делает библиотека.

Пример

Установка пакета и ошибка окружения

Пакет устанавливают в терминале (это не код Python, а команда операционной системы):

Терминал · Windows
PS C:\Users\student> python -m pip install numpy
Терминал · macOS
% python3 -m pip install numpy
Терминал · Linux
$ python3 -m pip install numpy

Если пакет не установлен, попытка подключить его в интерактивном режиме Python дает такое сообщение:

Интерактивный режим Python
>>> import Bio
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ModuleNotFoundError: No module named 'Bio'
  1. Команда python -m pip installpython3 -m pip installpython3 -m pip install запускает установщик pip той версии Python, которой вы пользуетесь. Так пакет гарантированно попадет туда, где его будет искать ваш интерпретатор.
  2. Bio — имя, под которым подключается пакет Biopython. Сообщение No module named 'Bio' значит, что пакет не найден среди установленных.
  3. На компьютерах в аудитории устанавливать пакеты для практики 1 не нужно: все модули, которые понадобятся, входят в стандартную библиотеку.

2. Подключение модулей

Необходимый минимум

Здесь только то, что нужно в практике 1. Подробно модули и пакеты разбираются в теме 11 «Модули, пакеты и интерфейс командной строки».

Теория

Модуль стандартной библиотеки уже установлен, но в программе он становится доступен только после команды import. Ее пишут в начале файла.

import имя_модуля
имя_модуля.имя_функции(…)

from имя_модуля import имя
имя(…)

Первая форма подключает модуль целиком; к его содержимому обращаются через точку: math.sqrt(16) означает «функция sqrt из модуля math». Вторая форма берет из модуля одно имя, и дальше его пишут без приставки.

Функция math.sqrt() вычисляет квадратный корень и всегда возвращает вещественное число. Модуль math понадобится на странице 07 для сравнения вещественных чисел, а класс Decimal из модуля decimal на странице 08 для точной десятичной арифметики.

Пример

Модуль math

Предскажите: будет ли корень из 16 напечатан как 4?

modules.py
import math
print(math.sqrt(16))  # → 4.0
print(math.pi)        # → 3.141592653589793
Вывод
4.0
3.141592653589793
  1. Модуль math подключается целиком.
  2. Функция sqrt из модуля math вычисляет корень из 16. Результат вещественный: 4.0, а не 4.
  3. math.pi — не функция, а значение числа π, поэтому скобок после него нет.

Одно имя из модуля

decimal_import.py
from decimal import Decimal
print(Decimal('1.45'))  # → 1.45
Вывод
1.45
  1. Строка 1: из модуля decimal берется только имя Decimal.
  2. Строка 2: Decimal пишется без приставки decimal.. Что это за число и зачем оно нужно, разобрано на странице 08.

Типичная ошибка: обращение без имени модуля

Неверно: sqrt без math.
import math
print(sqrt(16))
Сообщение об ошибке
Traceback (most recent call last):
  File "mistake.py", line 2, in <module>
    print(sqrt(16))
          ^^^^
NameError: name 'sqrt' is not defined
Верно
import math
print(math.sqrt(16))  # → 4.0
Вывод
4.0

После import math в программе появляется одно имя: math. Функция sqrt доступна только через него.

Практика

Посчитайте корень из 2, а затем удалите первую строку и прочитайте сообщение об ошибке.

try_math.py
import math
print(math.sqrt(16))  # → 4.0
Вывод
4.0

3. Стиль кода: PEP 8

Теория

Код читают чаще, чем пишут: при отладке, доработке, проверке чужой работы. Поэтому в Python принят общий стиль оформления, а не личный вкус каждого. Соглашение о стиле называется PEP 8.

  • отступ одного уровня: 4 пробела, без символов табуляции;
  • длина строки не больше 79 символов;
  • имена из строчных букв со знаком подчеркивания: read_length;
  • вокруг = и знаков операций по одному пробелу, после запятой пробел, внутри скобок пробелов нет.

Раз стиль общий, его можно проверять и применять автоматически. Автоформатер (например, black) сам расставляет пробелы и переносы, линтер (например, pylint) находит нарушения стиля и подозрительные места. В редакторе их подключают один раз, и дальше код оформляется при сохранении.

Табуляцию и пробелы в отступах смешивать нельзя: символы невидимы, а Python воспринимает их по-разному. Отступы станут важны в теме 3 «Логика и ветвления»; редактор заранее настраивают так, чтобы клавиша Tab вставляла 4 пробела (страница 03).

Пример

Одна программа, два оформления

style_bad.py
print( 2+3 )  # → 5
Вывод
5
style_good.py
print(2 + 3)  # → 5
Вывод
5
  1. Для интерпретатора программы одинаковы, вывод совпадает.
  2. Вторая оформлена по PEP 8: без пробелов внутри скобок и с пробелами вокруг +. Такой код привычнее читать любому, кто пишет на Python.
