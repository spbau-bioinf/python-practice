print() и input()

20 минутЕрофеев А. И.

Научиться выводить несколько значений одной строкой, подставлять значения в текст f-строкой, читать данные функцией input() и сразу преобразовывать их в числа.

Как устроены задачи с этой страницы. Исходные данные больше не задаются в коде: программа читает их функцией input(), каждое значение с новой строки, в том порядке, в каком они перечислены в условии. В задачах input() пишется без текста-приглашения: проверка сравнивает весь вывод программы с ответом, и приглашение попало бы в него лишним текстом.

1. Вывод нескольких значений

Теория

Функция print() принимает любое число значений через запятую. Она печатает их в одну строку, разделяя пробелом, и в конце переводит строку. Оба поведения настраиваются именованными аргументами: sep задает разделитель, end — окончание.

print(значение, …, sep=' ', end='\n')

Запись '\n' означает символ перевода строки. Значения разных типов можно печатать вместе: print('Длина:', 1250) работает без str(), потому что print() сама переводит каждое значение в текст.

Это объясняет загадку со страницы 05: в print(1,000,000) запятые разделяют три значения, 1, 000 и 000, а два последних равны нулю. Поэтому напечатано 1 0 0. Именованные аргументы вроде sep='-' пишутся после всех значений; подробно они разбираются в теме 7 «Функции и декомпозиция».

Пример

Несколько значений и разделитель

print_many.py
print('Длина:', 1250)          # → Длина: 1250
print(1,000,000)               # → 1 0 0
print('A', 'T', 'G', sep='-')  # → A-T-G
Вывод
Длина: 1250
1 0 0
A-T-G
  1. Строка 1: текст и число напечатаны через пробел.
  2. Строка 2: три значения, а не одно число с разделителями.
  3. Строка 3: вместо пробела между значениями стоит дефис.

Окончание строки

print_end.py
print('GC', end='')
print('-состав')  # → -состав
Вывод
GC-состав
  1. Строка 1: после GC перевода строки нет, окончание пустое.
  2. Строка 2 продолжает ту же строку вывода.
Практика

Напечатайте кодон ATG так, чтобы буквы шли без пробелов: подберите значение sep.

try_sep.py
print('A', 'T', 'G')  # → A T G
Вывод
A T G

2. f-строки

Необходимый минимум

Здесь только подстановка значения и формат :0.Nf. Подробно форматирование строк разбирается в теме 2 «Строки и текстовые данные».

Теория

f-строка пишется с буквой f перед кавычкой. Выражение в фигурных скобках вычисляется, и его значение подставляется в текст. В скобках может стоять не только имя, но и вычисление. После двоеточия задается формат: {x:0.2f} показывает число с двумя знаками после точки.

f'текст {выражение} текст {число:0.2f}'

Формат :0.2f округляет только запись числа при выводе, само число не меняется. Результат f-строки всегда строка.

f-строка избавляет от целого класса ошибок с преобразованием типов. Склейка 'Длина: ' + 7 дает TypeError, склейка со str(7) работает, но громоздка, а f'Длина: {7}' переводит значение в текст сама. Формат :0.3f удобен для долей вроде GC-состава: вычисления идут с полной точностью, а человек видит три знака.

Пример

Подстановка и формат

fstring.py
sample = 'S12'
volume = 2.5
print(f'Проба {sample}: {volume} мл')       # → Проба S12: 2.5 мл
print(f'Удвоенный объем: {volume * 2} мл')  # → Удвоенный объем: 5.0 мл
gc = 0.47683
print(f'GC: {gc:0.3f}')                     # → GC: 0.477
Вывод
Проба S12: 2.5 мл
Удвоенный объем: 5.0 мл
GC: 0.477
  1. Имя sample связано со строкой.
  2. Имя volume связано с числом 2.5.
  3. Вместо {sample} и {volume} подставлены значения; число переведено в текст без str().
  4. В скобках вычисление: 2.5 · 2 = 5.0.
  5. Доля GC с пятью знаками.
  6. Формат :0.3f показывает три знака после точки с округлением.

Типичная ошибка: забыта буква f

Неверно: обычная строка
sample = 'S12'
print('Проба {sample}')  # → Проба {sample}
Вывод
Проба {sample}
Верно
sample = 'S12'
print(f'Проба {sample}')  # → Проба S12
Вывод
Проба S12

Без f фигурные скобки остаются обычными символами строки, и подстановки нет. Сообщения об ошибке нет, неверен только вывод.

3. Ввод: input()

Теория

Функция input() останавливает программу и ждет, пока человек наберет текст и нажмет Enter. Текст в скобках (приглашение) печатается перед ожиданием: из него пользователь узнает, что вводить. Программа, которая «висит» сразу после запуска, чаще всего ждет ввода.

input() всегда возвращает строку, даже если набраны цифры. Для вычислений ее сразу преобразуют: int(input()) или float(input()).

Если набрать не число, преобразование завершится ValueError во время выполнения. Одна и та же строка кода ведет себя по-разному в зависимости от того, что напечатал человек. Обработку таких ошибок разбирают в теме 9; сейчас достаточно понимать причину.

Что видитеПричинаЧто делать
TypeError при арифметикезначение осталось строкойпреобразовать сразу при вводе
ValueError: invalid literalво вводе не числопроверять введенные данные
программа «висит»input() ждет ввода, приглашения нетпередать текст в input()
числа склеились: 3542+ над строкамиint() перед сложением

Три симптома из четырех вытекают из одного факта: input() возвращает строку. Распознать их можно по первому слову последней строки сообщения.

Пример

Программа ждет ввода. Пользователь набирает S12 и нажимает Enter.

Приглашение и ввод

ask.py
name = input('Как называется образец? ')
print(f'Образец {name} принят')  # → Образец S12 принят
Вывод
Как называется образец? S12
Образец S12 принят
  1. Строка 1: печатается приглашение, программа останавливается. Набранный текст становится значением name.
  2. Строка 2: значение подставляется в ответ. В окне вывода введенное выделено: это не вывод программы, а то, что набрал человек.

Программа ждет ввода. Пользователь набирает 150 и нажимает Enter.

Ввод всегда строка

always_str.py
reads = input('Сколько прочтений? ')
print(reads + reads)            # → 150150
print(int(reads) + int(reads))  # → 300
Вывод
Сколько прочтений? 150
150150
300
  1. Строка 2: reads хранит строку '150', и + склеивает ее саму с собой.
  2. Строка 3: после int() получаются числа, и они складываются.

Типичная ошибка: арифметика над введенной строкой

Неверно: нет преобразования
length = input()
print(length + 5)
Вывод
150
Сообщение об ошибке
Traceback (most recent call last):
  File "mistake.py", line 2, in <module>
    print(length + 5)
          ~~~~~~~^~~
TypeError: can only concatenate str (not "int") to str
Верно
length = int(input())
print(length + 5)  # → 155
Вывод
150
155

Пользователь ввел 150. Преобразуйте значение сразу при вводе: потом легко забыть, что оно пришло строкой.

4. Ввод, обработка, вывод

Теория

Почти любая программа устроена по одному шаблону: ввод, обработка, вывод. Сейчас данные вводятся функцией input(), обрабатываются арифметикой и выводятся функцией print() с f-строками. Дальше в середину добавятся ветвления (тема 3), циклы (тема 4) и функции (тема 7), а ввод станет чтением файла FASTA. Каркас при этом не меняется.

Хорошая программа читается как условие задачи: имена мнемоничные, введенные значения преобразуются сразу в строке ввода, результат выводится одной f-строкой с нужным числом знаков. Такая программа еще не защищена от букв вместо чисел, но это задача темы 9.

Пример

Масса ДНК в пробе

Программа ждет ввода. Пользователь набирает 25.5, нажимает Enter, затем набирает 40 и снова нажимает Enter.

dna_mass.py
conc = float(input('Концентрация, нг/мкл: '))
volume = float(input('Объем, мкл: '))
mass = conc * volume
print(f'Масса ДНК: {mass:0.1f} нг')  # → Масса ДНК: 1020.0 нг
Вывод
Концентрация, нг/мкл: 25.5
Объем, мкл: 40
Масса ДНК: 1020.0 нг
  1. Ввод: строка сразу преобразуется в float.
  2. Ввод второго значения, тоже с преобразованием.
  3. Обработка: 25.5 · 40 = 1020.0; нанограммы на микролитр, умноженные на микролитры, дают нанограммы.
  4. Вывод: значение подставлено в текст с одним знаком после точки.
