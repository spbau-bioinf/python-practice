Программа и алгоритм

10 минутЕрофеев А. И.

Научиться отличать алгоритм от программы, называть этапы, которые проходит программа на Python до результата, и определять вид ошибки по сообщению интерпретатора.

1. От задачи к исполнению

Теория

Человек и компьютер сильны в разном. Человек понимает смысл текста, придумывает и догадывается, но пересчитывать тысячи чисел вручную ему тяжело. Компьютер смысла не понимает, зато выполняет миллиарды простых операций в секунду и никогда не устает. Программирование передает машине рутину и оставляет человеку смысл: в этом курсе рутиной будут подсчет GC-состава, поиск мотивов, частоты кодонов, разбор файлов FASTA.

Алгоритм — точное описание способа решения задачи: последовательность шагов, которая из исходных данных получает результат.

Программа — запись алгоритма на конкретном языке программирования, которую может выполнить компьютер.

Путь от задачи до результата состоит из четырех этапов: задача (что нужно получить), алгоритм (способ решения словами, схемой или псевдокодом), программа (инструкции на языке Python) и исполнение (запуск и проверка результата). Алгоритм от языка не зависит, программа зависит. Большинство ошибок появляется при переводе алгоритма в программу, поэтому программу всегда проверяют запуском.

Решение задачи состоит из трех разных действий: сформулировать проблему, найти решение и выразить его на языке исполнителя. Их полезно разделять: если программа работает неверно, сначала проверьте алгоритм на бумаге и только потом ищите ошибку в коде.

Программа при работе использует несколько устройств компьютера:

УстройствоЧто делаетЧто там во время работы программы
внешняя память (диск)хранит файлы и после выключенияфайл программы hello.py
оперативная памятьхранит данные, пока есть питаниезагруженная программа и ее данные
процессорвыполняет командыпо одной выполняет инструкции программы
ввод и выводклавиатура, файл, сеть; экран, файлто, что программа получает и выдает

После строки x = 123 число 123 появляется в оперативной памяти, а имя x указывает на него (подробно на странице 04). Когда программа завершится, оперативная память освободится; сохранится только то, что записано в файл во внешней памяти.

Пример

Алгоритм подсчета GC-состава

Задача: узнать, какую долю последовательности ДНК составляют гуанин (G) и цитозин (C). Алгоритм словами:

  1. Посчитать, сколько в последовательности букв G.
  2. Посчитать, сколько букв C.
  3. Сложить эти два числа.
  4. Разделить сумму на длину последовательности.
  5. Сообщить результат.
  1. Алгоритм не упоминает ни одного слова Python: так же его выполнит человек с карандашом или программа на другом языке.
  2. Каждый шаг однозначен: у исполнителя не возникает вопроса, что делать дальше.
  3. Запись этого алгоритма на Python появится на страницах 08 и 10. Шаги 1–2 без готовых чисел требуют циклов (тема 4 «Циклы и итеративная обработка»), поэтому в практике 1 числа G и C будут даны заранее.

2. Интерпретатор

Теория

Процессор выполняет только машинный код: команды в двоичном виде, свои для каждого типа процессора. Python — язык высокого уровня, он спроектирован так, чтобы программу мог прочитать человек. Между человеком и процессором всегда стоит программа-переводчик.

Компилятор — переводчик, который переводит программу целиком в файл с машинным кодом; запускать этот файл можно позже.

Интерпретатор — переводчик, который читает программу и сразу выполняет ее по ходу дела.

Python интерпретируемый язык. Интерпретатор CPython сначала разбирает весь файл .py и переводит его в байт-код (промежуточный код для виртуальной машины Python), затем выполняет байт-код строка за строкой. Отсюда главное следствие: синтаксическая ошибка (SyntaxError) обнаруживается при разборе, до выполнения первой строки, а остальные ошибки проявляются только тогда, когда строка с ошибкой действительно выполняется.

Слово «Python» означает три разные вещи: язык (правила, общие для всех), реализацию (программа-переводчик CPython, написанная на языке C) и версию, установленную на вашем компьютере. Код выполняет именно установленная версия, поэтому ее полезно знать:

Терминал · Windows
PS C:\Users\student> python --version
Python 3.12.3
Терминал · macOS
% python3 --version
Python 3.12.3
Терминал · Linux
$ python3 --version
Python 3.12.3

В курсе нужен Python 3.10 или новее. Команда python на разных системах может вести к старой версии или отсутствовать, поэтому в терминале пишут python3 (в Windows обычно работает python, подробнее на странице 03).

Машинный код привязан к процессору, поэтому программа в машинных кодах не переносится на другой компьютер. Исходный текст на Python один, а интерпретаторы для разных систем разные. Если открыть файл с машинным кодом в текстовом редакторе, увидите набор непонятных символов вроде ^?ELF^A^A^A: он предназначен не для человека.

Байт-код модулей, которые подключает программа, Python сохраняет в папку __pycache__ (файлы .pyc), чтобы в следующий раз не разбирать их заново. Эту папку не нужно ни редактировать, ни сдавать.

Пример

Две программы ниже отличаются одной ошибкой. Предскажите, что успеет напечатать каждая.

Ошибка во время выполнения

runtime.py
print('Начало анализа')  # → Начало анализа
print('126' / 3)
print('Конец анализа')
Вывод
Начало анализа
Сообщение об ошибке
Traceback (most recent call last):
  File "runtime.py", line 2, in <module>
    print('126' / 3)
          ~~~~~~^~~
TypeError: unsupported operand type(s) for /: 'str' and 'int'
  1. Строка 1 выполнилась: текст напечатан.
  2. Строка 2: делить текст '126' на число нельзя. Ошибка обнаружена только сейчас, когда строка начала выполняться, и программа остановилась.
  3. Строка 3 не выполнилась: после ошибки программа не продолжается.

Синтаксическая ошибка

syntax.py
print('Начало анализа')
print('Конец анализа'
Сообщение об ошибке
  File "syntax.py", line 2
    print('Конец анализа'
         ^
SyntaxError: '(' was never closed
  1. Во второй строке не закрыта скобка.
  2. Окна вывода нет: не напечатано даже «Начало анализа», хотя первая строка правильная. Python нашел ошибку при разборе файла, до выполнения первой строки.
Практика

Исправьте вторую строку программы syntax.py: допишите закрывающую скобку и запустите. Затем замените во второй строке текст на выражение '126' / 3 и посмотрите, какая строка успеет выполниться.

try_syntax.py
print('Начало анализа')  # → Начало анализа
print('Конец анализа')   # → Конец анализа
Вывод
Начало анализа
Конец анализа

3. Три вида ошибок

Теория

Ошибки различаются тем, когда они обнаруживаются.

ОшибкаКогда обнаруживаетсяПримерЧто видно
синтаксическаядо запуска, при разборе файлаmillion! = 1000000SyntaxError, не выполнилась ни одна строка
времени выполнения (исключение)во время работы'126' / 3программа остановилась на строке с ошибкой
семантическаяникогда1 + 3 / 2 вместо среднегопрограмма отработала, но результат не тот

Исключение — ошибка, которая возникает во время выполнения программы и прерывает ее, если ее не обработать.

Первые два вида ошибок Python найдет сам и выведет сообщение. Семантическую ошибку найдете только вы, проверив результат. Сообщение об ошибке (трассировку, англ. traceback) читают снизу вверх: последняя строка называет тип ошибки и причину, строки выше показывают файл и строку, где ошибка обнаружена.

Сообщение указывает место, где ошибка обнаружена, а не где она допущена. Настоящая причина часто строкой-двумя выше. Порядок действий: прочитать сообщение целиком, сформулировать гипотезу и только потом менять код.

Пример

Как читать трассировку

traceback.py
print('Образец принят')  # → Образец принят
print(sample_id)
Вывод
Образец принят
Сообщение об ошибке
Traceback (most recent call last):
  File "traceback.py", line 2, in <module>
    print(sample_id)
          ^^^^^^^^^
NameError: name 'sample_id' is not defined
  1. Строка выполнилась, текст напечатан.
  2. Имя sample_id нигде не задано, поэтому Python не знает, что печатать, и останавливает программу.

В сообщении три части. Заголовок Traceback (most recent call last): говорит, что ниже путь к месту ошибки. Строка File "traceback.py", line 2 называет файл и номер строки. Последняя строка ставит диагноз: тип ошибки NameError (неизвестное имя) и пояснение name 'sample_id' is not defined, то есть какое имя не найдено.

Семантическая ошибка

Нужно найти среднее чисел 1 и 3, то есть 2. Предскажите вывод обеих строк.

mean.py
print(1 + 3 / 2)    # → 2.5
print((1 + 3) / 2)  # → 2.0
Вывод
2.5
2.0
  1. Строка 1: деление выполняется раньше сложения, поэтому считается 1 + 1,5. Python не сообщает об ошибке: с его точки зрения выражение правильное.
  2. Строка 2: скобки задают нужный порядок. Правила порядка операций разобраны на странице 06.

Типичная ошибка: причина выше указанной строки

Неверно: скобка не закрыта в строке 1
print('Длина прочтения:'
print(150)
Сообщение об ошибке
  File "mistake.py", line 1
    print('Длина прочтения:'
         ^
SyntaxError: '(' was never closed
Верно
print('Длина прочтения:')  # → Длина прочтения:
print(150)                 # → 150
Вывод
Длина прочтения:
150

Python дочитал файл до конца и не нашел пару для скобки, открытой в первой строке. В этом случае он показывает строку, где скобка открыта; в других синтаксических ошибках указанное место бывает ниже настоящей причины. Текст сообщений о синтаксических ошибках часто малоинформативен: позиция в нем только отправная точка поиска.

Подробнее: почему в Python 3.12 сообщения стали понятнее

Начиная с версии 3.10 интерпретатор подсказывает причину синтаксических ошибок точнее: вместо общего invalid syntax он пишет, например, '(' was never closed. С той же версии 3.10 для NameError Python предлагает похожее имя: Did you mean: 'print'?. В версии 3.11 появились значки ^^^^ под частью строки, где возникла ошибка. Поэтому в старых учебниках текст сообщений может отличаться от того, что видите вы.

Практика

Имя функции написано с большой буквы. Прочитайте последнюю строку сообщения и исправьте программу.

try_name.py
Print('Hello, lab')
Сообщение об ошибке
Traceback (most recent call last):
  File "try_name.py", line 1, in <module>
    Print('Hello, lab')
    ^^^^^
NameError: name 'Print' is not defined. Did you mean: 'print'?
