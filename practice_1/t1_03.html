Среда и запуск

10 минутЕрофеев А. И.

Научиться создавать файл .py, запускать его из редактора и из терминала, пользоваться интерактивным режимом и настраивать редактор для работы по PEP 8.

1. Интерактивный режим и файл

Теория

Писать код на Python можно двумя способами. В интерактивном режиме (REPL, от англ. Read-Eval-Print Loop, цикл «чтение, вычисление, вывод») вы набираете строку после приглашения >>> и сразу получаете ответ; выход командой quit() или exit(). Ничего не сохраняется, поэтому режим годится, чтобы проверить одну мысль.

Программу, которую нужно сохранить, повторить или сдать, пишут в файле-скрипте: обычном текстовом файле с расширением .py. Все решения упражнений курса сдаются именно файлами.

Комментарий — часть строки от символа # до ее конца; интерпретатор его не выполняет.

В интерактивном режиме Python сам показывает значение выражения, например 2 + 3 дает ответ 5. В файле так не будет: программа печатает только то, что передано функции print(). Это частая причина вопроса «почему программа ничего не вывела».

Файл программы — обычный текст в кодировке UTF-8, поэтому русские буквы и другие символы Unicode в строках и комментариях допустимы. Если сохранить файл в другой кодировке и не объявить ее, Python выдаст SyntaxError еще до запуска. Современные редакторы сохраняют в UTF-8 по умолчанию.

Комментарий объясняет, зачем написан код, а не пересказывает, что он делает: это и так видно из кода.

Бесполезный комментарий
v = 8  # присвоить 8 переменной v
Полезный комментарий
v = 8  # скорость в милях в час
Пример

Интерактивный режим

Терминал · Windows
PS C:\Users\student> python
>>> print(4)
4
>>> 2 + 3
5
>>> quit()
PS C:\Users\student>
Терминал · macOS
% python3

>>> 2 + 3
5

$ python3
>>> print(4)
4
>>> 2 + 3

>>> quit()
$
  1. Команда pythonpython3python3 без имени файла открывает интерактивный режим.
  2. После каждой строки с приглашением >>> Python сразу показывает результат.
  3. quit() возвращает в обычный терминал, все набранное теряется.

Первая программа в файле

hello_world.py
# hello_world.py: первая программа практики
print('Hello Python world!')  # → Hello Python world!
print('Привет, лаборатория')  # → Привет, лаборатория
Вывод
Hello Python world!
Привет, лаборатория
  1. Строка 1: комментарий, интерпретатор ее пропускает.
  2. Строки 2–3 выполняются по порядку, каждая печатает одну строку. Русский текст печатается без проблем: файл в UTF-8.
  3. За доли секунды Python успел разобрать файл, перевести его в байт-код и выполнить (страница 01).
Практика

Добавьте третью строку, которая печатает название вашей группы, и запустите. Затем уберите print из второй строки, оставив только текст в кавычках: изменится ли вывод?

try_hello.py

Вывод

2. Запуск из терминала

Теория

Терминал всегда «находится» в какой-то папке (текущем каталоге), и команда запуска ищет файл именно там. Поэтому запуск состоит из трех шагов:

ШагWindowsmacOS / Linux
1. Перейти в папку с файломcd Documents\python_workcd Documents/python_work/
2. Убедиться, что файл тамdirls
3. Запустить программуpython hello_world.pypython3 hello_world.py

Сообщение «файл не найден» почти всегда значит, что пропущен шаг 1. Большинство программ вы будете запускать кнопкой в редакторе, но терминал понадобится, когда работа усложнится.

В Windows команда python обычно ведет к установленному Python 3, а python3 может отсутствовать. В macOS и Linux, наоборот, python может вести к старому Python 2 или не существовать, поэтому там пишут python3. Проверить, что запускается, можно командой python3 --version (или python --version).

3. Редактор

Теория

Код можно писать и в блокноте, но редактор для программиста избавляет от ошибок, которые трудно найти глазами. В курсе используется VS Code или PyCharm Community: выберите один, на оценку выбор не влияет. Оптимальный выбор: PyCharm Community 2023 года, инструкция по установке.

ПроблемаЧем помогает редактор
опечатка в имени функцииподсветка синтаксиса: print и текст в кавычках окрашены по-разному
смешаны табуляция и пробелыклавиша Tab вставляет 4 пробела
строка уходит за край экранавертикальная линия на 79–80 символах

Перед первым практическим занятием проверьте рабочее место:

  1. Python 3.10 или новее: python3 --version.
  2. Установлен редактор VS Code или PyCharm Community.
  3. В редакторе табуляция заменяется 4 пробелами, линейка стоит на 80 символах.
  4. Установлен Git, есть доступ к личному удаленному репозиторию.
  5. Создана папка проекта; имена папок и файлов строчными латинскими буквами, через подчеркивание.
Пример

Типичная ошибка: кавычки из текстового редактора

Неверно: «елочки» вместо прямых кавычек
print(«Hello»)
Сообщение об ошибке
  File "hello.py", line 1
    print(«Hello»)
          ^
SyntaxError: invalid character '«' (U+00AB)
Верно
print('Hello')  # → Hello
Вывод
Hello

Текстовые процессоры (Word и другие) автоматически заменяют прямые кавычки на типографские. Python понимает только прямые кавычки ' и ", поэтому код не переносят через Word, а пишут в редакторе.

Подробнее: что такое U+00AB

Каждому символу Unicode присвоен номер, его записывают как U+ и шестнадцатеричное число. U+00AB — открывающая кавычка «. Python указывает номер, потому что на экране похожие символы (прямая и типографская кавычки, латинская и русская «а») неотличимы, а номер у них разный.

Практика

Программу перенесли из текстового документа. Исправьте кавычки и запустите.
