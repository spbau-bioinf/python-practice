Биологические данные

15 минутЕрофеев А. И.

Научиться выбирать тип для каждой величины биологической записи, считать GC-состав по числам нуклеотидов и выводить его в нужном формате.

1. Что каким типом

Теория

Специального «биологического» типа в Python нет, и он не нужен. Последовательность, идентификатор записи, длина, GC-состав представляются теми же встроенными типами, что разобраны на странице 05. Значит, к последовательностям применимо все, что известно о строках, а к расчетам все, что известно о числах.

ВеличинаТипПочему
идентификатор записиstrтекст, а не число
последовательностьstrпоследовательность символов
длина последовательностиintсчитаем штуки
GC-составfloatдоля, не целое
«последовательность корректна?»boolдва исхода
описание отсутствуетNoneне пустая строка, а «ничего нет»

Нуклеотидная последовательность записывается буквами A, T, C, G (аденин, тимин, цитозин, гуанин). Строчными буквами обычно помечают мягко замаскированные повторы, буква N означает любое, неизвестное основание.

В формате FASTA запись состоит из строки описания, которая начинается с символа >, и последовательности на следующих строках. Идентификатор — часть строки описания до первого пробела, после пробела идет описание.

Содержимое файла gene.fa
>gene_00284728 length=32;type=dna
GAGAACTGATTCTGTTACCGCAGGGCATTCGG

Длина всегда целая. Если длина получилась с точкой, где-то в расчете деление / вместо // (страница 06). Формат FASTA сложился стихийно, единой спецификации идентификатора нет; распространенное соглашение делит строку описания по первому пробелу. Частые ошибки в таких файлах: лишний пробел после > и повторяющиеся идентификаторы. Разбирать файлы FASTA программой вы будете в темах 8–9.

Пример

Запись в переменных

record.py
record_id = 'gene_00284728'
sequence = 'GAGAACTGATTCTGTTACCG'
length = len(sequence)
print(type(record_id))  # → <class 'str'>
print(length)           # → 20
print(type(length))     # → <class 'int'>
Вывод
<class 'str'>
20
<class 'int'>
  1. Идентификатор хранится строкой.
  2. Последовательность тоже строка.
  3. Длина строки (страница 05) дает целое число.
  4. Тип идентификатора: str.
  5. В последовательности 20 нуклеотидов.
  6. Тип длины: int.

Отсутствующее описание

description.py
description = None
print(description is None)  # → True
print(description == '')    # → False
Вывод
True
False
  1. Строка 2: описания нет, проверка через is None (страница 04).
  2. Строка 3: None не равно пустой строке. Пустое описание и отсутствующее описание — разные ситуации.

2. GC-состав

Теория

GC-состав — доля гуанина и цитозина среди всех нуклеотидных остатков последовательности; обычно выражается в процентах.

GC-состав — доля, поэтому это float со всеми свойствами вещественных чисел (страница 07). Сравнивать его с другим вычисленным значением нужно с допуском (math.isclose), фильтровать по порогу через > и <, а округлять только при выводе, например f'{gc:0.3f}'.

Осторожно с нулем: GC-состав бывает равен нулю, а math.isclose(gc, 0.0) без abs_tol дает False для любого ненулевого значения, даже крошечного (страница 07). Если в последовательности есть неизвестные основания N, их обычно не учитывают ни в числителе, ни в знаменателе: доля считается среди определенных нуклеотидов.

Пример

GC-состав по числам нуклеотидов

gc.py
g = 205
c = 195
length = 1000
gc = (g + c) / length
print(gc)                  # → 0.4
print(f'{gc * 100:0.1f}')  # → 40.0
print(gc > 0.45)           # → False
Вывод
0.4
40.0
False
  1. Число гуанинов.
  2. Число цитозинов.
  3. Длина последовательности.
  4. Скобки нужны: сначала сумма, потом деление. Результат float.
  5. Доля 0,4.
  6. Проценты для человека с одним знаком после точки.
  7. Сравнение с порогом 45 % выполняется над долей: 0,4 меньше 0,45.

3. Одна последовательность и набор

Необходимый минимум

Подробно списки разбираются в теме 5 «Списки и кортежи», передача их в функции в теме 7 «Функции и декомпозиция».

Теория

Отдельная последовательность — строка, она неизменяема: два имени у одной строки безопасны. Набор последовательностей удобно хранить списком, а список изменяем: изменение через одно имя видно через другое (страница 04). Риск определяется не тем, биологические перед вами данные или нет, а только изменяемостью объекта.

То же произойдет, когда набор передают в функцию: функция получает ссылку на тот же список, а не копию, и ее изменения увидит вызывающий код. К этому вернетесь в темах 5 и 7.

Пример

Строка и список

batch.py
seq = 'ACGT'
alias = seq
seq = seq + 'A'
print(alias)  # → ACGT
batch = ['ACGT', 'GGCC']
same = batch
same[0] = 'TTTT'
print(batch)  # → ['TTTT', 'GGCC']
Вывод
ACGT
['TTTT', 'GGCC']
  1. Строки 1–4: склейка создает новую строку и переносит на нее имя seq; alias остался на старой.
  2. Строки 5–8: список один, изменение через same видно через batch.

Практики курса развивают одну программу «Анализ биологических последовательностей»: проверка данных (тема 3), статистики и GC-состав (тема 4), частоты нуклеотидов (тема 6), поиск мотивов (темы 4 и 8), разбор FASTA и отчет (темы 8–9). Сейчас вы на первом шаге: типы, переменные, ввод и вывод.
