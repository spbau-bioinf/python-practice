Типы данных

20 минутЕрофеев А. И.

Научиться определять тип значения, явно преобразовывать строки в числа и обратно и различать ошибки TypeError и ValueError.

Как устроены задачи. Как и на странице 04, исходные данные задаются в начале программы. Строки записываются в кавычках: a = '1200'. Проверка подставляет свои значения того же типа.

1. Значение и тип

Теория

Одни и те же символы могут означать разное: 17 можно сложить с другим числом, а «17» на бирке пробирки — это надпись. Python различает такие случаи по типу значения. От типа зависит, что со значением можно делать: числа складывают, строки соединяют, а разделить строку на число нельзя.

Тип — класс, к которому принадлежит значение; он определяет, какие операции с ним допустимы.

ЗначениеТипЧто это
17intцелое число
4.2floatвещественное число
'Hello, World!'strстрока символов
Trueboolистина или ложь

Тип значения сообщает функция type(). Кавычки обозначают строку, поэтому 17 и '17' имеют разные типы. True и False пишутся без кавычек и с большой буквы: это не строки.

Одно и то же целое число можно записать в коде по-разному:

ЗаписьСистема счисленияЗначение
42десятичная42
0b101010двоичная42
0o52восьмеричная42
0x2aшестнадцатеричная42

Форма записи относится к исходному тексту, а не к числу: основание в значении не сохраняется, и print(0x2a) печатает 42. Для удобства чтения длинные числа разделяют подчеркиванием: 123_456_789 хранится как 123456789. Запятая разделителем разрядов не работает: print(1,000,000) печатает 1 0 0. Разгадка на странице 09.

Пример

Спросить тип у интерпретатора

types.py
print(type(17))    # → <class 'int'>
print(type(4.2))   # → <class 'float'>
print(type('17'))  # → <class 'str'>
print(type(True))  # → <class 'bool'>
Вывод
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
  1. Строки 1–2: числа без точки и с точкой имеют разные типы.
  2. Строка 3: '17' в кавычках является строкой, хотя состоит из цифр.
  3. Строка 4: True имеет логический тип bool.

Разные записи одного числа

literals.py
print(0b101010)     # → 42
print(0x2a)         # → 42
print(123_456_789)  # → 123456789
Вывод
42
42
123456789
  1. Python печатает целые числа в десятичной записи, в какой бы системе они ни были записаны в коде.
  2. Подчеркивания нужны только человеку и в значение не попадают.

2. Строки: склейка и повторение

Необходимый минимум

Здесь только склейка, повторение и длина строки. Подробно строки разбираются в теме 2 «Строки и текстовые данные».

Теория

Смысл оператора определяют типы операндов. Для строк + означает склейку (конкатенацию), а * с целым числом — повторение. Функция len() возвращает длину строки, то есть число символов в ней.

ВыражениеРезультатЧто произошло
100 + 150250сложение чисел
'100' + '150''100150'склейка строк, не сложение
'AT' * 3'ATATAT'повторение строки
len('GATTACA')7длина строки

Смешивать строку и число нельзя: 'Hello' + 3 и 'Hello' * 3.0 вызывают TypeError. Повторять строку можно только целое число раз.

Пример

Один знак, разные действия

string_ops.py
print(100 + 150)       # → 250
print('100' + '150')   # → 100150
print('AT' * 3)        # → ATATAT
print(len('GATTACA'))  # → 7
Вывод
250
100150
ATATAT
7
  1. Строки 1–2: одинаковый знак +, но во второй строке операнды — строки, и цифры склеиваются.
  2. Строка 3: мотив AT повторен три раза.
  3. Строка 4: в последовательности GATTACA семь нуклеотидов.

Типичная ошибка: строка и число в одном выражении

Неверно: склейка с числом
print('Длина: ' + 7)  # → ошибка: TypeError
Сообщение об ошибке
Traceback (most recent call last):
  File "mistake.py", line 1, in <module>
    print('Длина: ' + 7)
          ~~~~~~~~~~^~~
TypeError: can only concatenate str (not "int") to str
Верно
print('Длина: ' + str(7))  # → Длина: 7
Вывод
Длина: 7

Python не переводит число в строку сам. Функция str() из следующего раздела делает это явно. На странице 09 появится более удобный способ: f-строки.

3. Явное преобразование

Теория

Python никогда не истолковывает содержимое строки как число сам: выражение '37' + '42' склеивает строки в '3742'. Чтобы посчитать, строку нужно явно преобразовать функцией нужного типа.

ВызовРезультатЧто делает
int('101')101строка с целым числом в int
int('101', 2)5строка с двоичной записью в int
int(42.9)42отбрасывает дробную часть, не округляет
float('4.2')4.2строка в float
float(42)42.0целое в float
str(42)'42'любое значение в строку

Второй аргумент int() задает основание системы счисления, в которой записана строка. Результат всегда обычное целое число и печатается в десятичной записи.

Схема преобразований: вверх, в строку, ведет str(); вниз, из строки в число, ведут int() и float(); между числами тоже int() и float(). Функция int() у вещественного числа отбрасывает дробную часть: int(42.9) дает 42, а не 43. Для отрицательных чисел отбрасывание тоже идет к нулю: int(-3.5) дает -3 (страница 06).

Пример

Склеить или сложить

convert.py
a = '37'
b = '42'
print(a + b)            # → 3742
print(int(a) + int(b))  # → 79
Вывод
3742
79
  1. Имя a связано со строкой из двух символов.
  2. Имя b тоже со строкой.
  3. Операнды — строки, поэтому + склеивает их.
  4. Каждая строка сначала превращается в число, затем числа складываются: 37 + 42 = 79.

Преобразования по таблице

convert_more.py
print(int('101', 2))  # → 5
print(int(42.9))      # → 42
print(float(42))      # → 42.0
print(str(42) + '0')  # → 420
Вывод
5
42
42.0
420
  1. Строка 1: 101₂ = 1 · 4 + 0 · 2 + 1 = 5.
  2. Строка 2: дробная часть отброшена, результат 42.
  3. Строка 3: целое стало вещественным, появилась точка.
  4. Строка 4: после str(42) знак + склеивает строки: получилось 420, а не 42.
Практика

Замените в третьей строке + на * и запустите: какая получилась ошибка? Затем исправьте программу так, чтобы вторая строка печатала ATATAT, а не ошибку.

try_convert.py
motif = 'AT'
times = '3'
print(motif + times)  # → AT3
Вывод
AT3

4. Два разных отказа

Теория

Преобразование может не удаться двумя разными способами, и название ошибки уже ставит диагноз.

СитуацияПримерРезультатЧто делать
все сходитсяint('126') / 342.0продолжать работу
тип верный, содержимое негодноеint('hello')ValueErrorпроверять данные до преобразования
тип вообще не тот'126' / 3TypeErrorпреобразовать тип или исправить логику

int() принимает строку только с записью целого числа. Строку '42.9' она не примет (ValueError), хотя число 42.9 примет. Поэтому целую часть из такой строки получают в два шага: int(float('42.9')).

Пример

Целая часть из строки

two_steps.py
s = '42.9'
x = float(s)
print(x)       # → 42.9
print(int(x))  # → 42
Вывод
42.9
42
  1. Строка 2: строка превращается в вещественное число.
  2. Строка 4: у числа отбрасывается дробная часть. Вызов int(s) сразу со строкой завершился бы ошибкой.

Типичная ошибка: int() от строки с точкой

Неверно: ValueError
print(int('42.9'))  # → ошибка: ValueError
Сообщение об ошибке
Traceback (most recent call last):
  File "mistake.py", line 1, in <module>
    print(int('42.9'))
          ^^^^^^^^^^^
ValueError: invalid literal for int() with base 10: '42.9'
Верно
print(int(float('42.9')))  # → 42
Вывод
42

Содержимое '42.9' не является записью целого числа, и int() честно отказывается. Последняя строка сообщения говорит, что именно не так: негодная запись '42.9' для целого числа в десятичной системе.

5. Истина и ложь

Необходимый минимум

Истинность значений понадобится в условиях. Подробно она разбирается в теме 3 «Логика и ветвления».

Теория

Тип bool имеет ровно два значения: True и False. Функция bool() показывает, считается ли значение истинным. Ложью считаются False, число 0 (и 0.0), пустая строка '' и None; истиной все остальное, в том числе любое ненулевое число и любая непустая строка.

Проверка на истинность склеивает разные ситуации: пустая строка и отсутствие значения (None) обе дают ложь, хотя означают разное. На это наталкиваются в условиях if; условия разбираются в теме 3.

Пример

Что считается ложью

truth.py
print(bool(0))    # → False
print(bool(''))   # → False
print(bool('0'))  # → True
print(bool(-1))   # → True
Вывод
False
False
True
True
  1. Строки 1–2: ноль и пустая строка ложны.
  2. Строка 3: '0' — непустая строка из одного символа, поэтому истина.
  3. Строка 4: любое ненулевое число, даже отрицательное, истинно.
