Выход из цикла

25 минутЕрофеев А. И.

Завершать поиск командой break, пропускать ненужные элементы командой continue и проверять после цикла, нашлось ли искомое.

1. Поиск до первой находки

Теория

Когда первая N найдена, остальные буквы проверять незачем, а их может быть миллион. Нужно уметь выйти из цикла раньше, чем кончились элементы.

Команда break сразу завершает ближайший цикл, в котором стоит; выполнение продолжается со строки после цикла. После break переменная цикла for хранит элемент, на котором цикл остановился.

Линейный поиск — перебор элементов по порядку до первой находки.

Если искомого нет, break не сработает, и после цикла переменная цикла укажет на последний элемент. По ней одной не понять, нашлось ли искомое: нужна отдельная проверка (раздел 2).

Пример

Первая неоднозначная буква

first_ambiguous.py
seq = "ACGTRACN"
for i in range(len(seq)):
    if seq[i] not in "ACGT":
        break
print(i, seq[i])  # → 4 R
Вывод
4 R
  1. Строки 3–4: на i = 4 буква R не входит в ACGT, и break завершает цикл; буквы после R не проверялись.
  2. Строка 5: i хранит индекс, на котором цикл остановился. Для строки "ACGT" программа напечатала бы 3 T, хотя неоднозначных букв там нет.
ШагСтрокаЗначения переменныхВывод
12–3i = 0, A входит в ACGT
22–3i = 1, C входит
32–3i = 2, G входит
42–3i = 3, T входит
52–4i = 4, R не входит, break
65i = 44 R
Практика

Замените строку на "ACGT" и запустите: убедитесь, что программа «находит» букву, которой нет. Затем поставьте N первой буквой.

try_search.py
seq = "GGYTA"
for i in range(len(seq)):
    if seq[i] not in "ACGT":
        break
print(i, seq[i])  # → 2 Y
Вывод
2 Y

2. Два выхода из цикла

Теория

У цикла два выхода: элементы кончились или сработал break. Чтобы после цикла узнать, каким выходом он закончился, есть два способа.

Первый способ: ветвь else цикла. Она пишется на уровне for, а не if, и выполняется, только если цикл закончился без break.

Ветвь else цикла выполняется, когда элементы кончились, и не выполняется после break; для пустой строки она тоже выполняется.

Второй способ: флаг. До цикла found = False, перед break found = True, после цикла обычная проверка if found: или if not found:.

Документация Python приводит else цикла как прием для поиска. В книге «Effective Python» советуют его избегать: слово else легко понять наоборот, как «если цикл не выполнился». Флаг длиннее на две строки, но читается однозначно. Пользуйтесь тем, что вам понятнее, и умейте читать оба.

  1. Ветвь else цикла стоит с тем же отступом, что и for.
  2. Итераций не было, значит, не было и break: для пустой строки else выполняется.
  3. Пустую строку, если она не должна считаться допустимой, проверяют до цикла: if not seq:.
Пример

Проверка алфавита: for и else

alphabet.py
seq = "ACGTTGCA"
for base in seq:
    if base not in "ACGT":
        print("недопустимая:", base)
        break
else:
    print("все буквы допустимы")  # → все буквы допустимы
Вывод
все буквы допустимы
  1. Строки 3–5: при первой недопустимой букве программа печатает ее и выходит из цикла.
  2. Строки 6–7: else стоит на уровне for. Здесь break не сработал, поэтому ветвь выполнилась. При seq = "ACGN" программа напечатала бы недопустимая: N, и else не выполнился бы.

То же с флагом

alphabet_flag.py
seq = "ACGN"
found = False
for base in seq:
    if base not in "ACGT":
        found = True
        break
if found:
    print("недопустимая:", base)  # → недопустимая: N
else:
    print("все буквы допустимы")
Вывод
недопустимая: N
  1. Строка 2: до цикла флаг говорит «не найдено».
  2. Строка 5: перед break флаг ставится в True.
  3. Строки 7–10: обычное ветвление после цикла; else здесь относится к if.

Пустая строка

Предскажите вывод: был ли в цикле break?

empty.py
seq = ""
for base in seq:
    if base not in "ACGT":
        break
else:
    print("все буквы допустимы")  # → все буквы допустимы
Вывод
все буквы допустимы
  1. Строка 2: итераций нет, значит, нет и break, поэтому ветвь else выполняется. Пустую строку проверяют отдельно, до цикла: if not seq:.

Упражнение 4.4.1. Первая буква N

Условие задачи

Найдите позицию первой буквы N в последовательности; позиции нумеруются с 1. Остановите цикл командой break, как только буква найдена.

Входные данные

Одна строка из заглавных латинских букв длиной от 1 до 100.

Выходные данные

Позиция первой буквы N или 0, если буквы N в строке нет.

Пример

Разберем пример

Ввод ACGNTN
→
Вывод 4

Первая N стоит на позиции 4; цикл перебирает буквы по порядку и останавливается на ней командой break.

Примеры
ВводВывод
 
ACGNTN
4
GATTACA
0
Контекст

Позиция на единицу больше индекса: seq[index] стоит в позиции index + 1. Цикл по индексам останавливают командой break при первой же букве N, а если N нет, переменная позиции остается нулем.

Основные определения

  • Позиция — номер нуклеотида; нумерация начинается с 1.
  • Индекс — номер символа в строке; нумерация начинается с 0.
  • Команда break — немедленно завершает цикл.
  • N — код IUPAC, который означает любой нуклеотид.
Подсказка
  1. Прочитайте последовательность: seq = input(); заведите pos = 0.
  2. Перебирайте индексы: for index in range(len(seq)):.
  3. При первой N запишите позицию pos = index + 1 и выйдите из цикла через break.
  4. Выведите pos; сверьтесь с примером: ACGNTN дает 4, а GATTACA — 0.

Упражнение 4.4.1. Проверка алфавита

Условие задачи

Проверьте, что последовательность состоит только из букв A, C, G, T. Если это так, выведите OK. Иначе выведите первую недопустимую букву и ее позицию (нумерация с 1) через пробел. Пустая строка не считается последовательностью: для нее выведите EMPTY.

Входные данные

Одна строка из заглавных латинских букв длиной от 0 до 100.

Выходные данные

OK, EMPTY или буква и позиция через пробел.

Пример

Разберем пример

Ввод ACGTRAC
→
Вывод R 5

Буква R не входит в алфавит A, C, G, T и стоит на позиции 5; проверка останавливается на первой недопустимой букве.

Примеры
ВводВывод
 
ACGTRAC
R 5
(пустая строка)
EMPTY
Контекст

Пустая строка ложна, поэтому проверка not seq отсекает ее до цикла. Дальше цикл перебирает индексы и при первой букве вне ACGT записывает ответ и выходит через break; если выход не случился, ответ остается OK.

Основные определения

  • Алфавит — набор допустимых букв; здесь A, C, G и T.
  • Пустая строка — строка без символов; она ложна в условии.
  • Оператор not in — истинен, когда символ не встречается в строке.
  • Команда break — немедленно завершает цикл.
Подсказка
  1. Прочитайте строку: seq = input().
  2. Пустой случай разберите первым: if not seq: answer = "EMPTY", иначе answer = "OK".
  3. В цикле по индексам ищите недопустимую букву: if seq[index] not in "ACGT": — запишите f"{seq[index]} {index + 1}" и выйдите через break.
  4. Выведите answer; сверьтесь с примером: ACGTRAC дает R 5, а пустая строка — EMPTY.

Упражнение 4.4.1. Открытая рамка считывания

Условие задачи

Дано. Строка из букв A, C, G, T. Кодоном называют тройку подряд идущих букв. Старт-кодон ATG, стоп-кодоны TAA, TAG, TGA.

Найти. Найдите первое вхождение ATG и остановите поиск командой break. От найденного ATG читайте кодоны по три буквы до первого стоп-кодона. Посчитайте кодоны от ATG до стопа, включая ATG; стоп-кодон не считается.

Ответ. Число кодонов или NO.

Границы. Если ATG нет, после ATG не хватает букв на полный кодон или стоп-кодон не встретился, выведите NO. Стоп-кодон ищите только в рамке, заданной первым ATG, а не в любом месте строки.

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

Одно число или NO.

Пример

Разберем пример

Ввод CCATGGCCTAAGT
→
Вывод 2

Рамка начинается с ATG (позиция 3) и читается тройками: ATG, GCC, затем TAA — стоп. Стоп-кодон не считается, поэтому кодонов два.

Примеры
ВводВывод
 
CCATGGCCTAAGT
2
ATGCCC
NO
Контекст

Рамку задает сам ATG: сначала цикл ищет его срезом seq[index:index + 3], затем второй цикл идет от найденного места шагом 3. Стоп-кодоны TAA, TAG и TGA обрывают счет, причем стоп в ответ не входит. Если ATG нет, букв не хватает на кодон или стопа нет, ответ NO.

Основные определения

  • Открытая рамка считывания — участок от ATG до стоп-кодона, прочитанный тройками.
  • ATG — стартовый кодон, с которого начинается рамка.
  • Стоп-кодон — TAA, TAG или TGA; завершает рамку и в счет не входит.
  • Срез — кусок строки, вырезанный по индексам.
  • Команда break — немедленно завершает цикл.
Подсказка
  1. Прочитайте последовательность: seq = input(); заведите result = "NO" и start = -1.
  2. Ищите первое ATG срезом: for index in range(len(seq) - 2): — при seq[index:index + 3] == "ATG" запомните start и выйдите через break.
  3. Если start >= 0, читайте кодоны шагом 3: codon_start пробегает range(start, len(seq) - 2, 3); при стоп-кодоне запишите в result текущий счет и выйдите.
  4. Иначе счет увеличивайте на единицу за кодон; выведите result; сверьтесь с примером: CCATGGCCTAAGT дает 2, а ATGCCC — NO.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.

3. Пропуск шага

Теория

Команда continue пропускает остаток тела и переходит к следующей итерации: в for к следующему элементу, в while к проверке условия. Цикл при этом продолжается.

break и continue действуют только на ближайший цикл, внутри которого стоят.

continue удобен, когда часть элементов нужно отбросить, например буквы N или строки-заголовки FASTA. Проверка «этот элемент не нужен» стоит в начале тела, а вся обработка нужных элементов идет ниже без лишнего отступа. Без continue ту же программу пишут через if с обработкой внутри ветви: результат тот же, но код уходит вправо.

Пример

Последовательность без N

skip_n.py
seq = "GGNCANNT"
for base in seq:
    if base == "N":
        continue
    print(base, end="")
print()
Вывод
GGCAT
  1. Строки 3–4: для N остаток тела пропускается, и цикл переходит к следующей букве.
  2. Строка 5: выполняется только для букв, которые не N.

continue в цикле while

Программа ждет ввода. Пользователь набирает >seq1, ACGT, done.

skip_headers.py
while True:
    line = input()
    if line == "done":
        break
    if line.startswith(">"):
        continue
    print(len(line))  # → 4
Вывод
>seq1
ACGT
4
done
  1. Строки 3–4: стоп-слово завершает цикл.
  2. Строки 5–6: заголовок пропускается: continue возвращает выполнение к строке 1, и читается следующая строка.
Практика

Замените continue на break и сравните вывод.

try_continue.py
seq = "ACNGT"
for base in seq:
    if base == "N":
        continue
    print(base, end="")
print()
Вывод
ACGT

Упражнение 4.4.2. Без пропусков

Условие задачи

Чтобы сравнить две последовательности, их выравнивают: записывают одну под другой так, чтобы похожие участки стояли друг под другом, и для этого вставляют пропуски. Пропуски обозначены дефисом -; выравнивание подробно разбирается в теме 15 «Выравнивание последовательностей». Выведите последовательность без пропусков. Пропускайте дефисы командой continue, остальные буквы печатайте по одной.

Входные данные

Одна строка из букв A, C, G, T и дефисов длиной от 1 до 100; хотя бы одна буква в ней есть.

Выходные данные

Последовательность без дефисов одной строкой.

Пример

Разберем пример

Ввод AC-GT--A
→
Вывод ACGTA

Три дефиса пропускаются командой continue, остальные буквы печатаются по одной.

Примеры
ВводВывод
 
AC-GT--A
ACGTA
TTAG
TTAG
Контекст

Команда continue пропускает остаток тела цикла и переходит к следующей букве, поэтому дефисы в вывод не попадают. Буквы печатают подряд через end="", а после цикла добавляют перевод строки.

Основные определения

  • Выравнивание — запись двух последовательностей одну под другой с пропусками.
  • Пропуск — дефис, который вставляет выравнивание.
  • Команда continue — пропускает остаток тела цикла и переходит к следующему шагу.
  • Параметр end у print() — задает, чем заканчивается вывод; end="" печатает без перевода строки.
Подсказка
  1. Прочитайте строку: seq = input().
  2. Пройдите по буквам циклом: for base in seq:.
  3. Дефис пропускайте: if base == "-": continue.
  4. Остальные буквы печатайте через print(base, end=""), после цикла добавьте print(); сверьтесь с примером: AC-GT--A дает ACGTA.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.

Упражнение 4.4.2. FASTA в одну строку

Условие задачи

В FASTA последовательность записана на нескольких строках, а строки, которые начинаются с >, являются заголовками. Программа читает строки до строки done. Выведите все буквы последовательностей одной строкой, пропуская заголовки командой continue.

Входные данные

Несколько строк: заголовки, которые начинаются с >, и строки из букв A, C, G, T; последней идет строка done. Хотя бы одна строка с буквами есть.

Выходные данные

Буквы всех строк последовательностей подряд, одной строкой.

Пример

Разберем пример

Ввод >seq1
ACGT
GGTA
done
→
Вывод ACGTGGTA

Строка-заголовок >seq1 пропускается, буквы ACGT и GGTA склеиваются подряд; done завершает чтение.

Примеры
ВводВывод
 
>seq1
ACGT
GGTA
done
ACGTGGTA
TTAG
done
TTAG
Контекст

Заголовки FASTA начинаются со знака >, и их узнают методом startswith(). Строку done проверяют первой и выходят через break; заголовки пропускают командой continue, а буквы печатают без перевода строки.

Основные определения

  • FASTA — формат записи последовательностей: заголовок и строки с буквами.
  • Заголовок — строка, которая начинается со знака >.
  • Метод startswith() — проверяет, начинается ли строка с заданного куска.
  • Команда continue — пропускает остаток тела цикла.
Подсказка
  1. Читайте в бесконечном цикле: while True: — первой строкой тела line = input().
  2. При стоп-слове выходите: if line == "done": break.
  3. Заголовок пропускайте: if line.startswith(">"): continue.
  4. Буквы печатайте через print(line, end=""), после цикла добавьте print(); сверьтесь с примером: >seq1, ACGT, GGTA и done дают ACGTGGTA.

Упражнение 4.4.2. Первое прочтение с мотивом

Условие задачи

Прочтение — участок ДНК, который секвенатор (прибор для чтения ДНК) прочитал за один раз и выдал строкой букв. Буквой N секвенатор отмечает позицию, которую не смог прочитать. Мотивом называют короткую последовательность, которую ищут внутри прочтений. В первой строке мотив, дальше прочтения, по одному в строке, до строки done. Прочтения нумеруются с 1 подряд, в том числе те, в которых есть буква N. Прочтения с буквой N ненадежны: их нужно пропустить командой continue. Выведите номер первого прочтения без N, в котором встречается мотив, или 0, если такого нет. Программа читает все строки до done, даже если подходящее прочтение уже найдено: не завершайте программу досрочно.

Входные данные

В первой строке мотив из букв A, C, G, T, дальше от 0 до 20 прочтений из букв A, C, G, T, N, затем строка done.

Выходные данные

Номер прочтения или 0.

Пример

Разберем пример

Ввод GAT
ACGT
TTGNATG
CCGATA
GATT
done
→
Вывод 3

Прочтение 2 содержит N и пропускается; первое надежное прочтение с мотивом GAT — третье (CCGATA), на нем поиск и останавливается.

Примеры
ВводВывод
 
GAT
ACGT
TTGNATG
CCGATA
GATT
done
3
AAA
CCC
GGG
done
0
Контекст

Номер прочтения увеличивают до всех проверок, поэтому пропущенные строки тоже считаются. Прочтения с N отбрасывает continue, а мотив ищут оператором in; первое совпадение запоминают, но цикл продолжается до строки done.

Основные определения

  • Прочтение — участок ДНК, который секвенатор прочитал за один раз.
  • Мотив — короткая последовательность, которую ищут внутри прочтений.
  • N — отметка позиции, которую секвенатор не смог прочитать.
  • Оператор in — проверяет, встречается ли подстрока в строке.
  • Команда continue — пропускает остаток тела цикла.
Подсказка
  1. Прочитайте мотив: motif = input(); заведите num = 0 и answer = 0.
  2. Читайте в бесконечном цикле: while True: — при read == "done" выходите через break.
  3. Сразу увеличьте номер, затем ненадежные прочтения пропускайте: if "N" in read: continue.
  4. Первое подходящее запоминайте: если answer == 0 и motif in read, присвойте answer = num; сверьтесь с примером: при мотиве GAT прочтения ACGT, TTGNATG, CCGATA и GATT дают 3.

Проверка на этой странице работает в браузере с JavaScript и доступом в интернет. Без них проверьте программу в редакторе сами: запустите ее, введите строки из левой колонки таблицы «Примеры» по одной, как они записаны, завершая каждую клавишей Enter, и сравните вывод с правой колонкой.

Задача со звездочкой

Необязательная задача для тех, кому хочется больше. В зачет не входит, за решение дается дополнительный опыт в игровом режиме. Вариант каждого уровня сложнее упражнения этого уровня.

Задача со звездочкой 4.4. Первая плохая позиция

Условие задачи

Секвенатор, прибор для чтения ДНК, оценивает надежность каждой прочитанной буквы. В этой задаче оценки записаны строкой цифр от 0 до 9, по одной на букву: чем больше, тем надежнее. Найдите первую позицию, где оценка ниже порога threshold, и выведите ее номер (позиции нумеруются с 1). Если таких позиций нет, выведите NO.

Входные данные

В первой строке оценки: строка цифр длиной от 1 до 100. Во второй порог threshold от 0 до 9.

Выходные данные

Номер позиции или NO.

Пример

Разберем пример

Ввод 9987654
6
→
Вывод 6

Оценки 9, 9, 8, 7 и 6 не ниже порога 6, а цифра 5 на позиции 6 уже ниже — это первая плохая позиция.

Примеры
ВводВывод
 
9987654
6
6
9999
5
NO
Контекст

Оценки записаны строкой цифр, поэтому каждую цифру переводят в число функцией int(). Ответ начинается со строки NO: первая оценка ниже порога заменяет ее номером позиции и прерывает цикл через break.

Основные определения

  • Оценка качества — надежность прочитанной буквы; цифра от 0 до 9.
  • Порог — граница threshold: оценки ниже нее считаются плохими.
  • Функция int() — читает строку из цифр как число.
  • Команда break — немедленно завершает цикл.
Подсказка
  1. Прочитайте оценки и порог: qual = input(), threshold = int(input()).
  2. Заведите answer = "NO".
  3. Перебирайте индексы: for index in range(len(qual)): — при int(qual[index]) < threshold запишите answer = index + 1 и выйдите через break.
  4. Выведите answer; сверьтесь с примером: 9987654 при пороге 6 дает 6, а 9999 при пороге 5 — NO.

Задача со звездочкой 4.4. Проверка FASTA с комментариями

Условие задачи

Формат FASTA (страница 09 практики 3): строка заголовка начинается с >, следующие строки содержат буквы последовательности. В старых файлах встречаются строки-комментарии, которые начинаются с ;, и пустые строки; их пропускают. Первая не пропущенная строка должна быть заголовком. Строка последовательности может содержать только буквы A, C, G, T, N. Строки нумеруются с 1 все подряд, вместе с пропущенными. Выведите номер первой ошибочной строки или OK, если ошибок нет.

Входные данные

Строки файла, затем строка done.

Выходные данные

Номер первой ошибочной строки или OK.

Пример

Разберем пример

Ввод >s1
ACGT
;comment
ACXT
done
→
Вывод 4

Строка 3 начинается с ; и пропускается, но номер у нее есть; строка 4 ACXT содержит X, которой нет в алфавите, поэтому ответ 4.

Примеры
ВводВывод
 
>s1
ACGT
;comment
ACXT
done
4
>s1
(пустая строка)
ACGT
done
OK
Контекст

Строки перебирают по очереди, и номер растет у всех строк, включая пропущенные. Как только найдена ошибка, дальнейшие строки не проверяются, ведь нужна первая. Заголовок обязан встретиться до строки с буквами, а буквы строки последовательности входят только в ACGTN.

Основные определения

  • FASTA — формат записи последовательностей: заголовок и строки с буквами.
  • Строка-комментарий — строка, которая начинается с точки с запятой.
  • Заголовок — строка, которая начинается со знака >.
  • Флаг header — переменная-признак: заголовок уже встретился.
  • Команда continue — пропускает остаток тела цикла.
Подсказка
  1. Заведите num = 0, bad = 0 и header = False.
  2. В цикле while True: при line == "done" выходите; иначе сразу увеличьте num, а если bad > 0, все дальнейшие строки пропускайте.
  3. Пустые строки и комментарии пропускайте через continue; строка с > ставит header = True; строка с буквами без header — ошибка: bad = num.
  4. В остальных строках ищите букву вне ACGTN; после цикла замените нулевой bad на OK и выведите; сверьтесь с примером: файл >s1, ACGT, ;comment, ACXT дает 4.

Задача со звездочкой 4.4. Чистый участок

Условие задачи

Буквой N секвенатор отмечает позицию, которую не смог прочитать. Для анализа нужен участок из size подряд идущих букв без N. Найдите самый левый такой участок и выведите позицию его первой буквы (позиции нумеруются с 1). Если такого участка нет, выведите NO.

Входные данные

В первой строке последовательность из букв A, C, G, T, N длиной от 1 до 100, во второй число size от 1 до 100.

Выходные данные

Позиция начала участка или NO.

Пример

Разберем пример

Ввод ACNNACGTN
3
→
Вывод 5

Участки из трех букв без N: ACG на позициях 5–7 и CGT на 6–8; самый левый начинается с позиции 5.

Примеры
ВводВывод
 
ACNNACGTN
3
5
NNNN
1
NO
Контекст

Длину текущего участка без N хранят в run: буква N обнуляет его, а каждая обычная буква увеличивает на единицу. Когда run достигает size, участок заканчивается на позиции index, и его начало — index - size + 2 в нумерации с единицы.

Основные определения

  • N — отметка позиции, которую секвенатор не смог прочитать.
  • Участок — несколько подряд идущих букв без N.
  • Счетчик run — длина текущего участка без N.
  • Позиция — номер нуклеотида; нумерация начинается с 1.
Подсказка
  1. Прочитайте последовательность и длину участка: seq = input(), size = int(input()).
  2. Заведите answer = "NO" и run = 0.
  3. В цикле по индексам: при seq[index] == "N" обнулите run и пропустите; иначе увеличьте run на единицу.
  4. Когда run == size, запишите начало answer = index - size + 2 и выйдите через break; сверьтесь с примером: ACNNACGTN при size = 3 дает 5, а NNNN при size = 1 — NO.
