Выход из цикла

25 минутЕрофеев А. И.

Завершать поиск командой break, пропускать ненужные элементы командой continue и проверять после цикла, нашлось ли искомое.

1. Поиск до первой находки

Теория

Когда первая N найдена, остальные буквы проверять незачем, а их может быть миллион. Нужно уметь выйти из цикла раньше, чем кончились элементы.

Команда break сразу завершает ближайший цикл, в котором стоит; выполнение продолжается со строки после цикла. После break переменная цикла for хранит элемент, на котором цикл остановился.

Линейный поиск — перебор элементов по порядку до первой находки.

Если искомого нет, break не сработает, и после цикла переменная цикла укажет на последний элемент. По ней одной не понять, нашлось ли искомое: нужна отдельная проверка (раздел 2).

Пример

Первая неоднозначная буква

first_ambiguous.py
seq = "ACGTRACN"
for i in range(len(seq)):
    if seq[i] not in "ACGT":
        break
print(i, seq[i])  # → 4 R
Вывод
4 R
  1. Строки 3–4: на i = 4 буква R не входит в ACGT, и break завершает цикл; буквы после R не проверялись.
  2. Строка 5: i хранит индекс, на котором цикл остановился. Для строки "ACGT" программа напечатала бы 3 T, хотя неоднозначных букв там нет.
ШагСтрокаЗначения переменныхВывод
12–3i = 0, A входит в ACGT
22–3i = 1, C входит
32–3i = 2, G входит
42–3i = 3, T входит
52–4i = 4, R не входит, break
65i = 44 R
Практика

Замените строку на "ACGT" и запустите: убедитесь, что программа «находит» букву, которой нет. Затем поставьте N первой буквой.

try_search.py
seq = "GGYTA"
for i in range(len(seq)):
    if seq[i] not in "ACGT":
        break
print(i, seq[i])  # → 2 Y
Вывод
2 Y

2. Два выхода из цикла

Теория

У цикла два выхода: элементы кончились или сработал break. Чтобы после цикла узнать, каким выходом он закончился, есть два способа.

Первый способ: ветвь else цикла. Она пишется на уровне for, а не if, и выполняется, только если цикл закончился без break.

Ветвь else цикла выполняется, когда элементы кончились, и не выполняется после break; для пустой строки она тоже выполняется.

Второй способ: флаг. До цикла found = False, перед break found = True, после цикла обычная проверка if found: или if not found:.

Документация Python приводит else цикла как прием для поиска. В книге «Effective Python» советуют его избегать: слово else легко понять наоборот, как «если цикл не выполнился». Флаг длиннее на две строки, но читается однозначно. Пользуйтесь тем, что вам понятнее, и умейте читать оба.

  1. Ветвь else цикла стоит с тем же отступом, что и for.
  2. Итераций не было, значит, не было и break: для пустой строки else выполняется.
  3. Пустую строку, если она не должна считаться допустимой, проверяют до цикла: if not seq:.
Пример

Проверка алфавита: for и else

alphabet.py
seq = "ACGTTGCA"
for base in seq:
    if base not in "ACGT":
        print("недопустимая:", base)
        break
else:
    print("все буквы допустимы")  # → все буквы допустимы
Вывод
все буквы допустимы
  1. Строки 3–5: при первой недопустимой букве программа печатает ее и выходит из цикла.
  2. Строки 6–7: else стоит на уровне for. Здесь break не сработал, поэтому ветвь выполнилась. При seq = "ACGN" программа напечатала бы недопустимая: N, и else не выполнился бы.

То же с флагом

alphabet_flag.py
seq = "ACGN"
found = False
for base in seq:
    if base not in "ACGT":
        found = True
        break
if found:
    print("недопустимая:", base)  # → недопустимая: N
else:
    print("все буквы допустимы")
Вывод
недопустимая: N
  1. Строка 2: до цикла флаг говорит «не найдено».
  2. Строка 5: перед break флаг ставится в True.
  3. Строки 7–10: обычное ветвление после цикла; else здесь относится к if.

Пустая строка

Предскажите вывод: был ли в цикле break?

empty.py
seq = ""

Вывод

  1. Строка 2: итераций нет, значит, нет и break, поэтому ветвь else выполняется. Пустую строку проверяют отдельно, до цикла: if not seq:.

Упражнение 4.4.1. Открытая рамка считывания

Что нужно сделать

Участок от старт-кодона до стоп-кодона, прочитанный тройками, в этой задаче называется открытой рамкой считывания. Если ATG нет или после него в рамке нет стоп-кодона, выведите NO.

3. Пропуск шага

Теория

Команда continue пропускает остаток тела и переходит к следующей итерации: в for к следующему элементу, в while к проверке условия. Цикл при этом продолжается.

break и continue действуют только на ближайший цикл, внутри которого стоят.

continue удобен, когда часть элементов нужно отбросить, например буквы N или строки-заголовки FASTA. Проверка «этот элемент не нужен» стоит в начале тела, а вся обработка нужных элементов идет ниже без лишнего отступа. Без continue ту же программу пишут через if с обработкой внутри ветви: результат тот же, но код уходит вправо.

Пример

Последовательность без N

skip_n.py
seq = "GGNCANNT"
for base in seq:
    if base == "N":
        continue
    print(base, end="")
print()
Вывод
GGCAT
  1. Строки 3–4: для N остаток тела пропускается, и цикл переходит к следующей букве.
  2. Строка 5: выполняется только для букв, которые не N.

continue в цикле while

Программа ждет ввода. Пользователь набирает >seq1, ACGT, done.

skip_headers.py
while True:
    line = input()
    if line == "done":
        break
    if line.startswith(">"):
        continue
    print(len(line))  # → 4
Вывод
>seq1
ACGT
4
done
  1. Строки 3–4: стоп-слово завершает цикл.
  2. Строки 5–6: заголовок пропускается: continue возвращает выполнение к строке 1, и читается следующая строка.
Практика

Замените continue на break и сравните вывод.

try_continue.py
seq = "ACNGT"
for base in seq:
    if base == "N":
        continue
    print(base, end="")
print()
Вывод

Упражнение 4.4.2. Первое прочтение с мотивом

Что нужно сделать

Прочтение — участок ДНК, который секвенатор (прибор для чтения ДНК) прочитал за один раз и выдал строкой букв. Буквой N секвенатор отмечает позицию, которую не смог прочитать. Мотивом называют короткую последовательность, которую ищут внутри прочтений. В первой строке мотив, дальше прочтения, по одному в строке, до строки done. Прочтения нумеруются с 1 подряд, в том числе те, в которых есть буква N. Прочтения с буквой N ненадежны: их нужно пропустить. Выведите номер первого прочтения без N, в котором встречается мотив, или 0, если такого нет. Программа читает все строки до done.

Входные данные

  3. Загрузите папку t4_04 в свой репозиторий внутрь папки projects_4 и отправьте изменения до срока. Итоговая проверка добавляет закрытые тесты, которых нет на странице: программа должна правильно работать на любых допустимых входных данных, а не только на примерах.
