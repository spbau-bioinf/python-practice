Цикл while

25 минутЕрофеев А. И.

Повторять действие, пока верно условие, и останавливать цикл по событию, а не по концу последовательности.

1. Повторение, пока верно условие

Теория

Цикл for делает столько итераций, сколько элементов в последовательности. Но бывает, что число повторений заранее неизвестно: при чтении ввода не сказано, сколько будет строк, а при удвоении культуры неизвестно, сколько удвоений нужно до тысячи клеток. Остановиться нужно, когда наступит событие, а не когда кончатся элементы.

Цикл while повторяет тело, пока условие истинно. Условие проверяется перед каждой итерацией; если оно ложно с самого начала, тело не выполнится ни разу.

Цикл while перед каждой итерацией вычисляет условие и выполняет тело, если оно истинно; когда условие стало ложным, выполнение продолжается со строки после цикла.

while i < len(seq):
    …

Переменную, от которой зависит условие, программист задает до цикла и сам меняет в теле. Цикл for сам переходит к следующему элементу, а while нет.

  1. Условие проверяется только перед итерацией, а не непрерывно. Если внутри тела условие стало ложным, тело все равно доработает до конца.
  2. После каждой итерации выполнение возвращается к заголовку и снова вычисляет условие.
  3. Если условие ложно с самого начала, тело не выполнится ни разу, как у for по пустой строке.
Пример

Обход строки через while

walk_while.py
seq = "GATC"
i = 0
while i < len(seq):
    print(seq[i], end=" ")
    i = i + 1
print()
print("i =", i)  # → i = 4
Вывод
G A T C 
i = 4
  1. Строка 2: начальное значение индекса задает программист.
  2. Строка 3: перед каждой итерацией проверяется, не вышел ли индекс за конец строки.
  3. Строка 5: шаг индекса тоже задает программист. Последней прочитана буква seq[3]; после нее i стало 4, и условие ложно.

Когда проверяется условие

Предскажите вывод. Когда именно проверяется условие n > 0?

minus_three.py
n = 10
while n > 0:
    n = n - 3
    print(n, end=" ")
print()
Вывод

  1. Строка 2: условие проверяется только перед итерацией.
  2. Строки 3–4: на четвертой итерации n стало −2 уже внутри тела, но print() все равно выполнился. Всего 4 итерации; перед пятой условие ложно.

2. Бесконечный цикл и while True

Теория

Тело цикла должно менять переменную, от которой зависит условие. Если забыть i = i + 1, условие всегда истинно, и цикл не кончится. Такой цикл называют бесконечным. Зависшую программу в терминале останавливают клавишами Ctrl+C, в PyCharm кнопкой Stop (красный квадрат) в окне запуска. Перед запуском спросите себя: что сделает условие ложным?

Иногда выход удобнее проверять не в заголовке, а в середине или в конце тела: например, сначала прочитать строку, потом решить, последняя ли она. Тогда пишут while True, условие которого всегда истинно, а выходят командой break: она сразу завершает цикл. Тело такого цикла выполнится хотя бы один раз. Подробно о break на странице 04.

Как выбрать цикл. Если известно, по чему идти (буквы строки, числа range()), берите for: число итераций равно числу элементов, и переходить к следующему элементу Python будет сам. Если нужно повторять до события (ввод до стоп-слова, рост до порога), берите while. В учебнике «Python for Everybody» for называют определенным циклом, а while неопределенным.

Пример

Удвоение до порога

doubling.py
n = 1
steps = 0
while True:
    n = n * 2
    steps = steps + 1
    if n > 1000:
        break
print(steps, n)  # → 10 1024
Вывод
10 1024
  1. Строка 3: условие True никогда не станет ложным; выход только через break.
  2. Строка 5: steps считает итерации: до цикла 0, на каждой итерации плюс 1.
  3. Строки 6–7: проверка стоит в конце тела. После десятого удвоения n равно 1024, и break завершает цикл.

Ввод до стоп-слова

Программа ждет ввода. Пользователь набирает GATTACA, затем ACG, затем done, каждый раз нажимая Enter.

until_done.py
while True:
    line = input()
    if line == "done":
        break
    print(len(line))
Вывод
GATTACA
7
ACG
3
done
  1. Строка 2: строка читается в начале каждой итерации.
  2. Строки 3–4: сразу после чтения проверяется, не стоп-слово ли это; на done цикл завершается, и строка 5 для нее не выполняется.
  3. Строка 5: для остальных строк печатается длина.

Типичная ошибка: тело не меняет условие

Неверно: цикл не кончается
seq = "GATC"
i = 0
while i < len(seq):
    print(seq[i], end=" ")
Верно
seq = "GATC"
i = 0
while i < len(seq):
    print(seq[i], end=" ")
    i = i + 1
Вывод
G A T C

В неверном варианте i всегда 0, условие всегда истинно, и программа бесконечно печатает G. Остановите ее в терминале клавишами Ctrl+C или кнопкой Stop в PyCharm.
