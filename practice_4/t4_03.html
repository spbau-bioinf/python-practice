Цикл while

25 минутЕрофеев А. И.

Повторять действие, пока верно условие, и останавливать цикл по событию, а не по концу последовательности.

1. Повторение, пока верно условие

Теория

Цикл for делает столько итераций, сколько элементов в последовательности. Но бывает, что число повторений заранее неизвестно: при чтении ввода не сказано, сколько будет строк, а при удвоении культуры неизвестно, сколько удвоений нужно до тысячи клеток. Остановиться нужно, когда наступит событие, а не когда кончатся элементы.

Цикл while повторяет тело, пока условие истинно. Условие проверяется перед каждой итерацией; если оно ложно с самого начала, тело не выполнится ни разу.

Цикл while перед каждой итерацией вычисляет условие и выполняет тело, если оно истинно; когда условие стало ложным, выполнение продолжается со строки после цикла.

while i < len(seq):
    …

Переменную, от которой зависит условие, программист задает до цикла и сам меняет в теле. Цикл for сам переходит к следующему элементу, а while нет.

  1. Условие проверяется только перед итерацией, а не непрерывно. Если внутри тела условие стало ложным, тело все равно доработает до конца.
  2. После каждой итерации выполнение возвращается к заголовку и снова вычисляет условие.
  3. Если условие ложно с самого начала, тело не выполнится ни разу, как у for по пустой строке.
Пример

Обход строки через while

walk_while.py
seq = "GATC"
i = 0
while i < len(seq):
    print(seq[i], end=" ")
    i = i + 1
print()
print("i =", i)  # → i = 4
Вывод
G A T C 
i = 4
  1. Строка 2: начальное значение индекса задает программист.
  2. Строка 3: перед каждой итерацией проверяется, не вышел ли индекс за конец строки.
  3. Строка 5: шаг индекса тоже задает программист. Последней прочитана буква seq[3]; после нее i стало 4, и условие ложно.

Когда проверяется условие

Предскажите вывод. Когда именно проверяется условие n > 0?

  2. Строки 3–4: на четвертой итерации n стало −2 уже внутри тела, но print() все равно выполнился. Всего 4 итерации; перед пятой условие ложно.

Упражнение 4.3.1. Удвоение культуры

Условие задачи

В модели роста культуры число клеток в пробирке удваивается каждый час; вначале клетка одна. Через сколько часов клеток станет не меньше target? Удваивайте число клеток в цикле while, пока оно меньше target, и считайте часы.

Входные данные

Целое число target, 1 ≤ target ≤ 109.

Выходные данные

Число часов.

Разберем пример

Ввод 100
→
Вывод 7

Контекст

Клетки делятся пополам: за час из одной клетки получается две. Пока число клеток меньше target, тело цикла while удваивает его и считает час; при target = 1 цикл не выполнится ни разу, и ответ 0.

Основные определения

  • Культура — клетки, растущие в пробирке или на среде.
  • Цикл while — повторяет тело, пока условие истинно.
  • Удвоение — каждый час число клеток становится вдвое больше.
  • Счетчик часов — переменная, которая растет на единицу за каждый час.
Подсказка
  1. Прочитайте target: target = int(input()).
  2. Заведите cells = 1 и hours = 0.
  3. Цикл идет, пока клеток меньше цели: while cells < target: — внутри удвойте cells = cells * 2 и добавьте час.
  4. Выведите hours; сверьтесь с примером: при target = 100 получается 7, а при target = 1 — 0.

Упражнение 4.3.1. Делимость на 2

Условие задачи

Сколько раз целое число number можно разделить на 2 нацело, прежде чем получится нечетное число? Например, 48 делится 4 раза: 48, 24, 12, 6, 3.

Входные данные

Целое число number, 1 ≤ number ≤ 109.

Выходные данные

Число делений.

Пока число четное, его делят нацело на 2, потому что остаток от деления на 2 равен нулю. Четность служит условием продолжения цикла while: нечетное число его останавливает, и счетчик делений выводится.

  • Четное число — число, которое делится на 2 без остатка.

  2. Заведите счетчик count = 0.
  3. Делите, пока число четное: while number % 2 == 0: — внутри number = number // 2 и count = count + 1.
  4. Выведите count; сверьтесь с примером: 48 дает 4, а 7 — 0.

Упражнение 4.3.1. Двоичная запись

Условие задачи

В двоичной системе число записывается по степеням двойки: 6 = 1 · 4 + 1 · 2 + 0 · 1, поэтому двоичная запись числа 6 это 110. Компьютер хранит числа именно так. Выведите двоичную запись числа number без ведущих нулей. Функции bin(), format() и запись f"{number:b}" не используйте.

Входные данные

Целое число number от 0 до 1 000 000 000.

Выходные данные

Двоичная запись числа одной строкой.

Пример

Разберем пример

Ввод 6
→
Вывод 110

6 = 4 + 2 + 0 · 1, поэтому запись 110. Остатки от деления на 2 дают цифры справа налево: 6 % 2 = 0, 3 % 2 = 1, 1 % 2 = 1.

Примеры
ВводВывод
 
6
110
1
1
Контекст

Остаток number % 2 дает младший двоичный разряд, а number // 2 сдвигает число на разряд вправо. Цифры появляются от младших к старшим, поэтому каждую новую приписывают слева. Особый случай — ноль: его записывают как 0.

Основные определения

  • Двоичная система — запись числа по степеням двойки: только цифры 0 и 1.
  • Разряд — одна цифра двоичной записи.
  • Оператор % — остаток от деления; number % 2 дает младшую цифру.
  • Оператор // — целочисленное деление; number // 2 отбрасывает младшую цифру.
Подсказка
  1. Прочитайте number: number = int(input()).
  2. Ноль — особый случай: if number == 0: bits = "0", иначе заведите пустую строку bits = "".
  3. В цикле while number > 0: припишите слева младшую цифру: bits = str(number % 2) + bits, затем отбросьте ее: number = number // 2.
  4. Выведите bits; сверьтесь с примером: 6 дает 110, а 1 — 1.

2. Бесконечный цикл и while True

Теория

Тело цикла должно менять переменную, от которой зависит условие. Если забыть i = i + 1, условие всегда истинно, и цикл не кончится. Такой цикл называют бесконечным. Зависшую программу в терминале останавливают клавишами Ctrl+C, в PyCharm кнопкой Stop (красный квадрат) в окне запуска. Перед запуском спросите себя: что сделает условие ложным?

Иногда выход удобнее проверять не в заголовке, а в середине или в конце тела: например, сначала прочитать строку, потом решить, последняя ли она. Тогда пишут while True, условие которого всегда истинно, а выходят командой break: она сразу завершает цикл. Тело такого цикла выполнится хотя бы один раз. Подробно о break на странице 04.

Как выбрать цикл. Если известно, по чему идти (буквы строки, числа range()), берите for: число итераций равно числу элементов, и переходить к следующему элементу Python будет сам. Если нужно повторять до события (ввод до стоп-слова, рост до порога), берите while. В учебнике «Python for Everybody» for называют определенным циклом, а while неопределенным.

Пример

Удвоение до порога

doubling.py
n = 1
steps = 0
while True:
    n = n * 2
    steps = steps + 1
    if n > 1000:
        break
print(steps, n)  # → 10 1024
Вывод

  1. Строка 3: условие True никогда не станет ложным; выход только через break.
  2. Строка 5: steps считает итерации: до цикла 0, на каждой итерации плюс 1.
  3. Строки 6–7: проверка стоит в конце тела. После десятого удвоения n равно 1024, и break завершает цикл.

Ввод до стоп-слова

Программа ждет ввода. Пользователь набирает GATTACA, затем ACG, затем done, каждый раз нажимая Enter.

until_done.py
while True:
    line = input()
    if line == "done":
        break
    print(len(line))
Вывод
GATTACA
7
ACG
3
done
  1. Строка 2: строка читается в начале каждой итерации.
  2. Строки 3–4: сразу после чтения проверяется, не стоп-слово ли это; на done цикл завершается, и строка 5 для нее не выполняется.
  3. Строка 5: для остальных строк печатается длина.

Типичная ошибка: тело не меняет условие

Неверно: цикл не кончается
seq = "GATC"
i = 0
while i < len(seq):
    print(seq[i], end=" ")
Верно
seq = "GATC"
i = 0
while i < len(seq):
    print(seq[i], end=" ")
    i = i + 1
Вывод
G A T C

В неверном варианте i всегда 0, условие всегда истинно, и программа бесконечно печатает G. Остановите ее в терминале клавишами Ctrl+C или кнопкой Stop в PyCharm.

Упражнение 4.3.2. Строки до done

Условие задачи

Программа читает строки, пока не встретит строку done. Выведите, сколько строк было прочитано до нее. Читайте ввод в цикле while True и выходите из него командой break.

Входные данные

Несколько строк из букв A, C, G, T, затем строка done. Строк до done может не быть совсем.

Выходные данные

Число строк до done; сама строка done не считается.

Пример

Разберем пример

Ввод GATTACA
ACGT
TTT
done
→
Вывод 3

Программа читает GATTACA, ACGT и TTT — три строки, — а на строке done выходит из цикла; сама done в счет не входит.

Примеры
ВводВывод
 
GATTACA
ACGT

0
Контекст

Бесконечный цикл while True удобен, когда число строк заранее неизвестно: строку читают, проверяют и при стоп-слове выходят из цикла командой break. Строка done в счет не входит.

Основные определения

  • Цикл while True — бесконечный цикл, выход из которого задают вручную.
  • Команда break — немедленно завершает цикл.
  • Строка-ограничитель — стоп-слово, после которого ввод заканчивается.
  • Счетчик — переменная, которая растет на единицу за каждую строку.
Подсказка
  1. Заведите счетчик count = 0.
  2. Читайте в бесконечном цикле: while True: — первой строкой тела line = input().
  3. При стоп-слове выходите: if line == "done": break, иначе увеличьте счетчик.
  4. Выведите count; сверьтесь с примером: GATTACA, ACGT, TTT и done дают 3, а одна строка done — 0.

Упражнение 4.3.2. Суммарная длина прочтений

Условие задачи

Программа получает длины прочтений по одной в строке; после последнего прочтения стоит 0. Выведите суммарную длину всех прочтений.

Входные данные

Целые положительные числа по одному в строке, затем 0. Чисел до 0 может не быть совсем.

Выходные данные

Сумма чисел до 0.

150 + 100 + 250 = 500; нуль завершает ввод и в сумму не входит.

Контекст

Секвенатор читает ДНК кусками: каждое прочтение приходит отдельной строкой. Длины идут до нуля-ограничителя: цикл while True читает число, при нуле выходит через break, а сумму накапливает.

Основные определения

  • Секвенатор — прибор, который читает ДНК и выдает прочитанные участки строками букв.
  • Прочтение — один прочитанный участок ДНК.
  • Ноль-ограничитель — нуль после последнего прочтения; сам в сумму не входит.
  • Накопление суммы — переменная, к которой прибавляют каждое новое число.

  2. Читайте в бесконечном цикле: while True: — первой строкой тела length = int(input()).
  3. При нуле выходите: if length == 0: break, иначе прибавьте длину к сумме.
  4. Выведите total; сверьтесь с примером: 150, 100, 250 и 0 дают 500, а один нуль — 0.

Упражнение 4.3.2. Число ячеек

Условие задачи

Фрагменты ДНК упаковывают в ячейки вместимостью capacity. Фрагменты поступают по одному в порядке ввода, и каждый целиком кладут в текущую ячейку, если там хватает свободного места; иначе открывают новую ячейку, а остаток прежней пропадает. Сколько ячеек понадобится?

Рекомендуемые имена. capacity для вместимости ячейки, length для длины фрагмента, cells для числа ячеек. Переменные записывают строчными буквами; заглавные буквы оставляют для констант.

Вывод 2

Контекст

Ячейка вмещает фрагменты, пока их суммарная длина не превысит capacity. Порядок фрагментов задан, поэтому упаковка идет по очереди, а остаток ячейки, в которую не влез следующий фрагмент, уже не используется.

Основные определения

  • Ячейка — емкость, в которую целиком кладут фрагменты.
  • Вместимость — наибольшая суммарная длина фрагментов в одной ячейке.
  • Свободное место — сколько длины еще поместится в текущую ячейку.
  • Строка-ограничитель — стоп-слово done, после которого ввод заканчивается.
Подсказка
  1. Прочитайте вместимость: capacity = int(input()); заведите cells = 0 и free = 0.
  2. Читайте в бесконечном цикле: while True: — первой строкой тела line = input(), при line == "done" выходите через break.
  3. Длину фрагмента читайте числом: length = int(line); если length > free, откройте ячейку: cells = cells + 1 и free = capacity.
  4. Уменьшите свободное место: free = free - length; выведите cells; сверьтесь с примером: при вместимости 1000 фрагменты 300, 400, 200 и 500 занимают 2 ячейки.

Задача со звездочкой 4.3. Сумма цифр номера

Условие задачи

У каждого образца в лаборатории есть номер, а для быстрой сверки к нему записывают сумму его цифр. Найдите сумму цифр номера циклом while, отделяя цифры арифметикой: последняя цифра числа number равна number % 10, а number // 10 отбрасывает ее. Перевод в строку здесь не нужен.

Входные данные

Целое число number от 0 до 1018.

Выходные данные

Одно число: сумма цифр.

Пример

Разберем пример

Ввод 2024
→
Вывод 8

2 + 0 + 2 + 4 = 8. Каждую цифру дает остаток n % 10, а n // 10 отбрасывает ее.

Контекст

Последняя цифра числа — остаток от деления на 10, а деление нацело на 10 отбрасывает ее. Цикл while идет, пока в числе остались цифры; ноль в цикл не заходит, и сумма остается нулевой.

Основные определения

  • Оператор % — остаток от деления; number % 10 дает последнюю цифру.
  • Оператор // — целочисленное деление; number // 10 отбрасывает последнюю цифру.
  • Сумма цифр — результат сложения всех цифр числа.
  • Номер образца — число, которым подписан образец в лаборатории.
Подсказка
  1. Прочитайте номер: number = int(input()).
  2. Заведите сумму total = 0.
  3. В цикле while number > 0: прибавьте последнюю цифру number % 10 и отбросьте ее: number = number // 10.
  4. Выведите total; сверьтесь с примером: 2024 дает 8, а 0 — 0.

Задача со звездочкой 4.3. Кролики Фибоначчи

Условие задачи

Задача из сборника Rosalind. В первый месяц есть одна пара новорожденных кроликов. Пара становится взрослой через месяц, и с этого момента каждая взрослая пара каждый месяц дает offspring новых пар. Кролики не умирают. Число пар в месяц target_month равно F(target_month) = F(target_month − 1) + offspring · F(target_month − 2), где F(1) = F(2) = 1: в следующий месяц остаются все пары и добавляется потомство всех пар, которые были два месяца назад. Найдите число пар в месяц target_month.

Входные данные

Одна строка: числа target_month (от 1 до 40) и offspring (от 1 до 5) через пробел.

Выходные данные

Одно число: сколько пар в месяц target_month.

Пример

Разберем пример

Ввод 5 3
→
Вывод 19

F₁ = F₂ = 1; F₃ = 1 + 3 · 1 = 4; F₄ = 4 + 3 · 1 = 7; F₅ = 7 + 3 · 4 = 19.

Примеры
ВводВывод
 
5 3
19
1 1
1
Контекст

Число пар растет по правилу F(target_month) = F(target_month-1) + offspring * F(target_month-2). В решении хранят два прошлых значения: older и young сдвигаются назад, а born считает новое. Цикл while идет по месяцам от 2 до target_month.

Основные определения

  • Фибоначчи — последовательность, где каждый член — сумма двух предыдущих.
  • Пара кроликов — единица счета в модели; пара становится взрослой через месяц.
  • Рекуррентная формула — правило, по которому член считается из предыдущих.
  • Сдвиг значений — старое young становится older, новое значение — young.
Подсказка
  1. Прочитайте строку и разберите числа: data = input().split(), затем target_month = int(data[0]) и offspring = int(data[1]).
  2. Заведите два прошлых значения: older = 1, young = 1, и месяц month = 2.
  3. В цикле while month < target_month: считайте новое: born = young + offspring * older, затем сдвиньте: older = young, young = born, month = month + 1.
  4. Выведите young; сверьтесь с примером: target_month = 5 и offspring = 3 дают 19, а target_month = 1 — 1.

Задача со звездочкой 4.3. Схлопывание пар

Условие задачи

Это игровая модель, не реальный процесс. Соседние комплементарные буквы образуют пару и выпадают из строки. Один проход удаляет все вхождения AT, затем все TA, затем CG, затем GC: методом replace() именно в этом порядке. После удаления пар могут сойтись новые соседи, поэтому проходы повторяют, пока строка меняется. Выведите, сколько проходов изменили строку, и что от нее осталось. Если не осталось ничего, выведите дефис.

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

В первой строке число проходов, которые изменили строку, во второй остаток строки или -.

Пример

Разберем пример

Ввод AATTG
→
Вывод 2
G

Первый проход удаляет AT из AATTG — остается ATG; второй удаляет еще одну пару AT — остается G; третий проход строку не меняет и в счет не идет.

Примеры
ВводВывод
 
AATTG
2
G
GCGC
1
-
Контекст

replace() удаляет все вхождения подстроки сразу, поэтому один проход задают цепочкой четырех замен в указанном порядке. Если после прохода строка не изменилась, пары кончились; иначе проход повторяют, ведь после удаления соседями стали другие буквы.

Основные определения

  • Комплементарные буквы — пары A — T и C — G.
  • Метод replace() — удаляет все вхождения подстроки в строке.
  • Проход — цепочка четырех замен AT, TA, CG и GC по порядку.
  • Остаток строки — то, что осталось после удаления всех пар.
Подсказка
  1. Прочитайте строку: seq = input(); заведите счетчик passes = 0.
  2. Один проход — цепочка замен в заданном порядке: четыре вызова replace подряд, пары "AT", "TA", "CG", "GC" заменяются на пустую строку.
  3. Если new == seq, выходите через break; иначе запомните new в seq и увеличьте счетчик проходов.
  4. Пустой остаток замените дефисом и напечатайте сначала passes, затем остаток; сверьтесь с примером: AATTG дает 2 и G, а GCGC — 1 и дефис.
