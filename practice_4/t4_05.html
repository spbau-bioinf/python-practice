Счетчики

25 минутЕрофеев А. И.

Собирать результат в цикле: считать буквы счетчиками, складывать значения накопителем и вычислять GC-состав.

1. Шаблон накопления

Теория

Метод count() считает одну букву, а пропустить N или сложить массы нуклеотидов он не умеет. Для этого пишут свой цикл. Он работает так же, как подсчет на бумаге: ноль в начале, плюс одна черточка на каждую нужную букву, ответ в конце.

Результат в цикле собирают по шаблону из трех шагов. До цикла переменную инициализируют: count = 0. В теле ее обновляют: count = count + 1. После цикла читают готовый ответ.

Счетчик — переменная, которая считает события: на каждом событии к ней прибавляется 1.

Накопитель — переменная, к которой прибавляют сами значения, например массы.

Без инициализации строка count = count + 1 дает NameError: на первой итерации прибавлять не к чему.

Подробнее: встроенные функции вместо цикла

Для простых случаев Python уже содержит готовые счетчики и накопители: seq.count("G"), функции sum(), max(), min(). Они работают быстрее ручного цикла, потому что написаны на C. Ручной цикл оправдан, когда правило подсчета сложнее или когда за один проход нужно собрать несколько результатов, например сразу четыре счетчика.

Пример

Счетчик гуанинов

count_g.py
seq = "GGACTGA"
g = 0
for base in seq:
    if base == "G":
        g = g + 1
print(g)  # → 3
Вывод
3
  1. Строка 2: инициализация до цикла.
  2. Строки 4–5: обновление в теле, только для букв G.
  3. Строка 6: после цикла в g готовый ответ.

Четыре счетчика за один проход

Задача DNA из Rosalind: вывести числа букв A, C, G, T через пробел. Предскажите вывод.

rosalind_dna.py
seq = "AGCTTTTCATTC"
a = c = g = t = 0
for base in seq:
    if base == "A":
        a = a + 1
    elif base == "C":
        c = c + 1
    elif base == "G":
        g = g + 1
    elif base == "T":
        t = t + 1
print(a, c, g, t)  # → 2 3 1 6
Вывод
2 3 1 6
  1. Строка 2: четыре счетчика получают 0 одной строкой.
  2. Строки 4–11: на каждой итерации увеличивается ровно один счетчик, тот, чья буква.
  3. Строка 12: то же дают четыре вызова count(), но они четыре раза проходят строку, а цикл один.

Типичная ошибка: счетчик в теле цикла

Неверно: ответ 0
seq = "GGCAT"
for base in seq:
    gc = 0
    if base in "GC":
        gc = gc + 1
print(gc)  # → 0
Вывод
0
Верно
seq = "GGCAT"
gc = 0
for base in seq:
    if base in "GC":
        gc = gc + 1
print(gc)  # → 3
Вывод
3

Строка gc = 0 в теле обнуляет счетчик на каждой итерации. Тело выполняется целиком на каждой итерации, поэтому инициализация должна стоять до цикла. Неверная программа печатает 0, потому что последняя буква T.

Практика

Сейчас программа считает итерации. Сделайте из счетчика накопитель: пусть она складывает сами числа и напечатает 15.

try_total.py
total = 0
for i in range(1, 6):
    total = total + 1
print(total)  # → 5
Вывод
5

Упражнение 4.5.1. Масса цепи

Условие задачи

Масса одной цепи ДНК складывается из масс ее звеньев, нуклеотидов. Средняя масса нуклеотида в цепи: A 313, C 289, G 329, T 304 г/моль (значения округлены до целых; источник: Thermo Fisher). Масса цепи — сумма масс ее нуклеотидов. Таблицу масс разбирают цепочкой условий: A, C и G различают ветками if и elif, а T достается последней ветке else, поэтому каждая буква добавляет ровно одну массу.

Упражнение 4.5.1. Транзиции, трансверсии и N

Условие задачи

Дано. Две строки одной длины из букв A, C, G, T, N. Буква N отмечает позицию, которую не удалось прочитать.

Найти. Пройдите по позициям циклом for и сравните строки. Если буквы совпадают, позиция не считается заменой. Если различаются, отнесите замену к транзициям или трансверсиям. Посчитайте число транзиций и число трансверсий.

Ответ. Отношение числа транзиций к числу трансверсий, округленное функцией round() до двух знаков. Если трансверсий нет, выведите NA.

Границы. Позиции с N не считаются ни транзицией, ни трансверсией. Если замен нет, трансверсий тоже нет, ответ NA.

Входные данные

Две строки одной длины от 1 до 100 из букв A, C, G, T, N.

Выходные данные

Одно число или NA.

Пример

Разберем пример

Ввод AGCTAGNT
GGTTCANC
→
Вывод 4.0

Позиции 2 и 4 совпадают, позиция 7 с N пропускается; из пяти замен четыре транзиции и одна трансверсия, поэтому отношение 4 / 1 = 4.0.

Примеры
ВводВывод
 
AGCTAGNT
GGTTCANC
4.0
ACGT
ACGT
NA
Контекст

Транзиция — замена пурина на пурин (A и G) или пиримидина на пиримидин (C и T). Любая другая замена — трансверсия. Позиции с N не считаются, а делить на ноль нельзя, поэтому при нуле трансверсий ответ NA.

Основные определения

  • Транзиция — замена A на G или C на T и обратно.
  • Трансверсия — замена пурина на пиримидин или наоборот.
  • Замена — позиция, где буквы двух строк различаются.
  • N — код IUPAC, который означает любой нуклеотид.
  • Функция round() — округляет число; второй аргумент задает число знаков.
Подсказка
  1. Прочитайте обе строки: first = input(), second = input(); заведите ts = 0 и tv = 0.
  2. В цикле по индексам сравните буквы: при first_base == "N", second_base == "N" или first_base == second_base пропускайте позицию.
  3. Транзиция — обе буквы из одной группы: first_base in "AG" и second_base in "AG", либо обе из "CT"; все остальное — трансверсия.
  4. Если tv == 0, выведите NA, иначе round(ts / tv, 2); сверьтесь с примером: AGCTAGNT и GGTTCANC дают 4.0, а две одинаковые строки — NA.

2. GC-состав

Теория

GC-состав последовательности — процент букв G и C среди ее нуклеотидов. Для него нужны два счетчика: сколько G и C и сколько нуклеотидов всего. После цикла один делят на другой и умножают на 100.

Буква N означает неизвестный нуклеотид, и в GC-состав ее не включают: такие буквы пропускают командой continue до того, как обновить счетчики.

Если в последовательности одни N, знаменатель равен 0, и деление дает ZeroDivisionError. В программе, которая обрабатывает реальные данные, этот случай проверяют до деления.

Пример

GC-состав без N

gc_content.py
seq = "GGCNNATGC"
gc = 0
known = 0
for base in seq:
    if base == "N":
        continue
    known = known + 1
    if base in "GC":
        gc = gc + 1
pct = gc / known * 100
print(round(pct, 1))  # → 71.4
Вывод
71.4
  1. Строки 5–6: обе N пропущены и не попали ни в один счетчик.
  2. Строка 7: known считает все известные нуклеотиды, их 7.
  3. Строки 10–11: 5 из 7 составляют 71,43 %; для показа число округляется до одного знака.
Практика

Добавьте в последовательность две буквы A и посмотрите, как изменится ответ. Затем запустите программу для строки "NNN" и прочитайте сообщение об ошибке.

try_gc.py
seq = "ATGCNG"
gc = 0
known = 0
for base in seq:
    if base == "N":
        continue
    known = known + 1
    if base in "GC":
        gc = gc + 1
print(round(gc / known * 100, 1))  # → 60.0
Вывод
60.0

Упражнение 4.5.2. GC-состав

Условие задачи

Найдите GC-состав последовательности: процент букв G и C среди всех букв. Посчитайте G и C в цикле, без метода count().

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

GC-состав в процентах, округленный функцией round() до одного знака.

Пример

Разберем пример

Ввод GATTACA
→
Вывод 28.6

Из семи букв G и C дают две: 2 / 7 · 100 ≈ 28.6 процента.

Примеры
ВводВывод
 
GATTACA

Контекст

GC-состав считают как долю букв G и C от длины, умноженную на 100. В цикле копят только подходящие буквы, а деление выполняют один раз после цикла, когда известны и числитель, и длина.

Основные определения

  • GC-состав — доля букв G и C в процентах от длины последовательности.
  • Оператор in — проверяет, встречается ли символ в строке.
  • Функция len() — возвращает длину строки.
  • Функция round() — округляет число; второй аргумент задает число знаков.
Подсказка
  1. Прочитайте последовательность: seq = input(); заведите gc = 0.
  2. В цикле for base in seq: считайте подходящие буквы: if base in "GC": gc = gc + 1.
  3. После цикла поделите на длину и умножьте на 100: gc / len(seq) * 100.
  4. Округлите до одного знака и выведите; сверьтесь с примером: GATTACA дает 28.6, а GGCC — 100.0.

Упражнение 4.5.2. GC-состав по строкам

Условие задачи

Последовательность записана на нескольких строках, после последней стоит строка done. Найдите GC-состав всей последовательности. Здесь можно пользоваться методом count(): цикл нужен для строк.

Входные данные

Одна или несколько строк из букв A, C, G, T, затем строка done.

Выходные данные

GC-состав в процентах, округленный функцией round() до одного знака.

done

Вывод 37.5

  • Метод count() — считает, сколько раз подстрока встречается в строке.

Упражнение 4.5.2. GC-состав с кодами IUPAC

Условие задачи

GC-состав, доля букв G и C в процентах, разобран в разделе выше. Коды IUPAC (страница 09 практики 3) обозначают позицию, где возможен один из нескольких нуклеотидов. S значит C или G, поэтому считается как целая буква G или C. W значит A или T и в GC-состав не идет. R (A или G), Y (C или T), K (G или T) и M (A или C) считаются за половину: только один из двух вариантов G или C. N значит любой нуклеотид, такая позиция не учитывается ни в числителе, ни в знаменателе. Выведите GC-состав в процентах, округленный функцией round() до одного знака. Если учитывать нечего, выведите 0.0.

Входные данные

Одна строка из букв A, C, G, T, R, Y, K, M, S, W, N длиной от 1 до 100.

Выходные данные

Одно число.

Пример

Разберем пример

Ввод GCAT
→
Вывод 50.0

G и C считаются целиком, A и T — нет: 2 / 4 · 100 = 50.0.

Примеры
ВводВывод
 
GCAT
50.0
SSWN
66.7
Контекст

Неоднозначные коды дают частичный вклад: S считается как G или C целиком, R, Y, K и M — за половину, а N вообще не учитывают. Поэтому числитель может быть дробным, знаменатель считают без N, а при пустом знаменателе ответ 0.0.

Основные определения

  • IUPAC — система кодов, которой обозначают неоднозначные позиции.
  • S и W — S значит C или G, W значит A или T.
  • Половина вклада — R, Y, K и M дают в числитель 0.5.
  • N — код IUPAC, который означает любой нуклеотид.
Подсказка
  1. Прочитайте последовательность: seq = input(); заведите gc = 0 и total = 0.
  2. В цикле for base in seq: пропускайте N: if base == "N": continue; иначе увеличивайте total.
  3. Буквы G, C, S дают в числитель 1, а R, Y, K, M — 0.5.
  4. Если total равна нулю, выведите 0.0, иначе round(100 * gc / total, 1); сверьтесь с примером: GCAT дает 50.0, а SSWN — 66.7.

Задача со звездочкой 4.5. Средняя длина прочтений

Условие задачи

Прочтением называют участок ДНК, который секвенатор прочитал за один раз и выдал строкой букв. Найдите среднюю длину прочтений, округленную функцией round() до одного знака. Если прочтений нет, выведите 0.0.

Входные данные

Прочтения по одному в строке, затем строка done.

Выходные данные

Одно число.

Пример

Ввод ACGT
AC
GGGTTT
done
→
Вывод 4.0

Длины прочтений 4, 2 и 6 дают в сумме 12; 12 / 3 = 4.0.

Контекст

Средняя длина — суммарная длина, деленная на число прочтений. Обе величины накапливают в цикле до строки done, а отдельным условием обрабатывают случай без прочтений: делить на ноль нельзя, ответ 0.0.

Основные определения

  • Прочтение — участок ДНК, который секвенатор прочитал за один раз.
  • Среднее — сумма значений, деленная на их число.
  • Функция len() — возвращает длину строки.
  • Строка-ограничитель — стоп-слово, после которого ввод заканчивается.
Подсказка
  1. Заведите count = 0 и total = 0.
  2. Читайте в бесконечном цикле: while True: — при read == "done" выходите через break.
  3. Для каждого прочтения увеличивайте count на единицу, а total — на len(read).
  4. Если прочтений не было, выведите 0.0, иначе round(total / count, 1); сверьтесь с примером: ACGT, AC и GGGTTT дают 4.0, а одна строка done — 0.0.

Задача со звездочкой 4.5. CpG: наблюдаемое и ожидаемое

Условие задачи

CpG называют пару соседних букв C и G именно в таком порядке: C, за ней G. Чтобы понять, часто ли встречаются такие пары, их число сравнивают с ожидаемым при случайном порядке букв: count_c · count_g / length, где count_c и count_g — числа букв C и G, length — длина последовательности. Выведите отношение наблюдаемого числа пар CG к ожидаемому, то есть cg · length / (count_c · count_g), округленное до двух знаков. Если букв C или G нет, выведите 0.0. Формула из статьи Gardiner-Garden, Frommer, 1987.

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

Одно число.

Пример

Разберем пример

Ввод CGCGAATT
→
Вывод 4.0

Пар CG две, букв C и G по две, длина 8: 2 · 8 / (2 · 2) = 4.0.

Примеры
ВводВывод
 
CGCGAATT
4.0
CCCC
0.0
Контекст

Пары CG ищут по соседним буквам: у каждой буквы C проверяют следующую позицию. Числа C и G накапливают тем же проходом, а ожидаемое число пар count_c * count_g / length получают уже после цикла; при нуле C или G ответ 0.0.

Основные определения

  • CpG — пара соседних букв C и G именно в таком порядке.
  • Наблюдаемое число — сколько пар CG реально встретилось в строке.
  • Ожидаемое число — сколько пар CG было бы при случайном порядке букв: count_c * count_g / length.
  • Соседние буквы — буква и символ в следующей позиции.
Подсказка
  1. Прочитайте последовательность: seq = input(); заведите count_c = 0, count_g = 0 и cg = 0.
  2. В цикле по индексам при seq[index] == "C" увеличьте count_c; проверьте соседа: index + 1 < len(seq) и seq[index + 1] == "G" — тогда увеличьте cg.
  3. Букву G считайте веткой elif.
  4. Если count_c == 0 or count_g == 0, выведите 0.0, иначе округлите cg * len(seq) / (count_c * count_g) до двух знаков: round(..., 2); сверьтесь с примером: CGCGAATT дает 4.0, а CCCC — 0.0.

Задача со звездочкой 4.5. Сбалансированные окна

Условие задачи

Окном называют участок из window_size подряд идущих букв. Окна идут с каждой позиции и перекрываются: у строки длины length их length − window_size + 1. Окно сбалансировано, если в нем поровну букв G и C. Сколько сбалансированных окон? Попробуйте обойтись одним проходом по строке: при сдвиге окна на одну букву меняются только буква, которая вошла, и буква, которая вышла.

Входные данные

В первой строке последовательность из букв A, C, G, T длиной от 1 до 1000, во второй число window_size от 1 до длины последовательности.

Выходные данные

Одно число.

Пример

Разберем пример

Ввод GCAGG
2
→
Вывод 1

Окна: GC, CA, AG, GG; поровну G и C только в первом, поэтому ответ 1.

Примеры
ВводВывод
 
GCAGG
2
1
ATAT
2
3
Контекст

Разность diff считает перевес G над C в текущем окне: G прибавляет единицу, C отнимает. При сдвиге окна на шаг в окно входит одна буква и выходит одна, поэтому diff правят двумя действиями, а окно сбалансировано, когда diff равен нулю.

Основные определения

  • Окно — участок из window_size подряд идущих букв.
  • Перекрывающиеся окна — соседние окна сдвинуты на одну букву и делят общие буквы.
  • Разность diff — число G минус число C в текущем окне.
  • Баланс — поровну букв G и C; diff равен нулю.
Подсказка
  1. Прочитайте последовательность и ширину окна: seq = input(), window_size = int(input()); заведите diff = 0 и count = 0.
  2. В цикле по индексам добавляйте вошедшую букву: G увеличивает diff, C уменьшает.
  3. Когда index >= window_size, уберите вышедшую букву seq[index - window_size] обратными действиями.
  4. Когда окно уже полное (index >= window_size - 1) и diff == 0, увеличьте count; сверьтесь с примером: GCAGG при window_size = 2 дает 1, а ATAT — 3.
