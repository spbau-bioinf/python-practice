Счетчики

25 минутЕрофеев А. И.

Собирать результат в цикле: считать буквы счетчиками, складывать значения накопителем и вычислять GC-состав.

1. Шаблон накопления

Теория

Метод count() считает одну букву, а пропустить N или сложить массы нуклеотидов он не умеет. Для этого пишут свой цикл. Он работает так же, как подсчет на бумаге: ноль в начале, плюс одна черточка на каждую нужную букву, ответ в конце.

Результат в цикле собирают по шаблону из трех шагов. До цикла переменную инициализируют: count = 0. В теле ее обновляют: count = count + 1. После цикла читают готовый ответ.

Счетчик — переменная, которая считает события: на каждом событии к ней прибавляется 1.

Накопитель — переменная, к которой прибавляют сами значения, например массы.

Без инициализации строка count = count + 1 дает NameError: на первой итерации прибавлять не к чему.

Подробнее: встроенные функции вместо цикла

Для простых случаев Python уже содержит готовые счетчики и накопители: seq.count("G"), функции sum(), max(), min(). Они работают быстрее ручного цикла, потому что написаны на C. Ручной цикл оправдан, когда правило подсчета сложнее или когда за один проход нужно собрать несколько результатов, например сразу четыре счетчика.

Пример

Счетчик гуанинов

count_g.py
seq = "GGACTGA"
g = 0
for base in seq:
    if base == "G":
        g = g + 1
print(g)  # → 3
Вывод
3
  1. Строка 2: инициализация до цикла.
  2. Строки 4–5: обновление в теле, только для букв G.
  3. Строка 6: после цикла в g готовый ответ.

Четыре счетчика за один проход

Задача DNA из Rosalind: вывести числа букв A, C, G, T через пробел. Предскажите вывод.

rosalind_dna.py
seq = "AGCTTTTCATTC"
a = c = g = t = 0
for base in seq:
    if base == "A":
        a = a + 1
    elif base == "C":
        c = c + 1
    elif base == "G":
        g = g + 1
    elif base == "T":
        t = t + 1
print(a, c, g, t)  # → 2 3 1 6
Вывод
2 3 1 6
  1. Строка 2: четыре счетчика получают 0 одной строкой.
  2. Строки 4–11: на каждой итерации увеличивается ровно один счетчик, тот, чья буква.
  3. Строка 12: то же дают четыре вызова count(), но они четыре раза проходят строку, а цикл один.

Типичная ошибка: счетчик в теле цикла

Неверно: ответ 0
seq = "GGCAT"
for base in seq:
    gc = 0
    if base in "GC":
        gc = gc + 1
print(gc)  # → 0
Вывод
0
Верно
seq = "GGCAT"
gc = 0
for base in seq:
    if base in "GC":
        gc = gc + 1
print(gc)  # → 3
Вывод
3

Строка gc = 0 в теле обнуляет счетчик на каждой итерации. Тело выполняется целиком на каждой итерации, поэтому инициализация должна стоять до цикла. Неверная программа печатает 0, потому что последняя буква T.

Практика

Сейчас программа считает итерации. Сделайте из счетчика накопитель: пусть она складывает сами числа и напечатает 15.

try_total.py
total = 0
for i in range(1, 6):
    total = total + 1
print(total)  # → 5
Вывод
5

Упражнение 4.5.1. Транзиции, трансверсии и N

Что нужно сделать

Две последовательности одной длины выровнены: буква с индексом i первой строки стоит под буквой с тем же индексом второй. Замена пурина на пурин (A и G) или пиримидина на пиримидин (C и T) называется транзицией, остальные замены трансверсиями. В практике 3 (упражнение 3.2.2 «Транзиция») так проверяли одну пару букв. Буквой N отмечена позиция, которую не удалось прочитать: если N стоит хотя бы в одной из строк, позиция пропускается. 2. GC-состав

Теория

GC-состав последовательности — процент букв G и C среди ее нуклеотидов. Для него нужны два счетчика: сколько G и C и сколько нуклеотидов всего. После цикла один делят на другой и умножают на 100.

Буква N означает неизвестный нуклеотид, и в GC-состав ее не включают: такие буквы пропускают командой continue до того, как обновить счетчики.

Если в последовательности одни N, знаменатель равен 0, и деление дает ZeroDivisionError. В программе, которая обрабатывает реальные данные, этот случай проверяют до деления.

Пример

GC-состав без N

gc_content.py
seq = "GGCNNATGC"
gc = 0
known = 0
for base in seq:
    if base == "N":
        continue
    known = known + 1
    if base in "GC":
        gc = gc + 1
pct = gc / known * 100
print(round(pct, 1))  # → 71.4
Вывод
71.4
  1. Строки 5–6: обе N пропущены и не попали ни в один счетчик.
  2. Строка 7: known считает все известные нуклеотиды, их 7.
  3. Строки 10–11: 5 из 7 составляют 71,43 %; для показа число округляется до одного знака.
Практика

Добавьте в последовательность две буквы A и посмотрите, как изменится ответ. Затем запустите программу для строки "NNN" и прочитайте сообщение об ошибке.

Упражнение 4.5.2. GC-состав с кодами IUPAC

Что нужно сделать

GC-состав, доля букв G и C в процентах, разобран в разделе выше. Коды IUPAC (страница 09 практики 3) обозначают позицию, где возможен один из нескольких нуклеотидов. S значит C или G, поэтому считается как целая буква G или C. W значит A или T и в GC-состав не идет. R (A или G), Y (C или T), K (G или T) и M (A или C) считаются за половину: только один из двух вариантов G или C. N значит любой нуклеотид, такая позиция не учитывается ни в числителе, ни в знаменателе. Выведите GC-состав в процентах, округленный функцией round() до одного знака. Если учитывать нечего, выведите 0.0.

Одна строка из букв A, C, G, T, R, Y, K, M, S, W, N длиной от 1 до 100.

Задача со звездочкой 4.5. CpG: наблюдаемое и ожидаемое

Что нужно сделать

CpG называют пару соседних букв C и G именно в таком порядке: C, за ней G. Чтобы понять, часто ли встречаются такие пары, их число сравнивают с ожидаемым при случайном порядке букв: C · G / L, где C и G числа этих букв, L длина последовательности. Выведите отношение наблюдаемого числа пар CG к ожидаемому, то есть CG · L / (C · G), округленное до двух знаков. Если букв C или G нет, выведите 0.0. Формула из статьи Gardiner-Garden, Frommer, 1987.

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

Одно число.
