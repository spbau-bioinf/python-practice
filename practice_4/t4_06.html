1. Экстремум за один проход

Теория

Самое длинное прочтение или последовательность с наибольшим GC-составом: поиск наибольшего значения встречается в биологических данных постоянно. Наибольшее и наименьшее значения называют экстремумами. Устроен поиск по тому же шаблону накопления: инициализация до цикла, обновление в теле, ответ после цикла.

Для поиска наибольшего значения заводят переменную mx. В теле цикла каждое новое значение сравнивают с ней и, если оно больше, записывают в mx. После цикла в mx наибольшее из всех.

Поиск максимума начинают с None, а в теле пишут условие mx is None or x > mx: первое значение сразу становится лучшим, дальше его вытесняет только большее.

Начинать с нуля опасно: если все значения отрицательные, ни одно не окажется больше 0, и ответ будет неверным. Поиск минимума устроен так же, со знаком <.

  1. Условие mx is None or x > mx вычисляется слева направо. Пока mx равно None, первая часть истинна, и Python не вычисляет вторую; поэтому сравнения x > None, которое дало бы TypeError, не происходит.
  2. Вместо None можно начать с первого элемента, если он точно есть: прочитать его до цикла и сравнивать с ним остальные.
  3. Строгое > оставляет первое из равных значений, нестрогое >= последнее. Если вместе со значением запоминают, где оно встретилось, от выбора знака зависит ответ.

Почему такой цикл всегда дает верный ответ, разобрано на странице 07 «Инвариант цикла».

Пример

Самое длинное прочтение

Программа ждет ввода. Пользователь набирает ACGT, GATTACAGA, TT, затем done.

longest.py
mx = None
while True:
    read = input()
    if read == "done":
        break
    if mx is None or len(read) > mx:
        mx = len(read)
print(mx)  # → 9
Вывод
ACGT
GATTACAGA
TT
done
9
  1. Строка 1: до первого прочтения лучшего значения нет.
  2. Строки 6–7: первое прочтение сразу становится лучшим (4), второе вытесняет его (9), третье короче и ничего не меняет.
  3. Строка 8: после цикла в mx наибольшая длина.

Начальное значение 0

Предскажите вывод: какие числа дает range(-5, -1) и больше ли они нуля?

largest_zero.py
largest = 0
for x in range(-5, -1):
    if x > largest:
        largest = x
print(largest)  # → 0
Вывод
0
  1. Строка 2: числа от −5 до −2, ни одно не больше 0.
  2. Строка 5: начальное значение сохранилось, хотя 0 среди чисел нет. Правильный ответ −2 дает начало с None.

Значение и место

Часто нужно знать не только наибольшее значение, но и где оно встретилось. Для этого вторую переменную обновляют в той же ветви.

min_quality.py
quality = "IIH5II9"
mn = None
for i in range(len(quality)):
    if mn is None or quality[i] < mn:
        mn = quality[i]
        where = i + 1
print(mn, where)  # → 5 4
Вывод
5 4
  1. Строка 1: в формате FASTQ качество каждой буквы прочтения записано одним символом, как в упражнении 2.8.1 «Качество прочтения» практики 2: оценка качества по шкале Phred равна номеру символа минус 33. Чем раньше символ в таблице кодов, тем меньше оценка и тем ниже качество. Цифры стоят в таблице раньше заглавных букв.
  2. Строки 4–6: строки сравниваются по кодам символов. Значение и позиция обновляются вместе, в одной ветви.
  3. Строка 7: самый плохой символ 5 стоит на позиции 4.

2. Обход split() и функции max(), min(), sum()

Необходимый минимум

Подробно эта тема разбирается в теме 5 «Списки и кортежи».

Теория

Метод split() из темы 2 делит строку на части по пробелам. Цикл for обходит эти части по одной, так же как буквы строки: for w in line.split():. Сам результат split() называется списком; что это за тип, разбирается в теме 5.

Для простых случаев в Python есть готовые функции: sum() складывает числа ряда, max() и min() находят наибольший и наименьший элемент. Строки они сравнивают по кодам символов, поэтому min("GATC") дает A. В упражнениях этой практики они не нужны: там поиск пишется циклом.

Части, которые дает split(), остаются строками, даже если выглядят как числа. Строки сравниваются по символам слева направо, поэтому из "10" и "9" больше "9": первый символ 9 больше 1. Прежде чем искать наибольшее число, части переводят в числа функцией int().

Пример

Наибольший GC-состав

max_gc.py
fa = ">1 GGAT >2 GCGA >3 ATCA"
mx = None
for w in fa.split():
    if w.startswith(">"):
        continue
    gc = w.count("G") + w.count("C")
    pct = gc / len(w) * 100
    if mx is None or pct > mx:
        mx = pct
        mx_seq = w
print(mx_seq, mx)  # → GCGA 75.0
Вывод
GCGA 75.0
  1. Строка 3: split() делит строку по пробелам, w получает части по одной.
  2. Строки 4–5: заголовки записей пропускаются.
  3. Строки 8–10: шаблон поиска максимума из раздела 1; вместе со значением запоминается последовательность.
Практика

Посчитайте функцией sum() сумму чисел от 1 до 100.

Вывод
