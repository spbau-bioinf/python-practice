Цикл for

15 минутЕрофеев А. И.

Обходить строку циклом for и выполнять действие для каждой ее буквы.

Как устроены упражнения. Программа читает данные функцией input() без текста приглашения и печатает только ответ. Все упражнения этой практики решаются циклом; если цикла в решении нет, проверка об этом напомнит.

1. Обход строки

Теория

Проверка base in "ACGT" из темы 3 работает для одной буквы. В FASTA-файле последовательность может состоять из тысяч букв, и ее длина заранее неизвестна. Писать проверку для каждой буквы отдельно нельзя: нужна конструкция, которая сама повторит действие столько раз, сколько в строке букв.

Цикл for берет элементы последовательности по одному, по порядку. Строка тоже последовательность, поэтому for base in seq: дает букву за буквой: сначала base равна первой букве, затем второй и так до последней.

Цикл for выполняет тело цикла для каждого элемента последовательности; перед каждым выполнением переменная цикла получает очередной элемент.

Переменная в заголовке (base) называется переменной цикла, одно выполнение тела называют итерацией. Заголовок кончается двоеточием, тело выделяется отступом в четыре пробела, как у if.

for base in seq:
    …

Итерация — одно выполнение тела цикла.

Имя переменной цикла выбираете вы. Для букв последовательности удобно base, для чисел i или n. Переменная цикла обычная переменная: в теле ее можно читать, сравнивать, передавать в print(). Сколько итераций сделает цикл, решает длина строки: для строки из 7 букв тело выполнится 7 раз, для пустой строки ни разу.

Подробнее: переменная цикла после цикла

После того как цикл закончился, переменная цикла не исчезает и хранит последний элемент. Если строка пустая, итераций нет, и переменная не получает значения: обращение к ней после цикла дает NameError, если раньше она не была создана. Поэтому опираться на переменную цикла после цикла не стоит; к этому вопросу вернемся на странице 04.

Пример

Обход строки

walk.py
seq = "GATTACA"
for base in seq:
    print(base, end=" ")
print()
print("обход завершен")  # → обход завершен
Вывод
G A T T A C A 
обход завершен
  1. Строка 2: заголовок цикла; base по очереди получает буквы строки seq.
  2. Строка 3: тело цикла выполнилось 7 раз, по разу на букву. Аргумент end=" " ставит после буквы пробел вместо перевода строки, поэтому буквы идут в одну строку.
  3. Строка 4: стоит без отступа, поэтому выполняется один раз, после цикла; print() без аргументов завершает строку вывода.
  4. Строка 5: тоже после цикла, печатается один раз.

Пурин или пиримидин

В кодах IUPAC буква R означает любой пурин (A или G), буква Y любой пиримидин (C или T). Программа заменяет каждую букву ее классом.

purines.py
seq = "GATCCA"
for base in seq:
    if base in "AG":
        cls = "R"
    else:
        cls = "Y"
    print(cls, end="")
print()
Вывод
RRYYYR
  1. Строки 3–6: в теле цикла стоит ветвление; его строки сдвинуты еще на четыре пробела, потому что относятся к if и else. В переменную cls попадает класс текущей буквы.
  2. Строка 7: снова отступ в четыре пробела, это тело цикла, но уже не ветвление: печать выполняется на каждой итерации. end="" ничего не ставит после буквы, поэтому буквы идут подряд.
  3. Строка 8: завершает строку вывода после цикла.

Замените end=" " на end="-", затем подставьте свою последовательность и запустите снова.

2. Тело цикла и отступ

Теория

Границу тела цикла Python находит только по отступу. Строки с отступом после заголовка повторяются на каждой итерации. Первая строка без отступа уже не входит в цикл и выполняется один раз, когда цикл закончится.

Все строки тела цикла пишутся с одинаковым отступом; строку, которая должна выполниться один раз после цикла, пишут без отступа.

Если лишняя строка попала в тело, синтаксис остается верным и Python ошибки не покажет: программа просто сделает не то. Это ошибка в логике, а не в синтаксисе, и найти ее можно только по выводу.

Если же у тела нет отступа вовсе, Python не запустит программу и сообщит IndentationError: после заголовка с двоеточием он ждет хотя бы одну строку с отступом.

Пример

Типичная ошибка: лишняя строка в теле цикла

Неверно: «готово» печатается трижды
for base in "GAT":
    print(base)
    print("готово")
Вывод
G
готово
A
готово
T
готово
Верно
for base in "GAT":
    print(base)
print("готово")  # → готово
Вывод
G
A
T
готово

Строка 3 с отступом стоит в теле цикла и выполняется после каждой буквы. Без отступа она выполняется один раз, после цикла.

Типичная ошибка: тело без отступа

Неверно: IndentationError
for base in "GAT":
print(base)
Сообщение об ошибке
IndentationError: expected an indented block after 'for' statement on line 1
Верно
for base in "GAT":
    print(base)
Вывод
G
A
T

Сообщение называет строку заголовка, после которой Python ждал тело. Редакторы VS Code и PyCharm ставят отступ сами после двоеточия, если нажать Enter.

Что останется после цикла

Предскажите вывод, затем откройте его.

after_loop.py
seq = "TAG"
for base in seq:
    print(base + base, end=" ")
print(base)  # → G
Вывод
TT AA GG G
  1. Строка 3: на каждой итерации печатается удвоенная буква и пробел.
  2. Строка 4: выполняется один раз, после цикла; к этому моменту base хранит последнюю букву строки.

Упражнение 4.1.1. Транскрипция

Что нужно сделать

Транскрипция — построение молекулы РНК по участку ДНК. В РНК вместо тимина T стоит урацил U, остальные буквы те же. По последовательности ДНК выведите соответствующую последовательность РНК. В практике 2 (упражнение 2.5.1 «Транскрипция») это делали методом replace(), здесь каждую букву обрабатывает цикл. Обойдите строку циклом for и печатайте буквы по одной: print(..., end="").

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

Последовательность РНК одной строкой.

Упражнение 4.1.1. Сжатие повторов

Что нужно сделать

Гомополимер — участок, где одна буква повторяется несколько раз подряд, например GGG. Секвенаторы, приборы для чтения ДНК, часто ошибаются в длине таких участков, поэтому последовательность иногда записывают сжато: каждую серию подряд идущих одинаковых букв заменяют буквой и длиной серии. Например, GGGCCA записывается как G3C2A1: серия из трех G, двух C и одной A. Выведите сжатую запись последовательности.

Подсказка

Храните букву текущей серии и ее длину. Серия заканчивается, когда пришла другая буква; последняя серия заканчивается вместе со строкой.

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

Сжатая запись одной строкой.

Примеры
Входные данныеВыходные данные

G3C2A1

Задача со звездочкой 4.1. Комплементарная цепь с кодами IUPAC

Что нужно сделать

Коды IUPAC (страница 09 практики 3) обозначают позиции, где возможен один из нескольких нуклеотидов. R значит A или G, Y значит C или T, K значит G или T, M значит A или C, S значит C или G, W значит A или T, N значит любой. У кода тоже есть комплементарный: комплементарны все варианты. R комплементарен Y, K комплементарен M, а S, W и N комплементарны сами себе. Постройте обратную комплементарную цепь: прочитайте последовательность от конца к началу и замените каждую букву комплементарной.

Выходные данные

Обратная комплементарная цепь одной строкой.
