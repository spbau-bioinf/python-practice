Инвариант цикла

20 минутЕрофеев А. И.

Формулировать инвариант цикла, проверять его тремя проверками и по нему писать циклы, которые дают верный ответ для любой строки.

1. Утверждение, верное на каждой итерации

Теория

Запуском счетчик GC можно проверить лишь на нескольких строках, а строк бесконечно много. Пример проверяет один случай; чтобы обосновать ответ для любой строки, нужно рассуждение о самом цикле.

Инвариант цикла — утверждение о переменных цикла, которое верно в начале каждой итерации.

Для счетчика GC инвариант такой: перед обработкой seq[i] в gc лежит число букв G и C в срезе seq[:i], то есть среди уже просмотренных букв.

Инвариант проверяют тремя проверками (Кормен и др., «Алгоритмы: построение и анализ»):

  1. Инициализация: инвариант верен перед первой итерацией.
  2. Сохранение: итерация, начатая при верном инварианте, его не нарушает.
  3. Завершение: при выходе из цикла инвариант дает нужный ответ.

Первые две проверки устроены как математическая индукция: база и шаг. Отличие в том, что индукция идет бесконечно, а рассуждение об инварианте останавливается вместе с циклом, и третья проверка говорит, что получилось в конце.

Для счетчика GC проверки выглядят так. Перед первой итерацией i = 0, срез seq[:0] пустой, в нем 0 букв G и C, и gc = 0: инвариант верен. Итерация с индексом i прибавляет 1, только если seq[i] есть G или C; после нее gc равно числу G и C в seq[:i + 1], то есть инвариант верен перед следующей итерацией. После последней итерации, при i = len(seq) - 1, просмотрены все буквы: срез seq[:len(seq)] это вся строка, и gc равно ответу.

Инвариант помогает найти ошибку в начальном значении. Если начать с gc = 1, ломается первая проверка; если обнулять счетчик в теле, ломается вторая.

Пример

Трассировка счетчика GC

gc_invariant.py
seq = "GACG"
gc = 0
for i in range(len(seq)):
    if seq[i] in "GC":
        gc = gc + 1
print(gc)  # → 3

Инвариант на экране

Программа печатает i и gc в начале каждой итерации и после цикла. Предскажите вывод.

gc_print.py
seq = "CATG"
gc = 0
for i in range(len(seq)):
    print(i, gc)
    if seq[i] in "GC":
        gc = gc + 1
print(len(seq), gc)  # → 4 2
Вывод
0 0
1 1
2 1
3 1
4 2
  1. Строка 4: в каждой строке вывода gc равно числу G и C среди первых i букв.
  2. Строка 7: последняя строка вывода та же пара для i, равного длине строки, то есть ответ.

Инвариант поиска максимума

mx = None
for x in nums:
    if mx is None or x > mx:
        mx = x

Инвариант: перед каждой итерацией mx равно наибольшему из уже просмотренных чисел. До первой итерации чисел нет, и mx равно None: так и отмечено, что максимума пока нет. Итерация сравнивает новое число с наибольшим из прежних и оставляет большее. После цикла просмотрены все числа, и инвариант превращается в ответ: mx равно наибольшему числу во всей последовательности. Утверждение «x > mx» инвариантом не является: оно верно не на каждой итерации.

Практика

Начните счетчик с 1 и запустите. Какая из трех проверок нарушилась и в какой строке вывода это видно?

2. Цикл по инварианту

Теория

По инварианту цикл можно не только проверить, но и написать. Если сначала сформулировать, что должно быть верно перед каждой итерацией, код цикла почти следует из этого утверждения: инициализация делает его верным до цикла, тело сохраняет, а ответ читается после цикла.

Пример: длина серии одинаковых букв в конце последовательности. Инвариант: перед обработкой индекса i переменная cur равна длине серии одинаковых букв, которой кончается seq[:i]. Цикл начинается с i = 1: в срезе из одной буквы серия длины 1. Если seq[i] совпадает с предыдущей буквой, серия продолжается; иначе начинается новая серия длины 1.

Пример

Серия в конце строки

last_run.py
seq = "GGTAAA"
cur = 1
for i in range(1, len(seq)):
    if seq[i] == seq[i - 1]:
        cur = cur + 1
    else:
        cur = 1
print(cur)  # → 3
Вывод
3
  1. Строка 2: инициализация. Перед i = 1 просмотрена одна буква, серия длины 1.
  2. Строки 4–7: сохранение. Серия либо продолжается, либо начинается заново.
  3. Строка 8: завершение. Просмотрена вся строка, cur равно длине серии AAA в ее конце.
МоментПросмотреноcurСерия в конце
перед i = 1"G"1G
перед i = 2"GG"2GG
перед i = 3"GGT"1T
перед i = 4"GGTA"1A
перед i = 5"GGTAA"2AA
после цикла"GGTAAA"3AAA

Самая длинная серия не обязательно стоит в конце. Инвариант говорит только о серии, которой кончается просмотренная часть. Чтобы найти самую длинную серию во всей строке, к инварианту нужно добавить вторую переменную, как в поиске максимума на странице 06.

Подробнее: инвариант и while

Для цикла while к трем проверкам добавляется четвертая: цикл заканчивается. Ее обосновывают величиной, которая на каждой итерации уменьшается и не может уменьшаться бесконечно, например len(seq) − i. В обходе строки через while на странице 03 она уменьшается на 1 за итерацию и доходит до 0.

Теория

Расстояние Хэмминга — число позиций, в которых две строки одинаковой длины различаются.

Оно показывает, насколько похожи две последовательности. Если два прочтения взяты с одного участка ДНК, они различаются в стольких позициях, сколько букв изменили ошибки секвенатора или мутации. В задаче Counting Point Mutations на Rosalind так считают точечные мутации, замены одной буквы на другую. Если сравнивать два вектора одной размерности, это число несовпавших координат.

Как найти: строки записывают одну под другой, идут по позициям слева направо и отмечают позиции, где буквы разные. Ответ равен числу отметок.

Позиция12345678
Строка 1ACGTTGCA
Строка 2AGGTCGTA
Различие≠≠≠

Отметки стоят в позициях 2, 5 и 7, расстояние Хэмминга равно 3. Так же посчитайте первый пример из таблицы упражнения: должно получиться 7.

Величина названа по фамилии математика Ричарда Хэмминга: в 1950 году он использовал ее в теории кодов, которые находят и исправляют ошибки при передаче данных. В упражнении «Вхождения с одной заменой» на странице 08 ищут участки, расстояние Хэмминга от которых до мотива не больше 1.

Упражнение 4.7.1. Минимум накопленного перекоса

Что нужно сделать

Накопленный перекос префикса длины i равен числу G минус число C среди первых i букв; у пустого префикса (i = 0) он равен 0. В отличие от GC-перекоса со страницы 05, разность здесь не делится на G + C. Перед делением клетки ДНК удваивается; этот процесс называется репликацией. У бактерий репликация начинается в одной точке кольцевой ДНК. Если идти по последовательности, до этой точки буква C обычно встречается чаще G и накопленный перекос убывает, а после нее G встречается чаще и перекос растет. Поэтому минимум накопленного перекоса подсказывает, где искать точку начала репликации, но не доказывает, что она там. Найдите наименьшую длину i (от 0 до длины строки), при которой накопленный перекос минимален.

Подсказка

Сформулируйте инвариант для двух переменных: перед обработкой индекса i одна равна перекосу префикса длины i, другая наименьшему перекосу среди префиксов длины от 0 до i. Проверьте, что он верен до первой итерации.

Входные данные

Одна строка из букв A, C, G, T длиной от 1 до 100.

Выходные данные

Наименьшая длина префикса с минимальным перекосом.
